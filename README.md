**BYOX — русский каталог Build Your Own X** — это подборка из **359 пошаговых
руководств** на русском языке для воссоздания ваших любимых технологий с нуля:
компиляторы, операционные системы, игровые движки, базы данных, нейросети,
рендереры и многое другое.

Для каждого руководства создана отдельная посадочная страница с кратким
содержанием на русском, целями обучения, основной идеей с фрагментами кода,
ссылками на первоисточник и перекрёстными ссылками на английскую и персидскую
версии (когда они доступны).

## Возможности

- **359 посадочных страниц руководств** по 30 категориям — от 3D-рендереров
  и BitTorrent-клиентов до языков программирования, нейросетей и ОС.
- **Быстрый статический сайт без зависимостей** — обычный HTML + CSS +
  нативный JavaScript, без фреймворков и шага сборки (единственное внешнее
  подключение — Google Fonts).
- **Поиск по мере ввода** и **фильтрация по категориям** на главной странице.
- **Отслеживание прогресса**: счётчики переведённых страниц и прогресс-бары
  по каждой категории.
- **Перекрёстная навигация**: каждая страница ссылается на английскую и
  персидскую версии, когда они доступны.
- **Автотест качества**: скрипт аудита проверяет все 359 страниц на
  соответствие индексу — гарантированно чистый результат `359/359`.
- **Самодостаточное развёртывание**: GitHub Actions публикует сайт на
  GitHub Pages при каждом push в `main`.

## Анатомия страницы руководства

Каждая страница в `tutorials-ru/{id}.html` содержит:

- Бейджи языка (⚙ Язык) и категории (📁);
- Бейджи «Русская страница» и «Оригинальный источник»;
- Ссылки на первоисточник и на английскую/персидскую версии;
- Четыре обязательных раздела: **«О чём это»**, **«Что вы узнаете»**,
  **«Основная идея»** (с фрагментами кода) и **«Почему это важно»**;
- Примечание об авторских правах: руководство принадлежит автору
  оригинала, страница — лишь перевод и обзор.


## Как создавался каталог

1. **Индекс.** Метаданные всех руководств собраны в
   `assets/js/tutorials-ru.js` — 359 записей: id, категория, язык, ссылка на
   оригинал, видео-флаг.
2. **Перевод.** Каждый урок переводится на русский и оформляется по единому
   шаблону: четыре смысловых раздела, основные идеи с кодом, часть «Почему
   это важно» и примечание об авторских правах.
3. **Генерация.** Посадочные страницы собираются Python-генератором из
   `templates/page_template_ru.html`; готовый HTML коммитится в репозиторий,
   чтобы сайт оставался чистым статическим.
4. **Аудит.** Скрипт проверяет каждую страницу: соответствие заголовков,
   бейджей и разделов индексу, целостность блоков кода, отсутствие
   сырых `&` в тексте и битых внутренних ссылок. Результат —
   гарантированно `359/359`.
5. **Публикация.** Push в `main` автоматически разворачивает сайт на
   GitHub Pages.

## Развёртывание

Репозиторий разворачивается автоматически при каждом push в `main` с
помощью GitHub Actions. Конвейер использует официальные экшены:

```yaml
name: Deploy BYOX Russian to GitHub Pages

on:
  push:
    branches: ["main"]
  workflow_dispatch:

permissions:
  contents: read
  pages: write
  id-token: write

jobs:
  deploy:
    environment:
      name: github-pages
      url: ${{ steps.deployment.outputs.page_url }}
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/configure-pages@v5
      - uses: actions/upload-pages-artifact@v3
        with: { path: . }
      - uses: actions/deploy-pages@v4
```

## Как помочь проекту

- **Нашли ошибку в переводе?** Откройте issue или pull request с
  исправлением соответствующей страницы из `tutorials-ru/`.
- **Хотите добавить руководство?** Убедитесь, что его нет в
  [исходном списке](https://github.com/codecrafters-io/build-your-own-x),
  добавьте запись в `assets/js/tutorials-ru.js`, создайте посадочную страницу
  по шаблону и прогоните аудит — результат должен остаться `359/359` (или
  больше, но без замечаний).
- **Предложения по сайту** (поиск, фильтры, статистика) — всегда
  приветствуются.

## FAQ

**Почему страницы закоммичены, а не собираются на лету?**
Так сайт остаётся мгновенно работающим статическим хостингом: GitHub Pages
отдаёт готовый HTML без шага сборки, а ломающийся генератор не может
«положить» продакшн.

**Что проверяет аудит?**
Соответствие заголовков, бейджей и разделов индексу, баланс блоков кода,
чистоту ссылок (нет сырых `&` и битых внутренних ссылок) — и только после
полной проверки страница считается готовой.

**Являются ли переводы оригинальным контентом?**
Нет. Каждая страница — перевод и обзор авторского руководства со ссылкой
на первоисточник и примечанием об авторских правах.

**Планируется ли добавить ещё языки?**
Сайт уже существует в трёх версиях — персидской, английской и русской;
структура репозитория спроектирована так, что добавление нового языка —
это отдельный каталог с той же схемой.

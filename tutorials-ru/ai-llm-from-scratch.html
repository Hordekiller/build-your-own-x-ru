О проекте

Этот репозиторий содержит код разработки, предобучения (pretraining) и тонкой настройки (finetuning) большой языковой модели, похожей на GPT, и является официальным кодом книги Build a Large Language Model (From Scratch) Себастьяна Рашки.

В этой книге вы узнаете, как большие языковые модели (LLM) работают изнутри — написав их с нуля, шаг за шагом. Автор ведёт вас по пути создания собственной LLM, объясняя каждый шаг ясным текстом, диаграммами и примерами.

Методика обучения и разработки небольшой, но рабочей модели в учебных целях — тот же подход, что используется при создании больших базовых моделей, например моделей, лежащих в основе ChatGPT. Кроме того, в книге есть код загрузки весов более крупных предобученных моделей для тонкой настройки.

Предпосылки

  • Самый важный предмет — прочный фундамент программирования на Python
  • Знакомство с глубокими нейронными сетями поможет, так как LLM строятся на этих архитектурах
  • Книга реализует весь код с нуля — без внешних LLM-библиотек, только с PyTorch; знание основ PyTorch полезно (краткое введение есть в приложении A)

Требования к оборудованию

Код основных глав рассчитан на выполнение на обычных ноутбуках за разумное время и не требует специального оборудования; при наличии GPU код автоматически использует его.

RAG с нуля: генерация с дополнением поиском

О проекте

Большие языковые модели (LLM) обучены на большом, но статичном массиве данных, что ограничивает их способность рассуждать о частной или недавней информации. Тонкая настройка (fine-tuning) — один из способов смягчить это ограничение, но она часто не подходит для извлечения фактов и может быть дорогостоящей.

Генерация с дополнением поиском (Retrieval Augmented Generation — RAG) стала популярным и мощным механизмом расширения базы знаний LLM: используя документы, извлечённые из внешнего источника данных, генерация LLM обосновывается (grounding) через обучение в контексте (in-context learning).

Эти блокноты сопровождают видеоплейлист, который строит понимание RAG с нуля — начиная с основ индексации (indexing), поиска (retrieval) и генерации (generation).

Ключевые концепции

  • Индексация (Indexing): подготовка и организация документов для базы знаний
  • Поиск (Retrieval): нахождение документов, релевантных вопросу пользователя (поиск по векторному сходству)
  • Генерация (Generation): ответ модели с использованием извлечённых документов в качестве контекста (grounding)
  • Перевод запроса (Query Translation): такие техники, как multi-query, RAG-fusion и decomposition для улучшения поиска
  • Маршрутизация (Routing): выбор подходящего пути (поиск по нескольким разным источникам) на основе вопроса
  • Конструирование запроса (Query Construction): преобразование естественного запроса в поисковые структуры (например, SQL или структурированные данные)
  • Оценивание (Scoring): поиск с типизированным оцениванием (type-aware) и сравнение различных метрик поиска

Видео шаг за шагом реализуют эти концепции в коде, а блокноты репозитория хранят этот же код в запускаемом виде.

Python# Базовый цикл RAG: индексация → поиск → генерация
from langchain_text_splitters import RecursiveCharacterTextSplitter

# 1) Индексация: разбиваем документы на фрагменты и векторизуем их
chunks = RecursiveCharacterTextSplitter(chunk_size=500).split_documents(docs)
index = FAISS.from_documents(chunks, embeddings)

# 2) Поиск: ближайшие к запросу документы
hits = index.similarity_search("вопрос пользователя", k=4)

# 3) Генерация: передаём извлечённые документы модели как контекст
answer = llm.invoke(f"Ответь на основе этих документов:\n{hits}")

Эти три шага — ядро всех блокнотов репозитория; последующие видео углубляют каждый шаг (продвинутый поиск, маршрутизация, оценивание и т. д.).

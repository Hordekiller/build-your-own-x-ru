Об этом учебнике

Занимательный практический урок: разместите 3D-дракона на реальных поверхностях с помощью Unity и ARCore и посмотрите его анимацию и взаимодействие.

Подходит для закрепления базовых навыков ARCore на интересном проекте.

C#// Размещение дракона на распознанной поверхности (Unity + AR Foundation)
public void OnPlaneHit(ARRaycastHit hit) {
    dragon.transform.position = hit.pose.position;   // точка пересечения луча
    dragon.transform.rotation = hit.pose.rotation;
    dragon.SetActive(true);                          // активируем модель
}

Эти две строки позиционирования — основа сенсорного взаимодействия, которое в видео доводится до конца.

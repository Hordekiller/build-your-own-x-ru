Об этом учебнике

В этом пошаговом видеоуроке вы научитесь создавать AR-приложение с нуля на Unity 3D и Vuforia: от создания проекта и настройки лицензии Vuforia до отображения 3D-моделей на изображениях-маркерах (Image Target).

Видео рассчитано на новичков и не требует ничего, кроме установленного Unity.

C#// Показ 3D-модели, когда Image Target распознан (Vuforia)
public class TargetHandler : MonoBehaviour, ITrackableEventHandler {
  public GameObject model;   // 3D-модель, привязанная к маркеру

  void OnTrackableStateChanged(TrackableBehaviour.Status st) {
    model.SetActive(st == TrackableBehaviour.Status.TRACKED);
  }
}

В видео эта простая логика дополняется настройкой лицензии Vuforia и созданием Image Target.

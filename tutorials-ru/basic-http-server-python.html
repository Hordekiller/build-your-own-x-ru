Создание базового HTTP-сервера с нуля на Python

О чём это

Чёткое руководство по созданию простого HTTP-сервера на Python: вы откроете сокет, научитесь принимать запросы, разбирать их и возвращать корректные ответы, а затем добавите раздачу файлов и обработку простых ошибок.

Что вы узнаете

  • Создание сокета и прослушивание порта
  • Чтение и разбор HTTP-запроса
  • Отправка ответов с правильными статус-кодами и заголовками
  • Раздача статических файлов с веб-интерфейса

Основная идея

HTTP-сервер — это цикл: принять соединение, прочитать текст запроса, отправить текст ответа. На чистом Python это делается просто и наглядно.

Чтение одного запроса выглядит так:

Pythondef read_request(conn):
    data = b""
    while b"\r\n\r\n" not in data:
        data += conn.recv(4096)
    return data.decode()

Почему это важно

Когда сервер собран своими руками, протокол HTTP теряет всю загадочность — вы сможете читать и отлаживать любой сетевой обмен, от curl до браузера.

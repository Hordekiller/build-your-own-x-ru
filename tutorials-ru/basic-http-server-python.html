Создание базового HTTP-сервера с нуля на Python

Введение

По своей сути современный веб — это просто текст, перемещаемый между клиентами и серверами. Как разработчики, мы часто используем веб-фреймворки для построения строк, отправляемых клиентам. Веб-фреймворки отдаляют нас от лежащей в основе «текстовой реальности»: они разбирают входящие http-запросы (которые являются просто строкой), вызывают соответствующую функцию и строят строковый ответ (чаще всего с шаблонами). В конце концов, клиенты разбирают эти строки и делают с ними всё, что хотели.

Этот пост в блоге показывает, как построить с нуля совершенно простой HTTP-сервер, и основан на упражнении, которое автор давал своим студентам магистратуры. Единственное требование — базовое понимание Python 3. Если хотите реализовывать вместе с учебником, возьмите программу-стартёр по этой ссылке. Финальный исходник вы увидите в этом gist.

HTTP — это просто текст

HTTP — протокол, по которому браузеры получают информацию от серверов и отправляют её им. По своей сути HTTP — просто текст, следующий особому шаблону: в первой строке вы указываете, какой ресурс хотите, затем идут заголовки, а затем пустая строка, отделяющая заголовки от тела сообщения (если оно есть). Вот так можно получить страницу «about» веб-сайта:

HTTPGET /about.html HTTP/1.0
User-Agent: Mozilla/5.0

а так с методом POST отправляются данные формы на веб-сервер:

HTTPPOST /form.php HTTP/1.0
Content-Type: application/x-www-form-urlencoded
Content-Length: 21

name=John&surname=Doe

Чтобы доказать, что это просто текст, можно скопировать и вставить текст выше и использовать что-нибудь, позволяющее отправить текст по сети. Давайте с telnet получим страницу about у Google:

Отправка HTTP-ответов с помощью сокетов

Если вы собираетесь реализовывать сетевые программы с нуля, вам, вероятно, придётся поработать с сетевыми сокетами. Сокет — абстракция, предоставленная вашей операционной системой, позволяющая отправлять и получать байты по сети. Вот простая базовая реализация HTTP-сервера:

python"""
Реализация простого HTTP/1.0 сервера
"""

import socket

# Определение хоста и порта сокета
SERVER_HOST = '0.0.0.0'
SERVER_PORT = 8000

# Создание сокета
server_socket = socket.socket(socket.AF_INET, socket.SOCK_STREAM)
server_socket.setsockopt(socket.SOL_SOCKET, socket.SO_REUSEADDR, 1)
server_socket.bind((SERVER_HOST, SERVER_PORT))
server_socket.listen(1)
print('Listening on port %s ...' % SERVER_PORT)

while True:
        # Ждём соединения клиента
    client_connection, client_address = server_socket.accept()

    # Получаем запрос клиента
    request = client_connection.recv(1024).decode()
    print(request)

    # Отправляем HTTP-ответ
    response = 'HTTP/1.0 200 OK\n\nHello World'
    client_connection.sendall(response.encode())
    client_connection.close()

# Закрываем сокет
server_socket.close()

Мы начинаем с определения хоста и порта сокета. Затем создаём переменную server_socket и устанавливаем её на AF_INET (семейство адресов IPv4) и SOCK_STREAM (по сути TCP). Остальной код нужен, чтобы подготовить сокет к прослушиванию запросов на заданных (host, port). Документация Python о сокетах содержит больше информации.

Остальной код самоочевиден: ждём соединения клиента, читаем строку запроса, отправляем строку в HTTP-формате с Hello World в теле ответа и закрываем соединение клиента. Делаем так вечно (или пока кто-нибудь не нажмёт Ctrl+C). Откройте в браузере http://localhost:8000/ — и вы должны увидеть ответ сервера:

В качестве упражнения измените Hello World на <h1>Hello World</h1> и посмотрите, что произойдёт. А видите print(request) в коде сервера? Вот его вывод в консоли:

Да, браузер запрашивает корневую страницу («/») сервера.

index.html

По умолчанию, когда браузер запрашивает корень сервера (запросом вроде GET / HTTP/1.0), мы должны вернуть страницу index.html. Давайте изменим код внутри while, чтобы он всегда возвращал содержимое файла htdocs/index.html:

pythonwhile True:
    # Ждём соединения клиента
    (...)

    # Получаем запрос клиента
    (...)

    # Получаем содержимое htdocs/index.html
    fin = open('htdocs/index.html')
    content = fin.read()
    fin.close()

    # Отправляем HTTP-ответ
    response = 'HTTP/1.0 200 OK\n\n' + content
    client_connection.sendall(response.encode())
    (...)

По сути, мы читаем содержимое файла и вместо прежнего Hello World добавляем его в строку response как тело сообщения. Файл index.html — просто текстовый файл (внутри каталога htdocs) с html-содержимым:

html<html>
<head>
    <title>Hello World</title>
</head>
<body>
    <h1>Hello World!</h1>
    <p>Welcome to the index.html web page..</p>
    <p>Here's a link to <a href="ipsum.html">Ipsum</a></p>
</body>
</html>

Можете кликать по ссылке сколько угодно, но ваш сервер всегда возвращает содержимое index.html; так запрограммировано!

Возврат других страниц

До сих пор наш сервер возвращает страницу index.html, но нужно позволить ему возвращать и остальные страницы. Технически это значит разобрать первую строку HTTP-запроса (что-то вроде GET /ipsum.html HTTP/1.0), открыть запрошенный файл и вернуть его содержимое. Изменения:

pythonwhile True:
    # Ждём соединения клиента

    fin.close()

    client_connection.sendall(response.encode())

По сути, мы вытаскиваем имя файла из строки запроса, открываем файл (предполагаем, что все html-файлы находятся в папке htdocs) и возвращаем его содержимое. Также видно, что когда клиенты запрашивают корневой ресурс ('/'), мы корректно возвращаем файл index.html.

404 — не найдено

Ещё не всё! Вот что произойдёт, если запросить файл, которого нет, — например http://localhost:8000/hello.html:

ConsoleGET /hello.html HTTP/1.1

Traceback (most recent call last):
  File "httpserver.py", line 36, in <module>
    fin = open('htdocs' + filename)
FileNotFoundError: [Errno 2] No such file or directory: 'htdocs/hello.html'

Сервер падает и завершается!

Нужно перехватить исключение и отправить ответ 404:

pythonwhile True:
    # Ждём соединения клиента
    (...)

    # Получаем запрос клиента
    (...)

    # Разбираем HTTP-заголовки
    headers = request.split('\n')
    filename = headers[0].split()[1]

    # Получаем содержимое файла
    if filename == '/':
        filename = '/index.html'

    try:
        fin = open('htdocs' + filename)
        content = fin.read()
        fin.close()

        response = 'HTTP/1.0 200 OK\n\n' + content
    except FileNotFoundError:
        response = 'HTTP/1.0 404 NOT FOUND\n\nFile Not Found'

    # Отправляем HTTP-ответ
    client_connection.sendall(response.encode())
    client_connection.close()

Напиши свой BitTorrent-клиент на Node.js

О чём это

Руководство пишет BitTorrent-клиент на Node.js: bencode, трекер, пиры, загрузка и раздача, битовая карта кусков — пост в духе веб-воркшопов, который проходит весь протокол.

Что вы узнаете

  • Метаданные и bencode на Node.js
  • Запрос трекера и peer discovery
  • Рукопожатие и протокол обмена
  • Потоковая загрузка и фон на файле

Основная идея

Клиент — это конечный автомат: bencode-метаданные → трекер → пиры → обмен кусками. Node.js с его async-сетью удобен для каждого шага.

Получение списка пиров от трекера:

Node.jsconst peers = decodeTrackerResponse(body); // список пиров
for (const peer of peers) {
  const conn = net.createConnection(peer.port, peer.ip);
  conn.on("connect", () => handshake(conn));
}

Почему это важно

P2P-обмен — классика распределённых систем: пройдя протокол целиком, вы поймёте, как программы сотрудничают без центрального сервера.

Основная идея

Урок тренирует суть: блок — хеш — работа. Затем на это ложатся транзакции, защищённые подписями. Узловой взгляд на каждый компонент.

Проверка цепочки — цикл по блокам:

JavaScriptfunction isValidChain(chain) {
  for (let i = 1; i < chain.length; i++) {
    if (chain[i].previousHash !== hash(chain[i - 1])) return false;
  }
  return true;
}

Почему это важно

Уроки хешей и подписей пригодятся вне блокчейна — в любой системе, где важна целостность: вы получите и код, и ясную ментальную модель.

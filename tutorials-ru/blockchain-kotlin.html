О чём это

Серия строит криптовалюту на Kotlin: блоки, PoW, транзакции и сериализация — современный стек с Express-подходом и понятным кодом.

  • Сложность и майнинг

  • Сериализация и хранение

Основная идея

Kotlin отлично подходит для точных структур: компактный синтаксис, безопасность, полная совместимость с JVM — блокчейн читается как спецификация.

Майнер, ищущий nonce, в Kotlin:

Kotlinfun mine(block: Block): Block {
    while (!block.hash.startsWith("00")) {
        block.nonce++
        block.hash = block.calculateHash()
    }
    return block
}

Почему это важно

Второй язык для того же протокола — отличный способ закрепить знания: серия покажет, что суть одна, а выразительность разная.

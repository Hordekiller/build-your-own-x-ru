Основная идея

Блокчейн на Node — одинаковая структура с другими реализациями, но важный бонус: async-сеть и JSON-протокол делает общение нод очевидным.

Обмен блоками между нодами:

Node.js// Нода получает новую цепочку и проверяет её
socket.on("chain", (chain) => {
  if (isValid(chain) && chain.length > myChain.length) {
    myChain = chain;
  }
});

Почему это важно

Node.js — идеальный язык для P2P: урок покажет, как ноды договариваются о цепочке, и вы соберёте свою сеть блокчейна за вечер.

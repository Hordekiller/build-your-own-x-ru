Хотя некоторые считают, что блокчейн — это решение, всё ещё ждущее свою проблему, несомненно одно: эта новая технология — одно из чудес вычислительной техники. Но что же такое блокчейн на самом деле?

Блокчейн (Blockchain)

Цифровой реестр (digital ledger), в котором транзакции, совершённые в биткоине или любой другой криптовалюте, регистрируются хронологически и публично.

В более общем смысле блокчейн — это публичная база данных, в которой новые данные сохраняются в контейнерах, называемых блоками (block), и добавляются в неизменяемую цепочку (immutable chain) — отсюда и «блокчейн» — содержащую и данные, добавленные в прошлом. В случае биткоина и других криптовалют это данные — группы транзакций (transactions). Но, конечно, данными может быть что угодно.

Технология блокчейна породила совершенно новые криптовалюты, такие как биткоин и лайткоин, которые не выпускаются и не управляются никаким центральным органом. Это дало новую свободу людям, считающим, что сегодняшние банковские системы мошеннические или несостоятельны. Блокчейн также произвёл революцию в распределённых вычислениях (distributed computing) в таких технологиях, как Ethereum, которые ввели интересные концепции вроде смарт-контрактов (smart contracts).

В этой статье я создам простой блокчейн менее чем в 50 строках Python 2. Назову его SnakeCoin.

Структура блоков

Сначала определим, как будут выглядеть наши блоки. В блокчейне каждый блок хранится с меткой времени (timestamp) и, опционально, с индексом (index). В SnakeCoin мы храним оба. А чтобы гарантировать целостность (integrity) всей цепочки, каждый блок будет иметь самодостаточный хеш (hash). Как и в биткоине, хеш каждого блока — это криптографический хеш (cryptographic hash) индекса, метки времени, данных и хеша предыдущего блока. И да — данными может быть всё, что угодно.

pyimport hashlib as hasher
import datetime as date

# Определение того, что такое блок SnakeCoin
class Block:
  def __init__(self, index, timestamp, data, previous_hash):
    self.index = index
    self.timestamp = timestamp
    self.data = data
    self.previous_hash = previous_hash
    self.hash = self.hash_block()

  def hash_block(self):
    sha = hasher.sha256()
    sha.update(str(self.index) + str(self.timestamp) + str(self.data) + str(self.previous_hash))
    return sha.hexdigest()

Блок-генезис (Genesis Block)

Отлично! У нас есть структура блока, но мы строим блокчейн и должны начать добавлять блоки в настоящую цепочку. Как я упоминал ранее, каждый блок нуждается в информации от предыдущего блока. Но возникает вопрос: как первый блок попадает в блокчейн? Что ж, первый блок, или блок-генезис (genesis block), — особенный. Во многих случаях он добавляется вручную или имеет уникальную логику, позволяющую его добавить.

Чтобы всё было просто, создадим функцию, которая просто возвращает блок-генезис. У этого блока индекс 0, произвольное значение данных и произвольное значение параметра «предыдущий хеш».

py# Генерация блока-генезиса
def create_genesis_block():
  # Создаём вручную блок с
  # нулевым индексом и произвольным предыдущим хешем
  return Block(0, date.datetime.now(), "Genesis Block", "0")

Генерация следующих блоков

Теперь, когда мы умеем создавать блок-генезис, нужна функция, которая генерирует последующие блоки цепочки. Эта функция принимает предыдущий блок цепочки как параметр, создаёт данные блока, который нужно сгенерировать, и возвращает новый блок с его собственными данными. Когда новые блоки хешируют информацию предыдущих блоков, целостность блокчейна возрастает с каждым новым блоком. Если бы мы этого не делали, внешней стороне было бы легче «изменить прошлое» и подменить нашу цепочку совершенно новой цепочкой собственного производства. Эта цепочка хешей служит криптографическим доказательством и гарантирует, что, как только блок добавлен в блокчейн, его нельзя заменить или удалить.

py# Генерация всех последующих блоков блокчейна
def next_block(last_block):
  this_index = last_block.index + 1
  this_timestamp = date.datetime.now()
  this_data = "Hey! I'm block " + str(this_index)
  this_hash = last_block.hash
  return Block(this_index, this_timestamp, this_data, this_hash)

Создание блокчейна

Это была основная часть тяжёлой работы. Теперь можно построить наш блокчейн! В нашем случае сам блокчейн — это простой список Python. Первый элемент списка — блок-генезис. И, конечно, нужно добавлять последующие блоки. Поскольку SnakeCoin — самый маленький блокчейн, мы добавим только 20 новых блоков. Сделаем это с помощью цикла for.

py# Создание блокчейна и добавление блока-генезиса
blockchain = [create_genesis_block()]
previous_block = blockchain[0]

# Количество блоков для добавления в цепочку
# (после блока-генезиса)
num_of_blocks_to_add = 20

# Добавление блоков в цепочку
for i in range(0, num_of_blocks_to_add):
  block_to_add = next_block(previous_block)
  blockchain.append(block_to_add)
  previous_block = block_to_add

  # Сообщаем всем!
  print "Block #{} has been added to the blockchain!".format(block_to_add.index)
  print "Hash: {}\n".format(block_to_add.hash)

Ограничения и следующие шаги

Чтобы SnakeCoin масштабировался до уровня сегодняшних production-блокчейнов, нужно добавить больше функций, таких как серверный слой (server layer) для отслеживания изменений цепочки на нескольких машинах и алгоритм доказательства работы (proof-of-work) для ограничения количества блоков, добавляемых за заданный период времени.

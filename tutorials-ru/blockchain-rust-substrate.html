О чём это

Урок создаёт собственный блокчейн на Rust с фреймворком Substrate (Polkadot): палитра модулей, рантайм, нода и решение консенсуса — кастомный блокчейн из стандартных кубиков.

Что вы узнаете

  • Что такое Substrate и зачем он
  • Палитры: баланс, стейкинг, смарт-контракты
  • Рантайм на Rust и WebAssembly
  • Запуск собственной ноды

Основная идея

Substrate — конструктор блокчейнов: вы выбираете палитры (модули языка), пишете рантайм на Rust, и получаете работающую ноду со своей логикой.

Рантайм-палитра — объявление логики:

Rustdecl_module! {
  pub struct Module<T: Trait> {
    // Метод, который можно вызвать из транзакции
    #[weight = 10_000]
    pub fn do_something(origin, value: u64) {
      let me = ensure_signed(origin)?;
      Something::put(&me, value);
    }
  }
}

Почему это важно

Substrate — стандарт индустрии для своих сетей: урок откроет мир полкадатов, парачейнов и современной блокчейн-инженерии на Rust.

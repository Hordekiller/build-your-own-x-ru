Как создать простой блокчейн на акторной модели (Scala)

О чём это

Урок строит блокчейн на Scala с акторами: каждый узел — актор, сообщения между ними, консенсус и цепочка — распределённые вычисления в чистом виде.

Что вы узнаете

  • Акторная модель и сообщения
  • Узел-актор: приём и распространение
  • Валидация и консенсус в сообщениях
  • Отказоустойчивость и перезапуски

Основная идея

Акторы превращают ноды в изолированные сущности, общающиеся сообщениями: распределённость становится частью дизайна, а не дополнением.

Актор, реагирующий на блок:

Scalaclass NodeActor extends Actor {
  override def receive: Receive = {
    case BlockMsg(b) =>
      if (valid(b)) chain.add(b); broadcast(b)
  }
}

Почему это важно

Акторная модель — современная парадигма распределённых систем: урок объединяет её с блокчейном, давая двойной навык за один проект.

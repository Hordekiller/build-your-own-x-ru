Умный чат-бот для Facebook Messenger с API.ai

⚙ Язык: Node.js 📁 Бот 🌐 Русская страница 🔗 Оригинальный источник
Оригинальный источник: «Creating a Simple Facebook Messenger AI Bot with API.ai in Node.js»
↗ Перейти к оригинальному уроку فارسی — Персидская версия EN — English version

Введение

В этом руководстве вы научитесь создавать умного AI-бота для Facebook Messenger с помощью API.ai (сегодня известного как Dialogflow) и Node.js. Мы создадим простого бота — вашего умного «бухгалтера»: с API.ai мы даём ему обработку естественного языка (Natural Language), чтобы он понимал простые диалоги — он даже умеет шутить! Дойдите до конца — и у вас будет по-настоящему рабочий бот.

Этот туториал основан на платформе Facebook Messenger и её официальном быстром старте, но с двумя большими отличиями: во-первых, мы строим бота на Express.js и Node.js; во-вторых — вместо заранее определённых ответов добавляем боту искусственный интеллект через API.ai.

Что вам понадобится

  • Приложение Facebook и страница Facebook (для получения Page Token)
  • Аккаунт API.ai (бесплатный) и новый Agent
  • Node.js-сервер — тестируйте локальный webhook с помощью ngrok
  • Доступ к терминалу/CLI (установлены Node и npm)

Шаг 1: настройка Node.js-проекта

Сначала создайте папку проекта и инициализируйте package.json. Боту нужны две библиотеки: express для веб-сервера и request для вызовов API Facebook и API.ai. Если хотите использовать минимум — шаблон быстрого старта Facebook, рекомендую следовать коду самого туториала.

bashnpm init
npm install express request --save

Затем создайте файл app.js. Его стартовый код (упрощённый, по шаблону туториала):

js// app.js — бот Facebook Messenger с API.ai
const express = require('express');
const request = require('request');

const app = express();

// Токен доступа страницы — из настроек приложения Facebook
const PAGE_ACCESS_TOKEN = 'ВАШ_ТОКЕН_СТРАНИЦЫ';
// Токен проверки webhook — придумываете сами
const VERIFY_TOKEN = 'ВАШ_ТОКЕН_ПРОВЕРКИ';

app.use(express.json());

// Подтверждение webhook Facebook'ом
app.get('/webhook', (req, res) => {
  if (req.query['hub.mode'] === 'subscribe' &&
      req.query['hub.verify_token'] === VERIFY_TOKEN) {
    res.status(200).send(req.query['hub.challenge']);
  } else {
    res.sendStatus(403);
  }
});

// Получение сообщений от Facebook
app.post('/webhook', (req, res) => {
  const body = req.body;
  if (body.object === 'page') {
    body.entry.forEach(entry => {
      entry.messaging.forEach(event => {
        const senderId = event.sender.id;
        if (event.message && event.message.text) {
          handleMessage(senderId, event.message.text);
        }
      });
    });
    res.sendStatus(200);
  }
});

function handleMessage(senderId, messageText) {
  // Здесь отправляем текст сообщения в API.ai
  console.log('Получено сообщение:', messageText);
}

app.listen(process.env.PORT || 3000, () => {
  console.log('Сервер бота запущен');
});

Шаг 2: создание приложения Facebook и получение Page Token

Перейдите на developers.facebook.com и:

  • Добавьте продукт Messenger в своё приложение
  • Привяжите свою страницу Facebook к приложению
  • Скопируйте Page Access Token и вставьте в app.js
  • Задайте произвольный Verify Token (например, случайную строку) и поместите его в код

Настройка webhook

В настройках Facebook Developer откройте раздел Webhooks, укажите адрес https://YOUR_SERVER/webhook и введите Verify Token. Для проверки Facebook отправляет GET-запрос на ваш адрес; код выше отвечает с помощью hub.challenge, и соединение устанавливается.

Шаг 3: локальное тестирование с ngrok

Чтобы Facebook мог достучаться до вашего локального сервера, ngrok создаёт безопасный туннель:

bashnode app.js
# Во втором терминале:
ngrok http 3000

ngrok даст публичный адрес, например https://xxxx.ngrok.io — именно его (с /webhook) укажите как адрес Callback webhook в Facebook.

Шаг 4: подключение API.ai к боту

В панели API.ai создайте нового Agent. Сделаем два ключевых действия:

  • Small Talk: в меню Agent включите домен (Domain) «Small Talk», чтобы бот умел отвечать на повседневные разговоры (приветствия, «как дела», шутки и т. д.)
  • Создайте пользовательский Intent, например get.current.time, чтобы бот понимал, чего хочет пользователь, — например, когда пользователь спрашивает «сколько времени?», API.ai понимает это и отправляет подходящий ответ

Затем в handleMessage отправляйте текст сообщения в https://api.dialogflow.com/v1/query и возвращайте ответ (result.fulfillment.speech) пользователю через «Send API» Facebook:

jsfunction handleMessage(senderId, messageText) {
  request({
    url: 'https://api.dialogflow.com/v1/query',
    method: 'POST',
    headers: { Authorization: 'Bearer ' + APIAI_TOKEN },
    json: { query: messageText, lang: 'en', sessionId: senderId }
  }, (err, res, body) => {
    if (err) { console.error(err); return; }
    const reply = body.result.fulfillment.speech;
    sendTextMessage(senderId, reply);
  });
}

Шаг 5: публикация бота

После успешного теста опубликуйте бота: задеплойте код на Heroku (или аналогичный сервис) и замените ngrok публичным адресом. Подключите страницу Facebook к Messenger, чтобы все могли с ним общаться.

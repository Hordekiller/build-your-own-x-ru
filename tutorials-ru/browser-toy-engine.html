Игрушечный браузерный движок на Rust

О чём это

Мини-браузер на Rust: DOM, CSS и раскладка — от HTML до отрисованной страницы.

Что вы узнаете

  • Парсинг HTML → DOM
  • CSS: селекторы и стили
  • Раскладка блоков
  • Отрисовка страницы

Основная идея

Браузер — конвейер: HTML → DOM, CSS → стили, затем раскладка и рисование. Игрушечный движок проходит его весь.

Узел DOM на Rust:

Ruststruct Node {
    children: Vec<Node>,
    node_type: NodeType, // Text или Element
}

Почему это важно

Браузеры — основа интернета: сборка своего движка дарит взгляд, который меняет отношение к каждому сайту.

О чём это

Урок строит git-реплику, чтобы понять git: индексация, коммиты, ветки и работа с файлами — git как система объектов.

Что вы узнаете

  • Индекс и статус файлов
  • Объекты блоба и дерева
  • Ветки и checkout
  • Сообщения и история

Основная идея

Всё в git — объекты: блоб — файл, дерево — папка, коммит — история. Урок повторяет эти сущности на примере.

Запись файла как объекта:

JavaScriptobjDir = ".git/objects/" + sha1(content).slice(0, 2);
fs.writeFileSync(objDir + sha1(content).slice(2), content);

Почему это важно

Практика — лучшая лекция: этот урок перестроит ваше мышление о git и перестанет быть «волшебством».

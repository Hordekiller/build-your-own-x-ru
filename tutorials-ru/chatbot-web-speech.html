Простой ИИ-чат-бот с Web Speech API и Node.js

О чём это

Урок делает голосового чат-бота: распознавание речи в браузере через Web Speech API, отправка текста на Node.js-сервер и синтез ответа голосом — интерфейс, которым можно говорить.

Что вы узнаете

  • Web Speech API: распознавание и синтез
  • Микрофон и события речи
  • Сервер ответов на Node.js
  • Соединение: браузер ↔ сервер в реальном времени

Основная идея

Бот оживает через два API: SpeechRecognition превращает голос в текст, а SpeechSynthesis — текст в голос. Между ними — ваш сервер, который формулирует ответ.

Запуск распознавания речи — три строки:

JavaScriptconst rec = new (window.SpeechRecognition || window.webkitSpeechRecognition)();
rec.lang = "ru";
rec.start(); // говорите — текст появится в событии result

Почему это важно

Голосовые интерфейсы захватывают всё больше экранов: урок даст вам инструмент построить голосового помощника и понять, как устроены VA-ассистенты.

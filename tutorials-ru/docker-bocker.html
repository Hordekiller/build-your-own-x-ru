О чём это

Bocker реализует Docker на Bash (~100 строк): namespaces, chroot, image и сеть — самый быстрый путь увидеть контейнер с нулевой абстракции.

  • Сеть и мосты

Основная идея

Bocker доказывает: контейнер — это несколько системных команд. 100 строк bash — и ваш docker pull/run работает.

Запуск контейнера — сердце:

Bash#!/usr/bin/env bash
# bocker run — изоляция через unshare и chroot
unshare -m -p -f --mount-proc chroot "$ROOTFS" /bin/sh

Почему это важно

Лучший способ узнать все детали: если Docker упирается в 100 строк bash, вы поймёте его фундамент раз и навсегда.

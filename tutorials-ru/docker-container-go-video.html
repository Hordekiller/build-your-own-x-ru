Контейнер на Go (видео: libcontainer и cgroups)

О видео

В этом живом сеансе программирования «Лиз Райс (Liz Rice)» создаёт контейнер с нуля — только на Go, без готовых инструментов вроде Docker. Вы увидите, как примерно в 100 строк кода рождается настоящий контейнер, запускающий изолированные процессы.

В ходе видео эти концепции демонстрируются на практике:

  • Namespaces: изоляция PID, сети, mount и имени хоста с помощью CLONE_NEWPID и других флагов clone()
  • Изоляция файловой системы: монтирование rootfs и pivot_root
  • cgroups: ограничение ресурсов (таких как CPU и память) для процесса внутри контейнера
  • Понижение привилегий: управление capabilities и setuid для большей безопасности
  • Цепочка процессов: как «родительский» процесс запускает «дочерний» внутри изолированных namespace

Это видео — отличная отправная точка для всех, кто хочет понять, как контейнеры реально работают на уровне операционной системы.

go// Ядро контейнера: запуск дочернего процесса в изолированных namespace
cmd := exec.Command("/proc/self/exe", "child")
cmd.SysProcAttr = &syscall.SysProcAttr{
    Cloneflags: syscall.CLONE_NEWUTS | // отдельное имя хоста
        syscall.CLONE_NEWPID |         // отдельное дерево процессов
        syscall.CLONE_NEWNS,           // отдельный mount
}
cmd.Run()

Именно эти несколько флагов и есть то, что в видео доводится до конца примерно в 100 строках Go; cgroups позже добавляют ограничение ресурсов.

Mocker: свой Docker-раннер на Python

О чём это

Mocker — минимальный контейнер-раннер на Python: namespace, chroot, volumes и интерфейс командной строки ~1000 строк — свой docker run.

Что вы узнаете

  • Раннер и команды
  • Namespace и chroot
  • Volumes и монтирование
  • CLI-интерфейс

Основная идея

Mocker реализует рабочий docker run: изоляция, своя ФС, летающие папки. Проект пугающе конкретен для 1000 строк.

Запуск контейнера — интерфейс:

Pythonmocker run -v ./src:/code python:3.12 ./app.py

Почему это важно

Свой docker run — этот опыт вы запомните: после Mocker чтение документации Docker наконец-то будет на знакомом языке.

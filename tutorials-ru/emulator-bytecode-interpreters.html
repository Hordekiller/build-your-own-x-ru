Основная идея

Интерпретатор байткода — это цикл по инструкциям: взять опкод, выполнить, перейти дальше. Урок добавляет стек, регистры и даже дизассемблер.

Цикл исполнения байткода:

Cfor (;;) {
    uint8_t op = code[pc++];
    switch (op) {
        case PUSH: sp[++st] = code[pc++]; break;
        case ADD:  sp[st-1] += sp[st]; st--; break;
        case RET:  return;
    }
}

Почему это важно

Байткод — основа JVM, Python и Wasm: написав интерпретатор, вы поймёте виртуализацию на глубоком уровне.

Основная идея

CHIP-8 на Python — самый быстрый путь к эмуляции: меньше всего кода, вся суть видна. Библиотека для отрисовки проста.

Чтение инструкции в Python:

Pythondef fetch(self):
    op = (self.mem[self.pc] << 8) | self.mem[self.pc + 1]
    self.pc += 2
    return op

Почему это важно

Короткий код без ухищрений — лучший учебник: вы играете, отлаживаете и превращаете ретро-идеи в реальность.

О чём это

Реализация учебной машины LC-3 на C: 16-битный процессор, регистры, инструкции и трассировка — классическое введение в эмуляцию.

Что вы узнаете

  • Архитектура LC-3
  • Регистры R0–R7
  • Выполнение инструкций
  • I/O и трассировка

Основная идея

LC-3 — учебная архитектура: 65536 слов, 8 регистров, простые инструкции. Эмуляция — это цикл выборки/исполнения.

Цикл исполнения LC-3:

Cwhile (running) {
    uint16_t instr = memory[++pc];
    uint16_t op = instr >> 12; // старшие 4 бита — операция
    switch (op) { /* ADD, LD, BR, ... */ }
}

Почему это важно

LC-3 — баба любой ВМ: урок доносит принцип всех процессоров — выборка, декодирование, исполнение — без дестрых фокусов.

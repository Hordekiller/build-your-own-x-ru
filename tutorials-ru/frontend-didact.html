Didact: свой React — алгоритм рендеринга

1. Введение: зачем Didact?

Цель Родриго Помбо — показать, что в React нет никакой «магии»: из нескольких простых кусочков JavaScript можно собрать рабочую версию. Didact строится в шесть шагов и в итоге включает: createElement, виртуальное дерево, рендер, diff, компоненты и Hooks.

Любопытная деталь дизайна: у каждого шага своя отдельная папка в репозитории, и на каждом шаге предыдущий код переписывается, чтобы концепции прояснялись вместе с реализацией.

2. Шаги 1 и 2: createElement и рендер

Первый шаг, как всегда, — фабрика узлов виртуального дерева. Вместо прямого построения DOM каждый элемент представляется простым объектом:

jsfunction createElement(type, props, ...children) {
  return {
    type,
    props: {
      ...props,
      children: children.map((child) =>
        // тексты — тоже узлы: их тип "TEXT_ELEMENT"
        typeof child === "object" ? child : createTextElement(child)
      ),
    },
  };
}

Затем функция render превращает это дерево в настоящий DOM: рекурсивно для каждого узла создаёт DOM-элемент, навешивает props (такие как onClick и className) и присоединяет детей. Этих двух функций достаточно для рендера однократно.

3. Шаг 3: рендер с Fiber

Проблема рекурсивного рендера: если дерево большое, весь процесс выполняется разом, без остановок, блокируя главный поток (теряются кадры). Решение: разбить работу рендера на мелкие единицы работы и выполнять их порциями:

js// каждый fiber хранит указатели на своего ребёнка, сестру и родителя
{
  type,        // тип узла ("div", "TEXT_ELEMENT" или функция-компонент)
  props,
  parent,      // родитель в дереве
  child,       // первый ребёнок
  sibling,     // следующий ребёнок (сестра)
  ...
}

Это планируется через requestIdleCallback, чтобы браузер выполнял очередной фрагмент работы каждый раз, когда он простаивает.

5. Шаги 5 и 6: функциональные компоненты и Hooks

Функциональный компонент — это когда type сам является функцией; её нужно вызвать, чтобы получить дочерние элементы. Для Hooks хранятся глобальный массив и счётчик определений; useState использует старый хук из alternate:

jslet wipFiber = null;
let hookIndex = null;

6. Итоги

  • Виртуальное дерево — простая структура данных; вся сложность в планировании и сравнении.
  • Fiber — обходимая структура, делающая рендер дробимым; это основа конкурентного рендера и Suspense в настоящем React.

Gooact: React на 500 строках

О чём это

Проект Gooact реализует React в 500 строках: JSX без Babel, элементы, рендер и обновления — мини-React, читаемый от начала до конца.

Что вы узнаете

  • JSX своими руками
  • Элементы и рендер
  • Сравнение и обновление
  • Компоненты-классы

Основная идея

Gooact ограничивает масштаб, чтобы кода хватило: вся технология — 500 строк, и каждая строка на виду.

Обновление DOM при сравнении:

JavaScriptfunction updateDom(node, prevProps, nextProps) {
  for (const k in nextProps) {
    node[k] = nextProps[k]; // просто присваиваем
  }
}

Почему это важно

Полноценный мини-React — ценный актив: после Gooact вы сможете экспериментировать с React-архитектурой без лишней массы.

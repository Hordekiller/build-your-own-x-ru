Основная идея

Урок воспроизводит API Redux строка за строкой: каждый инструмент (store, reducer, middleware) получает реализацию и объяснение.

Создание store — сердце Redux:

JavaScriptfunction createStore(reducer) {
  let state = reducer(undefined, { type: "__INIT__" });
  const listeners = [];
  return {
    getState: () => state,
    dispatch: (action) => {
      state = reducer(state, action);
      listeners.forEach(l => l());
    },
    subscribe: (l) => listeners.push(l),
  };
}

Почему это важно

Реализовав Redux, вы сможете докручивать его под свои задачи и вести себя уверенно на собеседованиях по state-management.

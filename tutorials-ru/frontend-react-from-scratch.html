1. О докладе

Пол О'Шэннесси — один из старших инженеров команды React в Facebook — в этом 33-минутном докладе показывает, что ядро React можно построить на чистом JavaScript (без JSX и без каких-либо библиотек). Он работает в среде разработки без инструментов сборки и пишет всё с нуля.

Примечание: этот доклад — один из лучших источников «о закулисье React», особенно для тех, кто хочет знать, что происходит в настоящем коде React, а не в упрощённой учебной версии.

3. Что вы узнаете из этого видео

  • Elements и Instance: концептуальная разница между описанием UI (элементом) и реальным объектом, хранящим состояние (экземпляром/instance), и почему это разделение важно в архитектуре React.
  • Механизм рендера: превращение дерева элементов в настоящий DOM, управление экземплярами и обновление.
js// Сердце React: превращение элемента в настоящий DOM
function render(element, container) {
  const node = document.createElement(element.type);
  node.textContent = element.props.children;
  for (const name in element.props) {
    node[name] = element.props[name];
  }
  ...
}

В докладе эта простая функция дополняется Instance, state и полным diff.

4. Почему это видео важно?

Большинство уроков «построй свой React» дают упрощённую версию концепций; но О'Шэннесси, будучи членом основной команды, объясняет реальные дизайнерские решения React (например, зачем нужен Instance, отдельный от Element) из уст того, кто их принимал.

Продолжение: если вы не знакомы с Fiber и конкурентным рендером, после этого видео прочитайте архитектурные заметки команды React (например, объяснения Fiber от Andrew Clark), чтобы получить полную картину архитектуры.

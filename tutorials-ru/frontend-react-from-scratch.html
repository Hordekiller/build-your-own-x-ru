О чём это

Статья пишет React с нуля на JS: элементы, рендеринг, update и события — маленький, но настоящий React-подобный движок.

Что вы узнаете

  • Элементы и рендер
  • Обновление DOM
  • Компоненты и пропсы
  • Мерж обновлений

Основная идея

Идея: элементы описывают UI, рендер обновляет DOM. Урок показывает, как таблица обновлений (update queue) превращается в плавный интерфейс.

Рендер элемента в DOM:

JavaScriptfunction render(element, container) {
  const node = document.createElement(element.type);
  for (const child of element.props.children) {
    render(child, node);
  }
  container.appendChild(node);
}

Почему это важно

Реализовав React в 100 строк, вы навсегда избавитесь от «волшебства»: вся индустрия виртуального DOM станет знакомой территорией.

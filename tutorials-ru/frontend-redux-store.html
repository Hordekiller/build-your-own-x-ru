3. Ядро урока: реализация createStore

Содержание и код урока — тот же классический подход, кратко изложенный ниже, — с ручной реализацией четырёх основных методов:

jsconst createStore = (reducer) => {
  let state;
  let listeners = [];

  // только reducer может менять state
  const getState = () => state;

  const dispatch = (action) => {
    state = reducer(state, action);
    listeners.forEach((listener) => listener());
  };

  const subscribe = (listener) => {
    listeners.push(listener);
    return () => {
      listeners = listeners.filter((l) => l !== listener);
    };
  };

  // инициализация: вызываем reducer с неопределённым state
  dispatch({});

  return { getState, dispatch, subscribe };
};

Важная деталь — вызов dispatch({}) в конце: пустой action обычно возвращается reducer'ом через default как есть, но при этом state инициализируется значением по умолчанию reducer'а (например, пустым массивом).

4. Практическое использование

js// простой reducer для счётчика
const counter = (state = 0, action) => {
  switch (action.type) {
    case 'INCREMENT': return state + 1;
    case 'DECREMENT': return state - 1;
    default: return state;
  }
};

const store = createStore(counter);

store.subscribe(() => {
  console.log('текущий state:', store.getState());
});

store.dispatch({ type: 'INCREMENT' }); // 1
store.dispatch({ type: 'INCREMENT' }); // 2
store.dispatch({ type: 'DECREMENT' }); // 1

Дизайнерская деталь, на которой настаивает урок: action должен явно говорить «что произошло», а не «как изменить state» — то есть мы отправляем только { type: 'INCREMENT' }, а что это значит, знает reducer. Это разделение и есть философия Redux.

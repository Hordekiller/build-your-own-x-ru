Redux: пишем свой Store

О чём это

Сфокусированный урок про Store в Redux: подписки, dispatch и связи с UI — основы создания предсказуемого состояния.

Что вы узнаете

  • Что такое Store
  • Подписки и уведомления
  • Dispatch и immutable-обновления
  • Связь с компонентами

Основная идея

Store — единственный источник правды: компоненты подписываются, изменения распространяются. Немногие строки делают состояние предсказуемым.

Иммутабельное обновление состояния:

JavaScriptstore.dispatch({ type: "TOGGLE", id });
// состояние никогда не меняется на месте:
state = { ...state, todos: [...state.todos, newTodo] }

Почему это важно

Дисциплина store-подхода — ключ к здоровым приложениям: вы поймёте, почему огромные приложения выбирают предсказуемое состояние.

О чём это

Redux изнутри: store, action, reducer и подписки — государственный контейнер, который можно написать за 50 строк.

Что вы узнаете

  • Store и состояние
  • Actions и reducers
  • Подписки и dispatch
  • Промежуточки (middleware)

Основная идея

Redux — это функция: (state, action) → new state. Store держит состояние, dispatch передаёт изменения, subscribe уведомляет слушателей.

Классический reducer:

JavaScriptfunction reducer(state = { count: 0 }, action) {
  switch (action.type) {
    case "INC": return { count: state.count + 1 };
    default: return state;
  }
}

Почему это важно

Redux-школа улучшает мышление о состоянии: написав свой store, вы сможете проектировать глобальное состояние без внешних зависимостей.

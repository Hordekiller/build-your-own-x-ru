О серии

В этой серии на JavaScript и Canvas создаётся полноценная игра 8-Ball Pool (американский бильярд) — без каких-либо библиотек. От физики столкновения шаров, удара кием, движения и трения до правил «восьмёрки» и интерфейса — всё реализуется шаг за шагом. Серия начинается с «Part 1» и завершается в трёх частях.

Совет: у проекта полная физика: столкновение шар-шар, шар-борт, спин (вращение) и трение — это один из лучших уроков настоящей двухмерной физики в браузере.

Концепции реализации

Пример физики шаров, создаваемой в серии:

js// Шар: позиция, скорость, радиус и состояние
class Ball {
  constructor(x, y, radius, color, id) {
    this.x = x; this.y = y;
    this.vx = 0; this.vy = 0;
    this.radius = radius;
    this.color = color;
    this.id = id;
  }

  // Движение и применение трения
  update(dt) {
    this.x += this.vx * dt;
    this.y += this.vy * dt;
    this.vx *= FRICTION; // трение стола
    this.vy *= FRICTION;
    if (Math.abs(this.vx) < EPSILON) this.vx = 0;
    if (Math.abs(this.vy) < EPSILON) this.vy = 0;
    this.collideWalls();
  }

  // Упругое столкновение круг-круг между двумя шарами
  collide(other) {
    const dx = other.x - this.x;
    const dy = other.y - this.y;
    const dist = Math.hypot(dx, dy);
    if (dist < this.radius + other.radius) {
      // Вектор нормали и обмен скоростей вдоль него
      const nx = dx / dist, ny = dy / dist;
      const relVx = this.vx - other.vx;
      const relVy = this.vy - other.vy;
      const speed = relVx * nx + relVy * ny;
      if (speed > 0) {
        this.vx -= speed * nx;
        this.vy -= speed * ny;
        other.vx += speed * nx;
        other.vy += speed * ny;
      }
    }
  }
}

В следующих частях: прицеливание и удар мышью, правило «восьмёрки» (победа с шаром 8), подсчёт очков и красивый пользовательский интерфейс.

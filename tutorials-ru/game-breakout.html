Предпосылки и место главы

Эта глава — часть «In Practice → 2D Game» книги LearnOpenGL: прикладной проект, применяющий весь предыдущий материал книги в виде реальной игры. Предпосылка: знакомство с главами «Getting Started» и «Lighting» (особенно шейдеры, текстуры и матричная математика).

Игра Breakout (Atari, 1976): ракетка внизу, мяч, отскакивающий от стен и блоков, а блоки уничтожаются. Что делает именно эту реализацию особенной — графические технологии: particles (частицы), рендеринг текста, power-ups и постобработка — всё на чистом OpenGL.

Уровни определяются в текстовых файлах: каждая строка — ряд блоков, а каждый символ задаёт цвет блока — создать новый уровень значит просто написать файл!

Логика столкновений: AABB и круг

Сердце игры — столкновение мяча (круга) с блоками и ракеткой (прямоугольниками AABB). Техника bounce-off — определение того, с какой стороны мяч столкнулся, и отражение на его основе:

cpp// Определение столкновения круга (мяча) с прямоугольником (блок/ракетка)
Collision CheckCollision(BallObject &ball, GameObject &box) {
  // Ближайшая точка прямоугольника к центру круга
  glm::vec2 closest = glm::clamp(ball.Position, box.Position,
                                 box.Position + box.Size);
  // Расстояние от центра круга до этой точки
  glm::vec2 diff = ball.Position - closest;
  float distance = glm::length(diff);

  // Если расстояние меньше радиуса, произошло столкновение
  if (distance <= ball.Radius) {
    // Определение направления удара сравнением diff с размерами
    glm::vec2 overlap = glm::abs(diff);
    if (overlap.x < overlap.y) {
      ball.Velocity.x = -ball.Velocity.x;  // сбоку
    } else {
      ball.Velocity.y = -ball.Velocity.y;  // сверху/снизу
    }
    return { true, ball.Position - closest };
  }
  return { false, glm::vec2(0.0f) };
}

Визуальные эффекты

  • Particles: шлейф частиц за мячом и умирающими блоками; каждая частица — маленький четырёхугольник с GLSL-шейдером, который умирает и возрождается.
  • Postprocessing: с помощью FrameBuffer сцена рендерится в текстуру, после чего применяется эффект shake со случайными смещениями сэмплирования.
  • Text rendering: вывод счёта и сообщений через FreeType на одном шейдере.
  • Power-ups: падающие «горшочки» с эффектами вроде большой ракетки, липкого мяча, проходящих (пробивающих блоки) мячей и множественных мячей.

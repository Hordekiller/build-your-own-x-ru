Об обучении

BYTEPATH — обучающая серия из пятнадцати частей, в которой создаётся полный космический шутер с деревом навыков — комбинация Bit Blaster XL и пассивного дерева Path of Exile. Аудитория: программисты с небольшим опытом (не совсем новички). Все части читаются в issues блога a327ex (SSYGEN/blog), и каждая часть содержит полный код.

Совет: структура серии отличная: каждая часть — независимая система (движение, враги, очки, дерево навыков, сохранение игры), и в сумме они показывают архитектуру целой игры.

Карта частей

  • #0 Введение и структура проекта
  • Система движения игрока, стрельба и враги
  • Паттерны и subs (расходники)
  • Система навыков: дерево навыков с узлами и прогрессией
  • Игровые режимы, сохранение, карта и эффекты
  • И далее — до готовой оформленной игры

Пример кода

lua-- Движение игрока (в стиле аркады)
function Player:update(dt)
    -- Физика с ускорением/затуханием вместо постоянной скорости
    local move_speed = self.stats.move_speed
    if input:down('left') then self.vx = self.vx - move_speed * dt end
    if input:down('right') then self.vx = self.vx + move_speed * dt end
    if input:down('up') then self.vy = self.vy - move_speed * dt end
    if input:down('down') then self.vy = self.vy + move_speed * dt end

    -- Затухание движения: постепенное возвращение к нулю
    self.vx = self.vx * (1 - 0.5 * dt)
    self.vy = self.vy * (1 - 0.5 * dt)

    self.x = self.x + self.vx * dt
    self.y = self.y + self.vy * dt
end

Итоги

Серия — один из самых полных уроков разработки игр на LÖVE; по ходу вы практикуете все навыки разработчика игр (пропорции, системы, управление состоянием, UI). Одна только реализация дерева навыков — уже ценный учебный проект.

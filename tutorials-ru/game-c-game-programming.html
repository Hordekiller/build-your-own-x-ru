Об обучении

Этот плейлист — полный видеокурс для изучения C через разработку игр, рассчитанный на новичков и тех, кто только начинает с C. Вместо сухих терминальных примеров вы сразу создаёте запускаемые игры (например, Pong и простые игры на графике), а по пути изучаете концепции C: переменные, циклы, функции, массивы и указатели.

Ключевые концепции

Пример структуры игрового цикла, используемой в курсе:

c// Главный цикл игры — три постоянных шага
while (game_is_running) {
  // 1) Обработка ввода
  handle_events();

  // 2) Обновление логики (движение мяча, коллизии, счёт)
  update();

  // 3) Рендер: отрисовка на экране
  render();
}

В ходе курса создаётся такая игра, как Pong: движение ракетки клавишами, движение мяча, отскок от стен, столкновение с ракеткой и подсчёт очков — а затем добавляются более продвинутые концепции (массив врагов, системы очков, уровни).

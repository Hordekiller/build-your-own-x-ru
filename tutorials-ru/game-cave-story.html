О плейлисте

Этот плейлист — долгосрочный проект реконструкции: Cave Story создаётся полностью — от запуска движка до уровней, врагов, оружия и босс-файтов — на C++. В отличие от одноразового видео, эта серия углубляется в игровые механики: система оружия с тремя уровнями прокачки, движок диалогов, порталы, сохранение игры и даже звуки.

Совет: если вы смотрели видео «Cavestory Part 1» и хотите увидеть проект доведённым до конца, этот плейлист — его продолжение.

Компоненты игры

Пример логики систем, реализуемых в серии, — прокачка оружия сбором кристаллов:

cpp// Трёхуровневая система оружия (как в Cave Story)
class Weapon {
public:
  int level;        // 1, 2 или 3
  int exp;          // опыт для прокачки

  void addExp(int amount) {
    exp += amount;
    if (exp >= REQUIREMENTS[level] && level < 3) {
      exp -= REQUIREMENTS[level];
      level++;      // прокачка
    }
  }

  void takeDamage() {
    // При получении урона опыт уменьшается, уровень может упасть
    exp -= PENALTY;
    if (exp < 0 && level > 1) { level--; exp = REQUIREMENTS[level]; }
  }
};

Другие части серии: построение карт в редакторе, управление триггерами, секретные двери, враги с разным поведением (птицы, пловцы, пушки), механика урона и здоровья, диалоги с NPC и полноценный геймплей босс-битв.

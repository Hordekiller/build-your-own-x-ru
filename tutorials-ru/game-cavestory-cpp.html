О проекте

Cave Story — сверхпопулярный экшн-платформер, созданный одним человеком (Daisuke «Pixel» Amaya) за 5 лет и считающийся отцом «инди-игр». В этой видео-серии игра воссоздаётся на C++: движение персонажа, физика прыжка и гравитации, оружие, враги, движок сцен и прокрутка — всё с нуля.

Совет: эта серия — один из самых полных уроков «реконструкции игры»: у Cave Story есть реальная сложность (прокрутка камеры, анимация, точные коллизии).

Пример структуры классов в серии:

cpp// Базовая структура игры в серии Cavestory
class Entity {
public:
  Vector2 position;
  Vector2 velocity;
  bool grounded;

  virtual void update(float dt) = 0;   // логика каждого существа
  virtual void render() = 0;           // отрисовка каждого существа
};

class Player : public Entity {
public:
  void update(float dt) override {
    // Ввод → горизонтальное движение
    velocity.x = input * MOVE_SPEED;
    // Гравитация
    velocity.y += GRAVITY * dt;
    // Прыжок
    if (jump_pressed && grounded) velocity.y = -JUMP_SPEED;
    // Применение движения с коллизиями
    position += velocity * dt;
    resolve_collisions();
  }
};

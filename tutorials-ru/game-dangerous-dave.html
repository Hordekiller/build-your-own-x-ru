Основная идея

Платформер — это уровни-карты и проверка столкновений: персонаж движется, стены останавливают, спрайты оживляются.

Проверка столкновения с тайлом:

C// тайл под ногами?
int tile = map[(playerY + h) / TILE][playerX / TILE];
if (solid[tile]) playerY -= 1; // не проваливаемся

Почему это важно

Платформер на C — эталон ретро: вы посмотрите на уровне/движение глазами авторов 80-х.

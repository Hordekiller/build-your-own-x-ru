Об обучении

Dangerous Dave — классический платформер для DOS, созданный Джоном Ромеро (создателем Doom и Wolfenstein) в 1988 году — и считающийся одной из первых простых и увлекательных «игр-конструкторов». В этом плейлисте та же игра с почти идентичной графикой и деталями воссоздаётся на C: спрайты 16×16, движение, гравитация, сбор предметов, враги, прыжки и несколько уровней.

Совет: эта серия отлично подходит для старта: кода в каждом выпуске немного, структура простая, а в конце вы получаете полноценную рабочую игру.

Ключевые концепции

Пример структуры 2D-платформера, реализуемой в серии:

c// Структура уровня: сетка тайлов
#define TILE_EMPTY 0
#define TILE_BLOCK 1
#define TILE_LADDER 2

typedef struct {
  int tile[ROWS][COLS];  // карта уровня
  Player player;         // игрок
  Monster monsters[MAX_MONSTERS];
  Item items[MAX_ITEMS];
} Level;

// Главный цикл игры: ввод → обновление физики → рендер
void game_loop(void) {
  while (running) {
    handle_input();
    // Физика игрока: гравитация, горизонтальное движение,
    // столкновения с тайлами
    update_player(&level.player, &level);
    // Враги и предметы
    update_monsters(&level);
    render(&level);  // отрисовка спрайтов в буфер
    swap_buffers();  // вывод на экран
    delay_frame();
  }
}

Учебные концепции серии: игровой цикл, движение на основе тайлов, простые коллизии, физика гравитации и прыжка, простой ИИ врагов и управление несколькими уровнями через файлы.

Итоги

Этот плейлист — один из самых приятных способов создать свою первую полноценную игру: известная игра, простой и развиваемый код. После него можно переходить к более сложным играм на той же структуре.

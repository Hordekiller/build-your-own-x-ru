О плейлисте

Go (иногда Голанг) с горутинами, сборкой мусора и быстрой компиляцией — очень подходящий язык для разработки игр; а библиотеки вроде Ebiten (создание 2D-игр с кроссплатформенной поддержкой) делают его ещё проще. В этом плейлисте игры от простых до средних (платформеры, dauer, головоломки и т.д.) создаются на Go, и главные концепции — игровой цикл, ввод, рендер спрайтов — реализуются шаг за шагом.

Замечание: Ebiten собирается и в веб (WASM) — созданные игры можно запускать и в браузере.

Пример кода: простая игра на Ebiten

gopackage main

import (
    "log"

    "github.com/hajimehoshi/ebiten/v2"
)

// Каждая игра — struct, реализующая интерфейс Game
type Game struct {
    // состояние игры: позиция игрока, ввод и т.д.
    playerX, playerY float64
}

// Обновление логики: ввод и физика
func (g *Game) Update() error {
    if ebiten.IsKeyPressed(ebiten.KeyArrowLeft) {
        g.playerX -= 2
    }
    if ebiten.IsKeyPressed(ebiten.KeyArrowRight) {
        g.playerX += 2
    }
    return nil
}

// Рендер: рисование сцены на экране
func (g *Game) Draw(screen *ebiten.Image) {
    // рисование прямоугольника игрока на screen (детали через DrawImage)
}

// Размеры окна и заголовок
func (g *Game) Layout(outsideWidth, outsideHeight int) (int, int) {
    return 640, 480
}

func main() {
    ebiten.SetWindowSize(640, 480)
    ebiten.SetWindowTitle("Моя игра на Go")
    if err := ebiten.RunGame(&Game{}); err != nil {
        log.Fatal(err)
    }
}

Итог

Если вы знаете Go и хотите начать делать игры, этот плейлист — хорошая точка старта; а если Go не знаете, создание небольшой игры на Ebiten — один из самых увлекательных способов его выучить.

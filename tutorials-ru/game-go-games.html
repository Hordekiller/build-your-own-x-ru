О чём это

Начало игрового программирования на Go: простые 2D-игры и библиотеки вроде Ebitengine — игры на приятном языке.

Что вы узнаете

  • Библиотека Ebitengine
  • Графика и ввод
  • Структура игры
  • Первая игра

Основная идея

Go + Ebitengine дают лёгкий вход: окно, спрайты и ввод на чистом API. Язык подкупает простотой.

Ключевой метод игры:

Gofunc (g *Game) Update() error {
    // ввод и логика — вызывается каждый кадр
    return nil
}

Почему это важно

Игры на Go — тренд: простые языки делают игровую разработку доступной и быстрой для идей.

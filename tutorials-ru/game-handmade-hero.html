О чём это

Handmade Hero — легендарная серия разработки игры на C без движков: окно, рендеринг, ввод и звук — год походов по игровой инженерии на бесплатном стеке.

Что вы узнаете

  • Окно, контекст и цикл
  • Пиксельный рендер
  • Ввод и физика
  • Инженерия игры целиком

Основная идея

Вся игра — это код: ни Unity, ни Unreal, только Win32 и C. Серия идёт от пустого окна к платформеру через сотни часов инженерии.

Цикл игры — сердце Handmade Hero:

Cfor (;;) {
    process_input();   // клавиатура и мышь
    update_game(dt);   // физика и логика
    render_frame();    // пиксели в буфер
}

Почему это важно

Handmade Hero — инвестиция в инженерное мышление: вы увидите, как разрабатывают software на самом высоком уровне.

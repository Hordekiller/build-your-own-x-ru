Handmade Hero: пишем игру с нуля на C

Что за проект

Handmade Hero — долгосрочный учебный проект: каждый день недели в течение часа Кейси Муратори сидит перед камерой и строит полноценную игру с абсолютного нуля. В итоге игра должна быть «коммерческого качества»: графика, звук, физика, искусственный интеллект, интерфейс и даже вспомогательные инструменты — всё с нуля на C/C++ (с несколькими вставками на ассемблере).

  • Старт: 17 ноября 2014 года; на сегодня более 600 выпусков.
  • Формат: каждый рабочий день — час видео + полный работающий код.
  • Подход: никаких движков, библиотек и middleware — всё делаете сами: окно, ввод, рендер, звук.

Почему это важно

Большинство обучалок по играм начинается с готовых движков (Unity/Unreal) или высокоуровневых библиотек. Handmade Hero идёт противоположным путём и отвечает на вопрос: «как делались игры 90-х — например, творения Криса Сойера — вообще без ничего?» Результат: глубокое понимание того, как работают компьютер, память и рендеринг.

Совет: начинайте с первых выпусков (создание окна Win32 и буфера рендера) — именно они закладывают базовые концепции. Код каждого выпуска можно скачать с сайта и запустить.

Основные подсистемы игры

В ходе проекта строятся следующие подсистемы (пример структуры кода):

cpp// Обзор модулей игры в ходе проекта
win32_handmade.cpp   // слой платформы: окно, ввод, звук, время
handmade.h           // общие структуры (буфер рендера, состояние игры)
handmade.cpp         // логика игры: обновление и рендер
handmade_math.h      // векторная/матричная математика
handmade_audio.cpp   // синтезатор звука и воспроизведение
handmade_asset.cpp   // система управления ассетами
handmade_world.cpp   // игровой мир, коллизии и ИИ

Ключевые концепции, реализуемые по ходу: пиксельный буфер рендера с прямым доступом, ввод без лагов, параллельный скролл (parallax), коллизии с сеткой мира, воспроизведение звука программным синтезатором — всё на чистом C с полным контролем над памятью.

Доступ и лицензия

  • Все видео и код каждого выпуска бесплатно доступны на сайте проекта.
  • Код игры после завершения проекта через два года после публикации переходит в общественное достояние (public domain) — им можно пользоваться даже в коммерческих проектах.

Итоги

Handmade Hero — уникальный ресурс для тех, кто хочет понять, «как на самом деле работают игры». Если у вас нет времени на долгие видео, посмотрите первые выпуски и всё, что связано с рендером и вводом, — этого достаточно для глубокого взгляда, которого не даёт ни один курс, завязанный на движок.

Основная идея

Движок — это архитектура: сущность, компонент, сцена и цикл. На Java вы построите её чисто и расширяемо.

Цикл обновления движка:

Javawhile (running) {
    input.poll();
    scene.update(dt);
    renderer.render(scene);
}

Почему это важно

Свой движок на Java — полноценный опыт архитектуры ПО: он научит вас компонентам, циклам и чистым интерфейсам.

О курсе

Этот многочасовой курс (выпущенный freeCodeCamp) строит 2D-игровой движок с нуля на Java, а затем на этом движке разрабатывает полноценную игру в духе Super Mario (клон). В конце игра упаковывается в исполняемый jar-пакет — настоящая игра, которую можно запустить на любой системе.

Замечание: курс рассчитан на новичков: в начале видео показывается даже установка JDK и настройка окружения.

▶ Курс «Code a 2D Game Engine using Java»

Содержание курса

  • Создание окна игры и главного цикла (Game Loop) на Java Swing/AWT
  • Система GameObject: рендеримые сущности с позицией и размером
  • Базовая физика: гравитация, скорость и столкновения с платформами
  • Анимация спрайтов: управление кадрами для ходьбы и прыжков
  • Камера и сцена: движение между уровнями и скролл
  • Редактор уровней: создание и дизайн этапов инструментом из курса
  • Финальная упаковка в jar

Пример структуры классов:

java// Базовая сущность движка
public class GameObject {
    public float x, y;          // позиция
    public float width, height; // размер
    public int animationIndex = 0;
    public boolean isActive = true;

    public void draw(Graphics2D g) {
        // рисование текущего кадра анимации в позиции сущности
    }
}

// Главный игровой цикл: 60 кадров в секунду
public class GameWindow implements Runnable {
    public void run() {
        while (running) {
            update();        // логика: движение, физика, столкновения
            render();        // отрисовка всех GameObject
            Thread.sleep(16); // ~60 кадров в секунду
        }
    }
}

LWJGL: 3D-игры на Java

О книге

LWJGL 3 — библиотека, дающая в Java низкоуровневый доступ к OpenGL, OpenAL (звук) и OpenCL — безо всякого игрового движка. Книга идёт пошагово с главы «First steps»: создание окна через GLFW, затем шейдеры OpenGL, рендер объектов, камера, освещение и, наконец, управляемая 3D-сцена.

Замечание: если вы не знакомы с OpenGL, первые главы книги (шейдеры, VBO/VAO, матрицы трансформаций) сами по себе — полноценный урок графики.

Карта глав

  • Первые шаги: настройка GLFW и окна
  • Шейдеры и современный конвейер OpenGL (GLSL)
  • Рендер треугольника и куба, камера, текстуры
  • Матрицы и трансформации (перемещение/поворот/масштаб)
  • Освещение и материалы
  • 3D-модели, вода, небо, частицы
  • Звук через OpenAL (в старой версии книги)

Пример кода

java// Настройка окна через GLFW
public class GameEngine implements Runnable {
    private final Window window;

    public static void main(String[] args) {
        new GameEngine().run();
    }

    @Override
    public void run() {
        init();              // окно, состояние OpenGL
        while (!window.shouldClose()) {
            gameLoop();      // ввод ← обновление ← рендер
        }
        cleanup();           // освобождение GLFW
    }

    private void init() {
        window = new Window("3D Game with LWJGL", 800, 600);
        window.init();
        // ... создание шейдеров, буферов и сцены
    }
}

Вся книга построена на одном шаблоне «Window + Scene + Renderer»; каждая глава добавляет сцене одну графическую возможность.

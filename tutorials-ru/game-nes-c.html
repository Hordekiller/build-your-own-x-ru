Почему NES

У консоли NES крайне жёсткие аппаратные ограничения: процессор Ricoh 2A03 (клон 6502 с частотой 1,79 МГц), 2 КБ RAM и отдельный графический чип (PPU). Создание игры для такого железа даёт глубокое понимание низкоуровневого программирования, управления памятью и дизайна в условиях ограничений — и этот вызов по-настоящему увлекателен!

Совет: для старта реальное железо не нужно — игры запускаются в эмуляторах (например, Mesen или FCEUX).

Структура уроков

Уроки сайта nesdoug идут по номерам (01–24 и далее); каждый урок — самостоятельная тема:

  • Настройка проекта с cc65 и сборка первого результата (файл .nes)
  • Ожидание v-blank (скрытой области экрана) и построение игрового цикла
  • Работа с nametable, атрибутами и цветами
  • Чтение контроллера (кнопки A/B/Select/Start и направления)
  • Спрайты (OAM) и столкновения спрайт-со-спрайтом
  • Экранные эффекты (прокрутка и split screen)
  • Работа с mapperами (MMC1, MMC3) и картриджами большего размера
  • Zapper (световой пистолет), Power Pad и другое

Простой пример: спрайт и движение

c// Простая структура спрайта в OAM (RAM атрибутов спрайтов)
// Каждый спрайт — 4 байта: позиция y, номер тайла, атрибуты, позиция x
struct sprite {
  unsigned char y;
  unsigned char tile;
  unsigned char attr;
  unsigned char x;
};

// Глобальный OAM — 64 спрайта
struct sprite sprites[64];

// Пример: движение спрайта с контроллера
void move_sprite(void) {
  // Чтение ввода: биты контроллера
  if (pad & PAD_LEFT)  sprites[0].x -= 1;
  if (pad & PAD_RIGHT) sprites[0].x += 1;
  if (pad & PAD_UP)    sprites[0].y -= 1;
  if (pad & PAD_DOWN)  sprites[0].y += 1;
}

Для работы с тайлами важны две области памяти: CHR-ROM (где хранятся тайлы 8×8 пикселей) и nametable (которая указывает, какой тайл где отображается). Графика NES — это раскладка тайлов 8×8 в сетку 32×30.

Инструменты

  • cc65: компилятор C, выдающий ассемблер 6502 (вместе с ld65 для линковки).
  • Спрайт-редакторы и тайл-редакторы для создания графики CHR.
  • Инструменты вроде Nesst для раскладки карты nametable.

Итоги

Уроки nesdoug — пожалуй, лучший бесплатный ресурс для старта программирования NES на C. Создав несколько простых игр (например, пинг-понг, змейка и платформер), вы и историю геймдева поймёте, и низкоуровневые навыки прокачаете.

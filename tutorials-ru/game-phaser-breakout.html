Breakout на Phaser (JavaScript)

Об уроке

Урок опубликован в разделе «Игры» (Games) сайта MDN и строит игру Breakout на Phaser. Его особенность: каждый шаг сопровождается живым редактируемым примером — можно менять код прямо в браузере и сразу видеть результат. Полный код есть на GitHub MDN. Предпосылка: JavaScript от начального до среднего уровня.

Замечание: MDN также ведёт версию той же игры на чистом JavaScript (Canvas); если хотите увидеть, как всё работает без фреймворка, сначала пройдите ту версию, а потом этот урок Phaser — различия очень наглядны.

Карта уроков

  • Настройка Phaser и создание игровой сцены
  • Рендер и перемещение изображений (ракетка, мяч)
  • Обнаружение столкновений (collision detection)
  • Управление: мышь и клавиатура
  • Анимация: движение мяча, твины (tweens)
  • Состояния победы и поражения (win/lose states)

Пример кода: игровая сцена

js// Создание сцен игры: Boot → Preload → Create → Update
class GameScene extends Phaser.Scene {
  constructor() {
    super({ key: 'GameScene' });
  }

  preload() {
    // загрузка изображений
    this.load.image('ball', 'images/ball.png');
    this.load.image('paddle', 'images/paddle.png');
    this.load.image('brick', 'images/brick.png');
  }

  create() {
    // мяч с физикой
    this.ball = this.physics.add.image(400, 300, 'ball');
    this.ball.setBounce(1);         // полное отражение
    this.ball.setVelocity(160, 160); // начальная скорость

    // ракетка: закреплена внизу, движется за мышью
    this.paddle = this.physics.add.image(400, 550, 'paddle');
    this.paddle.setImmovable(true);

    // столкновение мяча с ракеткой
    this.physics.add.collider(this.ball, this.paddle);

    // кирпичи: сетка
    for (let row = 0; row < 3; row++) {
      for (let col = 0; col < 8; col++) {
        const brick = this.physics.add.image(70 + col * 90, 60 + row * 40, 'brick');
        brick.setImmovable(true);
        this.physics.add.collider(this.ball, brick, this.hitBrick, null, this);
      }
    }

    this.input.on('pointermove', (p) => {
      this.paddle.x = Phaser.Math.Clamp(p.x, 50, 750);
    });
  }

  hitBrick(ball, brick) {
    brick.destroy(); // кирпич уничтожен
  }
}

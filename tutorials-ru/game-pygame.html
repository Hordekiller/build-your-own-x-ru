Игры на Pygame: первая игра

О курсе

Эта видео-серия создаёт игру «A bit Racey»: гоночная машина, управляемая клавишами, которая объезжает надвигающиеся препятствия. Первый урок показывает полную настройку: установку PyGame, создание окна, игровой цикл и контроль частоты кадров через Clock.

Совет: это текстово-видео обучение: у каждого урока есть и видео, и текст — отлично для пошагового следования.

Вводный код

pythonimport pygame

# Инициализация всех модулей pygame
pygame.init()

# Создание окна: ширина 800, высота 600
win = pygame.display.set_mode((800, 600))

# Заголовок окна
pygame.display.set_caption("A bit Racey")

# Часы: контроль частоты кадров
clock = pygame.time.Clock()

# Инициализация машины
x, y = 400, 500      # позиция машины
width, height = 40, 60
vel = 5              # скорость движения

run = True
while run:
    clock.tick(60)   # максимум 60 кадров в секунду

    # Обработка событий: закрытие окна
    for event in pygame.event.get():
        if event.type == pygame.QUIT:
            run = False

    # Ввод: движение стрелками
    keys = pygame.key.get_pressed()
    if keys[pygame.K_LEFT] and x > 0:
        x -= vel
    if keys[pygame.K_RIGHT] and x < 800 - width:
        x += vel

    # Рендер: очистка экрана и отрисовка машины
    win.fill((0, 0, 0))
    pygame.draw.rect(win, (255, 0, 0), (x, y, width, height))

    pygame.display.update()

pygame.quit()

Всего около 30 строк — и ваша первая рабочая игра готова; следующие уроки добавляют препятствия, столкновения, очки и экраны старта/конца.

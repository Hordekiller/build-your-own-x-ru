О книге

Ал Свейгарт — автор известных книг «Invent Your Own Computer Games with Python» и «Automate the Boring Stuff» — написал эту книгу для тех, кто уже выучил Python и хочет перейти к разработке игр. Книга полностью бесплатна (PDF скачивается с inventwithpython.com), а её уровень «средний»: предпосылка — основы Python (из его предыдущей книги).

Игры книги

Книга строит игры с полным кодом и построчными пояснениями:

  • Flippy (головоломка реверси/отэлло)
  • Ink Spill (пятиминутная игра)
  • Gemgem (игра на совпадение самоцветов)
  • Slide Puzzle и Simon
  • Star Pusher (сокобан)
  • Four in a Row, Memory Puzzle и Pong
  • и другие

Стиль обучения

Пример структуры кода книги — игровой цикл с событиями и рендером:

python# Общий паттерн игр книги
import pygame, sys
from pygame.locals import *

pygame.init()
FPS = 60
fpsClock = pygame.time.Clock()
DISPLAYSURF = pygame.display.set_mode((400, 300))
pygame.display.set_caption('Пример игры')

WHITE = (255, 255, 255)

while True:
    for event in pygame.event.get():
        if event.type == QUIT:
            pygame.quit()
            sys.exit()

    # Отрисовка сцены
    DISPLAYSURF.fill(WHITE)
    # ... рисование игровых объектов ...

    pygame.display.update()
    fpsClock.tick(FPS)

Фишка книги: каждая игра полная и запускается сразу; упражнения после каждой главы развивают креативность.

Итоги

  • Бесплатно, скачиваемо и полностью практично — десять полных игр с полным кодом.
  • Подходит после основ Python; хороший мост к настоящей разработке игр.
  • Код игр работает на любой платформе (Windows, Linux, Mac).

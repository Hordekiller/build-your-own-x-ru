Игра на React и SVG

Об обучении

Этот урок показывает, как строится настоящая игра — без игрового движка! — на React + Redux + SVG. Игра «Aliens, Go Home!» проста: пушка (cannon) внизу экрана, в которую вы целитесь мышью и стреляете по летающим тарелкам. Проект бутстрапится через create-react-app, а полный код доступен на GitHub (вместе с пошаговыми версиями).

Совет: если вы уже уверенно работаете с Redux, этот урок отлично подойдёт: архитектура игры (state в виде чистых объектов, actions и reducers) спроектирована очень аккуратно.

Архитектура: игра в стиле React

  • Центральный state в Redux: позиции тарелок, пуль и пушки; всё в одном store.
  • Рендеринг через SVG: каждый элемент игры (пушка, тарелка, пуля) — SVG-компонент.
  • Обновление через requestAnimationFrame: цикл, который каждый кадр диспатчит action и двигает state.
  • Столкновения и простая физика: вычисления внутри reducer'а или чистых хелперов.

Пример кода: игровой компонент

jsx// Компонент пушки: позиция берётся из state
const Cannon = ({ x, y }) => (
  <g>
    <polygon
      points="0,32 0,60 20,60 20,32"
      transform={`translate(${x}, ${y}) rotate(180)`}
      style={{ fill: '#000' }}
    />
  </g>
);

// Игровой цикл: каждый кадр диспатчит игровой тик
const Game = ({ shots, aliens, cannon }) => (
  <svg width="1000" height="600">
    <Cannon x={cannon.x} y={cannon.y} />
    {shots.map((shot) => (
      <circle key={shot.id} cx={shot.x} cy={shot.y} r="4" />
    ))}
    {aliens.map((alien) => (
      <circle key={alien.id} cx={alien.x} cy={alien.y} r="15" />
    ))}
  </svg>
);

// В componentDidMount запускается цикл кадров requestAnimationFrame
componentDidMount() {
  this.loopId = requestAnimationFrame(this.tick);
}
tick = () => {
  const { dispatch } = this.props;
  dispatch(moveAliensDown());   // движение тарелок
  dispatch(moveShotsUp());      // движение пуль
  dispatch(checkCollisions());  // столкновения
  this.loopId = requestAnimationFrame(this.tick);
};

  • Чистая архитектура: вся логика чистая и тестируемая (reducers).

Об обучении

Roguelike-игры — с ASCII-графикой, случайно генерируемыми подземельями и постоянной смертью — один из лучших жанров для обучения программированию игр: вся логика выполняется в терминале, и графика не нужна. В этом плейлисте создаётся полная игра в стиле Rogue/Nethack: генерация случайной карты, персонаж и характеристики, пошаговые бои, предметы и спуск по этажам подземелья.

Ключевые концепции

Структура roguelike-игр — отображение мира сеткой символов и пошаговый цикл:

c// Карта подземелья: сетка символов
#define WALL '#'
#define FLOOR '.'
#define PLAYER '@'
#define MONSTER 'M'
#define ITEM '$'

char map[MAP_H][MAP_W];

// Случайная генерация карты «комнаты и коридоры»
void generate_map(void) {
  // Размести случайные комнаты и соедини их коридорами
  for (int i = 0; i < NUM_ROOMS; i++) {
    make_room(x, y, w, h);
    connect_rooms(prev_x, prev_y, x, y);
  }
}

// Главный цикл: ход игрока → ходы врагов
void game_loop(void) {
  while (player_alive) {
    render_map();          // отображение в терминале
    int key = get_input(); // чтение клавиши (движение/действие)
    move_player(key);
    // Пошаговый бой: каждый враг делает ход
    for (int i = 0; i < num_monsters; i++) {
      move_monster(&monsters[i]);  // преследование игрока
      check_fight(&monsters[i]);   // атака при столкновении
    }
    check_items();  // подбор предметов
    check_descent(); // спуск на следующий этаж
  }
}

Серия использует библиотеку ncurses для полноэкранного вывода в терминале и чтения клавиш без Enter.

Итоги

Создание roguelike охватывает все базовые навыки разработки игр: игровой цикл, управление состоянием, случайную генерацию и проектирование систем — без путаницы графики. Видео серии идут с полным кодом и отлично подходят для старта.

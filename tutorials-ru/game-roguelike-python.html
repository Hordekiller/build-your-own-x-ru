Об обучении

Этот сайт — дом одного из самых известных roguelike-туториалов: раньше он был основан на libtcod, а в 2019 году был переписан под python-tcod. Новая версия отличается чистой архитектурой (выделение зависимостей, отдельные файлы вроде engine.py) и в последовательных частях строит полный roguelike: от отрисовки «@» в терминале до сложных систем.

Совет: первая часть обеих версий (старой и новой) — «отрисовка @»; дальше движение, ввод, FOV и далее — лучшая отправная точка для первого roguelike на Python.

Карта частей

  • Отрисовка символа «@» и движение клавишами
  • Терминал и ввод (с tcod и keydown)
  • Генерация подземелья с комнатами и коридорами
  • Поле зрения (FOV) и исследование
  • Столкновения, пошаговый цикл и управление игроком
  • Монстры, атака и урон
  • Глубокие игровые системы: инвентарь, снаряжение, заклинания
  • Сохранение, уровни и далее

Пример кода первой части

python# engine.py — ядро игры (новая версия)
import tcod

from input_handlers import EventHandler

class Engine:
    def __init__(self, event_handler: EventHandler):
        self.event_handler = event_handler

    def handle_events(self, events) -> None:
        for event in events:
            action = self.event_handler.dispatch(event)
            if action is None:
                continue
            action.perform(self, self.player)
            # ...

def main() -> None:
    screen_width = 80
    screen_height = 50

    tileset = tcod.tileset.load_tilesheet(
        "dejavu10x10_gs_tc.png", 32, 8, tcod.tileset.CHARMAP_TCOD
    )

    with tcod.context.new_terminal(
        columns=screen_width,
        rows=screen_height,
        tileset=tileset,
        title="Мой Roguelike",
    ) as context:

        event_handler = EventHandler()
        engine = Engine(event_handler)

        while True:
            root_console = tcod.console.Console(screen_width, screen_height)
            # ... отрисовка сцены на консоли ...

            context.present(root_console)  # показ
            events = tcod.event.wait()     # ожидание события
            root_console.clear()
            engine.handle_events(events)

if __name__ == "__main__":
    main()

Что такое RogueSharp

RogueSharp — open-source библиотека C# для roguelike-игр, которая берёт на себя тяжёлую работу: генерацию карты подземелья, поле зрения (Field of View), поиск пути (Pathfinding) и проверку линии видимости (Line of Sight). В обучении RogueSharp v3 сочетается с RLNET (для терминального рендера) — а более старая версия v2 также покрывалась с MonoGame.

Совет: если вы хотите писать всю логику roguelike самостоятельно, другие разделы этого сайта (то самое известное обучение «How to Make Your First Roguelike») относятся к той же теме.

Карта уроков

Серия уроков пошагово покрывает:

  • Настройка проекта RLNET и отображение первого «@»
  • Построение карты и случайная генерация подземелья (комнаты и коридоры)
  • Поле зрения с алгоритмом FOV и открытые стены
  • Движение и взаимодействие: ходьба, открытие дверей
  • Поиск пути врагов к игроку (Pathfinding)
  • Бой: монстры, атака, урон и смерть
  • Система предметов, шрифты и палитра, сохранение игры

Пример кода: карта и поле зрения

csharpusing RogueSharp;
using RogueSharp.MapCreation;

// Построение карты случайным генератором подземелья (как в Rogue)
IMapCreationStrategy<Map> strategy =
    new RandomRoomsMapCreationStrategy<Map>(width: 80, height: 50,
                                            maxRooms: 30, roomMaxSize: 12, roomMinSize: 6);
Map map = Map.Create(strategy);

// Вычисление поля зрения от взгляда игрока
map.ComputeFov(x: playerX, y: playerY, radius: 10, lightWalls: true);

// Обход карты и отрисовка: показывать только «видимые»
// или «открытые» клетки
foreach (Cell cell in map.GetAllCells())
{
    if (cell.IsInFov)
        // освещено — отрисовка клетки
    else if (cell.IsExplored)
        // темно, но уже видели — отрисовка приглушённым цветом
}

Так достигается классическое ощущение «неизведанной темноты» roguelike-игр — без переписывания алгоритма FOV.

Итоги

  • RogueSharp выдаёт тяжёлую работу готовой (FOV, pathfinding, генерация карт); ваш фокус — на геймплее.
  • Официальная серия уроков полная и актуальная; код каждого урока дополняет предыдущий.
  • Хороший путь: сначала эта серия, затем переписывание логики (например, FOV) вручную для глубокого понимания.

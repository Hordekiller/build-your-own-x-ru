О чём это

RPG на C#: персонаж, инвентарь, битвы и диалоги — консольная RPG, программируемая с нуля.

Что вы узнаете

  • Персонаж и инвентарь
  • Боевая система
  • Диалоги и квесты
  • Сохранение

Основная идея

RPG — это данные и состояния: герой, предметы, бои, сюжет. C# облегчает управление сущностями.

Классическая сущность раунда:

C#public class Hero {
    public string Name { get; set; }
    public int Hp { get; set; }
    public int Attack { get; set; }
    public List<Item> Inventory { get; set; }
}

Почему это важно

RPG на консоли — полный спектр дизайна: вы спроектируете систему сущностей, которая пригодится в любых играх.

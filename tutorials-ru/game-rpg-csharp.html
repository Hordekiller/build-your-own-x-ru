О курсе

Этот бесплатный курс учит C# на реальном проекте: простом текстовом RPG без графики — с 9 локациями, 3 монстрами, 2 видами оружия и 2 квестами. Всё начинается «с нуля»: даже установка Visual Studio разбирается отдельно. Результат: полное понимание классов, свойств (properties), функций, условий и циклов — лучшее для старта.

Совет: курс полностью рассчитан на новичков: если вы не написали ни строчки кода, это подходящий курс; каждая концепция объясняется на примере из игры.

Структура уроков

  • Установка инструментов и создание первого проекта
  • Структура программы, namespace и using
  • Переменные, типы данных и преобразования
  • Функции и параметры; вывод и возврат
  • Классы: создание питомца, оружия, монстра и снаряжения
  • Ввод пользователя и условия (if/switch)
  • Циклы и хранение в списках
  • Управление пошаговым боем, квестами и магией

Пример кода: класс игрового объекта

csharp// Базовый класс всех игровых объектов
public class WorldObject
{
    public int ID { get; set; }
    public string Name { get; set; }
    public string Description { get; set; }

    public WorldObject(int id, string name, string description)
    {
        ID = id;
        Name = name;
        Description = description;
    }
}

// Класс, наследующий от базового: оружие
public class Weapon : WorldObject
{
    public int MaximumDamage { get; set; }

    public Weapon(int id, string name, string description, int maximumDamage)
        : base(id, name, description)
    {
        MaximumDamage = maximumDamage;
    }
}

Точно так же создаются классы Monster, Quest, Location и Player, а затем из них строится игровой мир — локации, существа и предметы.

Итоги

В конце курса у вас есть небольшая, но полная игра: вы перемещаетесь по локациям, сражаетесь с монстрами, подбираете оружие и снаряжение и выполняете квесты. После этого курса лучший следующий шаг — версия WPF с графикой (SOSCSRPG того же автора).

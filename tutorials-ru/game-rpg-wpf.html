О курсе

Эта серия уроков строит полноценную RPG с графическим интерфейсом: перемещение по двумерному миру, пошаговые бои, предметы, квесты и торговые комнаты. Отличие курса от «простой RPG»: настоящий пользовательский интерфейс на WPF/XAML и более правильная архитектура (слои и принципы проектирования). Для входа нужен базовый C# (из предыдущего курса автора).

Замечание: начиная с урока «03.1 Создание Solution» и «04.2 Создание класса World с объектами Location», структура проекта объясняется полностью.

Структура архитектуры

Курс знакомит со слоистой архитектурой, в которой игровой мир полностью независим от пользовательского интерфейса:

textSimpleRPG/                  # Solution
├── SimpleRPG/               # главный проект WPF
│   ├── MainWindow.xaml      # пользовательский интерфейс
│   └── ViewModels/          # слой привязки данных к UI
├── SimpleRPG.Engine/        # игровой движок (без зависимостей от UI)
│   ├── World.cs             # локации и связи
│   ├── GameItems.cs         # предметы
│   ├── Quest.cs             # квесты
│   └── Monster.cs           # монстры
└── SimpleRPG.Core/          # общая библиотека (опции, логи)

Пример кода: классы World и Location

csharp// Класс Location — место на игровой карте
public class Location
{
    public int X { get; set; }
    public int Y { get; set; }
    public string Name { get; set; }
    public string Description { get; set; }

    public Location North { get; set; }
    public Location East  { get; set; }
    public Location South { get; set; }
    public Location West  { get; set; }

    // объекты в этой локации
    public Item ItemAvailableHere { get; set; }
    public Quest QuestAvailableHere { get; set; }
    public Monster MonsterLivingHere { get; set; }
}

// World: список локаций и построение карты
public static class World
{
    public static readonly List<Location> Locations = new List<Location>();

    // статический конструктор: определение локаций и их связей
    static World()
    {
        Location home = new Location { X = 0, Y = -1, Name = "Дом", ... };
        Location farm = new Location { X = 0, Y = 0, Name = "Старая ферма", ... };
        farm.North = home;
        home.South = farm;
        Locations.Add(home);
        Locations.Add(farm);
        // ...
    }

    public static Location LocationAt(int x, int y)
        => Locations.FirstOrDefault(l => l.X == x && l.Y == y);
}

Итог

  • Разделение Engine (логика) и UI (WPF) — та самая профессиональная архитектура.

  • Итог: полноценная игра с сохранением/загрузкой, боями и экономикой.

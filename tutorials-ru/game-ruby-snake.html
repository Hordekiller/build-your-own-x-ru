Об обучении

Эта статья показывает, что разработка игр на Ruby вполне возможна и приятна: в терминале создаётся игра «Змейка», и преподаётся структурированный образ мышления (классы Board, Snake, Food и Game) — без графики, на терминальных символах.

Совет: статья одновременно знакомит и с геймдевом, и с «чистой структурой игровых концепций»: у неё отличная разбивка по классам.

Структура классов

Набор классов и их обязанности:

ruby# Игровое поле: сетка и границы
class Board
  attr_accessor :grid_size, :x_limit, :y_limit

  def initialize(grid_size)
    @grid_size = grid_size
    @x_limit = @grid_size / 2   # координаты от -limit до +limit
    @y_limit = @grid_size / 2
  end

  def random_position
    [rand(-@x_limit..@x_limit), rand(-@y_limit..@y_limit)]
  end

  def within?(x, y)
    x.between?(-@x_limit, @x_limit) && y.between?(-@y_limit, @y_limit)
  end
end

# Еда: случайная точка
class Food
  attr_accessor :x, :y

  def initialize(board)
    @board = board
    spawn
  end

  def spawn
    @x, @y = @board.random_position
  end
end

# Змейка: последовательность сегментов
class Snake
  attr_accessor :body, :direction_head, :poisoning

  def initialize(length)
    @direction_head = [1, 0]
    @body = Array.new(length) { |i| [0, i] }
    @poisoning = false
  end

  def head
    @body.first
  end

  # Шаг: новая голова вперёд, хвост удаляется, если не поели
  def move(food_eaten = false)
    new_head = [head[0] + @direction_head[0], head[1] + @direction_head[1]]
    @body.unshift(new_head)
    @body.pop unless food_eaten
  end
end

Главный игровой цикл

rubyclass Game
  def initialize
    @board = Board.new(32)
    @snake = Snake.new(3)
    @food = Food.new(@board)
  end

  def run
    loop do
      input          # смена направления клавишами
      moved          # шаг змейки
      break if collision   # стена или сама себя
      eat            # поедание и рост
      render         # отрисовка поля в терминале
      sleep(0.1)
    end
  end
end

Интересная алгоритмическая деталь статьи: змейка реализована через body.unshift(new_head) и условный pop — то есть естественный рост при поедании еды без лишнего кода.

Итоги

  • Разработка игр на Ruby возможна так же просто, как на любом другом языке.
  • Чистая классовая структура (Board/Snake/Food/Game) — хороший паттерн для любой игры.
  • Терминал — отличная база для старта; графический UI можно добавить позже.

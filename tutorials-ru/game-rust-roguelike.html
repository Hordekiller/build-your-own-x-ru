Рогалик на Rust

Об обучении

Эта известная серия строит классический roguelike в стиле Roguebasin: ASCII-сетка, случайные подземелья, движение клавишами, поле зрения, поиск пути и монстры. Rust-версия — концептуальный перевод знаменитого Python-туториала (python/libtcod), и каждая часть доступна и в блоге, и в GitHub-репозитории (tomassedovic/roguelike-tutorial).

Совет: если вы раньше не делали roguelike, сначала посмотрите Python-версию (rogueliketutorials.com); эта версия предполагает знание концепций и фокусируется на их переводе на Rust.

Карта частей

  • Настройка проекта и отображение «@»
  • Движение клавишами и ввод с клавиатуры/мыши
  • Генерация подземелья (комнаты, коридоры и тоннели)
  • Поле зрения (FOV) с алгоритмом
  • Монстры и простой ИИ (преследование)
  • Сохранение через serde, предметы и пошаговый цикл

Пример кода

rustuse tcod::console::*;
use tcod::colors;

// Главная структура игры: игрок + карта + консоль
struct Game {
    player: Player,
    map: Map,
}

// Главный цикл с tcod
fn main() {
    let mut root = Root::initializer()
        .font("arial10x10.png", FontLayout::Tcod)
        .font_type(FontType::Greyscale)
        .size(SCREEN_WIDTH, SCREEN_HEIGHT)
        .title("Roguelike на Rust")
        .init();

    let mut con = Offscreen::new(SCREEN_WIDTH, SCREEN_HEIGHT);
    let mut game = Game::new();

    while !root.window_closed() {
        // Отрисовка карты и игрока на con
        game.render(&mut con);

        // Копирование con в root и показ
        blit(&con, (0, 0), (SCREEN_WIDTH, SCREEN_HEIGHT), &mut root, (0, 0), 1.0);
        root.flush();

        // Ввод: пересчёт поля зрения при каждом движении
        let key = root.wait_for_keypress(true);
        game.handle_key(key);
    }
}

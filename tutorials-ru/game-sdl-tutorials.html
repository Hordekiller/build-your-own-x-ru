Что такое SDL и почему Lazy Foo

SDL (Simple DirectMedia Layer) — open-source библиотека C/C++ для низкоуровневого доступа к графике, звуку, вводу и окнам; именно на ней построено множество игр и движков (даже эмуляторов). Уроки Lazy Foo — самый известный ресурс для старта с SDL 2: нумерованные уроки, полный скачиваемый код и подробное объяснение каждой концепции.

Совет: серия движется «от консоли к рендерингу в реальном времени»: сначала вы знакомитесь с первым окном и рендером текстуры, а постепенно приходите к полноценным системам (tiling, ввод с мыши/клавиатуры/геймпада, звук и видео).

Карта уроков

  • Уроки 1–5: установка, первое окно, рендер изображения и цикл событий
  • Уроки 6–10: текстуры, загрузка изображений (PNG через libpng), программный и аппаратный рендеринг
  • Уроки 11–15: движение клавиатурой и мышью, контроллеры, клиппинг
  • Уроки 16–20: звук (WAV и потоковое воспроизведение), tiling со sprite sheet, столкновения, шрифты (TTF)
  • Уроки 21–25: продвинутое: синхронизация дисплея (vsync), формат пикселей, анимированные спрайты
  • Далее: геймпад, запись экрана, композитинг и даже введение в Vulkan/SDL3

Пример первой программы

cpp// Урок 01: первое окно
#include <SDL.h>
#include <cstdio>

int main(int argc, char *argv[]) {
  if (SDL_Init(SDL_INIT_VIDEO) < 0) {
    printf("Не удалось инициализировать SDL! Ошибка: %s\n", SDL_GetError());
    return 1;
  }

  SDL_Window *window = SDL_CreateWindow(
    "Первое окно",              // заголовок
    SDL_WINDOWPOS_UNDEFINED,    // позиция x
    SDL_WINDOWPOS_UNDEFINED,    // позиция y
    SCREEN_WIDTH, SCREEN_HEIGHT,
    SDL_WINDOW_SHOWN
  );
  if (window == NULL) { printf("Окно не создано: %s\n", SDL_GetError()); return 1; }

  SDL_Surface *screen = SDL_GetWindowSurface(window);
  // Заливка поверхности окна
  SDL_FillRect(screen, NULL, SDL_MapRGB(screen->format, 0xFF, 0xFF, 0xFF));
  SDL_UpdateWindowSurface(window);

  // Цикл событий: пока окно не закрыто
  bool quit = false;
  SDL_Event e;
  while (!quit) {
    while (SDL_PollEvent(&e) != 0) {
      if (e.type == SDL_QUIT) quit = true;
    }
  }

  SDL_DestroyWindow(window);
  SDL_Quit();
  return 0;
}

Процесс каждого урока одинаков: инициализация ← цикл событий ← рендер ← очистка. Повторяя этот паттерн, в следующих уроках вы добавляете новые слои (текстуры, ввод, звук).

Итоги

  • Lazy Foo — лучшая отправная точка для SDL 2: уроки самодостаточны, код полный.
  • Каждый урок учит новому слою разработки игр (графика, ввод, звук, столкновения).
  • Для запуска кода достаточно библиотеки SDL2 и компилятора C++; примеры работают на Windows, Linux и Mac.

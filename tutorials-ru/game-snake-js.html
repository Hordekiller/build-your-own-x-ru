Главная идея: мыслить как программист

Цель статьи — не просто «сделать игру Змейка», а показать образ мышления программиста: вместо написания кода целиком разбейте задачу на маленькие решаемые части: (1) как отобразить змейку? (2) как она движется? (3) как ест и растёт? (4) как проигрываем? (5) как считать очки? В конце все части собираются в один файл snake.html.

Отображение змейки: массив координат

Змейка — это «массив координат» на сетке 20×20; голова — первый элемент, еда — случайная точка:

js// Змейка: массив [x, y]
let snake = [
  [9, 9],  // голова
  [8, 9],  // тело
  [7, 9],
];

let direction = [1, 0]; // движение вправо

// Сетка: canvas 400×400 с ячейками по 20 пикселей
const CELL = 20;
const GRID = 20;

function draw() {
  ctx.clearRect(0, 0, canvas.width, canvas.height);
  snake.forEach(([x, y]) => {
    ctx.fillStyle = 'green';
    ctx.fillRect(x * CELL, y * CELL, CELL - 1, CELL - 1);
  });
  // Еда
  ctx.fillStyle = 'red';
  ctx.fillRect(food[0] * CELL, food[1] * CELL, CELL - 1, CELL - 1);
}

Движение: unshift и pop

Движение змейки использует изящное правило: добавь сегмент к голове (unshift) и, если еда не съедена, удали последний сегмент (pop) — именно это обеспечивает движение и рост:

jsfunction gameStep() {
  // Новая голова
  const head = snake[0];
  const newHead = [head[0] + direction[0], head[1] + direction[1]];

  // Столкновение со стеной или собой → конец игры
  const hitWall = newHead[0] < 0 || newHead[0] >= GRID ||
                  newHead[1] < 0 || newHead[1] >= GRID;
  const hitSelf = snake.some(([x, y]) => x === newHead[0] && y === newHead[1]);
  if (hitWall || hitSelf) { gameOver(); return; }

  snake.unshift(newHead);

  // Еда съедена?
  if (newHead[0] === food[0] && newHead[1] === food[1]) {
    score++;
    food = randomFood();      // новая еда
  } else {
    snake.pop();              // без роста: хвост удаляется
  }
  draw();
}

// Игровой цикл
setInterval(gameStep, 100);

Ввод с клавиатуры

jsdocument.addEventListener('keydown', (e) => {
  // Запрет движения сразу в обратную сторону
  const keyMap = {
    ArrowUp:    [0, -1],
    ArrowDown:  [0, 1],
    ArrowLeft:  [-1, 0],
    ArrowRight: [1, 0],
  };
  const d = keyMap[e.key];
  if (d) {
    if (d[0] !== -direction[0] || d[1] !== -direction[1]) {
      direction = d;
    }
    e.preventDefault();
  }
});

Итоги

  • Разбейте задачу: отображение ← движение ← рост ← поражение ← очки; каждая часть укладывается в несколько строк кода.
  • Змейка как массив координат + unshift/pop — простейшая и самая правильная модель.
  • Вся игра в одном файле — открыл и играешь.

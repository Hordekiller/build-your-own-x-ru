Об обучении

Space Invaders (1978) — одна из самых простых и одновременно самых полных игр для реконструкции. Этот урок строит её на OpenGL 3.3 (современный конвейер с GLSL-шейдерами), а не на старом OpenGL. Инструменты: GLFW для окон и ввода и GLEW для загрузки функций OpenGL. Итог — работающая игра на современных графических техниках.

Совет: серия отлично подходит тем, кто хочет и игры делать, и всерьёз учить современный OpenGL: вы пишете шейдеры и настраиваете VBO/VAO.

Структура серии

  • Часть 1: создание окна с GLFW, буферы и первый шейдер
  • Часть 2: отрисовка игрока (глайдер) и физика движения
  • Часть 3: пули и стрельба
  • Часть 4: враги — движение, отражение и удаление
  • После этого: коллизии, очки, уровни и классический стиль игры

Пример кода: рендер с шейдером

cpp// Простой четырёхугольник с VBO и шейдером
float vertices[] = {
  // позиция    // цвет
  -0.5f, -0.5f, 1.0f, 1.0f, 1.0f,
   0.5f, -0.5f, 1.0f, 1.0f, 1.0f,
   0.5f,  0.5f, 1.0f, 1.0f, 1.0f,
  -0.5f,  0.5f, 1.0f, 1.0f, 1.0f,
};
unsigned int indices[] = { 0, 1, 2, 2, 3, 0 };

GLuint VBO, VAO, EBO;
glGenVertexArrays(1, &VAO);
glGenBuffers(1, &VBO);
glGenBuffers(1, &EBO);

glBindVertexArray(VAO);
glBindBuffer(GL_ARRAY_BUFFER, VBO);
glBufferData(GL_ARRAY_BUFFER, sizeof(vertices), vertices, GL_STATIC_DRAW);
glBindBuffer(GL_ELEMENT_ARRAY_BUFFER, EBO);
glBufferData(GL_ELEMENT_ARRAY_BUFFER, sizeof(indices), indices, GL_STATIC_DRAW);

// Атрибуты: позиция (3 числа) и цвет (3 числа)
glVertexAttribPointer(0, 3, GL_FLOAT, GL_FALSE, 6 * sizeof(float), (void*)0);
glEnableVertexAttribArray(0);
glVertexAttribPointer(1, 3, GL_FLOAT, GL_FALSE, 6 * sizeof(float), (void*)(3 * sizeof(float)));
glEnableVertexAttribArray(1);

После этого все игровые объекты (игрок, враги, пули) рисуются по одному паттерну VAO/VBO с одним шейдером; меняется только их позиция через uniform.

Об обучении

Судоку — классическая «интеллектуальная игра», и создание её решателя — отличная практика рекурсии и алгоритма backtracking на C. В этом плейлисте создаётся программа, которая читает любую доску судоку с ввода и решает её — с построчным объяснением логики.

Совет: backtracking — та же базовая техника, что используется в решении головоломок, поиске пути (например, робот в лабиринте) и даже в шахматных движках — учить её на судоку очень наглядно.

Основной алгоритм

Сердце программы — рекурсивная функция решения, реализуемая в серии:

c// Доска судоку 9×9 — пустая клетка обозначена 0
int board[9][9];

// Проверка, допустимо ли разместить num в (row, col)
int is_safe(int row, int col, int num) {
  // Проверка строки и столбца
  for (int i = 0; i < 9; i++) {
    if (board[row][i] == num || board[i][col] == num) return 0;
  }
  // Проверка квадрата 3×3
  int box_r = (row / 3) * 3, box_c = (col / 3) * 3;
  for (int i = 0; i < 3; i++)
    for (int j = 0; j < 3; j++)
      if (board[box_r + i][box_c + j] == num) return 0;
  return 1;
}

// Рекурсивное решение с backtracking
int solve(void) {
  for (int row = 0; row < 9; row++) {
    for (int col = 0; col < 9; col++) {
      if (board[row][col] == 0) {         // найдена пустая клетка
        for (int num = 1; num <= 9; num++) {
          if (is_safe(row, col, num)) {
            board[row][col] = num;        // предположи
            if (solve()) return 1;        // продолжай — решено?
            board[row][col] = 0;          // не вышло → вернись (backtrack)
          }
        }
        return 0;                         // ни одно число не подошло
      }
    }
  }
  return 1; // все клетки заполнены — решено
}

Этого простого алгоритма мгновенно хватает почти для всех обычных судоку. В видео также разбираются чтение ввода из файла, отображение доски и простые оптимизации (например, начало с клетки с наименьшим числом вариантов).

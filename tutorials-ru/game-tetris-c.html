История статьи

Много лет назад Бреннан написал тетрис, и эта статья — рассказ о переписывании его с нуля: что было плохо в первой версии, какие уроки он вынес из разработки и как написал вторую версию с лучшей архитектурой и более чистым кодом. Итог работы — два файла: tetris.c (полная игровая логика — без каких-либо зависимостей от интерфейса) и main.c (слой отображения на ncurses).

Совет: разделение «игровой логики» и «рендера» — ровно та архитектура, что используют профессиональные игры: можно заменить интерфейс (например, на графический), не трогая логику.

Структура кода

Логика тетриса включает: игровое поле (board), фигуры (тетромино), вращение, столкновения, удаление линий и систему очков:

c// tetris.c — чистая логика игры
// Игровое поле: матрица 20×10
static int board[BOARD_ROWS][BOARD_COLS];

// Определение 7 фигур матрицами 4×4 (каждая фигура со своими вращениями)
typedef struct {
  int shape[4][4];
} Tetromino;

static const Tetromino pieces[] = {
  // I, O, T, S, Z, J, L
};

// Проверка столкновения фигуры с полем или предыдущими фигурами
static int collides(const Tetromino *piece, int row, int col) {
  for (int r = 0; r < 4; r++)
    for (int c = 0; c < 4; c++)
      if (piece->shape[r][c] && (board[row + r][col + c] || out_of_bounds))
        return 1;
  return 0;
}

// Размещение фигуры на поле
static void place_piece(const Tetromino *piece, int row, int col) {
  for (int r = 0; r < 4; r++)
    for (int c = 0; c < 4; c++)
      if (piece->shape[r][c]) board[row + r][col + c] = 1;
}

// Удаление заполненных линий — снизу вверх
static int clear_lines(void) {
  int cleared = 0;
  for (int r = BOARD_ROWS - 1; r >= 0; r--) {
    if (row_full(r)) {
      shift_rows_down(r);
      cleared++;
      r++; // проверить ту же строку снова
    }
  }
  return cleared;
}

Интерфейс с ncurses

Слой отображения (main.c) использует только ncurses: отрисовка поля, чтение клавиш (движение, вращение, быстрое падение) и вывод счёта. Каждые 100 удалённых линий добавляется новый уровень — игра ускоряется.

c// main.c — отображение и ввод
#include <curses.h>
#include "tetris.h"

int main(void) {
  initscr();      // запуск ncurses
  cbreak();       // чтение клавиш без Enter
  noecho();
  keypad(stdscr, TRUE);
  nodelay(stdscr, TRUE); // неблокирующий ввод

  Game *game = game_new();
  while (!game->over) {
    int key = getch();
    // Преобразование клавиш в игровые действия
    if (key == KEY_LEFT)  game_move(game, LEFT);
    if (key == KEY_RIGHT) game_move(game, RIGHT);
    if (key == KEY_UP)    game_rotate(game);
    if (key == KEY_DOWN)  game_tick(game);
    // ...
    draw(game);           // отрисовка поля, текущей и следующей фигур
    usleep(100000 / game->level);
  }

  endwin();
  return 0;
}

Запуск: make, затем ./tetris — зависимости: терминал и библиотека ncurses.

Итоги

  • Тетрис — лучшая «первая игра»: логика простая, но полная (фигура, вращение, столкновение, удаление линий).
  • Двухслойная архитектура (логика/отображение) оправдывает себя при переписывании.
  • Переписывание старого проекта — одно из лучших упражнений для обучения.

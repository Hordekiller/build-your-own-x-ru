Главная идея: отделение логики от графики

Класс Board (логика) ничего не знает о графике: ни SDL, ни OpenGL, ни окон. Только матрицы и простые функции — а значит, игровой код работает на любой платформе (десктоп, мобильные, веб) с любой библиотекой. В уроке логика отображается через SDL 1.2, но фокус статьи — на самой логике.

Совет: этот подход — лучшая практика для понимания того, «почему профессиональные игры отделяют движок от игры».

Представление фигур матрицами

Каждая фигура (тетромино) и само игровое поле — матрицы; простейший и одновременно самый мощный способ представить сетку тетриса:

cpp// Игровое поле: матрица
const int BOARD_WIDTH  = 10;
const int BOARD_HEIGHT = 20;
int board[BOARD_WIDTH * BOARD_HEIGHT]; // 0 = пусто, 1 = занято

// Каждая фигура задаётся матрицей 2×2, 3×3 или 4×4
// Пример: фигура L
int pieceL[4][4] = {
  { 0, 0, 0, 0 },
  { 1, 1, 1, 0 },
  { 1, 0, 0, 0 },
  { 0, 0, 0, 0 },
};

Хак вращения без сложной математики

Вместо вычисления поворота матричным умножением каждая фигура имеет четыре предопределённых состояния вращения, и при повороте меняется только индекс состояния:

cpp// Вращение: переход к следующему состоянию — у каждой фигуры 4 состояния
void rotate(int x, int y, int rotation) {
  switch (rotation) {
    case 0: // базовое состояние (та же матрица)
      ...
    case 1: // поворот на 90 градусов — вычислено заранее
      ...
    // ...
  }
}

Почему это работает: у поворота на 90 градусов всего 4 состояния для каждой фигуры, и их можно заранее выписать на бумаге; никакая формула вращения не нужна.

Столкновения и главный цикл

cpp// Проверка столкновения: помещается ли фигура в (x, y)
// при данном вращении?
bool Board::isFreeBlock(int pX, int pY, int pType, int pRotation) {
  // Сравни каждую ненулевую клетку матрицы фигуры с полем
  for (int i1 = pX, i2 = 0; i1 < pX + size(pType); i1++, i2++) {
    for (int j1 = pY, j2 = 0; j1 < pY + size(pType); j1++, j2++) {
      if (getBlock(i2, j2, pType, pRotation) != 0 && isBlock(i1, j1)) {
        return false; // пересечение → столкновение
      }
    }
  }
  return true;
}

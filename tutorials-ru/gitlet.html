О чём это

Gitlet реализует git на JavaScript: commit, branch, merge и diff — подмножество git, работающее локально.

Что вы узнаете

  • Объектная модель: blob, tree, commit
  • Коммиты и ветки
  • Слияние (merge)
  • Сравнение (diff)

Основная идея

Git — система объектной модели: blob — содержимое, tree — структура, commit — история. Gitlet повторяет все шаги подмножества на JS.

Хеш коммита — sha1 содержимого:

JavaScriptfunction commitHash(treeHash, parentHash, msg) {
  return sha1(treeHash + parentHash + msg);
}

Почему это важно

Поняв объектную модель git, вы перестанете бояться команд и конфликтов: Gitlet — лучший учебник по git изнутри.

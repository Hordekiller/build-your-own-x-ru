Пишем lolcat на Go

⚙ Язык: Go 📁 Инструмент командной строки 🌐 Русская страница 🔗 Оригинальный источник
Оригинальный источник: «Build a Command line app with Go: lolcat»
↗ Перейти к оригинальному уроку فارسی — Персидская версия EN — English version

Введение

Научитесь создавать CLI-инструмент вроде lolcat на Go, который раскрашивает текст в радужные цвета с помощью ANSI-escape-кодов и функции rgb() и работает как пайп (pipe), читая из stdin.

Подсказка: интересуетесь CLI-приложениями? Не пропустите учебник по cowsay!

Я искал терминальные приложения для вдохновения и наткнулся на lolcat.

Оригинал — на https://github.com/busyloop/lolcat, и для него уже существует множество Go-реализаций:

  • https://github.com/cezarsa/glolcat
  • https://github.com/latotty/lolcat
  • https://github.com/lalyos/lolcat
  • https://github.com/vbatts/gogololcat

Похоже, строить его совершенно бесполезно; так давайте построим его!

Начнём с вывода нескольких значений на экран; затем займёмся их раскрашиванием и, наконец, разберёмся, как принимать пользовательский ввод, чтобы работать как пайп.

Генерация фиктивного вывода с faker

Для генерации фиктивного вывода использую https://github.com/enodata/faker.

shellgo get -u github.com/enodata/faker

Эта программа генерирует несколько фраз:

gopackage main

import (
    "fmt"
    "strings"

    "github.com/enodata/faker"
)

func main() {
    var phrases []string

    for i := 1; i < 3; i++ {
        phrases = append(phrases, faker.Hacker().Phrases()...)
    }

    fmt.Println(strings.Join(phrases[:], "; "))
}

Добавляем цвет

К сожалению, всё это чёрно-белое — скучно. Давайте добавим немного цвета. Сделаем это, поставив escape-последовательность (escape character sequence) в начало строки в fmt.Printf. Так все строки печатаются золотым цветом #FFD700, чей RGB-код равен (255,215,0):

gopackage main

import (
    "fmt"
    "strings"

    "github.com/enodata/faker"
)

func main() {
    var phrases []string

    for i := 1; i < 3; i++ {
        phrases = append(phrases, faker.Hacker().Phrases()...)
    }

    output := strings.Join(phrases[:], "; ")
    r, g, b := 255, 215, 0 // золотой цвет

    for j := 0; j < len(output); j++ {
        fmt.Printf("\033[38;2;%d;%d;%dm%c\033[0m", r, g, b, output[j])
    }
}

Радуга

Теперь, когда у нас есть строка и инфраструктура для раскрашивания каждого символа по-разному, пришло время радуги.

gopackage main

import (
    "fmt"
    "math"
    "strings"

    "github.com/enodata/faker"
)

func rgb(i int) (int, int, int) {
    var f = 0.1
    return int(math.Sin(f*float64(i)+0)*127 + 128),
        int(math.Sin(f*float64(i)+2*math.Pi/3)*127 + 128),
        int(math.Sin(f*float64(i)+4*math.Pi/3)*127 + 128)
}

func main() {
    var phrases []string

    for i := 1; i < 3; i++ {
        phrases = append(phrases, faker.Hacker().Phrases()...)
    }

    output := strings.Join(phrases[:], "; ")

    for j := 0; j < len(output); j++ {
        r, g, b := rgb(j)
        fmt.Printf("\033[38;2;%d;%d;%dm%c\033[0m", r, g, b, output[j])
    }
    fmt.Println()
}

Это уже стильно!

Радужный цвет генерируется функцией rgb() — так, как реализовано в оригинальном Ruby-исходнике на https://github.com/busyloop/lolcat/blob/master/lib/lolcat/lol.rb.

Работа в режиме пайпа (Pipe)

Теперь отредактируем программу: вместо генерации собственного вывода она будет работать как пайп для других программ. Она читает содержимое из os.Stdin и раскрашивает его в радужные цвета.

gopackage main

import (
    "bufio"
    "fmt"
    "io"
    "math"
    "os"
)

func rgb(i int) (int, int, int) {
    var f = 0.1
    return int(math.Sin(f*float64(i)+0)*127 + 128),
        int(math.Sin(f*float64(i)+2*math.Pi/3)*127 + 128),
        int(math.Sin(f*float64(i)+4*math.Pi/3)*127 + 128)
}

func print(output []rune) {
    for j := 0; j < len(output); j++ {
        r, g, b := rgb(j)
        fmt.Printf("\033[38;2;%d;%d;%dm%c\033[0m", r, g, b, output[j])
    }
    fmt.Println()
}

func main() {
    info, _ := os.Stdin.Stat()
    var output []rune

    if info.Mode()&os.ModeCharDevice != 0 {
        fmt.Println("The command is intended to work with pipes.")
        fmt.Println("Usage: fortune | gorainbow")
    }

    reader := bufio.NewReader(os.Stdin)
    for {
        input, _, err := reader.ReadRune()
        if err != nil && err == io.EOF {
            break
        }
        output = append(output, input)
    }

    print(output)
}

Каждый раз читается одна руна (rune) из os.Stdin и добавляется в срез (slice) рун output.

Вывод вынесен в функцию print(); но можно пайпить каждую руну «на лету» (just in time), как только она прочитана:

gopackage main

import (
    "bufio"
    "fmt"
    "io"
    "math"
    "os"
)

func rgb(i int) (int, int, int) {
    var f = 0.1
    return int(math.Sin(f*float64(i)+0)*127 + 128),
        int(math.Sin(f*float64(i)+2*math.Pi/3)*127 + 128),
        int(math.Sin(f*float64(i)+4*math.Pi/3)*127 + 128)
}

func main() {
    info, _ := os.Stdin.Stat()

    if info.Mode()&os.ModeCharDevice != 0 {
        fmt.Println("The command is intended to work with pipes.")
        fmt.Println("Usage: fortune | gorainbow")
    }

    reader := bufio.NewReader(os.Stdin)
    j := 0
    for {
        input, _, err := reader.ReadRune()
        if err != nil && err == io.EOF {
            break
        }
        r, g, b := rgb(j)
        fmt.Printf("\033[38;2;%d;%d;%dm%c\033[0m", r, g, b, input)
        j++
    }
}

Работает точно так же, как раньше.

Теперь можно развлекаться с fortune и cowsay.

Превращаем в системную команду

Сделаем программу системной командой (system-wide command) с помощью go build и go install. Команда будет называться gololcat, потому что так названа наша папка.

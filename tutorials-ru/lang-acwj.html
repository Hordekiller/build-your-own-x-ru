Самая реальная серия по сборке C-компилятора

Большинство уроков либо строят искусственный язык, либо ограничиваются маленьким подмножеством. Но курс Уоррена Туми (годы работы с настоящими компиляторами) строит компилятор SubC, поддерживающий большую часть настоящего языка C: все операторы, базовые типы, struct, union, enum, typedef, функции с переменным числом аргументов (varargs) и даже простой препроцессор.

Базовая архитектура: парсер Пратта

Первые части быстро закладывают основы: лексер с классами токенов, затем парсер, использующий «силу связывания» (binding power) и метод парсинга Пратта — современный способ, очень чисто обрабатывающий операторы с разными приоритетами:

C// Таблица приоритетов операторов
static struct {
  int token;
  int precedence;
} binop_prec[] = {
  { T_PLUS, 10 }, { T_MINUS, 10 },   // сложение/вычитание
  { T_STAR, 20 }, { T_SLASH, 20 },   // умножение/деление
  { T_EQ,   40 }, { T_NE, 40 },      // равенство
  ...
};

// Парсер бинарных операторов (Pratt)
static struct ASTnode *binexpr(int ptp) {
  struct ASTnode *left = unary();
  while (op_precedence(Token.token) > ptp) {
    int tok = Token.token;
    left = mkastnode(A_BINOP, left, NULL, tok, ...);
  }
  return left;
}

Главные шаги путешествия

Путешествие в 34 части: 1–5) основы lexer/parser и генерация ассемблера; 6–8) значения и логические операторы; 9–12) условия и циклы; 13–15) функции и вызовы (callq); 16–22) указатели и разыменование (самые напряжённые места!); 23–28) struct/union/enum и typedef; 29–31) varargs и препроцессор; 32–34) логические значения, лямбды и т.д.

Важно: каждая часть включает тесты, гарантирующие отсутствие регрессий, — как в настоящем проекте.

Пример кода: генерация ассемблера для умножения

Assembly# a = b * 3  →  сгенерированный код для x86-64
        movq    %rbx, %rax    # поместить b в rax
        imulq   $3, %rax, %rax   # умножение на 3
        movq    %rax, a(%rip) # сохранить в a

Итог

Если хотите понять, «как работает настоящий C-компилятор», acwj — лучший доступный источник: полная глубина, регулярные тесты, а в конце — компилятор, превращающий настоящие C-файлы в ассемблер.

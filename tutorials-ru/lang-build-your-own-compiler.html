Что вы создадите?

Этот учебник на Python строит полный компилятор для подмножества собственного языка программирования — и его выход — настоящий исполняемый файл x86-64, а не ассемблер! То есть конечный результат — бинарник, который напрямую запускается в операционной системе. Это отличает учебник от большинства «ассемблерных» руководств.

Путь обучения

Книга идёт маленькими шагами: (1) основы и первая программа; (2) целочисленная арифметика и операции; (3) переменные и память стека; (4) условия и циклы; (5) функции и вызовы; и в конце (6) управление вводом/выводом и машинные байты. В каждой главе есть все нужные файлы, и после любой главы вы можете проверить результат с помощью objdump.

Пример кода: генерация машинного кода

Каждый оператор превращается в одну или несколько машинных инструкций; например, сложение двух переменных вашего языка:

python# Взгляд в общем: связываем операторы с opcode x86-64
def gen_add(reg1, reg2):
    # add r64, r64 : opcode 0x01 /r
    # REX.W + 0x01 + ModRM (например, rax, rbx)
    return bytes([0x48, 0x01, modrm(reg1, reg2)])

def modrm(reg_rm, reg_reg):
    # mod=11 (регистр напрямую) + общие регистры
    return 0xC0 | (reg_reg << 3) | reg_rm

# Пример: для "a + b" сначала a в rax, b в rbx
# затем: gen_add(0, 3) -> add rax, rbx
# вывод: 48 01 C3

По тому же шаблону строятся умножение (через 0x48 0x0F 0xAF), условия (через cmp и jcc) и переходы.

Ключевые понятия

1) Режимы адресации и ModRM/SIB — вы близко увидите машинный язык x86; 2) стек вызовов rsp/rbp для локальных переменных и параметров; 3) конвенция вызова SystemV (регистры параметров rdi/rsi/…); 4) структура ELF для сборки запускаемого исполняемого файла. Автор просто объясняет всё это на Python.

Итоги

Если вы хотите узнать, «что на самом деле выполняет компьютер», — это лучший выбор: от вашего языка до байтов на диске всё под вашим контролем. Предпосылка: базовое знакомство с Python; результат: компилятор, который производит Linux-бинарник.

Оригинальный источник: «Build Your Own Lisp»

Книга, которая начинается «с нуля»

Дэниел Холден исходит из того, что читатель не знает C, и ведёт его шаг за шагом от установки компилятора до полного построения языка Lisp. Конечный результат — «Lispy»: язык с функциями, переменными, условиями, циклом и лямбда-правилами, работающий в REPL.

Отличительная особенность книги — использование библиотеки mpc (простого парсер-комбинатора, который строится прямо внутри книги) для определения грамматики языка — так читатель знакомится с настоящей архитектурой компиляторов, не увязая в сложностях лексера.

Ключевые концепции: mpc и грамматика языка

В первой главе вы строите калькулятор в польской нотации (Polish notation): вход вида + 1 (* 2 3). Затем через mpc_parser_t* вы определяете грамматику языка:

Cmpc_parser_t* Number    = mpc_new("number");
mpc_parser_t* Operator  = mpc_new("operator");
mpc_parser_t* Expr      = mpc_new("expr");
mpc_parser_t* Lispy     = mpc_new("lispy");

mpca_lang(MPCA_LANG_DEFAULT,
  " number : /-?[0-9]+/ ;            "
  " operator: '+' | '-' | '*' | '/' ;"
  " expr    : <number> | '(' <operator> <expr>+ ')' ;"
  " lispy   : /^/ <operator> <expr>+ /$/ ; ",
  Number, Operator, Expr, Lispy);

Эта грамматика определена рекурсивно — expr может содержать внутри себя expr — что лежит в основе понимания вложенных структур языков программирования.

От парсера к интерпретатору: eval

После того как mpc построит дерево синтаксиса (AST), вы пишете, как вычисляется каждый узел. Сердце интерпретатора — функция, которая берёт список, отделяет оператор от операндов и выполняет вычисление:

Clval* eval(lval* v) {
  if (v->type == LVAL_NUM) return v;      // число = конечное значение
  lval* f = pop(v, 0);                    // забрать оператор
  if (f->type != LVAL_FUN) { lval_del(f); lval_del(v); error! }
  for (int i = 0; i < v->count; i++)
    v->cell[i] = eval(v->cell[i]);       // рекурсивное вычисление аргументов
  return call(f, v);                      // выполнение функции
}

Позже, добавив Q-Expression (списки, которые не вычисляются), в язык приходят функции list, head и tail; а в следующих главах — переменные через def и =, определяемые функции через \ (lambda) и даже обработка ошибок и простой GC.

Финальные шаги

В последних главах книги: (1) система обработки ошибок и типы данных; (2) сохранение и загрузка кода в файл; (3) добавление маленькой стандартной библиотеки (например, sum, len). В конце можно писать настоящие программы на Lispy.

Весь код книги компилируется на Linux и macOS простым cc; единственная внешняя зависимость — mpc, которую вы создаёте сами.

Итог

Лучший выбор для того, кто «вообще ничего не знает о языках программирования»: вы начинаете с C, а в конце у вас Lisp-интерпретатор с функциями и переменными; вы глубоко понимаете концепции parser, AST, eval и REPL.

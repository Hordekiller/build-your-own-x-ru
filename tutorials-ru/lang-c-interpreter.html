Что мы строим

Этот проект — один из самых амбициозных уроков: полный интерпретатор языка C, написанный на C и — будучи зрелым проектом — способный выполнять сам себя (то есть берёт исходники интерпретатора и интерпретирует себя). Путь проходит через три главных компонента: lexer, parser и evaluator.

Структура кода

Код разбит на 9 небольших файлов, каждый из которых — один этап обучения: lexer (превращение исходника в токены), parser (построение AST из токенов), eval (вычисление AST). Каждый файл начинается с простого примера и постепенно дополняется.

В отличие от многих уроков, этот проект с самого начала спроектирован под настоящий язык C — поэтому вы знакомитесь с реальными конструкциями: struct, enum, pointer, typedef, массивы и даже стандартные допущения (например, неявный int).

Пример кода: ядро eval

C// Вычисление одного statement
void eval(struct AST_node *ast) {
  if (!ast) return;

  switch (ast->type) {
    case NODE_EXPR:          // выражение: вызов функции, оператор и т.д.
      handle_expr(ast);
      break;
    case NODE_ASSIGN:        // присваивание: a = b;
      handle_assign(ast);
      break;
    case NODE_IF:            // if/else
      handle_if(ast);
      break;
    case NODE_WHILE:         // цикл while
      while (is_true(eval_expr(ast->cond)))
        eval(ast->body);
      break;
    ...
  }
}

Управление памятью выполняется через таблицу функций и нумерованную кучу (make_label); благодаря этому указатели переводятся в «промежуточные индексы», и сам интерпретатор не взаимодействует с реальной памятью интерпретируемой программы.

Шаги реализации (карта изучения)

1. lexer: распознавание токенов (идентификаторы, числа, операторы, ключевые слова). 2. parser: грамматика подмножества C — от объявлений и выражений до struct/enum. 3. eval: реализация областей видимости (вложенные блоки через zset/zget), функций (с таблицей функций и рекурсией), указателей (через индекс кучи). 4. В конце попробуйте запустить интерпретатор на самом себе — отладка ошибок этого этапа лучший урок.

В проекте также есть пояснительные файлы (части 1–4 на китайском в docs), но англоязычной документации достаточно.

Итог

Если хотите понять, как язык C реально работает — не только его синтаксис — этот проект отлично подходит: среди главного, что вы выучите, — поведение указателей, структура областей видимости и реализация функций; а зрелище запуска интерпретатора на самом себе — приятный момент.

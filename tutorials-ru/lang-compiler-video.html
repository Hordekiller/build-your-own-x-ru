О видео

Это длинное обучающее видео показывает полный процесс построения компилятора: от определения простого входного языка до генерации исполняемого кода. Просмотр видео для старта, наблюдение за выходом компилятора на вашем собственном коде и разбор типичных ошибок — очень ценный опыт.

▶ Смотреть видео

Что вы строите в видео

Середина пути проясняет ваше понимание трёх главных концепций: lexer (превращение текста в токены), parser (превращение токенов в дерево синтаксиса) и code generator (превращение дерева в ассемблерный/машинный код). Отличие этого урока от текстовых — в том, что вы видите «решение ошибок в моменте».

Пример структуры токена

Если вы не знакомы с основными концепциями, этот раздел — фон; структура токена обычно выглядит так:

C++enum TokenType {
  TOK_NUMBER,   // число
  TOK_IDENT,    // идентификатор (переменная)
  TOK_PLUS,     // +
  TOK_STAR,     // *
  TOK_LPAREN,   // (
  TOK_RPAREN,   // )
  TOK_EOF
};

struct Token {
  TokenType type;
  std::string text;   // сырой текст токена
  long double value;  // если число
};

Ключевые советы из видео

1) Начните просто: сначала язык с числами и четырьмя операциями; 2) постепенно добавляйте условия и циклы; 3) всегда проверяйте ассемблерный выход через gcc или clang; 4) добавляйте по одной возможности, чтобы отладка оставалась простой.

Итог

Для визуального обучения, минимальной цены входа и максимального понимания: это видео ведёт вас от «что такое компилятор?» к «я могу собрать его сам». После него для глубины переходите к текстовым сериям, таким как acwj.

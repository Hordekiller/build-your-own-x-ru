Основная идея

Cradle переносит классику на Haskell: выражения разбираются рекурсивно, трансляция — чистые функции.

Разбор термина:

Haskellfactor :: Parser Expr
factor = do
  sign <- optional (char '-')
  n <- number
  return (if sign == Nothing then Num n else Neg (Num n))

Почему это важно

Функциональная реализация классики — двойной урок: компиляторы и Haskell в одном проекте.

Знакомство с Cradle

Серия «Давайте построим компилятор» Джека Креншоу (1988) — один из самых известных ресурсов по обучению построению компилятора методом одного прохода. Оригинал написан на Паскале для процессора 68000; проект Cradle переносит её на Haskell, чтобы работать на современных архитектурах и использовать мощь Haskell (сильная типизация и чистые функции).

Отличия от оригинала

В Паскале хранить «состояние» (текущий символ входа и т.д.) было просто; в Haskell нужно использовать монаду. Проект Cradle использует State monad для управления состоянием чтения входа — в результате и смысл трансляции сохранён, и код полностью чистый и доказуемый:

haskell-- Состояние компилятора: текущий символ + поток вперёд
data CradleState = CradleState { input :: String, cur :: Char }

type P a = State CradleState a

-- Получение следующего символа из входа
getChar' :: P Char
getChar' = do
  st <- get
  case input st of
    []     -> return '\0'          -- конец входа
    (c:cs) -> put (st { input = cs, cur = c }) >> return c

-- Печать выходного кода
emit :: String -> P ()
emit s = liftIO $ putStrLn s

Путь обучения: от сложения до функций

Как и в оригинальной серии, шаги постепенно усложняются: (1) четырёхоперационный калькулятор; (2) приоритет операторов (term/expression); (3) переменные и присваивание; (4) условия if/else; (5) циклы; (6) функции и параметры. Каждая часть находится в отдельном файле (Part1.hs … Part16.hs, как в оригинале).

Пример: разбор выражения с приоритетом

haskell-- expr := term (('+'|'-') term)*
expression :: P ()
expression = do
  term
  whilePlusOrMinus
  where
    whilePlusOrMinus = do
      c <- peek
      case c of
        '+' -> add
        '-' -> subtract_
        _   -> return ()

add :: P ()
add = do
  match '+'
  term
  emit "pop ebx"
  emit "add eax, ebx"

Итоги

Если вам интересны Haskell и функциональные языки, этот проект — отличная возможность: вы выучите принципы компиляторов методом Креншоу и получите практику работы с State monad и проектированием функционального кода. На выходе — исполняемый ассемблер x86.

О книге

«Crafting Interpreters» написал Роберт Найстром — тот самый, кто создал статью о «сборщике мусора для младенцев» и работал над языком Dart в Google. Книга реализует язык Lox дважды: первый раз — интерпретатор по дереву (tree-walker) на Java, второй — байткод-виртуальная машина на C. То, чего не даёт ни одна другая книга: прямое сравнение двух архитектур.

Часть первая: jlox — интерпретатор по дереву на Java

Первая часть (главы 4–13) строит scanner, parser (с генератором AST), evaluator, окружение, функции (closures), классы (наследование и полиморфизм). Вы учитесь тому, как вычисление идёт пошагово по дереву синтаксиса. Пример:

java// Вычисление узла по шаблону visitor
@Override
public Object visitBinaryExpr(Expr.Binary expr) {
  Object left = evaluate(expr.left);
  Object right = evaluate(expr.right);

  switch (expr.operator.type) {
    case PLUS:
      // число или строка: + складывает оба
      if (left instanceof Double && right instanceof Double)
        return (double) left + (double) right;
      if (left instanceof String && right instanceof String)
        return (String) left + (String) right;
      throw new RuntimeError(expr.operator, "значения должны быть числами или строками");
    case MINUS:
      checkNumberOperands(expr.operator, left, right);
      return (double) left - (double) right;
    case STAR:
      checkNumberOperands(expr.operator, left, right);
      return (double) left * (double) right;
    case SLASH:
      checkNumberOperands(expr.operator, left, right);
      return (double) left / (double) right;
    default:
      throw new RuntimeError(expr.operator, "неизвестный оператор");
  }
}

Часть вторая: clox — виртуальная машина на C

Во второй части (главы 14–30) всё строится заново и на скорости: байткод (глава 15), выполнение VM с циклом диспетчеризации (глава 16), хеш-таблицы для глобальных переменных (глава 18), closures с upvalue (глава 25), сборщик мусора mark-and-sweep (глава 26), классы и наследование (главы 27–28) и «государь» (глава 30). Эта часть показывает настоящую глубину выполнения байткода:

c// Главный цикл VM
static InterpretResult run() {
  for (;;) {
    uint8_t instruction;
    switch (instruction = READ_BYTE()) {
      case OP_CONSTANT: {
        Value constant = READ_CONSTANT();
        push(constant);
        break;
      }
      case OP_ADD: {
        Value b = pop();
        Value a = pop();
        push(NUMBER_VAL(AS_NUMBER(a) + AS_NUMBER(b)));
        break;
      }
      case OP_RETURN: {
        return INTERPRET_OK;
      }
    }
  }
}

Почему эта книга лучшая?

1) Логичный порядок: каждая глава — маленькая компилируемая возможность; 2) объяснение «почему» каждого решения (например, почему у closures есть upvalue); 3) повествование и юмор автора делают чтение приятным; 4) полный код каждой главы (файлы lox и c на GitHub). Как наставник, книга шаг за шагом идёт рядом с вами.

Предпосылки и итоги

Нужно среднее знакомство с программированием (Java или C — соответственно для каждой части), но сама книга объясняет все концепции. Если время есть только на одну книгу — выбирайте эту: после прочтения у вас и интерпретатор, и глубокое понимание VM — и тема «создание языка программирования» закрыта.

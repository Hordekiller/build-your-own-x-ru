О видео

Это видео строит на Python простой интерпретируемый язык: от определения базовых команд (присваивание, цикл, условие) до их выполнения на примерах. Подходит тому, кто хочет быстро увидеть результат работы.

▶ Смотреть видео

Ожидаемая структура

Как и в любом интерпретаторе, строятся три основных компонента: lexer (превращение текста в токены), parser (построение дерева/последовательности) и evaluator (выполнение команд). В видео эти три обычно пишутся в одном простом классе или файле с акцентом на читаемость.

Пример кода: выполнение команды

Чтобы заранее познакомиться с сутью работы, вот пример простого цикла eval:

pythondef execute(node, env):
    if node['type'] == 'assign':          # a = 5
        env[node['name']] = eval_expr(node['value'], env)
    elif node['type'] == 'print':         # print expr
        print(eval_expr(node['value'], env))
    elif node['type'] == 'if':            # if cond: ...
        if eval_expr(node['cond'], env):
            for stmt in node['body']:
                execute(stmt, env)
    elif node['type'] == 'while':         # while cond: ...
        while eval_expr(node['cond'], env):
            for stmt in node['body']:
                execute(stmt, env)

Советы

1) Начинайте с маленького языка и добавляйте возможности; 2) держите окружение (env) простым — dict; 3) уделите внимание ошибкам (синтаксическим), чтобы интерпретатор был полезным; 4) после видео прочитайте серию «lsbasi» Руслана Спивака, чтобы углубить концепции.

Итоги

Самый быстрый способ увидеть, «что делает интерпретатор»: посмотрите видео, следите за написанием кода вживую и попробуйте собрать свой маленький язык. Учиться написанию интерпретаторов, глядя на формирующийся код, проще, чем по любому сухому тексту.

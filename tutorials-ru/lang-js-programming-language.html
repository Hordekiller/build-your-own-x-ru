О учебнике

Эта серия реализует на JavaScript небольшой язык программирования под названием «PL»: функциональный язык с токенами, переменными, функциями и массивами. Отличает её стиль объяснения: каждая часть идёт короткими примерами кода с краткими пояснениями, без воды.

Части учебника

1) Токены: построение простого lexer на regex; 2) Разбор: парсер, превращающий грамматику в функции рекурсивного спуска; 3) Вычисление: обход и исполнение AST; 4) Функции: lambda и closures; 5) Окружение и область видимости: локальные и глобальные переменные. Полученный язык может исполнять примеры вроде sum(1,2,3) и более реальные программы.

Пример кода: парсер выражений

js// Минимальный парсер для математического диалекта (с приоритетом)
function parse_atom() {
  return function() {
    if (is_punc("(")) {            // список или группировка
      skip_punc("(");
      var exp = parse_expression();
      skip_punc(")");
      return exp;
    }
    if (is_num()) return make_number(parse_num());
    if (is_word()) return make_word(parse_word());
    error("неожиданный токен");
  };
}

// expr := atom (("+"|"-") atom)*
function parse_expression() {
  var left = parse_atom();
  while (is_op("+") || is_op("-")) {
    var op = parse_op();
    var right = parse_atom();
    left = { type: "binary", operator: op, left: left, right: right };
  }
  return left;
}

Часть вычисления

Вычислитель реализуется через таблицу env и функции evaluate/apply. Эта серия особенно хороша для изучения «модели исполнения» — где хранятся переменные и как происходит вызов функции; всё на чистом компактном JavaScript.

Итоги

Меньше чем за несколько часов чтения у вас функциональный язык с функциями, переменными и массивами. Для углубления предлагаются «mal» и «Crafting Interpreters»; но как быстрый и приятный десерт этот учебник отличен.

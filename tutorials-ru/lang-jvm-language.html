Свой язык на JVM: от AST к байткоду

Цель проекта

Enkel — простой язык в стиле Java, который вместо генерации обычного байткода производит напрямую байткод JVM: выход вашего компилятора можно запускать командой java! Изучая байткод JVM, вы превращаете свой компилятор в «безопасную гавань» для выполнения в JVM.

Части серии

Серия состоит из нескольких основных частей: (1) проектирование языка и структура AST; (2) lexer и parser на Apache Antlr или вручную; (3) генерация байткода через ASM (известная Java-библиотека); (4) поддержка переменных, функций, условий, циклов, классов и наследования; (5) обработка ошибок (error reporting).

Например, превращение выражения x + 3 в байткод с помощью ASM выглядит так:

java// Использование библиотеки ASM
MethodVisitor mv = cw.visitMethod(
    Opcodes.ACC_PUBLIC, "compute", "(I)I", null, null);   // метод compute(int):int

// Загрузка значения переменной x (индекс 1 в локальных переменных)
mv.visitVarInsn(Opcodes.ILOAD, 1);
// Загрузка константы 3
mv.visitIntInsn(Opcodes.BIPUSH, 3);
// Сложение двух целых
mv.visitInsn(Opcodes.IADD);
// Сохранение результата в переменную
mv.visitVarInsn(Opcodes.ISTORE, 1);

Почему этот урок особенный?

Большинство уроков выдают ассемблер; то, что здесь делается с байткодом JVM, даёт практические преимущества: (1) итоговый файл .class запускается без линкера; (2) через javap -c можно читать и сравнивать сгенерированный байткод; (3) структура классов, методов и таблицы исключений в самой JVM — целый урок по проектированию виртуальных машин.

Учебные моменты

В процессе сборки вы знакомитесь с важными концепциями: таблица локальных переменных; invokevirtual против invokespecial; управление стеком операндов; и почему первый аргумент, передаваемый методу, лежит по индексу 0 (это this). Всё это — основа любого JVM-языка вроде Kotlin и Scala.

Итоги

Если вам нравится Java и хочется понять JVM-языки, Enkel — отличный путь: от построения lexer до исполняемого файла .class. Гибко, запускаемо и полно реальных примеров.

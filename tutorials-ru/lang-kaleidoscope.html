Kaleidoscope: язык на LLVM

Что вы строите в этом уроке

LLVM (Low Level Virtual Machine) — набор инструментов для построения компиляторов; его выход — «промежуточный код» (IR), а затем оптимизированный машинный код. Этот официальный урок LLVM строит язык Kaleidoscope: функциональный язык с def для определения функций, extern для внешних функций, условиями, циклами, определяемыми пользователем операторами и изменяемыми переменными.

Десятичастная архитектура

Части спроектированы так, что каждая добавляет один слой: (1) lexer; (2) parser и AST; (3) генерация IR через IRBuilder; (4) добавление JIT для мгновенного исполнения; (5) оптимизатор (Optimizer с PassManager); (6) условия if/else (с узлами PHI); (7) циклы (for); (8) определяемые пользователем бинарные операторы (с динамической таблицей приоритетов); (9) изменяемые переменные (через alloca); (10) вывод в файл объектного кода.

Пример кода: генерация IR с IRBuilder

Например, код def add(a, b) a + b генерирует такой IR:

C++Value *CodegenVisitor::visit(BinaryExpr &e) {
  Value *L = codegen(e.LHS);
  Value *R = codegen(e.RHS);
  switch (e.Op) {
  case '+':
    return Builder->CreateFAdd(L, R, "addtmp");  // сложение с плавающей точкой
  case '-':
    return Builder->CreateFSub(L, R, "subtmp");
  case '*':
    return Builder->CreateFMul(L, R, "multmp");
  case '/':
    return Builder->CreateFDiv(L, R, "divtmp");
  default:
    return LogErrorV("неизвестный оператор");
  }
}

Результат этого кода — модуль LLVM, который можно запустить через lli ещё до того, как backend будет завершён.

Ценные технические моменты

Части 6 и 7 показывают работу с узлами PHI — важным понятием в SSA, которое вы увидите и в низкоуровневых языках, таких как Rust. Часть 9 на alloca (переменная на стеке) показывает, почему изменяемые переменные трудны в SSA. Часть 10 выводом в объектный файл делает ваш компилятор «настоящим».

Итог

Самое полное официальное введение в построение frontend на LLVM на C++. Если вы ищете путь, на котором ваш язык впоследствии сможет набрать скорость на реальном CPU (JIT или AOT), начните с этого урока — затем Kaleidoscope можно расширить типами данных и модулями.

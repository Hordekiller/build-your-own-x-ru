Основная идея

Lisp-интерпретатор на JS — это пара сотен строк: списки, eval, окружение. Учебник без лишней теории.

Оценка списка-вызова:

JavaScriptconst evaluate = (ast, env) => {
  if (ast[0] === "define") {
    env[ast[1]] = evaluate(ast[2], env);
    return;
  }
  const fn = evaluate(ast[0], env);
  const args = ast.slice(1).map(x => evaluate(x, env));
  return fn(...args);
};

Почему это важно

Ещё один маленький Lisp — ещё один уровень понимания: накопив опыт, вы пишете языки на автомате.

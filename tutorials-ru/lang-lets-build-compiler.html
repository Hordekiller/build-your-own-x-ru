Классическая серия Крэншоу

В 1980-х Джек Крэншоу опубликовал учебную серию «Let's Build a Compiler», которая начиналась с простого калькулятора и доходила до полного компилятора с функциями. Эта серия стала основой сотен последующих уроков. Порт lotabout переносит её с Pascal/68k на C и ассемблер x86, чтобы её можно было запускать на современных машинах.

Метод «одного прохода» (Single-Pass)

Главная философия серии: компилятор генерирует выходной код прямо во время чтения входа — без AST и без отдельного лексера. Достаточно определить три базовые функции: GetChar() (чтение следующего символа), Look() (текущий символ) и Match() (проверка символа) — и все правила строятся на этих трёх функциях:

Cvoid Expression() {   // правило выражения: +1+2 → mov eax,1; add eax,2
  Term();
  while (Look == '+' || Look == '-') {
    EmitLn("push eax");
    switch (Look) {
      case '+': Add(); break;
      case '-': Subtract(); break;
    }
  }
}

void Add() {
  Match('+');
  Term();
  EmitLn("pop ebx");     // восстановить второй операнд
  EmitLn("add eax, ebx");
}

Каждое правило грамматики — функция, и каждая функция напрямую генерирует ассемблер x86 (команды mov/add/sub и стек) — это даёт интуитивное понимание связи грамматики и машинного кода.

Путь обучения

Серия идёт шаг за шагом: (1) калькулятор сложения/вычитания, (2) умножение и деление с приоритетами, (3) переменные и присваивание, (4) условия if и ассемблерные переходы, (5) циклы while/loop, (6) функции и параметры, (7) больше типов данных. В конце у вас маленький, но полный компилятор.

Чем полезна эта C-версия

Оригинал предназначался для процессора 68000; порт lotabout — и понятный код на C, и ассемблер x86, исполняемый через as и ld. Если хотите начать своё путешествие медленно и на прочном фундаменте, а потом перейти к более реальным компиляторам (например, acwj) — это идеальная точка старта.

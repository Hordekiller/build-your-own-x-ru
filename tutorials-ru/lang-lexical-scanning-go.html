Лексический сканер на Go

О докладе

Роб Пайк в этом докладе объясняет реализацию сканера (лексера) пакетов text/template и html/template языка Go — паттерн, впоследствии широко использовавшийся при создании компиляторов и инструментов. Это классический урок по проектированию «машины состояний» (State Machine).

▶ Смотреть видео

Центральная идея: функция состояния вместо таблицы состояний

В паттерне Пайка каждое «состояние» — это функция, которая принимает вход (сканер) и возвращает следующую функцию-состояние. Так лексер работает как главный цикл (for state != nil), и каждая функция-состояние отвечает за распознавание своей части входа:

gotype stateFn func(*lexer) stateFn

func (l *lexer) run() {
  for state := l.state; state != nil; {
    state = state(l)   // выполнение текущего состояния, получение следующего
  }
}

// Начальное состояние
func lexText(l *lexer) stateFn {
  for {
    if strings.HasPrefix(l.input[l.pos:], "{{") {
      l.pos += 2
      return lexLeftDelim   // переход в состояние внутри тега
    }
    l.next()
    if l.pos >= len(l.input) {
      l.emit(itemEOF)
      return nil   // конец
    }
  }
}

Выход сканера: элементы и канал

Сканер отправляет все токены потребителю (парсеру) через канал; каждый элемент (item) имеет тип и текст. Этот паттерн полностью отделяет лексер от парсера и упрощает параллельное выполнение (goroutine):

gotype item struct {
  typ itemType  // тип элемента (itemText, itemLeftDelim, ...)
  val string    // сырой текст
  line int      // номер строки для ошибок
}

func (l *lexer) emit(t itemType) {
  l.items <- item{t, l.input[l.start:l.pos], l.line}
  l.start = l.pos
}

Почему этот паттерн важен?

Во-первых, фокус на «состоянии вместо условной логики» делает лексеры чистыми и тестируемыми. Во-вторых, именно этот доклад вдохновил множество реализаций лексеров на других языках (Rust, Python и др.). Если вы хотите создать свой язык и нужен лексер — этот паттерн лучший выбор.

Итоги

30 минут видео + несколько часов практики — и вы владеете проектированием лексера на машине состояний. С этим языком первая часть вашего компилятора (разбор текста) станет профессиональной и чистой.

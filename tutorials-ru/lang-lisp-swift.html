Основная идея

Swift подходит для интерпретаторов: перечисления и опциональные значения обрабатывают AST естественно.

Тип выражения на Swift:

Swiftindirect enum Expr {
    case number(Double)
    case symbol(String)
    case list([Expr])
    case lambda([String], Expr, Env)
}

Почему это важно

Интерпретатор на Swift — приятный опыт: вы увидите, как индустриальный язык справляется с семантикой.

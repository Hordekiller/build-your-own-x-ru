Lisp-интерпретатор на Swift

Почему Swift для Lisp-интерпретатора?

Lisp — один из самых простых языков для написания интерпретатора (его синтаксис — почти только скобки и функции), а Swift с вложенными enum и замыканиями даёт удобные инструменты для моделирования функциональных типов данных. Такое сочетание делает учебник интересным и знакомым с интерпретаторами, и любителям Swift.

У построенного интерпретатора три классических этапа: токенизатор, парсер и вычислитель — а в конце REPL, с которым можно работать в терминале.

Моделирование LispVal с enum

Важнейшее архитектурное решение — определение типа данных всех значений Lisp. С enum Swift это делается очень естественно:

swift// Все значения языка: число, имя символа, список, функция
enum LispVal {
    case atom(String)
    case number(Int)
    case string(String)
    case list([LispVal])
    case function(String, ([LispVal]) throws -> LispVal)
}

С таким определением список сам содержит другие LispVal, а функция моделируется как компонуемая структура. Все дальнейшие алгоритмы (парсер и evaluator) строятся на этой основе.

Токенизатор и парсер

Парсер работает посимвольно и при встрече ( начинает строить список. Для управления вложенными скобками используется рекурсия:

swiftfunc parseList(_ chars: [Character], _ pos: Int) throws -> (LispVal, Int) {
    var result: [LispVal] = []
    var i = pos
    while i < chars.count {
        let c = chars[i]
        if c == ")" { return (LispVal.list(result), i + 1) }
        if c == "(" {
            let (list, next) = try parseList(chars, i + 1)
            result.append(list)
            i = next
        } else {
            let (v, next) = try parseAtom(chars, i)
            result.append(v)
            i = next
        }
    }
    throw LispError.unexpectedEnd
}

// Преобразование атома в число или символ
func parseAtom(_ chars: [Character], _ pos: Int) throws -> (LispVal, Int) {
    var s = ""
    var i = pos
    while i < chars.count, !"() ".contains(chars[i]) {
        s.append(chars[i]); i += 1
    }
    if let n = Int(s) { return (LispVal.number(n), i) }
    return (LispVal.atom(s), i)
}

Этот простой парсер без ошибок читает весь базовый Lisp (числа, символы и глубокие списки).

Вычисление и замыкания

Вычислитель работает сопоставлением с образцом по LispVal: для atom выполняет определённую базовую функцию; для list вычисляет первый элемент как функцию, а остальные как аргументы. Функции хранятся как замыкания, чтобы иметь доступ к переменным своего окружения.

В конце учебник показывает разные решения: определение defun (именованные функции), арифметические операторы и даже рекурсию (fibonacci) — всё построено на тех же трёх основных конструкциях.

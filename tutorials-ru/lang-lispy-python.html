Lispy: Lisp-интерпретатор на Python

Знакомство

lisp.py — интерпретатор Lisp в несколько десятков строк Python, вмещающий главные уроки написания интерпретаторов: tokenizer, parser, evaluator с окружением и поддержку определения функций через lambda или def, условия if и базовые операторы.

Структура кода

Код разбит на три аккуратные части: tokenize (превращение текста в список), parse (построение дерева рекурсией) и eval (выполнение с окружением). Проект написан так, чтобы его можно было читать напрямую как «обучающий интерпретатор» — без внешних зависимостей, только стандартный Python.

Пример кода: сердце интерпретатора

pythondef eval(x, env):
    if type(x) is int:                    # число: само значение
        return x

    if type(x) is str:                    # символ: прочитать из окружения
        return env[x]

    if x[0] == 'quote':
        return x[1]

    if x[0] == 'if':                      # условие: только правильная ветка
        (_, test, true, false) = x
        return eval(true, env) if eval(test, env) else eval(false, env)

    if x[0] == 'lambda':                  # lambda: построение closure
        (_, params, body) = x
        return Lambda(params, body, env)

    if x[0] == 'define':                  # определение переменной
        (_, name, value) = x
        env[name] = eval(value, env)
        return None

    # вызов функции: вычисляем оператор и аргументы
    op = eval(x[0], env)
    args = [eval(arg, env) for arg in x[1:]]
    return apply(op, args, env)

Что ещё узнаете

Через apply и структуру Lambda, хранящую окружение определения, вы на практике увидите понятие closure — то, что делает функции Lisp мощными. Дальше можно добавить let, begin и даже простой GC (по статье «Baby's First Garbage Collector»).

Итоги

Небольшой, но полный проект для старта в написании интерпретаторов на Python: быстрый, на все базовые темы и удобный для практики. Если хотите увидеть тот же уровень с большей глубиной, следующий шаг — «lispy» Норвига (90 строк!).

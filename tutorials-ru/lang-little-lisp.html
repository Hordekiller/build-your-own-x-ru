О чём это

Маленький Lisp на JS: парсер, eval и REPL — язык с минималистичной красотой.

Что вы узнаете

  • Парсер списков
  • Eval
  • Стандартные функции
  • REPL

Основная идея

Little Lisp сохраняет суть Lisp: списки как данные, eval как программа. На JS — коротко и понятно.

Сердце Little Lisp:

JavaScriptfunction evaluate(ast, env) {
  if (Array.isArray(ast)) {
    // вызов функции: eval всех элементов
  }
  return env[ast] || parseInt(ast);
}

Почему это важно

Маленькие Lisp-ы — отличная практика: за вечер вы получите работающий язык и удовольствие.

Основная идея

Markdown-компилятор — дружелюбный вход: парсинг строк и рендер HTML показывают компиляторные приёмы.

Рендер заголовка:

Rubydef render(line)
  if line =~ /^(#{'#'}+) (.*)/
    level = $1.size
    "<h#{level}>#{$2}</h#{level}>"
  else
    line
  end
end

Почему это важно

Даже Markdown — компилятор: этот проект снимет страх перед языками и добавит уверенности.

История lis.py

Питер Норвиг (директор по исследованиям Google и автор знаменитой книги по ИИ) написал этот интерпретатор в около 90 строк Python, а позже продолжил его в самолёте: полный Lisp с функциями, переменными, условиями и даже quote. Три главных понятия: окружение (Environment), eval и apply — в точности как в знаменитой статье «The roots of Lisp» Джона Маккарти.

Пример кода: главный eval/apply

pythondef eval(x, env=global_env):
    if isinstance(x, Symbol):      # переменная
        return env.find(x)[x]
    elif not isinstance(x, list):  # число или строка
        return x
    elif x[0] == 'quote':          # quote: без вычисления
        (_, exp) = x
        return exp
    elif x[0] == 'if':             # условие
        (_, test, conseq, alt) = x
        exp = (conseq if eval(test, env) else alt)
        return eval(exp, env)
    elif x[0] == 'define':         # определение переменной
        (_, var, exp) = x
        env[var] = eval(exp, env)
    elif x[0] == 'lambda':         # определение функции
        (_, parms, body) = x
        return Procedure(parms, body, env)
    else:                          # вызов функции
        proc = eval(x[0], env)
        args = [eval(arg, env) for arg in x[1:]]
        return proc(*args)

class Procedure(object):           # closure
    def __init__(self, parms, body, env):
        self.parms, self.body, self.env = parms, body, env
    def __call__(self, *args):
        return eval(self.body, Env(self.parms, args, self.env))

Понятие окружения (Env) и цепочки

Класс Env — это dict с «родителем»; find поднимается по цепочке родителей, чтобы найти переменную. Это ровно тот же механизм области видимости, что и в реальных языках, — поняв его, вы поймёте все языки.

Примеры программ

Статья завершается несколькими реальными программами: функции fact (факториал) и count, которые выполняются на этом интерпретаторе. Это доказательство того, что маленький интерпретатор — настоящий. Есть и дополнительный раздел «введение функций Scheme-Паскаль».

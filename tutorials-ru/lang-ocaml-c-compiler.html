Основная идея

OCaml создан для компиляторов: ADT описывают AST, pattern matching обрабатывает узлы. C-компилятор — образец стиля.

Тип AST на OCaml:

OCamltype expr =
  | Int of int
  | Add of expr * expr
  | Mul of expr * expr
  | Var of string

Почему это важно

OCaml — язык для компиляторов: вы увидите, как типы превращают AST в естественный инструмент.

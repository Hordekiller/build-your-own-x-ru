Что такое комбинатор парсеров

Вместо написания отдельного парсера для каждого языка «комбинаторы» — маленькие функции, которые сочетаются друг с другом и строят парсер. Парсер — это «функция»: принимает вход (строку) и либо возвращает успех (результат + остаток входа), либо неудачу.

Скотт Влашин объясняет эту идею на F# — функциональном и читаемом языке; концепции переносимы на любой язык (существуют версии на Rust, Go, JavaScript).

Главная концепция: базовые функции и комбинирование

Три базовых комбинатора: preturn (всегда успех с фиксированным значением), pzero (всегда неудача), satisfy (символ, соответствующий предусловию). Затем структурные комбинаторы: andThen (p1 затем p2), orElse (либо p1, либо p2), many (ноль или больше раз). На них строятся сложные парсеры:

F#type Parser<'a> = string -> Result<'a * string, string>

// и затем: p1 и после него p2
let andThen p1 p2 = fun input ->
    match p1 input with
    | Error e -> Error e
    | Ok (r1, rest) ->
      match p2 rest with
      | Error e -> Error e
      | Ok (r2, rest2) -> Ok ((r1, r2), rest2)

// p1 или p2
let orElse p1 p2 = fun input ->
    match p1 input with
    | Ok r -> Ok r
    | Error _ -> p2 input

Обратите внимание: рекурсией и этими двумя простыми функциями можно определить полные грамматики — без инструментов генерации парсеров, пока вы сами этого не захотите.

Практическое применение: калькулятор

В продолжении статьи на этих комбинаторах строится маленький калькулятор (числа, сложение, умножение с приоритетами). Также обсуждается, как с помощью «монады» (в F# через forwardPipe и record) чище управлять ошибками и состоянием; и почему комбинаторы естественным образом страдают от «левой рекурсии» (left recursion) — проблемы, которую решают LALR-парсеры.

Пример кода: числа и операторы

F#let digitChar = satisfy (fun ch -> System.Char.IsDigit ch)
let digits = many1 digitChar   // одна или больше цифр

// преобразование строки цифр в int
let toInt (str:string) : int = System.Int32.Parse(str)

let number = digits |>> toInt   // парсер числа

// expr := number (("+"|"-") number)*
let expr =
    let op = char '-' |>> (fun _ -> (-)) <|> char '+' |>> (fun _ -> (+))
    number .>>. many (op .>>. number)

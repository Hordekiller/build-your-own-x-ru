Основная идея

Комбинаторы в Rust — про типы: парсеры как функции, композиция как типы. Проект — современная альтернатива hand-written парсерам.

Тип парсера на Rust:

Rusttype Parser<'a, T> = impl Fn(&'a str) -> Option<(T, &'a str)>;

fn literal<'a>(s: &'a str) -> Parser<'a, &'a str> {
    move |input| input.strip_prefix(s).map(|rest| (s, rest))
}

Почему это важно

Парсер-комбинаторы на Rust — современная практика: вы получите функциональный стиль в системном языке.

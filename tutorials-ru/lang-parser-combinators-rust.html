Что такое парсер-комбинаторы?

Вместо одного большого сложного парсера метод комбинаторов определяет маленькие парсеры, каждый из которых знает один простой шаблон, а затем с помощью комбинирующих операторов собирает из них полный парсер. Итог — модульный, читаемый код, который работает для любой синтаксической или бинарной структуры.

Главная философия: парсер — это «функция»: принимает вход; в случае успеха возвращает значение и остаток входа, в случае неудачи — ошибку. Эта простая схема — основа согласованности всех комбинаторов.

Базовая структура в Rust

В Rust этот паттерн выражается трейтом (trait) и обобщённой функцией. В определении учебника парсер задаётся через Parser и функцию parse:

rustpub trait Parser<I, O> {
    fn parse(&self, input: I) -> Result<(O, I), ParserErr>;
}

// Комбинатор pair: выполняет два парсера подряд
pub fn pair<P1, P2, I, O1, O2>(
    p1: P1,
    p2: P2,
) -> impl Parser<I, (O1, O2)>
where
    P1: Parser<I, O1>,
    P2: Parser<I, O2>,
{
    move |input: I| {
        let (o1, rest) = p1.parse(input)?;
        let (o2, rest) = p2.parse(rest)?;
        Ok(((o1, o2), rest))
    }
}

Видно, что pair ничего не знает о конкретном содержимом: он лишь принимает два парсера и выполняет их друг за другом. Эта композируемость — главное свойство метода.

Комбинатор many: ноль или больше

Для таких вещей, как список или последовательность, нужен парсер, который выполняется «ноль или несколько раз». Это many:

rust// many: выполняет парсер, пока это возможно
pub fn many<P, I, O>(p: P) -> impl Parser<I, Vec<O>>
where
    P: Parser<I, O>,
    I: Clone,
{
    move |mut input: I| {
        let mut result = Vec::new();
        while let Ok((o, next)) = p.parse(input.clone()) {
            input = next;
            result.push(o);
        }
        Ok((result, input))
    }
}

Важный учебный момент: поскольку парсеры могут падать, для «отката» (backtracking) нужно клонировать вход и продвигаться только при успехе.

Построение парсера JSON

После знакомства с map, and_then, left и right учебник шаг за шагом строит парсер JSON: сначала null, boolean и number, затем пару key: value, потом «object» и «array» с разделителем ,. Каждый шаг использует уже определённые комбинаторы.

Для проверки пишется набор простых тестов, показывающих поведение парсера на правильных и неправильных данных; в итоге финальный парсер меньше чем в 200 строк читает полный JSON.

Итоги

Учебник отлично показывает, как без внешних инструментов и всего несколькими маленькими функциями собрать полный надёжный парсер. Техника комбинаторов очень востребована в реальных проектах (интерпретаторы, инструменты командной строки).

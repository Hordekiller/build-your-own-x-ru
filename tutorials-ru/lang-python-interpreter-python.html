Постановка задачи

Задумывались ли вы, что именно делает Python, исполняя ваш код? Глава из сборника 500L, написанная Эллисон Каптур (работавшей над PyPy), отвечает на этот вопрос, построив byterun: интерпретатор, который читает и исполняет файлы .pyc (скомпилированный байткод Python) — не разбирая текст сам.

Четыре основных компонента

Интерпретатор состоит из четырёх классов: VirtualMachine (главный цикл исполнения), Frame (указатель исполнения: код, локальные переменные, стек возврата), Function (функция с closure) и Block (управление try/except и циклами). Ключевое понятие: у каждого фрейма есть стек исполнения и счётчик следующей инструкции.

Пример кода: главный цикл

pythonclass VirtualMachine:
    def run_code(self, code, global_names=None, local_names=None):
        frame = self.make_frame(code, global_names, local_names)
        self.run_frame(frame)

    def run_frame(self, frame):
        while True:
            opname = frame.code.co_names[frame.next_instr]
            instr = opname

            # главный цикл исполнения: выполняем инструкции
            if instr.startswith('UNARY'):
                self.unaryOperator(instr[5:])     # UNARY_NEGATIVE и др.
            elif instr.startswith('BINARY'):
                self.binaryOperator(instr[6:])    # BINARY_ADD и др.
            elif instr.startswith('LOAD'):
                self.load_name(instr[4:])         # LOAD_FAST и др.
            elif instr.startswith('STORE'):
                self.store_name(instr[5:])        # STORE_FAST и др.
            elif instr == 'JUMP_ABSOLUTE':
                frame.next_instr = self.parse_arg_and_increment(frame)
            elif instr == 'PRINT_ITEM':
                print(self.pop(), end=' ')
            elif instr == 'RETURN_VALUE':
                return self.pop()
            ...
            frame.next_instr += 1

Ценные концепции

1) Стек виртуальной машины для вычисления выражений; 2) байткоды вроде LOAD_FAST/STORE_FAST для локальных переменных и LOAD_GLOBAL для глобальных; 3) управление возвратом и вызовом через стек фреймов; 4) функции как значения с closure (захваченными переменными); 5) управление exception/loop через Block. С ними поведение Python (например, локальная область видимости в функции) становится полностью логичным.

Scheme за 48 часов: интерпретатор

Оригинальный источник: «Write Yourself a Scheme in 48 Hours»

Знакомство с книгой

Этот учебник, растущий на Wikibooks с 2007 года, написан с двумя целями: обучить Haskell на практике и построить полный интерпретатор Scheme. По пути вы знакомитесь с концепциями Haskell (композиция функций, Functor/Monad, Parsec и т.д.) и концепциями компиляторов (представление данных, окружение, вычисление).

Структура пути

Книга идёт в 7 главах: (1) представление и простое вычисление (числа, атомы); (2) парсинг через Parsec (определение LispVal и грамматики); (3) вычисление и обработка ошибок (Either/Error); (4) добавление типов данных (списки, булевы, строки) и функций; (5) переменные и окружение (через State monad, ключевые слова define и set!); (6) функции как значения (lambda) и функции с аргументами; (7) настоящий ввод/вывод и базовые функции (readFile, writeFile).

Пример кода: тип данных и вычисление

haskell-- Представление представимых значений
data LispVal = Atom String
             | List [LispVal]
             | DottedList [LispVal] LispVal
             | Number Integer
             | String String
             | Bool Bool

-- Сердце интерпретатора: вычисление в окружении
eval :: Env -> LispVal -> IOThrowsError LispVal
eval env val@(String _) = return val
eval env val@(Number _) = return val
eval env val@(Bool _)   = return val

eval env (List [Atom "quote", val]) = return val

eval env (List [Atom "if", cond, t, f]) = do
  result <- eval env cond
  case result of
    Bool False -> eval env f
    _          -> eval env t

eval env (List (Atom func : args)) = do
  funcVal <- eval env (Atom func)
  argVals <- mapM (eval env) args
  apply funcVal argVals

Все важные детали интерпретатора — от quote до вызова функций — видны в этих нескольких строках.

Заметки и уроки

В средних главах вы знакомитесь с типичными ошибками интерпретаторщиков (ошибки show и неправильное отображение) и учитесь комбинировать MonadError и State. В последней главе интерпретатор получает возможность читать примитивы и базовые функции I/O — вы сможете запускать настоящие Scheme-скрипты.

Чем отличается от первой версии?

Первая версия (2013) строила интерпретатор просто; вторая (2015) полностью переписана с нуля современными инженерными методами: поддержка cabal, автоматические тесты (QuickCheck и golden-тесты), документация через haddock, гигиеничная макросистема (hygienic macros) и структура данных, выстраиваемая снизу вверх.

Архитектура проекта

Код организован в небольшие модули: Language.Scheme.* включает parser, runtime (вычисление), environment и types. У каждого модуля есть свои тесты в папке test; например, с помощью golden-test поведение eval сверяется на примерных Scheme-скриптах.

Пример кода: окружение и вычисление

haskell-- Определение окружения с быстрым доступом к данным
data Env = Env { envParent :: Maybe Env
               , envValues :: Map.Map Text LispVal
               }

-- Вычисление через pattern matching
eval :: Env -> LispVal -> IOThrowsError LispVal
eval env (LispAtom a) = lookupEnv env a

eval env (LispList [LispAtom "if", cond, cons, alt]) = do
  result <- eval env cond
  case result of
    LispBool False -> eval env alt
    LispList []    -> eval env alt   -- в Scheme: пустой список = false
    _              -> eval env cons

eval env (LispList [LispAtom "lambda", params, body]) = ...

Отличительные особенности

1) Гигиеничные макросы: через syntax-rule и define-syntax — без конфликтов имён между макросом и кодом пользователя; 2) представление данных LispVal как sum type с pattern matching; 3) ошибки через MonadError; 4) полная система тестов, которая служит и образцом хорошего кода, и гарантией от регрессий.

Итоги

Для тех, кто читал первую версию или «Scheme за 48 часов» и хочет увидеть, как пишется «профессиональный» интерпретатор: модульная архитектура, тесты и макросы показывают все хорошие практики Haskell.

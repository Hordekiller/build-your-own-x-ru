Микро-компилятор на Go (Super Tiny Compiler)

История компилятора из 200 строк

Оригинальный компилятор (the-super-tiny-compiler) написан Джеймсом Кайлом (jamiebuilds) примерно в 200 строках JavaScript, чтобы показать: структура компилятора по сути проста; вход похож на Lisp (add 2 (subtract 4 2)), выход — на C: add(2, subtract(4, 2)). Версия на Go следует тем же путём с явными типами и аккуратными функциями.

Четыре главных этапа

1) Tokenizer: разбиение входа на токены; 2) Parser: превращение токенов в AST (дерево синтаксиса); 3) Transformer: превращение входного AST в выходной AST (со структурой C); 4) Code Generator: из выходного AST строится строка C-кода.

Для структурирования «компилятор» реализован тремя функциями — tokenizer, parser и transformer (с внутренним traverser), а в конце codeGenerator занимается печатью.

Пример кода: этап transformer на Go

Go// Преобразование узлов: листья в "CallExpression"
func transform(node *Node, parent *Node) {
  switch n := (*node).(type) {
  case *NumberLiteral:
    if parent != nil {
      (*parent).(type) = ... // преобразование в выходной NumberLiteral
    }
  case *CallExpression:
    // часть первая: функция превращается в отдельный CallExpression
    expression := &CallExpression{Callee: n.Callee, Arguments: []Node{}}
    // часть вторая: рекурсивно обойти аргументы с ним (как родителем)
    for _, arg := range n.Arguments {
      transform(&arg, newParent)
    }
  }
}

Главный трюк оригинального компилятора — функция traverser, которая обходит AST двумя видами посещения (enter и exit); версия на Go повторяет тот же паттерн.

Что вы узнаете

На 200 строках кода вы знакомитесь с главными концепциями компилятора: lexing (распознавание группирующих символов), parsing (построение иерархии), AST (дерево данных), traverser (рекурсивный обход) и codegen (печать кода). Поскольку вход прост, фокус на концепциях, а не на деталях языка.

Итог

Лучший «первый компилятор» для старта: короткий, читаемый, с тестами. Версия на Go отлично подходит тем, кому нравятся типы и ясность Go; JavaScript-версия — для быстрого знакомства с концепциями. После этого переходите к более реальным компиляторам (например, acwj или Crafting Interpreters).

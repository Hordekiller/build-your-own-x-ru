Основная идея

Super Tiny Compiler умещается в 200 строк: каждый этап — функция, каждая идея — комментарий.

Генерация кода из AST:

Gofunc codegen(node Node) string {
    switch n := node.(type) {
    case NumberLiteral:
        return n.Value
    case CallExpression:
        return n.Callee + "(" + join(n.Args) + ")"
    }
}

Почему это важно

Маленькие компиляторы — большие уроки: после STC вы сможете объяснить этапы компиляции за чашкой кофе.

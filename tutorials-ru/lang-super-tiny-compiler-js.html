Основная идея

Знаменитый учебник: весь компилятор в одном файле. Трансформация AST — мост между языками.

Генерация из AST:

JavaScriptfunction codeGenerator(node) {
  switch (node.type) {
    case "NumberLiteral": return node.value;
    case "CallExpression":
      return node.name + "(" + node.params.map(codeGenerator).join(", ") + ")";
  }
}

Почему это важно

Super Tiny Compiler — идеальный первый компилятор: его читают миллионы, и вы присоединитесь к ним.

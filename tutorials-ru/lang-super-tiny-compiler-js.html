Микро-компилятор на JavaScript

Идея проекта

Джеймс Кайл этим проектом хотел показать «скелет» компиляторов в минимально возможном коде. На входе — язык в духе Lisp: (add 2 (subtract 4 2)), на выходе — код в стиле C: add(2, subtract(4, 2)). Все ключевые концепции компилятора умещаются в эти 200 строк.

Этапы: 4 функции

1) tokenizer — превращает строку в токены; 2) parser — превращает токены в AST; 3) transformer — с помощью traverser (обход enter/exit) превращает входной AST в выходной; 4) codeGenerator — из выходного AST строит финальный код.

jsfunction tokenizer(input) {
  let current = 0;      // указатель позиции
  let tokens = [];

  while (current < input.length) {
    let char = input[current];

    // скобки
    if (char === '(') {
      tokens.push({ type: 'paren', value: '(' });
      current++;
      continue;
    }

    // числа: несколько цифр подряд
    const NUMBERS = /[0-9]/;
    if (NUMBERS.test(char)) {
      let value = '';
      while (NUMBERS.test(char)) {
        value += char;
        char = input[++current];
      }
      tokens.push({ type: 'number', value });
      continue;
    }

    // имена (add, subtract, ...)
    const LETTERS = /[a-z]/i;
    if (LETTERS.test(char)) {
      let value = '';
      while (LETTERS.test(char)) {
        value += char;
        char = input[++current];
      }
      tokens.push({ type: 'name', value });
      continue;
    }

    // пропускаем пробелы
    const WHITESPACE = /\s/;
    if (WHITESPACE.test(char)) {
      current++;
      continue;
    }

    throw new TypeError('неизвестный символ: ' + char);
  }

  return tokens;
}

Почему стоит прочитать?

Если вы никогда не видели код компилятора, этот проект — мягкое вхождение: подробная документация в комментариях объясняет каждую функцию, и всё можно пошагово запустить с node. Также от этого проекта произошли версии на Go, Rust и др.; чтение оригинала даёт более полное представление об архитектуре.

Куда идти после этого проекта?

Для продолжения держите в голове ядро — tokenizer, parser, AST, traverser, codegen. Затем переходите к «Little Lisp» или «Crafting Interpreters», чтобы добавить вычисление и окружение, — или, если хочется мощности компиляции, к учебнику Kaleidoscope с LLVM.

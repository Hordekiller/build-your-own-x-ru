Основная идея

Интерпретатор — это eval: разобрать дерево и выполнить. Мини-версия на JS умещается на ладони.

Выполнение вызова функции:

JavaScriptfunction evaluate(node, env) {
  if (node.type === "Call") {
    const fn = env[node.name];
    return fn(...node.args.map(a => evaluate(a, env)));
  }
}

Почему это важно

Микро-интерпретаторы — вход в семантику: вы поймёте eval, окружения и вызовы за один вечер.

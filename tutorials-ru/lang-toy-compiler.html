О чём это

Игрушечный компилятор на C++: лексер, парсер и простой байткод — маленький, но настоящий компилятор.

Что вы узнаете

  • Лексер
  • Парсер
  • Байткод
  • Интерпретация

Основная идея

Учебный компилятор — это конвейер: токены, AST, байткод. На C++ всё видно структурно.

Выполнение байткода:

C++void run() {
    for (int pc = 0; pc < code.size(); ) {
        switch (code[pc++]) {
            case PUSH: stack.push(code[pc++]); break;
            case ADD: stack.push(stack.pop() + stack.pop()); break;
        }
    }
}

Почему это важно

Игрушечные компиляторы — фундамент сложных: после этого шага можно смело читать LLVM.

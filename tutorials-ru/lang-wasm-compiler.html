Компилятор в WebAssembly на TypeScript

Почему WebAssembly — отличная цель для компилятора?

WebAssembly — бинарный формат для быстрого выполнения в браузере. Его преимущество для изучения компиляторов в том, что конечный результат — исполняемый в браузере файл .wasm: сразу, без посредников, видно, работает ли ваш код.

Учебник начинается со своего мини-языка и проходит три основных этапа: lexer для распознавания токенов, parser для построения дерева синтаксиса и генератор кода для производства байт-кода wasm.

Структура входного языка

У языка JavaScript-подобный синтаксис: целые числа, локальные переменные, инструкция return и функция main. Простейшая отправная точка — генерировать функцию, работающую с заданным числом входных аргументов и возвращающую результат через return.

Лексер и парсер

Начальные части классические: токены number, identifier, операторы и ключевые слова. Далее парсер рекурсивным спуском строит AST:

typescript// Разбор выражения: число, переменная или вызов функции
function parseExpression(): AstNode {
  const token = nextToken();
  if (token.type === "number") {
    return { kind: "number", value: Number(token.value) };
  }
  if (token.type === "identifier") {
    const next = peek();
    if (next.type === "lparen") {          // вызов функции
      nextToken();
      const args: AstNode[] = [];
      while (peek().type !== "rparen") {
        args.push(parseExpression());
        if (peek().type === "comma") nextToken();
      }
      nextToken();                         // закрыть скобку
      return { kind: "call", name: token.value, args };
    }
    return { kind: "var", name: token.value };
  }
  throw new Error(`Неожиданный токен: ${token.value}`);
}

Этот простой парсер корректно разбирает вложенные структуры вроде main(add(1, 2)).

Генерация байт-кода wasm

Самая интересная часть — перевод AST в двоичные инструкции: каждый узел превращается в серию opcode и leb128. Например, сложение двух чисел — инструкция i32.add, а функция — type section и function body:

typescript// Генерация байт-кода для функции main
function emitFunction(name: string, params: number[], body: AstNode): Uint8Array {
  const bytes: number[] = [];

  // Регистрирует section function type
  const typeIdx = encodeL128(params.filter(p => p === i32).length);

  // body: содержимое выражения return
  bytes.push(0x0b);          // конец блока выражения
  emitExpression(body);      // инструкции добавляются в bytes

  return new Uint8Array(bytes);
}

Здесь видно, что разные части (header, type и code) регистрируются модульным байтом 0x и идентификатором.

Запуск и тестирование

В конце загрузчик выполняет байт-код в браузере через WebAssembly.instantiate и печатает результат функции. Этот цикл — редактирование, компиляция, запуск — даёт мгновенную обратную связь и делает обучение по-настоящему осязаемым.

Итоги

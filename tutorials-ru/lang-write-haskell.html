Введение и цель

Если вы читали «Write Yourself a Scheme за 48 часов» — эта книга следующий шаг: вместо простого интерпретатора вы строите полный компилятор функционального языка с системой типов Hindley-Milner, type classes, алгоритмом десахаринга (desugaring) и финальным исполнением через трансляцию в C. Итог — настоящий исполняемый файл.

Содержание и архитектура

Книга в 14 главах: синтаксис через Parsec; AST (термы через сопоставление с образцом); промежуточное представление (Core Language); система типов (подстановка, унификация, Hindley-Milner); type classes и разрешение инстансов; преобразование кортежей/строк в базовые структуры; десахаринг; мономорфизация; и наконец генератор кода, переводящий Core в C.

Пример кода: унификация (Unification)

haskell-- Подстановка типов
type Subst = Map.Map TVar Type

-- Унификация: приведение двух типов к одному виду через подстановку
unify :: Type -> Type -> Subst -> Either String Subst
unify (TAp l r) (TAp l' r') s = do
  s1 <- unify l l' s
  s2 <- unify r r' s1
  return s2
unify (TVar a) t s = bind a t s
unify t (TVar a) s = bind a t s
unify TInt TInt s = return s
unify TBool TBool s = return s
unify t1 t2 _ =
  Left ("несовпадение типов: " ++ show t1 ++ " и " ++ show t2)

Это тот же алгоритм (Робинсона), что используется во многих реальных функциональных компиляторах, включая GHC.

Финальный шаг: трансляция в C

После проверки типов программы Core Language переводятся в код C (пакет Crunch) — здесь вы сталкиваетесь с реальными проблемами вроде управления кучей и сборки мусора (выделение через malloc и сборка по меткам). Финальные шаги — выполнение реальных примеров (например, интерпретатора и небольших программ).

Итоги

Продвинутый, но уникальный ресурс для понимания функциональных компиляторов: система типов Хиндли-Милнер, алгоритм унификации, type classes и трансляция в промежуточный язык — всё на практике. Предпосылки: знакомство с Haskell и базовыми концепциями компиляторов.

О чём это

Первая часть подробного руководства по созданию веб-сервера с нуля на Python. Автор показывает, как с помощью исключительно стандартной библиотеки написать HTTP-сервер, который обрабатывает запросы, отдаёт файлы и может вести лог — шаг за шагом, начиная с голого сокета.

Что вы узнаете

  • Разбор HTTP-запросов вручную: строка запроса и заголовки
  • Построение ответов: статус, заголовки, тело
  • Обработка GET-запросов и раздача файлов
  • Структура учебного сервера, которую легко расширять

Основная идея

Сервер построен на чистом socket-модуле Python: один файл, одна точка входа, цикл обслуживания клиентов. Запрос и ответ разбираются как простые строки — это и есть весь HTTP.

Ядро решения — функция-обработчик запроса:

Pythondef handle_request(client):
    request = request_string(client)
    # Разбираем метод, путь и заголовки
    response = build_response(request)
    client.send(response)

Почему это важно

События HTTP понятны до последней строки: принцип «передай данные через сокет» работает в любом масштабе — от учебного сервера до веб-серверов, обслуживающих миллионы запросов.

Создадим Express с нуля — пишем свою библиотеку

О чём это

Цикл статей, в которых библиотека Express воссоздаётся с нуля на Node.js: вы сами реализуете цепочку промежуточных обработчиков (middleware), маршрутизацию по методам и путям и простой механизм запросов-ответов, повторяя то, как устроен настоящий мини-фреймворк.

Что вы узнаете

  • Как устроена цепочка middleware и зачем она нужна
  • Реализация app.use, app.get, app.post своими руками
  • Маршрутизация с параметрами путей
  • Передача запроса дальше по цепочке через next()

Основная идея

Главная идея Express — массив функций-обработчиков: запрос проходит по списку, пока кто-то не ответит. Каждое зарегистрированное приложение — это функция, вызываемая по порядку.

Вот так выглядит цепочка в миниатюре:

Node.jsconst chain = [];

function use(fn) { chain.push(fn); }

use((req, res, next) => {
  // Логирование каждого запроса
  console.log(req.url);
  next(); // передаём запрос дальше
});

Почему это важно

Понимание middleware-цепочки открывает внутренности почти всех современных JS-фреймворков: Express, Koa и их клоны — всего лишь список функций, которые решают, отвечать или передать управление дальше.

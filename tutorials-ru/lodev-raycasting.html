О чём это

Урок Lode's Raycasting рендерит мир в духе Wolfenstein 3D: лучи из камеры по 2D-карте, расстояние до стен и вертикальные полосы — трюк псевдо-3D, покоривший 90-е.

Что вы узнаете

  • Почему рэйкастинг — не трассировка: полосы стен
  • Алгоритм DDA: быстрый шаг по клеткам карты
  • Расстояние, затенение и искажение перспективы
  • Текстуры стен и вращение камеры

Основная идея

Волкастер — компромисс: вместо геометрии — высоты полос по расстоянию до стен из 2D-карты, считанное по алгоритму DDA. За несколько сотен строк получается убедительный 3D-мир.

Шаг по клетке карты — алгоритм DDA:

C++// Волшебная формула дельты шагов по сетке
deltaDistX = fabs(1 / rayDirX);
sideDistX = (rayDirX < 0 ? (posX - mapX) * deltaDistX
                         : (mapX + 1 - posX) * deltaDistX);

Почему это важно

Игры 90-х — это программы, которыми можно управлять: волкастинг остаётся элегантным курсом в графику и фейки, из которых собрана вся игровая индустрия.

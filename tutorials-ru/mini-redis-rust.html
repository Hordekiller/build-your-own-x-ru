О чём это

Проект mini-redis на Rust: сервер с async-сетью (tokio), команды, транзакции и время жизни ключей — высокопроизводительная in-memory база.

Что вы узнаете

  • Async-сеть с tokio
  • Команды и парсинг
  • Ключи и время жизни
  • Клиентская библиотека

Основная идея

Mini-redis использует асинхронность Rust: сервер обслуживает тысячи соединений, команды исполняются без блокировок. Проект — официальный пример токио.

Async-обработка команды:

Rustasync fn process(cmd: Command) -> Result<Value> {
    match cmd {
        Command::Set { key, value } => { store.set(key, value).await }
        Command::Get { key } => store.get(key).await,
    }
}

Почему это важно

Современный async-Rust — стандарт сетевых сервисов: mini-redis показывает, как строятся высоконагруженные хранилища в 2020-е.

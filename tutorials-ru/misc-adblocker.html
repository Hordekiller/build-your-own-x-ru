Основная идея

Блокировщик рекламы — это фильтр на уровне браузера: расширение перехватывает запросы и блокирует те, что идут на домены рекламных сетей. Список доменов — это и есть вся «база данных» фильтра.

Фильтрация одного запроса — несколько строк:

JavaScript// Перехватываем сетевые запросы
browser.webRequest.onBeforeRequest.addListener(
  (details) => {
    if (blockedDomains.includes(new URL(details.url).host)) {
      return { cancel: true }; // реклама заблокирована
    }
  },
  { urls: ["<all_urls>"] },
  ["blocking"]
);

Почему это важно

Каждый день ваши данные собираются рекламными сетями: свой блокировщик — это и отличный способ изучить API браузеров, и шаг к приватности.

Как работает расширение для блокировки рекламы?

Реклама обычно загружается со специальных доменов (например, adserver.com). AdBlocker перехватывает запросы браузера к этим доменам и блокирует их. В Chrome это делается через API webRequest и событие onBeforeRequest.

Преимущество этого метода: блокировка происходит на уровне сети, поэтому реклама даже не загружается — это быстрее, чем скрытие через CSS.

manifest.json

Первый шаг любого расширения — файл manifest, объявляющий разрешения. Для AdBlocker нужны webRequest и webRequestBlocking:

json{
  "manifest_version": 2,
  "name": "Простой AdBlocker",
  "version": "1.0",
  "description": "Простой блокировщик рекламы",
  "permissions": [
    "webRequest",
    "webRequestBlocking",
    "<all_urls>"
  ],
  "background": {
    "scripts": ["blocker.js"],
    "persistent": true
  }
}

У третьей версии расширений (MV3) есть другой способ (declarativeNetRequest), но эта простая структура отлично подходит для обучения.

Логика блокировки

Сердце расширения — background-скрипт, который перед каждым запросом сравнивает URL со списком рекламных доменов:

javascript// Простой список рекламных доменов
const AD_DOMAINS = [
  'doubleclick.net',
  'googleadservices.com',
  'adservice.google.com',
  'adsense.com',
  'googlesyndication.com'
];

// Блокировка запросов к рекламным доменам
chrome.webRequest.onBeforeRequest.addListener(
  function (details) {
    const url = new URL(details.url);
    const host = url.hostname;

    if (AD_DOMAINS.some(domain => host === domain || host.endsWith('.' + domain))) {
      console.log('Заблокировано:', details.url);
      return { cancel: true };   // прерываем запрос
    }
    return {};                   // разрешаем продолжение
  },
  { urls: ['<all_urls>'] },
  ['blocking']
);

Точное сравнение hostname (равенство или суффикс) блокирует и поддомены, не задевая похожие домены по ошибке.

Продвинутые опции

Для настоящего AdBlocker нужно больше: огромные списки фильтров (EasyList), блокировка по URL-паттернам, а не только по доменам, и UI для управления исключениями. Но этих 20 строк уже достаточно для базового поведения — и разница заметна на «тяжёлых» сайтах.

Итог

Создание AdBlocker — отличный первый шаг к пониманию экосистемы расширений браузера: manifest, background-скрипт и мощные API. С этими знаниями можно делать и другие полезные расширения.

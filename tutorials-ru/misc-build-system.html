Что делает система сборки?

Инструменты вроде make или ninja знают, что «чтобы получить выход X, сначала нужно выполнить эти действия в таком порядке». Вы просто хотите результат: build system строит граф зависимостей, выполняет только необходимые задачи и пропускает повторные (когда входные данные не менялись).

В этом уроке мы сделаем простую систему сборки на Nim, определяющую задачи и их зависимости и выполняющую их в правильном порядке.

Определение задачи и зависимостей

Основная идея: у задачи есть имя, исполняемое тело и список предварительных задач. После запуска система должна выполнить каждую задачу только один раз (даже если на неё ссылаются из нескольких мест):

nimtype
  Task = ref object
    name: string
    deps: seq[string]
    action: proc()

var tasks = initTable[string, Task]()

# Регистрация новой задачи
proc task(name: string, deps: seq[string] = @[], action: proc()) =
  tasks[name] = Task(name: name, deps: deps, action: action)

# Выполнение задачи + всех её зависимостей (один раз)
proc build(name: string) =
  if name in built: return        # повторные вызовы пропускаем
  built.incl(name)
  let t = tasks[name]
  for d in t.deps: build(d)      # сначала зависимости
  t.action()                     # потом сама задача

Множество built играет роль «отметок о выполнении»: граф не зацикливается, и лишняя работа не повторяется.

Пример использования

Определим несколько задач с зависимостями, чтобы увидеть порядок выполнения:

nimtask("compile") do:
  echo "Компиляция файлов..."

task("test", @["compile"]) do:
  echo "Запуск тестов..."

task("package", @["test"]) do:
  echo "Сборка финального пакета..."

build("package")
# Вывод:
# Компиляция файлов...
# Запуск тестов...
# Сборка финального пакета...

Это ровно тот алгоритм, что make применяет к «целям», только без разбора синтаксиса Makefile.

К настоящей системе

Следующим шагом можно добавить сравнение «времени файлов» (timestamps), чтобы, как в make, пересобирались только изменённые файлы, отчёты о цепочках ошибок и параллельное выполнение задач. Этот простой каркас — основа всех систем сборки в мире.

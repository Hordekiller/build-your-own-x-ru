О чём это

Проект cache-lite реализует собственный кеш на Kotlin: хранение значений, время жизни записей, ограничение размера и понятный API — маленькая библиотека, которую можно использовать в приложениях.

Что вы узнаете

  • Интерфейс кеша: put, get, удаление по ключу
  • Время жизни записи и истечение (TTL)
  • Ограничение размера и политики вытеснения
  • Потокобезопасность и простота API

Основная идея

Кеш — это словарь, который умеет забывать: записи живут ограниченное время, а при переполнении старые удаляются. Простая идея, но именно она делает приложения быстрыми.

Классический get с проверкой срока жизни:

Kotlinfun get(key: String): T? {
  val entry = store[key] ?: return null
  // Запись устарела — удаляем и возвращаем null
  if (entry.expiresAt < now()) { store.remove(key); return null }
  return entry.value
}

Почему это важно

Кеширование — главный трюк производительности: от DNS до CDN и кешей приложений. Собрав свою библиотеку, вы поймёте нюансы TTL и вытеснения и будете осознанно выбирать готовые решения.

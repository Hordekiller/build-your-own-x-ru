Что такое LRU-кеш?

Кеш (Cache) хранит часто используемые данные рядом с программой, чтобы следующий запрос отвечал быстрее. LRU (Least Recently Used — «давно не использовавшийся») — политика, при которой, когда ёмкость заполнена, удаляется элемент, дольше всех остававшийся без использования. Эта политика применяется в операционных системах, базах данных и браузерах.

Правильная реализация LRU требует сочетания HashMap (быстрый поиск) и двусвязного списка (Doubly Linked List), чтобы знать порядок использования.

Структура данных

Основная идея: каждый элемент — «узел» двусвязного списка, а HashMap отображает ключи на узлы. Когда элемент используется, узел переносится в конец списка (самый свежий); а когда ёмкость заполнена, удаляется первый узел списка:

kotlinclass CacheLite<K, V>(private val capacity: Int) {

    private class Node<K, V>(val key: K, var value: V) {
        var prev: Node<K, V>? = null
        var next: Node<K, V>? = null
    }

    private val map = HashMap<K, Node<K, V>>()
    private var head: Node<K, V>? = null   // самый старый
    private var tail: Node<K, V>? = null   // самый свежий

    operator fun get(key: K): V? =
        map[key]?.also { node -> moveToTail(node) }?.value

    operator fun set(key: K, value: V) {
        val existing = map[key]
        if (existing != null) {
            existing.value = value              // обновление
            moveToTail(existing)
        } else {
            val node = Node(key, value)
            map[key] = node
            appendTail(node)                    // добавить в конец
            if (map.size > capacity) evictHead()  // удалить старый
        }
    }
}

Операторы get/set делают использование кеша естественным, как с HashMap, — то самое ощущение, к которому стремился автор.

Управление списком

Вспомогательные функции (moveToTail, evictHead) — сердце поддержания порядка:

kotlin    private fun moveToTail(node: Node<K, V>) {
        if (node === tail) return
        if (node === head) {
            head = node.next
            head?.prev = null
        } else {
            node.prev?.next = node.next
            node.next?.prev = node.prev
        }
        appendTail(node)
    }

    private fun appendTail(node: Node<K, V>) {
        node.prev = tail
        node.next = null
        tail = node
        node.prev?.next = node
        if (head == null) head = node
    }

    private fun evictHead() {
        head?.let {
            map.remove(it.key)
            head = it.next
            head?.prev = null
        }
    }

Обратите внимание: evictHead должен удалять ключ и из HashMap — иначе останутся следы «просроченных» элементов.

Итог

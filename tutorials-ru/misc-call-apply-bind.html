Реализуй сам методы call(), apply() и bind() в JavaScript

О чём это

Урок реализует с нуля три важнейших метода функций: call, apply и bind. Вы разберёте, как this подменяется в вызове и как замыкания сохраняют контекст, — всё без встроенных методов.

Что вы узнаете

  • Как работает this в функциях и зачем его подменять
  • call: вызов с явным контекстом
  • apply: передача аргументов массивом
  • bind: каррирование контекста через замыкание

Основная идея

call и apply — это просто вызов функции с подменой контекста: JavaScript на уровне языка даёт нам эту силу. bind возвращает новую функцию, навсегда помнящую контекст, — с помощью замыкания.

Собственный call не сложнее нескольких строк:

JavaScriptFunction.prototype.myCall = function (context, ...args) {
  context = context || globalThis;
  const key = Symbol();
  context[key] = this;   // временно кладём функцию в объект
  const result = context[key](...args);
  delete context[key];   // и убираем следы
  return result;
};

Почему это важно

Эти методы — рабочие лошадки JS-кода: поняв их устройство, вы научитесь читать сложные библиотеки и писать код, не зависящий от случайного контекста вызова.

Что такое CDN и как он работает?

Сеть доставки контента (CDN) копирует ваш контент (изображения, видео, страницы) на edge-серверы по всему миру. Когда пользователь запрашивает что-то у ближайшего edge, ответ приходит быстрее, а нагрузка на исходный сервер снижается. Основные компоненты: edge node, кеш, проксирование к origin и умное обновление.

Этот урок с OpenResty (Nginx вместе с Lua) строит настоящий работающий CDN, дающий и теоретическое понимание, и практические навыки.

Разница кеша и предварительного кеша

Есть два основных типа кеширования: pull caching — edge берёт контент, только когда приходит запрос, и push caching — контент заранее рассылается по всем edge-узлам. Для начала pull достаточно. HTTP-заголовки вроде Cache-Control: max-age определяют, что и как долго можно кешировать:

lua-- Проверка кешируемости запроса и настройка заголовков
local cache_ttl = 3600   -- один час

function handle_request(ngx)
    local status, headers, body = ngx.location.capture('/proxy_upstream')

    if status == ngx.HTTP_OK then
        -- Кеширование ответа с временем жизни
        ngx.shared.cache:set(ngx.var.uri, body, cache_ttl)
        ngx.header['Cache-Control'] = 'public, max-age=' .. cache_ttl
    end
    ngx.status = status
    ngx.say(body or 'error')
end

Вся логика пишется на Lua, а Nginx делает остальное: TLS, HTTP/2, gzip.

Конфигурация Nginx

Файл nginx.conf, связывающий edge с origin:

nginx# edge node: кеш + прокси к origin
server {
    listen 8080;

    location / {
        # Имя этого edge node в заголовке для отладки
        add_header X-CDN-Node "edge-ru-1";

        # Отправка к backend с выборкой из кеша
        content_by_lua_block {
            local res = ngx.location.capture("/internal_origin")
            ngx.status = res.status
            ngx.say(res.body)
        }
    }

    location /internal_origin {
        proxy_pass http://origin-backend:3000;
        proxy_set_header Host $host;
    }
}

С такой структурой каждый запрос может обслуживаться из общего кеша (shared dict) или уходить к origin.

Теория за кулисами

В ходе урока рассматриваются и реальные проблемы CDN: инвалидация кеша (очистка запросом PURGE), настройка TTL по типу контента, география edge-узлов и тёплое хранение (prefetch). Каждая решается примерами на Lua.

О чём это

Проект строит чат-сервис на Rust: TCP-приём клиентов, асинхронные соединения, бродкаст сообщений и протокол чата — сервис, готовый держать тысячи пользователей.

Что вы узнаете

  • Асинхронный TCP-сервер (tokio)
  • Протокол чата: подключение, текст, уведомления
  • Список комнат и рассылка по подписчикам
  • Обработка отключений и веревочка задач

Основная идея

Чат — это набор соединений и реестр подписчиков: каждое сообщение попадает в комнату, а сервер рассылает его всем участникам. Асинхронность позволяет держать тысячи соединений в одном процессе.

Рассылка сообщения — центральный узел:

Rustasync fn broadcast(room: &Room, msg: &Message) {
    // Отправляем сообщение каждому участнику комнаты
    for client in room.clients.iter() {
        client.send(msg.clone()).await;
    }
}

Почему это важно

Серверы реального времени — это управление тысячами асинхронных потоков: на Rust вы увидите, как компилятор помогает писать безопасный параллельный код.

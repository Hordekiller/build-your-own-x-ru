Дерево решений — это «задавание вопросов»

Дерево решений превращает классификацию в последовательность простых вопросов: «возраст старше 30?», «какого цвета айфон?». Каждый вопрос делит данные на две ветви, пока не будут достигнуты листья, где сосредоточены образцы одного класса. Главный вопрос построения: какой признак и с каким порогом даёт лучшее разделение?

Мера нечистоты: Gini

Хорошее разделение разводит смешанные классы. «Нечистота Джини» измеряет, насколько классы перемешаны внутри группы (0 = чисто); каждый split выбирается так, чтобы уменьшение нечистоты было максимальным:

pythondef gini(groups, classes):
    """Взвешенная нечистота всех ветвей"""
    total = sum(len(g) for g in groups)
    score = 0.0
    for group in groups:
        size = len(group)
        if size == 0: continue
        # вероятность каждого класса внутри этой ветви
        probs = [group.count(c) / size for c in classes]
        score += (size / total) * (1 - sum(p ** 2 for p in probs))
    return score

1 - Σp²: если все одного класса → ноль. Чем сильнее перемешано, тем больше значение.

Поиск лучшего разделения

Для каждого признака пробуем кандидатные пороги (средние соседних значений) — побеждает тот, у кого минимальный Gini:

pythondef best_split(data, classes):
    """Найди (признак, порог) с наименьшим gini"""
    best = None
    for col in range(len(data[0]) - 1):
        values = sorted({row[col] for row in data})
        for i in range(len(values) - 1):
            threshold = (values[i] + values[i + 1]) / 2
            left = [r for r in data if r[col] <= threshold]
            right = [r for r in data if r[col] > threshold]
            g = gini([left, right], classes)
            if best is None or g < best[0]:
                best = (g, col, threshold, left, right)
    return best

Построение порога из «среднего соседних значений» делает пригодными и непрерывные признаки.

Рекурсивное построение дерева

Всё та же рекурсивная функция: если группа чистая → лист; иначе делаем лучший split и повторяем на двух ветвях. Предсказание проходит тот же путь от корня до листа. С этими ~80 строками у вас есть идея всех настоящих деревьев (Random Forest, XGBoost) — они лишь объединяют сотни таких деревьев.

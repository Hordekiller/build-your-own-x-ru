Зачем сеть с нуля?

Большинство людей просто «вызывают библиотеку»: model.add(...) и model.fit(...). В этой серии вы строите то же самое на numpy и понимаете, что на самом деле делают forward pass, backpropagation и gradient descent. Это понимание — единственный способ разобраться, почему сеть работает хорошо или плохо.

Нейрон и слой

Слой Dense — это: умножение матрицы входов на веса + смещение. В numpy весь слой записывается двумя строками:

pythonimport numpy as np

class Layer_Dense:
    def __init__(self, n_inputs, n_neurons):
        # маленькие случайные веса + смещения
        self.weights = np.random.randn(n_inputs, n_neurons) * 0.01
        self.biases = np.zeros((1, n_neurons))

    def forward(self, inputs):
        self.inputs = inputs
        self.output = np.dot(inputs, self.weights) + self.biases
        return self.output

Матричное умножение значит, что все нейроны и все образцы одного batch считаются одновременно — в этом сила numpy.

Вместе с активацией и ошибкой

После слоя добавляются функция активации (ReLU в промежуточных слоях, Softmax на выходе) и функция ошибки (Cross-Entropy). Важная деталь серии: всё это отдельные классы с forward и (позже) backward:

pythondef relu_forward(inputs):
    return np.maximum(0, inputs)

def softmax_forward(z):
    exp = np.exp(z - np.max(z, axis=1, keepdims=True))  # числовая устойчивость
    return exp / np.sum(exp, axis=1, keepdims=True)

def cross_entropy(y_pred, y_true):
    return -np.log(y_pred[range(len(y_pred)), y_true] + 1e-9).mean()

Вычитание максимума перед exp нужно, чтобы не произошло переполнения — деталь, которую не видно в готовых библиотеках.

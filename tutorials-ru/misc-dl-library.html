О чём это

Проект Ruchi et al.: библиотека глубокого обучения на NumPy с нуля — автоматическое дифференцирование, слои, оптимизатор и обучение сетей как на маленьком PyTorch.

Что вы узнаете

  • Автоматическое дифференцирование и граф вычислений
  • Слои: линейный, активации, потеря
  • Обратное распространение из первых принципов
  • Мини-обучение: градиентный спуск на данных

Основная идея

Глубокое обучение — это вычисления с градиентами: библиотека строит граф операций, а автодифференцирование проходит по нему назад, вычисляя производные для каждого параметра.

Ядро автодифа — одна операция с градиентом:

Pythonclass Mul(Op):
    def forward(self, a, b): return a * b
    def backward(self, grad):  # градиент через правило произведения
        return grad * b, grad * a

Почему это важно

Под PyTorch и TensorFlow лежат именно эти механизмы: написав свою библиотеку на NumPy, вы увидите, что автодиф — это просто правила дифференцирования в коде.

Пишем парсер DMIDecode на Nim

Что такое dmidecode?

Инструмент dmidecode читает информацию об аппаратуре системы из таблиц SMBIOS/DMI: производителя материнской платы, версию BIOS, тип памяти, серийные номера и другое. Эти данные печатаются в стандартный вывод структурированным текстом, и обычно их нужно разбирать для автоматизации серверов (мониторинг, инвентаризация).

Структура вывода

Вывод dmidecode состоит из «секций»: каждая начинается с типа (Type) и Handle, затем идут поля с отступами; группы информации — BIOS, System, Baseboard и другие:

nim# Пример вывода:
# Handle 0x0000, DMI type 0, 24 bytes
# BIOS Information
#     Vendor: American Megatrends Inc.
#     Version: 5.19
#     Release Date: 08/10/2023
# Handle 0x0001, DMI type 1, 27 bytes
# System Information
#     Manufacturer: LENOVO
#     Product Name: ThinkPad T14

Отличительный паттерн начала секции: строка, начинающаяся с Handle и сообщающая тип DMI и размер, а следующая строка — имя группы.

Парсер на Nim

Парсер читает построчно: увидев строку Handle, начинает новую секцию, а поля с отступами прикрепляет к ней:

nimimport strutils, tables, sequtils

type
  DmiRecord = object
    dmiType: int
    name: string
    fields: Table[string, string]

proc parseDMI(content: string): seq[DmiRecord] =
  var
    current: DmiRecord
    inRecord = false

  for line in content.splitLines():
    if line.startsWith("Handle"):
      if inRecord: result.add(current)
      # Извлечение типа из: Handle 0x0001, DMI type 1, 27 bytes
      let m = line.findAll("\d+")
      current = DmiRecord(
        dmiType: parseInt(m[1]),
        name: "", fields: initTable[string, string]()
      )
      inRecord = true
    elif line.startsWith("    ") and inRecord:
      let parts = line.strip().split(":", 1)
      if parts.len == 2:
        current.fields[parts[0]] = parts[1].strip()
    elif inRecord and not line.startsWith(" "):
      current.name = line.strip()

  if inRecord: result.add(current)

Тонкий момент: поля имеют отступ в 4 пробела, а имя секции — без отступа; этих двух правил достаточно, чтобы структурировать весь вывод.

К настоящему инструменту

Когда данные структурированы, можно собрать серийные номера серверов, прочитать MAC сетевых карт из секций типа 41 (Onboard Device) или генерировать вывод в JSON. У dmidecode более 40 типов DMI; этот урок — база для чтения их всех.

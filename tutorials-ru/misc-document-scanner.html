Четыре шага до скана

Мобильный сканер (как CamScanner) делает четыре вещи: 1) находит края бумаги, 2) извлекает её углы, 3) выполняет перспективное преобразование (из-за съёмки под углом), 4) улучшает изображение (серый/порог). Всё это на OpenCV в несколько десятков строк.

Поиск бумаги

Классическая проблема: снимок под углом, плохое освещение, разный фон. Стандартное решение: серый → шумоподавление → поиск краёв → поиск большого контура:

pythonimport cv2
import numpy as np

def find_document(image):
    gray = cv2.cvtColor(image, cv2.COLOR_BGR2GRAY)
    blur = cv2.GaussianBlur(gray, (5, 5), 0)
    edged = cv2.Canny(blur, 75, 200)      # края

    cnts, _ = cv2.findContours(edged.copy(), cv2.RETR_LIST,
                               cv2.CHAIN_APPROX_SIMPLE)
    # самый большой контур = бумага
    cnt = max(cnts, key=cv2.contourArea)
    peri = cv2.arcLength(cnt, True)
    approx = cv2.approxPolyDP(cnt, 0.02 * peri, True)

    # у бумаги должно быть четыре стороны
    return approx if len(approx) == 4 else None

approxPolyDP упрощает углы контура; лист A4 на любом фото имеет четыре стороны.

Перспективное преобразование

Теперь у нас четыре угла. Отображаем их через getPerspectiveTransform в полноценный прямоугольник A4, а warpPerspective формирует новое изображение. Порядок углов (верх-лево, верх-право и т.д.) важен и должен быть отсортирован:

pythondef order_points(pts):
    # сортировка: TL, TR, BR, BL по сумме и разности координат
    s = pts.sum(axis=1); d = np.diff(pts, axis=1)
    return np.array([
        pts[np.argmin(s)], pts[np.argmin(d)],
        pts[np.argmax(s)], pts[np.argmax(d)]
    ], dtype="float32")

def scan(image, corners):
    rect = order_points(corners)
    w = int(max(np.linalg.norm(rect[0]-rect[1]),
                np.linalg.norm(rect[2]-rect[3])))
    h = int(max(np.linalg.norm(rect[0]-rect[2]),
                np.linalg.norm(rect[1]-rect[3])))
    dst = np.array([[0,0],[w-1,0],[w-1,h-1],[0,h-1]], dtype="float32")
    M = cv2.getPerspectiveTransform(rect, dst)
    return cv2.warpPerspective(image, M, (w, h))

Видите — «всего 5 минут» это и есть эти ~30 строк! Результат прогоните через cv2.threshold, чтобы он стал как у настоящего сканера.

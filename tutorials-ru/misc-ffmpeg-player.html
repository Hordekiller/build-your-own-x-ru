Как написать видеоплеер меньше чем в 1000 строк

Цель и поток данных

Воспроизведение видео — это превращение сжатого файла в кадры, которые показываются на экране. Этот урок работает с библиотекой FFmpeg и имеет три этапа: открытие файла и поиск потоков (video/audio), декодирование кадров подходящим кодеком и вывод через SDL. Всё это делается на старом, несколько упрощённом API FFmpeg.

Основной конвейер такой: файл → закодированные пакеты → декодированные кадры → преобразование в RGB → вывод на экран.

Кодеки и структура API

Ключ к этой задаче — понимание двух структур: AVFormatContext (файл и его потоки) и AVCodecContext (активный кодек). Для вывода буфер кадра создаётся через av_frame_alloc.

В цикле воспроизведения каждый кадр декодируется и преобразуется в формат RGB (для SDL). Функция, «подготавливающая кадр для SDL», — ядро всей работы:

c// Преобразование декодированного кадра в RGB и вывод
void displayFrame(AVFrame *frame, AVPicture *pict, SwsContext *sws,
                  SDL_Surface *screen) {
    int w = frame->width, h = frame->height;

    // Преобразование YUV в RGB с помощью swscale
    sws_scale(sws, frame->data, frame->linesize, 0, h,
              pict->data, pict->linesize);

    // Копирование пикселей в поверхность SDL
    SDL_LockSurface(screen);
    memcpy(screen->pixels, pict->data[0],
           pict->linesize[0] * h);
    SDL_UnlockSurface(screen);
    SDL_UpdateRect(screen, 0, 0, w, h);
}

Здесь sws_scale выполняет преобразование формата (YUV → RGB), после чего пиксели напрямую копируются в буфер поверхности SDL.

Управление таймингом (Timing)

Трудная, но важная часть — синхронизация звука и изображения. Чтобы кадры воспроизводились с правильной скоростью, нужно вычислять «время показа» (PTS) и делать usleep между кадрами. Если пропустить этот этап, видео будет воспроизводиться слишком быстро или слишком медленно.

В продвинутой версии разница времени вычисляется по «audio clock»; но в начальном уроке достаточно простой формулы на основе длительности каждого кадра: delay = (frame->pts - last_pts) * (1000 / fps).

Итог

Этот урок показывает, что за несколько сотен строк на C с FFmpeg можно собрать настоящий видеоплеер. Понятия кодеков, преобразования цвета и синхронизации пригодятся в любой мультимедийной работе — и этот путь лучший для начала.

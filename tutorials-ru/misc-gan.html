Что такое GAN?

Generative Adversarial Network (порождающе-состязательная сеть) состоит из двух сетей: генератор (Generator), который из случайного шума создаёт поддельное изображение, и дискриминатор (Discriminator), который пытается отличить подделку от настоящего. Они «играют» друг с другом: подделыватель совершенствуется, пока не обманет распознавателя, а распознаватель становится точнее — равновесие этой гонки и есть реалистичные изображения.

Архитектура

В этом простом уроке используются только слои Dense и LeakyReLU, без свёрток. Генератор: вход 100 шумов → несколько слоёв → изображение 28×28. Дискриминатор: изображение → несколько слоёв → вероятность «настоящести»:

pythondef generator(z_dim):
    model = Sequential([
        Dense(256, input_dim=z_dim),
        LeakyReLU(alpha=0.2),
        Dense(512), LeakyReLU(alpha=0.2),
        Dense(784, activation='tanh')   # 28*28 пикселей
    ])
    return model

def discriminator():
    model = Sequential([
        Dense(256, input_dim=784),
        LeakyReLU(alpha=0.2),
        Dense(128), LeakyReLU(alpha=0.2),
        Dense(1, activation='sigmoid')  # вероятность настоящести
    ])
    return model

tanh на выходе генератора держит изображение между -1 и 1: входные данные (MNIST) тоже должны быть заранее отмасштабированы в этот диапазон.

Состязательное обучение

В каждом шаге обучения сначала дискриминатор тренируется на настоящих+поддельных данных, затем генератор обновляется через всю объединённую сеть. Чтобы генератор не застрял в начале, дискриминатор иногда держат «сильнее», а метки подделок для генератора смягчают до ~0.9 (label smoothing):

pythonfor epoch in range(epochs):
    # 1) обучение дискриминатора
    real = batch_from_dataset()
    fake = gen.predict(noise)
    d_loss = disc.train_on_batch(
        np.concatenate([real, fake]),
        np.concatenate([ones, zeros])   # real=1, fake=0
    )

    # 2) обучение генератора через объединённую сеть
    combined.train_on_batch(noise, ones * 0.9)

Классическая ошибка: если дискриминатор слишком быстро «отвергает всё», градиент генератора исчезает, и изображения становятся серыми; стабильность GAN — искусство этого равновесия.

Наблюдение за прогрессом

Каждые несколько шагов делайте снимок с генератора и сохраняйте: вы увидите путь от полного шума до читаемых цифр. Это «наблюдение за обучением» — одно из самых захватывающих переживаний в машинном обучении.

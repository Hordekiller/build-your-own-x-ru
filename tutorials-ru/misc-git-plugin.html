О чём это

Руководство расширяет git собственным плагином на Python: хуки, пользовательские команды и автоматизация репозитория через инструменты, которые уже встроены в git.

Что вы узнаете

  • Что такое хуки git и как их писать
  • Пользовательская команда git mycommand
  • Работа с протоколом git из Python
  • Автоматизация: предкоммитные проверки

Основная идея

Git — расширяемая система: хуки запускают ваши скрипты на события (pre-commit, post-merge), а команды вида git-xxx становятся подкомандами git. Плагин — это просто скрипт и несколько файлов.

Плагин-команда умещается в файл:

Python#!/usr/bin/env python3
# этот файл называется git-statline
import subprocess
print(subprocess.check_output(["git", "log", "--oneline", "-5"]).decode())

Почему это важно

Свой плагин — это привычка иерархии: если вы автоматизируете git-поток, команда уходит в подкоманды, а знание расширяемости git сэкономит часы рутины.

Git расширяем на любом языке

Мало кто знает: любая программа с именем git-XXX, лежащая в PATH, вызывается командой git XXX! Этот простой механизм создаёт все «плагины git» — от git-flow до личных инструментов. Так же можно и на Python — нужно лишь быть исполняемым файлом и правильно работать со stdin/stdout.

Правило именования

Главное правило: git-<имя> в PATH → команда git <имя>. Поэтому положите файл git-brag или git-stats в /usr/local/bin или в папку scripts проекта:

bash# git-brag — работает без какой-либо настройки git
code git-brag
chmod +x git-brag          # обязателен исполняемый бит!
sudo cp git-brag /usr/local/bin/

git brag                   # ← плагин выполняется
git brag --help            # ← аргументы тоже принимаются

Важнейший момент: сам git не знает такую команду; он просто находит программу и запускает её.

Простой плагин: ваша статистика за сегодня

python#!/usr/bin/env python3
import subprocess, sys

# подсчёт всех коммитов за сегодня
cmd = ["git", "log", "--since=midnight", "--oneline"]
result = subprocess.run(cmd, capture_output=True, text=True)

commits = result.stdout.strip().splitlines()
print(f"Сегодня ты сделал {len(commits)} коммитов:")
for c in commits[:10]:
    print(" ", c)

С subprocess вы опираетесь на сам git (а не переписываете его логику!) — стандартный подход всех плагинов.

Проверка хуками через плагин

Плагины не только для веселья: можно запускать git pre-push плагин на CI или сделать плагин, читающий git status --porcelain и сообщающий об ошибках стиля кода. Разница плагина и хука: плагин пользователь вызывает сам, хук выполняется автоматически.

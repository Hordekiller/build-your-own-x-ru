GTK не только на C?

GTK — имя графического интерфейса Linux (его использует GNOME). Хотя GTK написан на C, у него есть отличные привязки для Ruby (gem gtk3). Этот урок строит полноценный «список задач» (Todo list): окно, список, добавление/удаление задач.

Окно и цикл событий

У GTK есть «цикл событий»: программа ждёт события (клик, ввод, закрытие) и реагирует на них. Базовая структура:

rubyrequire 'gtk3'

class TodoApp
  def initialize
    # создаём главное окно
    @window = Gtk::Window.new('Мой список дел')
    @window.set_default_size(400, 500)
    @window.signal_connect('destroy') { Gtk.main_quit }

    # вертикальная раскладка: поле ввода + кнопка + список
    @vbox = Gtk::Box.new(:vertical, 6)
    @entry = Gtk::Entry.new
    @entry.placeholder_text = 'Новая задача...'
    @add_button = Gtk::Button.new(label: 'Добавить')
    @list = Gtk::ListBox.new

    @vbox.pack_start(@entry, expand: false, fill: false, padding: 0)
    @vbox.pack_start(@add_button, expand: false, fill: false, padding: 0)
    @vbox.pack_start(@list, expand: true, fill: true, padding: 0)
    @window.add(@vbox)
  end

  def run
    @window.show_all
    Gtk.main   # запуск цикла событий
  end
end

TodoApp.new.run

signal_connect подключает обработчик события — тот же механизм callback, что есть во всех тулкитах (Qt, Swing).

Добавление задачи по сигналу

rubydef add_todo
  text = @entry.text.strip
  return if text.empty?

  row = Gtk::ListBoxRow.new
  row.add(Gtk::Label.new(text))
  @list.add(row)          # добавить в список
  @entry.text = ''        # очистить поле ввода
end

# связь: клик по кнопке ← добавление
@add_button.signal_connect('clicked') { add_todo }
# связь: Enter тоже добавляет
@entry.signal_connect('activate') { add_todo }

Для удаления каждая строка получает свою кнопку с отдельным callback — тот же паттерн «сигнала» повторяется.

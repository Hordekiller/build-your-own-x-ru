Учимся писать хеш-таблицу на C

Что такое хеш-таблица и почему она важна?

Хеш-таблица — структура, которая с помощью хеш-функции отображает ключ в индекс массива; благодаря этому поиск, добавление и удаление в среднем выполняются за O(1). Почти всё — от словарей Python до кеша браузера — построено на этой структуре.

Создание хеш-таблицы на C учит управлять памятью и принимать решения о коллизиях и росте таблицы — вещах, скрытых в языках высокого уровня.

Базовые структуры и хеш-функции

Первый шаг — определить структуры ht_item (элемент, содержащий ключ и значение) и ht_hash_table (массив элементов и размер). Хеш-функция превращает строку в большое число, а затем берёт остаток от деления:

c#include <stdlib.h>
#include <string.h>

typedef struct {
    char* key;
    char* value;
} ht_item;

// Простая хеш-функция: взвешенная сумма символов
static int hash(const char* s, const int a, const int m) {
    long hash = 0;
    const int len = strlen(s);
    for (int i = 0; i < len; i++) {
        hash = (hash * a + s[i]) % m;
    }
    return hash;
}

Эту функцию можно настраивать, задавая a (простое число) и m (размер таблицы), чтобы получить более равномерное распределение.

Обработка коллизий

Когда два ключа попадают в один индекс, происходит «коллизия». Простейший способ борьбы — метод цепочек: каждая ячейка таблицы хранит связный список элементов. Другой способ — «открытая адресация» (open addressing), при которой элемент перемещается в следующую свободную ячейку.

В этом уроке используется открытая адресация: при поиске, если ячейка занята, мы продолжаем регулярные шаги, пока не найдём свободную.

Вставка и поиск

Функции ht_insert и ht_search составляют ядро таблицы:

c// Вставка пары ключ/значение
void ht_insert(ht_hash_table* ht, const char* key, const char* value) {
    ht_item* item = ht_new_item(key, value);
    int index = hash(key, ht->base_size, ht->size);
    ht_item* cur = ht->items[index];

    // Открытая адресация: найди свободную ячейку или ячейку с тем же ключом
    int i = index;
    while (cur != NULL) {
        if (cur != &DELETED_ITEM) {
            if (strcmp(cur->key, key) == 0) {
                free(cur->value);
                cur->value = item->value;
                free(item);
                return;
            }
        }
        i = (i + 1) % ht->size;
        cur = ht->items[i];
    }
    ht->items[i] = item;
    ht->count++;
    // Когда таблица заполнилась, увеличиваем её
    if (ht->count == ht->size) ht_resize_up(ht);
}

В этом коде удалённая ячейка помечается специальным указателем DELETED_ITEM, чтобы не разрывать цепочку поиска; когда таблица заполняется, ht_resize_up удваивает её размер.

Пишем INI-парсер на Nim

Формат INI

INI — простейший текстовый формат конфигурации: секции отделяются [именем], а внутри секции идут пары ключ=значение. Комментарии начинаются с ; или #. Формат до сих пор используется повсюду для небольших инструментов — от php.ini до системных конфигов:

ini[server]
host = 0.0.0.0
port = 8080

[database]
name = byox
user = admin
; это строка-комментарий
pass = secret123

Настройка парсера

Парсер работает построчно: пропускает пустые строки и комментарии, [x] регистрирует как новую секцию, а ключ=значение добавляет в текущую секцию. Состояние текущей секции нужно сохранять между строками:

nimimport strutils, tables

type IniFile = Table[string, Table[string, string]]

proc parseIni(content: string): IniFile =
  var
    currentSection = ""         # текущая секция
    section = initTable[string, string]()

  for line in content.splitLines():
    let trimmed = line.strip()

    # Пропуск пустых строк и комментариев
    if trimmed.len == 0 or trimmed[0] in {';', '#'}: continue

    if trimmed[0] == '[':       # начало новой секции
      if currentSection != "":
        result[currentSection] = section
      currentSection = trimmed[1..^2]
      section = initTable[string, string]()
    else:                       # ключ=значение
      let parts = trimmed.split("=", 1)
      let key = parts[0].strip()
      let value = (if parts.len > 1: parts[1].strip() else: "")
      section[key] = value

  if currentSection != "":
    result[currentSection] = section

Обратите внимание: split("=", 1) разбивает строку только по первому = — это важно для значений вроде URL, где тоже есть =.

Базовое использование

nimlet config = parseIni(readFile("app.ini"))
echo config["server"]["port"]       # 8080
echo config["database"]["name"]     # byox

# Безопасный доступ при отсутствии секции/ключа:
echo config.getOrDefault("missing", initTable[string, string]())

Вложенные таблицы в Nim — это те же словари, поэтому параметр по умолчанию getOrDefault должен быть типа Table[string,string]; это та же структура, которую возвращает parseIni.

Следующие шаги

Настоящие парсеры идут дальше базовой версии: поддержка : вместо =, снятие кавычек со значений, многострочные значения и автоматическое приведение типов (int, bool). Всё это добавляется к той же построчной структуре — каждое новое правило это просто ещё один разбор текущей строки.

Зачем этот репозиторий?

Изучение алгоритмов по обычным книгам часто сухо и безрезультатно. Этот репозиторий реализует более 120 алгоритмов и структур данных на чистом JavaScript (без зависимостей): от бинарного поиска и сортировок до деревьев, графов и динамического программирования. Каждый файл снабжён тестами на Jest и теоретическим объяснением.

Для каждой темы (массивы, связные списки, графы и так далее) совершенно ясно, «почему» и «как» — с временной сложностью Big-O рядом с каждой функцией.

Структура: алгоритмы и структуры данных

Охват: структуры данных: связный список, очередь, стек, двоичное дерево (BST), хеш-карта, граф, trie, куча (heap). Алгоритмы: сортировки (сравнительные и не-), поиск (линейный, бинарный, DFS/BFS), математика (GCD, факториал, простые числа), пути в графах (Dijkstra, Bellman-Ford) и динамическое программирование.

Такое разнообразие делает репозиторий полным справочником — и для подготовки к собеседованиям, и для понимания алгоритмов.

Пример: быстрая сортировка (Quick Sort)

Быстрая сортировка работает выбором опорного элемента (pivot) и делением массива на части меньше и больше него:

javascript// Быстрая сортировка со средней сложностью O(n log n)
function quickSort(original) {
  const arr = [...original];
  if (arr.length <= 1) return arr;

  const pivot = arr[0];
  const left = [];
  const right = [];

  for (let i = 1; i < arr.length; i++) {
    (arr[i] < pivot ? left : right).push(arr[i]);
  }

  return [...quickSort(left), pivot, ...quickSort(right)];
}

// Пример использования
console.log(quickSort([5, 2, 9, 1, 5, 6])); // [1, 2, 5, 5, 6, 9]

Более оптимальная версия в репозитории использует разбиение на месте и случайный pivot, чтобы покрыть и худший случай (отсортированный массив).

Двоичное дерево поиска

Одна из самых «классических» структур в репозитории — BST, реализующая insert/find/delete рекурсией:

javascriptclass BinarySearchTreeNode {
  constructor(value) {
    this.value = value;
    this.left = null;
    this.right = null;
  }

  insert(value) {
    if (value < this.value) {
      if (this.left) this.left.insert(value);
      else this.left = new BinarySearchTreeNode(value);
    } else if (value > this.value) {
      if (this.right) this.right.insert(value);
      else this.right = new BinarySearchTreeNode(value);
    }
    return this;
  }

  find(value) {
    if (value === this.value) return this;
    if (value < this.value) return this.left ? this.left.find(value) : null;
    return this.right ? this.right.find(value) : null;
  }
}

С этой небольшой структурой операции поиска в сбалансированном дереве выполняются за O(log n).

Как извлечь из него максимум?

Лучший способ — сначала реализовать каждый алгоритм заново, не глядя на код, и потом сравнить с реализацией репозитория. У каждого файла есть маленький тест, который можно запустить через jest; этот цикл — практика, тест, сравнение — делает обучение глубоким и долговечным.

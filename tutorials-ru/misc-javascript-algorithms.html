О чём это

Обширный репозиторий и статья с реализацией десятков алгоритмов и структур данных на JavaScript: от очередей и деревьев до сортировок и динамического программирования, с тестами и объяснениями.

Что вы узнаете

  • Базовые структуры: стек, очередь, связные списки
  • Деревья, графы и алгоритмы обхода
  • Классические сортировки и их сложность
  • Динамическое программирование и «жадные» алгоритмы

Основная идея

Репозиторий — это энциклопедия: каждый алгоритм оформлен как отдельный модуль с тестами. Изучение строится на повторении — вы реализуете структуру, смотрите на сложность и сравниваете подходы.

Пример — очередь на массиве с двумя концами:

JavaScriptclass Deque {
  constructor() { this.items = []; }
  addFront(x) { this.items.unshift(x); }
  removeBack() { return this.items.pop(); }
}

Почему это важно

Алгоритмы — язык собеседований и фундамент инженерии: JavaScript — отличная среда для их изучения, потому что каждая идея сразу исполнима в браузере.

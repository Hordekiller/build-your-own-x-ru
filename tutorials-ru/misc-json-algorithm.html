О чём это

Урок реализует парсер JSON с нуля на Python: разбор чисел, строк, массивов и объектов, обработка вложенности и корректные ошибки на неверном вводе.

Что вы узнаете

  • Грамматика JSON: пары ключ-значение, массивы, примитивы
  • Рекурсивный нисходящий разбор
  • Строки: экранирование и юникод
  • Обработка ошибок формата

Основная идея

JSON — это рекурсивная грамматика: значение — это число, строка, булево значение, null, массив или объект. Парсер смотрит на первый символ и вызывает нужный под-разбор.

Диспетчеризация значений — несколько строк:

Pythondef parse_value(s, i):
    if s[i] == "{": return parse_object(s, i)
    if s[i] == "[": return parse_array(s, i)
    if s[i] == '"': return parse_string(s, i)
    return parse_number_or_null(s, i)

Почему это важно

Каждый API отдаёт JSON, и каждое приложение его читает: написав парсер, вы поймёте, почему форматы данных аккуратны и где прячутся ошибки парсинга.

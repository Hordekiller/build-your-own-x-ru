Как выглядит JSON?

JSON — маленький язык с 8 типами значений: null, true, false, число, строка (с escape вида \" и \n), массив [...], объект {"k": v} и вложенные комбинации. Декодирование — это: прочитать текст и превратить его в структуры данных целевого языка.

Главный алгоритм

Центральная идея этой реализации: функция decoder, которая по следующему символу выбирает подходящую форму — диспетчеризация по состоянию. Вся логика умещается в одной рекурсивной функции:

pythondef decode(json_string):
    """JSON-декодер Чери в 80 строк"""
    pos = 0
    n = len(json_string)

    def read_ws():
        nonlocal pos
        while pos < n and json_string[pos] in ' \t\n\r':
            pos += 1

    def read_string():
        nonlocal pos
        pos += 1                       # пропускаем "
        out = []
        while json_string[pos] != '"':
            c = json_string[pos]
            if c == '\\':              # escape
                pos += 1
                esc = json_string[pos]
                out.append({'n': '\n', 't': '\t', '"': '"'}.get(esc, esc))
            else:
                out.append(c)
            pos += 1
        pos += 1                       # пропускаем закрывающую "
        return ''.join(out)

    # read_number, read_array и read_object определяются ниже в этой же функции

    def read_value():
        nonlocal pos
        read_ws()
        c = json_string[pos]
        if c == '"': return read_string()
        if c == '[': return read_array()
        if c == '{': return read_object()
        if c in '0123456789-': return read_number()
        if json_string.startswith('true', pos): pos += 4; return True
        if json_string.startswith('false', pos): pos += 5; return False
        if json_string.startswith('null', pos): pos += 4; return None
        raise ValueError(f'Недопустимый JSON: {c} в {pos}')

    return read_value()

Паттерн «посмотри на один символ и не тяни с проверкой недопустимости» (single-dispatch) — лучший способ ручного декодирования: строка, массив и объект имеют свои функции и связываются рекурсией.

Числа и структуры

python    def read_number():
        nonlocal pos
        start = pos
        while pos < n and json_string[pos] in '0123456789.eE+-':
            pos += 1
        text = json_string[start:pos]       # срез прочитанного числа
        if '.' in text or 'e' in text or 'E' in text:
            return float(text)              # дробное число
        return int(text)                    # целое число

    def read_array():
        nonlocal pos
        pos += 1                        # пропускаем [
        out = []
        read_ws()
        if json_string[pos] == ']':     # пустой массив
            pos += 1; return out
        while True:
            out.append(read_value())
            read_ws()
            if json_string[pos] == ',': pos += 1
            elif json_string[pos] == ']':
                pos += 1; return out

Тот же паттерн, что для массива, повторяется для объекта со словарём. С этими 80 строками у вас свой JSON.parse — тот самый, что браузеры выполняют сотни раз в день.

Итог

После этой работы декодер любого другого формата (YAML, TOML, XML) — это лишь добавленное состояние и несколько правил escape. Понимание такого маленького алгоритма — основа для ответа на вопрос «почему форматы устроены именно так».

Что делает балансировщик нагрузки?

Когда веб-трафик растёт, одного сервера недостаточно. Балансировщик нагрузки распределяет запросы между несколькими «бэкендами» (backend), чтобы сохранять отзывчивость. Простейшая стратегия — round-robin: каждый запрос уходит следующему по очереди серверу.

Этот урок строит балансировщик на стандартных инструментах Go (net/http и httputil), который также умеет проверки здоровья (health check).

Структура и reverse proxy

Сердце работы — httputil.ReverseProxy, переписывающий запрос на целевой сервер. Мы держим несколько бэкендов и обходим их по кругу со счётчиком (index):

go// Структура бэкендов
type Server struct {
    URL          *url.URL
    Alive        bool
    ReverseProxy *httputil.ReverseProxy
}

// Счётчик round-robin с блокировкой
type LoadBalancer struct {
    servers         []*Server
    current         uint64
    mu              sync.RWMutex
}

func (lb *LoadBalancer) NextServer() *Server {
    lb.mu.Lock()
    defer lb.mu.Unlock()
    // Найди следующий живой сервер
    for i := 0; i < len(lb.servers); i++ {
        idx := int(lb.current) % len(lb.servers)
        lb.current++
        if lb.servers[idx].Alive {
            return lb.servers[idx]
        }
    }
    return nil
}

Если ни один сервер не жив, нужно вернуть ошибку 503; иначе отвечает выбранный сервер.

Обработчик запросов

Когда запрос доходит до балансировщика, его нужно передать одному из серверов. Простейший обработчик:

go// Распределение запросов по серверам
func (lb *LoadBalancer) handleRequest(w http.ResponseWriter, r *http.Request) {
    server := lb.NextServer()
    if server == nil {
        http.Error(w, "Нет живых серверов", http.StatusServiceUnavailable)
        return
    }
    server.ReverseProxy.ServeHTTP(w, r)
}

func main() {
    lb := &LoadBalancer{}
    for _, s := range []string{"http://localhost:8081", "http://localhost:8082"} {
        u, _ := url.Parse(s)
        proxy := httputil.NewSingleHostReverseProxy(u)
        lb.servers = append(lb.servers, &Server{URL: u, Alive: true, ReverseProxy: proxy})
    }
    http.ListenAndServe(":8080", http.HandlerFunc(lb.handleRequest))
}

С этими тридцатью строками round-robin распределение на двух серверах уже работает.

Проверки здоровья

В более полной версии фоновая функция каждые несколько секунд опрашивает все серверы GET-запросом и обновляет флаг Alive:

go// Периодическая проверка здоровья серверов
func (lb *LoadBalancer) healthCheck() {
    for _, s := range lb.servers {
        resp, err := http.Get(s.URL.String() + "/health")
        lb.mu.Lock()
        s.Alive = err == nil && resp != nil && resp.StatusCode == http.StatusOK
        lb.mu.Unlock()
        if resp != nil { resp.Body.Close() }
    }
}

func startHealthCheck(lb *LoadBalancer, every time.Duration) {
    ticker := time.NewTicker(every)
    for range ticker.C { lb.healthCheck() }
}

Благодаря этому, если сервер падает, он автоматически выбывает из цикла распределения.

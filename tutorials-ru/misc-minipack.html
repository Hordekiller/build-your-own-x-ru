О чём это

Урок Minipack воссоздаёт веб-бандлер, подобный webpack, с нуля на JavaScript: граф зависимостей, трансформация модулей и генерация итогового бандла — всего несколько десятков строк кода.

Что вы узнаете

  • Что делает бандлер: от модулей к одному файлу
  • Разбор import/export через парсер модулей
  • Построение графа зависимостей и циклическая обёртка
  • Эмуляция require в браузере

Основная идея

Бандлер превращает десятки файлов в один: он читает каждый модуль, разбирает его зависимости, строит граф и упаковывает модули в единственный скрипт с собственной системой require.

Ключ всего — функция require, имитирующая Node.js:

JavaScriptfunction require(moduleId) {
  const { map, code } = modules[moduleId];
  const localRequire = (name) => require(map[name]);
  const module = { exports: {} };
  // исполняем код модуля в его окружении
  new Function("require", "module", "exports", code)(localRequire, module, module.exports);
  return module.exports;
}

Почему это важно

Каждый запуск npm build — этот маленький механизм: поняв бандлер, вы разберётесь в webpack, Vite и в том, почему фронтенд-инструменты устроены именно так.

MQTT и роль брокера

MQTT — лёгкий протокол обмена сообщениями для IoT, работающий по модели publish/subscribe. В этой модели устройства (клиенты) подписываются на темы (topics), а брокер обязан доставлять опубликованные сообщения нужным подписчикам. Брокер — «сердце» системы: без него ни одно сообщение не сдвинется с места.

Реализация брокера учит понимать двоичный протокол: каждое MQTT-сообщение — это фиксированный заголовок с байтом типа и флагами, а за ним — остаток тела с длиной переменной величины (2 байта LSB).

Отправка и получение: структура протокола

Первый шаг — определение структуры заголовка и его разбор. Например, сообщение CONNECT несёт protocol level и client id, а SUBSCRIBE должен нести packet identifier и topic-filter:

ctypedef struct {
    uint8_t type: 4;      // тип сообщения (1=CONNECT, 3=PUBLISH, ...)
    uint8_t flags: 4;
    uint8_t remaining_len; // длина Variable Byte Integer
} mqtt_fixed_header;

// Простая функция построения сообщения PUBLISH
int build_publish(uint8_t* buf, const char* topic,
                  const char* payload, int payload_len) {
    int off = 0;
    buf[off++] = 0x30;                    // PUBLISH QOS0
    int rem = 2 + strlen(topic) + payload_len;
    buf[off++] = (uint8_t)rem;
    buf[off++] = (strlen(topic) >> 8) & 0xff;
    buf[off++] = strlen(topic) & 0xff;
    memcpy(buf + off, topic, strlen(topic));
    off += strlen(topic);
    memcpy(buf + off, payload, payload_len);
    off += payload_len;
    return off;
}

Этот буфер — полное сообщение publish, которое можно отправить через сокет.

Управление подписками

Сердце брокера — структура данных «topic → list of clients». Когда публикуется сообщение, его нужно доставить всем подписчикам этой темы (или wildcard'ам). Это делается через дерево/хеш-таблицу и несколько параллельных потоков.

Главные вызовы: конкурентность (одно сообщение принимают несколько клиентов), обеспечение QoS и поведение с отвечающими-не-вовремя клиентами (keep-alive). Для начала достаточно однопоточной реализации, а затем добавления pthread.

Как создать настоящий Node CLI для реального мира

Как выглядит настоящий CLI?

Профессиональный инструмент командной строки: понимает аргументы и флаги, имеет цветной аккуратный вывод, беседует с пользователем (например, запрашивает подтверждение), умеет интерактивные вопросы и устанавливается через npm. Пример из урока — инструмент, печатающий вашу git-статистику.

Каркас проекта

В package.json нужно определить bin, чтобы npm создал команду из вашего скрипта. А в начале файла — shebang для прямого запуска:

json{
  "name": "git-stats-cli",
  "bin": {
    "git-stats": "./index.js"
  },
  "dependencies": {
    "chalk": "^2.0.0",
    "inquirer": "^5.0.0",
    "simple-git": "^1.0.0"
  }
}
javascript#!/usr/bin/env node
'use strict';
const chalk = require('chalk');
const inquirer = require('inquirer');

async function run() {
  const { repo } = await inquirer.prompt([{
    type: 'input',
    name: 'repo',
    message: 'Папка проекта?',
    default: '.'
  }]);

  const stats = await analyzeGit(repo);
  console.log(chalk.green.bold('Коммиты:'), stats.total);
  console.log(chalk.cyan('Активный автор:'), stats.topAuthor);
}

chalk управляет цветом, а inquirer — интерактивными вопросами: две главные опоры любого современного CLI.

Обработка аргументов

Настоящие клиенты принимают флаги (например, --json или -r). Простейший способ без отдельной библиотеки — читать process.argv и искать известные паттерны:

javascriptfunction parseFlags(argv) {
  const flags = { json: false, repo: '.' };
  for (let i = 2; i < argv.length; i++) {
    switch (argv[i]) {
      case '--json': flags.json = true; break;
      case '-r':
      case '--repo': flags.repo = argv[++i]; break;
      case '--help':
        console.log('Использование: git-stats [-r repo] [--json]');
        process.exit(0);
    }
  }
  return flags;
}

Для крупных CLI есть библиотеки commander или yargs, но понимание этого ручного цикла объясняет, что они делают под капотом.

Публикация в npm

Добавив "bin", достаточно выполнить npm publish, чтобы ваш инструмент стал доступен на любой системе через npx git-stats или npm i -g. Опыт создания и публикации инструмента сам по себе — половина урока программирования.

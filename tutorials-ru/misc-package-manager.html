О чём это

Урок реализует мини-пакетный менеджер на TypeScript: папка node_modules, разрешение версий, установка зависимостей и обработка конфликтов — вы поймёте npm изнутри.

Что вы узнаете

  • Что в package.json и как хранятся зависимости
  • Алгоритмы семантического версионирования
  • Установка: node_modules и резолвинг версий
  • Локальные и глобальные зависимости

Основная идея

Пакетный менеджер решает задачу: какие версии каких библиотек установить, чтобы всем хватило. Алгоритм резолвинга версий — настоящий интеллект npm под шелухой команд.

Проверка совместимости версии — функция:

TypeScriptfunction satisfies(version: string, range: string): boolean {
  // "^1.2.0" означает: любые 1.x.x >= 1.2.0
  return semVerMatches(version, range);
}

Почему это важно

Каждый npm install запускает целый алгоритмический мир: увидев его изнутри своими руками, вы перестанете бояться конфликтов зависимостей.

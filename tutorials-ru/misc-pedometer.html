Задача: считать шаги по акселерометру

В вашем телефоне есть акселерометр; каждый шаг создаёт небольшие колебания сигнала ускорения. Но сырой сигнал полон шума: взмах рукой с телефоном, неровная дорога и поездка в автобусе дают похожие паттерны. Превращение «шумного сигнала» в «число шагов» — настоящая инженерная задача; эта глава из книги 500 Lines решает её на Ruby.

Фильтрация сигнала

Первый шаг: сглаживание (smoothing) сигнала, чтобы убрать мгновенный шум, но сохранить общую форму колебаний. Подходит «скользящее среднее» — фильтр нижних частот, простейший и важнейший инструмент обработки сигналов:

rubyclass Pedometer
  def initialize
    @window = []                 # окно последних отсчётов
    @sum = 0.0
    @stepCount = 0
  end

  # фильтр нижних частот: среднее по окну из 20 отсчётов
  def filter(value)
    @window << value
    @sum += value
    if @window.size > 20
      @sum -= @window.shift
    end
    @sum / @window.size
  end
end

Размер окна подбирается под «скорость ходьбы» (примерно 2 шага в секунду): слишком маленький — шум остаётся, слишком большой — шаги смазываются.

Определение шага: пересечение порога

После сглаживания каждый шаг — это «пик». Алгоритм: сигнал пересекает порог снизу вверх → один шаг. Чтобы не считать один пик дважды, после каждого шага включается «режим охлаждения» (cooldown):

rubydef process(sample)
  smoothed = filter(sample.acceleration_magnitude)
  return unless smoothed > @threshold   # ниже порога: пропускаем

  # порог получен из нескольких дней данных/калибровки
  unless @last_step_at && now - @last_step_at < 0.3
    @stepCount += 1
    @last_step_at = now
  end
end

Величина (модуль трёхмерного ускорения) не зависит от ориентации телефона — умный выбор при любом способе ношения.

Уроки главы

Учебный момент главы не только алгоритм: сырые данные нужно собирать, калибровать и тестировать на настоящем устройстве. Счётчик шагов в кармане штанов и при размахивании рукой — совершенно разные вещи. Это и есть разница «примерного кода» и «системы реального мира» — урок, который повторяется во всей книге 500 Lines.

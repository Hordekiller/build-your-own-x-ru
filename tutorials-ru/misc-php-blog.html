Блог без фреймворка

Простой блог состоит из трёх частей: список постов, просмотр одного поста и админка (написание/редактирование). Этот урок делает всё на чистом PHP и MySQL, чтобы было видно, какое простое существо скрывается за словами WordPress и Laravel.

Подключение и таблицы

Сначала база данных: таблица для постов (id, title, content, created_at), а в полной версии — таблица комментариев. Подключение выполняется через PDO:

php// db.php — общее подключение
$pdo = new PDO(
    'mysql:host=localhost;dbname=blog;charset=utf8',
    'user', 'pass',
    [PDO::ATTR_ERRMODE => PDO::ERRMODE_EXCEPTION]
);

// Получение постов (подготовленный запрос)
$stmt = $pdo->query('SELECT * FROM posts ORDER BY created_at DESC');
$posts = $stmt->fetchAll();

Включение ERRMODE_EXCEPTION заставляет SQL-ошибку выбрасывать исключение, а не молчать — это критично для отладки.

Написание поста через форму

Админка состоит из HTML-формы и вставки через prepared statement — защита от SQL-инъекций:

phpif ($_SERVER['REQUEST_METHOD'] === 'POST') {
    $title = $_POST['title'] ?? '';
    $content = $_POST['content'] ?? '';

    $stmt = $pdo->prepare(
        'INSERT INTO posts (title, content) VALUES (:t, :c)'
    );
    $stmt->execute([':t' => $title, ':c' => $content]);

    header('Location: index.php');   // возвращаемся к списку
    exit;
}

Правило безопасности htmlspecialchars при выводе заголовка во вью: не оставляйте пользовательский ввод в сыром HTML, иначе получите XSS.

Просмотр одного поста

php$id = (int)($_GET['id'] ?? 0);   // cast в int: инъекция невозможна
$stmt = $pdo->prepare('SELECT * FROM posts WHERE id = ?');
$stmt->execute([$id]);
$post = $stmt->fetch();

if (!$post) { http_response_code(404); echo 'Пост не найден'; exit; }

Паттерны этого урока (PDO, prepared, форма, redirect-after-POST) — те же, что фреймворки выполняют автоматически. После этого блога WordPress больше не чёрный ящик.

Что такое контентная рекомендация?

«Если тебе нравится это, тебе понравится и вот это» — на основе самих товаров, а не поведения других людей. Каждый товар превращается в вектор признаков (текст описания, категория, бренд), и предлагаются товары с самыми близкими векторами. Преимущество: работает и для нового товара без истории продаж (решает проблему cold start).

Построение векторов с TF-IDF

Если у товаров есть текстовое описание (или комбинация признаков в одну строку), TF-IDF превращает его в вектор; слова, встречающиеся только в некоторых товарах, получают больший вес:

pythonfrom sklearn.feature_extraction.text import TfidfVectorizer
from sklearn.metrics.pairwise import linear_kernel

# каждый товар: id + склеенный текст признаков (title, brand, category)
docs = products['combined'].values

vec = TfidfVectorizer(stop_words='english')
matrix = vec.fit_transform(docs)          # (n_products, n_terms)

# матрица сходства между всеми товарами (вычисляется один раз)
cosine = linear_kernel(matrix, matrix)

linear_kernel — это та же косинусная мера сходства, но быстрее, чем brute force для больших матриц.

Рекомендация для товара

pythondef recommend(product_id, top_n=5):
    idx = products.index[products['id'] == product_id][0]

    scores = list(enumerate(cosine[idx]))   # сходство со всеми
    scores = sorted(scores, key=lambda x: x[1], reverse=True)

    # первый — сам товар; начни со второго и возьми похожие
    similar = [products.iloc[i]['id'] for i, s in scores[1:top_n + 1]]
    return similar

print(recommend('P-1042'))   # пять похожих товаров

Привлекательность подхода: никакого обучения не нужно — только TF-IDF и умножение матриц; меньше чем за 50 строк интернет-магазин получает блок «похожие товары».

Развитие

В продвинутой версии: комбинация нескольких признаков с разными весами (бренд важнее слов описания), векторы embedding (Word2Vec) вместо TF-IDF для смыслового понимания и гибрид с совместной фильтрацией для лучшей точности.

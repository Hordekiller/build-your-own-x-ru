Выучи промисы JavaScript, создав Promise с нуля

О чём это

Урок реализует Promise с нуля: состояния, цепочки then, обработка ошибок и асинхронное выполнение — вы напишете свой Promise-класс и поймёте, что происходит за синтаксическим сахаром.

Что вы узнаете

  • Состояния промиса: pending, fulfilled, rejected
  • Метод then: подписка на результат
  • Цепочки и прокидывание значений между then
  • Асинхронность: очередь микрозадач

Основная идея

Промис — это контейнер для будущего значения. Он умеет запомнить, кто ждёт результата, и при наступлении события вызвать обработчики. Вся магия — в управлении списком подписчиков.

Ядро Promise — список обработчиков:

JavaScriptclass MyPromise {
  constructor(executor) {
    this.state = "pending";
    this.handlers = []; // ждём результата
    executor(this.resolve.bind(this), this.reject.bind(this));
  }
  then(onFulfilled, onRejected) {
    // запомнить обработчик и вернуть новый промис
  }
}

Почему это важно

Асинхронный JavaScript — вокруг промисов: собрав его сами, вы перестанете бояться замыканий и очередей и будете уверенно читать любой асинхронный код.

Что делают рекомендатели?

Крупные магазины предлагают «вам может понравиться». Два главных семейства: контентные (Content-Based), которые сравнивают признаки товара со вкусами пользователя, и совместная фильтрация (Collaborative Filtering), которая сравнивает поведение похожих пользователей. Комбинация обоих даёт лучший результат.

Совместная фильтрация на подобиях

Идея: матрица пользователи×товары. Если пользователь A оценил фильмы X и Y и пользователь B тоже, вероятно, их вкусы близки; значит, новые фильмы B предлагаются и A. Сходство считается через косинусную меру или корреляцию:

pythonimport pandas as pd
from sklearn.metrics.pairwise import cosine_similarity

# матрица: строка = пользователь, столбец = фильм, ячейка = оценка
ratings = pd.DataFrame({
    'user': ['u1','u1','u2','u2','u3'],
    'movie': ['M1','M2','M1','M3','M2'],
    'rating': [5, 3, 4, 1, 2]
})
matrix = ratings.pivot(index='user', columns='movie', values='rating')
matrix = matrix.fillna(0)   # без оценки = 0

sim = pd.DataFrame(          # сходство между пользователями
    cosine_similarity(matrix),
    index=matrix.index, columns=matrix.index)

# что предложить u1? похожий пользователь: u2
print(sim.loc['u1'].sort_values(ascending=False))

После нахождения похожего пользователя предложите фильмы, которым он поставил высокие оценки, но которых ваш пользователь ещё не видел.

Подход с факторизацией матрицы

Когда данных много, матрицу пользователь×фильм раскладывают на две маленькие (скрытые факторы); каждый пользователь и каждый фильм получают «скрытый вектор», а оценка = их скалярное произведение. Библиотека surprise делает это легко:

pythonfrom surprise import SVD, Dataset, Reader
from surprise.model_selection import cross_validate

reader = Reader(rating_scale=(1, 5))
data = Dataset.load_from_df(ratings, reader)

algo = SVD()   # Singular Value Decomposition
cross_validate(algo, data, cv=3, verbose=True)

Этот алгоритм — тот самый, с которого начинали Netflix и Amazon.

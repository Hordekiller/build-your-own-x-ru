Что такое протокол RESP?

RESP (REdis Serialization Protocol) — простой текстово-бинарный протокол, по которому клиент и сервер Redis общаются друг с другом. Каждый тип данных отмечается буквой-префиксом: + — простая строка, - — ошибка, : — целое число, $ — бинарная строка и * — массив.

Написание парсера этого протокола — отличный шаг для изучения «бинарно-текстовых протоколов», и с Nim, у которого питоновский синтаксис и производительность C, это ещё и приятно.

Структура сообщений

Примеры сообщений: :1000\r\n — число 1000; $5\r\nhello\r\n — бинарная строка длиной 5; а *2\r\n$3\r\nfoo\r\n$3\r\nbar\r\n — массив из двух строк. Разделитель CRLF — стандарт.

Простой парсер на Nim

Реализация выполняется типом «буфер чтения» и маленькими функциями для каждого типа:

nimimport strutils, sequtils

# Общий тип данных для любого ответа RESP
type RespValue = object
  case kind: enum
    of rSimple: s: string
    of rError:  e: string
    of rInt:    i: int
    of rBulk:   b: string
    of rArray:  items: seq[RespValue]

# Парсинг простой строки: +OK\r\n
proc parseSimple(line: string): RespValue =
  result = RespValue(kind: rSimple, s: line)

# Парсинг bulk string: $len\r\n<payload>\r\n
proc parseBulk(data: seq[string], idx: var int): RespValue =
  let len = parseBiggestInt(data[idx]); inc idx
  if len == -1:
    return RespValue(kind: rBulk, b: "")
  result = RespValue(kind: rBulk, b: data[idx])
  inc idx

В главном цикле читается первая строка и по первому символу (префиксу) решение передаётся подходящей функции.

Главный цикл разбора

Со структурой данных, разбивающей сообщения по строкам, весь парсер идёт рекурсивно:

nim# Парсинг массивов: элементы разбираются по очереди
proc parseArray(data: seq[string], idx: var int): RespValue =
  let count = parseBiggestInt(data[idx]); inc idx
  var items: seq[RespValue]
  for i in 0..<count:
    items.add(parseMessage(data, idx))
  RespValue(kind: rArray, items: items)

proc parseMessage(data: seq[string], idx: var int): RespValue =
  let first = data[idx][0]
  case first
  of '+': result = parseSimple(data[idx][1..^1]); inc idx
  of ':': result = RespValue(kind: rInt, i: parseBiggestInt(data[idx][1..^1])); inc idx
  of '$': result = parseBulk(data, idx)
  of '*': result = parseArray(data, idx)
  of '-': result = RespValue(kind: rError, e: data[idx][1..^1]); inc idx
  else: raise newException(ValueError, "Неизвестно: " & first)

С парсером на 30 строк можно разговаривать с Redis (для запросов GET/SET).

Итог

RESP — один из самых простых реальных протоколов для изучения, и этот урок на Nim объясняет его маленьким и аккуратным кодом. После него можно доделать собственного Redis-клиента или перейти к более сложным бинарным протоколам.

О чём это

Практическое руководство по мобильному приложению вызова такси на React Native: экран карты, выбор точки, запрос поездки и общение с API — полный цикл мобильной разработки.

Что вы узнаете

  • Карта и геолокация в мобильном приложении
  • Выбор точки назначения и построение маршрута
  • Запрос поездки и статусы заказа
  • Связка UI и серверной логики

Основная идея

Приложение — это карта плюс состояния заказа: пользователь указывает точки, приложение рисует маршрут и отправляет запрос серверу. Каждый шаг — маленькая задача: от геолокации до сетевого запроса.

Отправка запроса на поездку:

JavaScriptasync function requestRide(from, to) {
  const res = await fetch("/api/rides", {
    method: "POST",
    body: JSON.stringify({ from, to }),
  });
  return res.json();
}

Почему это важно

Мобильные сервисы из реальной жизни — лучшие учебные проекты: вы пройдёте путь от карты до работающего заказа и получите приложение, которое можно показать другим.

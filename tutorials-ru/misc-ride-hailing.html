Создай приложение для вызова такси на React Native

Из каких частей состоит приложение такси?

Приложения вроде Uber состоят из трёх основных частей: отображение карты и позиции пользователя, построение маршрута и расчёт цены, а также связь в реальном времени между водителем и пассажиром. В этом уроке все три реализуются бесплатными инструментами: React Native для интерфейса, react-native-maps для карты и Pusher Channels для сообщений в реальном времени.

Шаг 1: карта и позиция

Первый экран — MapView с текущей позицией пользователя. С react-native-maps это очень просто:

javascriptimport MapView, { Marker, Polyline } from 'react-native-maps';

export default function MapScreen({ route }) {
  const { start, destination } = route.params;

  return (
    <MapView
      style={{ flex: 1 }}
      initialRegion={{
        latitude: start.latitude,
        longitude: start.longitude,
        latitudeDelta: 0.05,
        longitudeDelta: 0.05,
      }}
    >
      <Marker coordinate={start} title="Начало" pinColor="green" />
      <Marker coordinate={destination} title="Назначение" pinColor="red" />
      <Polyline coordinates={[start, destination]}
                 strokeColor="#00a" strokeWidth={4} />
    </MapView>
  );
}

С этим компонентом на карте видны обе точки и линия между ними.

Шаг 2: реальный маршрут и цена

Прямая линия — не настоящий маршрут; для дорожного маршрута нужно использовать сервис маршрутизации (например, Google Directions API). Ответ API содержит polyline и расстояние; по расстоянию и тарифу рассчитывается примерная цена и показывается на следующем экране.

Обращение к API нужно делать через промежуточный сервер, чтобы не засветить ключ API, — обычный паттерн реальных приложений.

Шаг 3: реальное время с Pusher

Когда пассажир отправляет запрос, в канал Pusher отправляется событие, которое получает водитель (во втором приложении). Красота каналов в их простоте:

javascriptimport Pusher from 'pusher-js/react-native';

// Структура клиента
const pusher = new Pusher('APP_KEY', { cluster: 'eu' });

export function subscribeToRides(onRide) {
  const channel = pusher.subscribe('rides');
  channel.bind('new-ride', onRide);
  return () => pusher.unsubscribe('rides');
}

// На стороне сервера: публикация события о новой поездке
// pusher.trigger('rides', 'new-ride', { start, destination });

Впрочем, более новые фреймворки (собственные WebSockets + Firebase) — тоже альтернатива, которая обсуждается в конце урока.

Итог

Этот проект покрывает все компоненты настоящего мобильного приложения: карту, сеть и реальное время, — и с React Native работает на Android и iOS. После него можно добавить автодополнение маршрутов с Google Places.

Политика того же источника (Same-Origin Policy)

Что такое политика одного источника?

Браузеры держат сайты изолированными друг от друга с помощью политики Same-Origin: JavaScript, загруженный из одного «источника» (protocol + host + port), не должен иметь доступа к данным другого источника. Без этой политики любая вредоносная вкладка могла бы читать куки и содержимое остальных сайтов.

Впрочем, определение «источника» сложнее, чем кажется: если два URL не могут разделять общий «document» или общий «origin», политика на том или ином этапе разрешает или запрещает доступ. Например, настройка document.domain меняет поведение политики.

Моделирование с помощью Alloy

Сильная сторона этой главы — применение формального языка Alloy для доказательства поведения политики в разных сценариях. Alloy позволяет определять «signature» и «relation», перебирать все возможные комбинации состояния браузера (две или более вкладок, разные источники) и проверять свойства безопасности.

Такой подход показывает, что даже «очевидные» вопросы безопасности на практике усложняются из-за разных видов доступа (например, <iframe>, document.domain и куки) и пограничных случаев — и становятся формально проверяемыми.

Пример кода на Alloy

Простая модель ниже определяет понятия «origin», «document» и связь между ними:

alloy// Базовые сигнатуры: источник, документ и окно
sig Origin {}
sig Document { origin: Origin }
sig Window {
    document: Document,
    opener: lone Window
}

// Правило: два документа одного источника, если их origin совпадает
pred sameOrigin[w1, w2: Window] {
    w1.document.origin = w2.document.origin
}

// По политике документ может получить доступ только к документу своего источника
assert sop {
    all w1, w2: Window |
        w2 in accessibleFrom[w1] => sameOrigin[w1, w2]
}

Запуск этого assert командой check sop может найти нарушение политики — комбинацию, в которой доступен документ из другого источника. Именно так в реальности проверяется безопасность браузеров.

Итог

Эта глава учит анализировать проблемы безопасности не только «кодом», но и «формальной моделью». Освоение Alloy + моделирование политик — навык, который пригодится в любом проекте по безопасности (баги CORS, изоляция, песочницы).

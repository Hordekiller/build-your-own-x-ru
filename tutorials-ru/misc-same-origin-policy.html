Что такое политика того же источника?

Чтобы держать разные веб-сайты отдельно друг от друга, браузеры применяют политику Same-Origin: JavaScript, загруженный с одного «источника» (protocol + host + port), не должен получать доступ к данным другого источника. Без этой политики любая вредоносная вкладка могла бы читать куки и содержимое других сайтов.

Разумеется, определение «источника» сложнее, чем кажется: если два URL не могут разделить «document» или не имеют общего «origin», на каком-то этапе политика разрешает или запрещает доступ. Например, при установке document.domain поведение политики меняется.

Моделирование на Alloy

Сила этой главы — использование формального языка Alloy для доказательства поведения политики в разных условиях. Alloy позволяет через «signature» и «relation» перебрать все возможные комбинации состояний браузера (2+ вкладки, разные источники) и проверить свойства безопасности.

Подход показывает: даже «очевидные» концепции безопасности на практике усложняются разными типами доступа (вроде <iframe>, document.domain и кук) и пограничными случаями — и становятся тестируемыми.

Пример кода Alloy

Простая модель ниже определяет понятия «origin» и «document» и отношение между ними:

alloy// Базовые сигнатуры: источник, документ и окно
sig Origin {}
sig Document { origin: Origin }
sig Window {
    document: Document,
    opener: lone Window
}

// Правило: два документа одного источника, если у них одинаковый origin
pred sameOrigin[w1, w2: Window] {
    w1.document.origin = w2.document.origin
}

// По политике документ может получать доступ только к документу своего источника
assert sop {
    all w1, w2: Window |
        w2 in accessibleFrom[w1] => sameOrigin[w1, w2]
}

Выполнение этого assert через check sop может найти нарушение политики — комбинацию, в которой доступен документ чужого источника. Именно так и делается на практике при тестировании безопасности браузеров.

Итог

Эта глава учит анализировать вопросы безопасности не только «кодом», но и «формальной моделью». Навык Alloy + моделирование политик пригодится в любом проекте по безопасности (дефекты CORS, изоляция, sandbox).

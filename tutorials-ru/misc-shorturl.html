Пишем сервис коротких ссылок на Nim

О чём это

Урок строит сервис коротких ссылок на Nim: приём длинного URL, выдача короткого идентификатора, перенаправление и хранение соответствий — полный мини-сервис из одного файла.

Что вы узнаете

  • Маршрутизация: POST создание и GET перенаправление
  • Генерация коротких идентификаторов без коллизий
  • Хранение соответствий в памяти или на диске
  • Обработка несуществующих ключей

Основная идея

Короткая ссылка — это ключ в таблице: сервис кладёт пару ключ→URL при создании и при переходе по ключу возвращает редирект 301/302. Простота прячет за собой вопросы коллизий и масштабирования.

Редирект по ключу — пара строк:

Nimproc redirect(key: string): string =
  # Возвращаем полный URL по короткому ключу
  let url = store.get(key)
  return if url.len > 0: $url else: "404"

Почему это важно

Сервисы вроде bit.ly — это простые ключи-таблицы плюс статистика: реализовав свой, вы поймёте базу практически любого URL-редиректа и шортлинка.

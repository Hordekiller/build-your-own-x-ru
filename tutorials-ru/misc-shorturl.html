Пишем сервис коротких ссылок на Nim

Что делает сервис сокращения ссылок?

На вход подаётся длинный URL (например, новости или страницы магазина), а сервис возвращает короткий код вроде abc123. Затем по запросу GET /abc123 пользователь с редиректом 301 Redirect попадает на исходную ссылку. Хорошая новость: само «сокращение» решается простым сопоставлением в Redis/базе данных.

Ключевая идея: кодирование Base62

Используем возрастающие числа (например, счётчик в Redis через INCR) и переводим число в 62-символьный алфавит (a-z, A-Z, 0-9), чтобы код был коротким и упорядоченным:

nimconst Alphabet = "abcdefghijklmnopqrstuvwxyzABCDEFGHIJKLMNOPQRSTUVWXYZ0123456789"

# Преобразование числа в код base62
proc toBase62(num: int): string =
  var n = num
  while n > 0:
    result.add(Alphabet[n mod 62])
    n = n div 62
  result.reverse()   # наименее значимая цифра в конце

# Преобразование кода обратно в число (для декодера / поиска)
proc fromBase62(code: string): int =
  for c in code:
    result = result * 62 + Alphabet.find(c)

С 7 символами 62^7 ≈ 3.5 триллиона ссылок — этого достаточно для любого практического применения.

HTTP-сервис

HTTP-часть: два основных маршрута. GET / показывает форму сокращения; POST /shorten регистрирует ссылку; а GET /<code> перенаправляет на целевой адрес. Для устойчивости счётчиков используется Redis:

nimproc shortenHandler(req: Request, resp: Response) =
  let longUrl = req.body["url"]
  # Увеличиваем счётчик в Redis на единицу
  let id = redis.incr("url_counter")
  let code = toBase62(id)
  # Сохраняем сопоставление код → URL
  redis.set("short:" & code, longUrl)
  resp.send("Короткая ссылка: /" & code)

proc redirectHandler(code: string, resp: Response) =
  let target = redis.get("short:" & code)
  if target.isEmpty:
    resp.send("Не найдено", Http404)
  else:
    resp.redirect(target, Http301)   # постоянный редирект

Использование 301 важно: поисковики считают его «постоянным переносом контента» и передают рейтинг страницы.

Реальные задачи

Для настоящего сервиса нужно: валидация URL, защита от спама (чтобы ссылки не вели на плохие сайты), ограничение частоты запросов и статистика переходов. Но ядро сервиса — счётчик + Base62 + redirect — показано именно здесь и укладывается меньше чем в 100 строк.

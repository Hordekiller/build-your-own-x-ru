Загрузка и рендеринг 3D-скелетной анимации с нуля на C# и OpenGL

Что такое скелетная анимация?

Когда 3D-персонаж ходит, перемещается не вся модель: внутри движется скелет (иерархия костей), а каждая вершина смещается матрицами соседних костей. Этот метод называется «skeletal animation» или «skinning».

В этом уроке всё создаётся с нуля: структура скелета, загрузка анимации (упрощённый формат glTF) и шейдер, применяющий матрицы костей.

Математика: матрица кости

Сердце работы — вычисление «итоговой матрицы» для каждой кости: global = parent * local. Эти матрицы отправляются в шейдер, где для каждой вершины они комбинируются с весами:

csharp// Вычисление глобальных матриц костей обходом дерева
void ComputeBoneMatrices(Bone[] bones, int parentIndex,
                         Matrix4<float> parentMatrix) {
    for (int i = 0; i < bones.Length; i++) {
        if (bones[i].parent != parentIndex) continue;

        // Глобальная матрица = матрица родителя × локальная матрица
        Matrix4<float> local = bones[i].localTransform;
        Matrix4<float> global = local * parentMatrix;

        // Итоговая матрица для рендера (inverse bind × global)
        boneMatrices[i] = bones[i].inverseBindMatrix
                          .Multiply(global);
        ComputeBoneMatrices(bones, i, global);
    }
}

Переменная inverseBindMatrix переводит вершину из «пространства модели» в «пространство кости», чтобы к ней применялось только движение кости.

Шейдер и вершинный скининг

У каждой вершины есть несколько индексов костей и весов (например, 4). Шейдер должен сложить соответствующие матрицы:

glsl// Входы вершины: позиция, веса и индексы костей
layout(location = 0) in vec3 aPosition;
layout(location = 3) in vec4 aWeights;
layout(location = 4) in ivec4 aBoneIndices;

uniform mat4 uBoneMatrices[24];
uniform mat4 uModelViewProjection;

void main() {
    // Комбинирование матриц костей с весами
    mat4 skin =
        uBoneMatrices[aBoneIndices.x] * aWeights.x +
        uBoneMatrices[aBoneIndices.y] * aWeights.y +
        uBoneMatrices[aBoneIndices.z] * aWeights.z +
        uBoneMatrices[aBoneIndices.w] * aWeights.w;

    vec4 worldPos = skin * vec4(aPosition, 1.0);
    gl_Position = uModelViewProjection * worldPos;
}

Именно этот шейдер превращает движение скелета в графику; без него анимация осталась бы только на бумаге.

Загрузка формата и проигрывание анимации

Часть загрузки читает ключевые кадры (keyframes) и интерполирует позиции и повороты. Для простоты вращения используют кватернионы, чтобы избежать «gimbal lock».

В конце у вас будет простой цикл проигрывания анимации, обновляющий матрицы с dt и заставляющий персонажа ходить или бегать.

Итог

Этот урок раскрывает всю математику «анимированных персонажей»: иерархию матриц, inverse bind и взвешенный рендер. После него коммерческие форматы (FBX, glTF) перестанут быть чёрным ящиком.

Мгновенный генератор статических сайтов на Node.js за 40 строк

Что такое SSG и зачем он нужен?

Генератор статических сайтов превращает контент (обычно Markdown) в HTML на этапе сборки (Build) — в отличие от CMS, которая собирает страницу на сервере в момент запроса. Преимущества: предельно быстро, безопасно и дёшево — подойдёт любой статический хостинг. Jekyll, Hugo и Next.js (в режиме SSG) делают то же самое.

Сердце SSG на 40 строках

Markdown-файлы лежат в папке posts. Node-скрипт для каждого файла: читает содержимое, превращает Markdown в HTML и встраивает результат в шаблон полной HTML-страницы:

javascriptconst fs = require('fs');
const path = require('path');
const MarkdownIt = require('markdown-it')();

const md = new MarkdownIt();               // парсер Markdown
const DIR = 'posts';
const OUT = 'public';

// HTML-шаблон вокруг каждого поста
const template = (title, body) => `<!DOCTYPE html>
<html lang="ru"><head><meta charset="utf-8">
<title>${title}</title></head>
<body><article>${body}</article></body></html>`;

fs.readdirSync(DIR).forEach(file => {
  const content = fs.readFileSync(path.join(DIR, file), 'utf8');
  const html = md.render(content);         // Markdown → HTML
  const title = file.replace('.md', '');
  fs.writeFileSync(path.join(OUT, title + '.html'), template(title, html));
});

Всё! Для каждого файла *.md создаётся HTML-файл — без сервера и без базы данных.

Добавление метаданных

Настоящие посты имеют front matter (заголовок, дату, теги). Можно начать просто и добавить её позже, отделяя двумя строками --- в начале файла. Тот же паттерн развивается вместе с шаблонами — можно генерировать и список постов (index):

javascript// Создание страницы-списка из всех постов
const indexItems = fs.readdirSync(DIR)
  .map(f => `<li><a href="${f.replace('.md', '.html')}">${f}</a></li>`)
  .join('\n');
fs.writeFileSync(path.join(OUT, 'index.html'),
  template('Мой блог', `<ul>${indexItems}</ul>`));

Итог

Этот урок показал, что «большой» SSG складывается из трёх простых операций: чтение файла, преобразование Markdown, встраивание в шаблон. Увеличьте эти блоки (теги, RSS, страницы-списки) — и у вас настоящий генератор, без сложных технологий.

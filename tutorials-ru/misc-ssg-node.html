О чём это

Урок показывает, что генератор статических сайтов можно написать за 40 строк на Node.js: разбор Markdown, шаблоны страниц, сборка HTML и запись результата в папку сайта.

Что вы узнаете

  • Чтение и разбор Markdown-файлов
  • Подстановка данных в шаблоны
  • Сборка списка страниц и карты сайта
  • Запись готовых HTML-файлов на диск

Основная идея

Магия статических сайтов — в сборке: исходники в Markdown превращаются в HTML по шаблону, а итог — набор готовых файлов, которые можно отдать любому хостингу без серверного кода.

Сердце генератора — цикл по файлам:

Node.jsconst md = require("marked");
for (const file of files) {
  const html = template.replace("{{content}}", md.parse(read(file)));
  write("site/" + name(file), html);
}

Почему это важно

Jekyll, Hugo, Astro — все они делают ровно это с комфортом: написав свой за 40 строк, вы поймёте, что и когда выбрать и как ускорить собственный сайт.

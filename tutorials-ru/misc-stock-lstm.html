Зачем LSTM для временных рядов?

Цена акций — «временной ряд»: результат каждого дня зависит от предыдущих. Обычные нейросети не видят прошлого; LSTM (Long Short-Term Memory — долгая и короткая память) имеет «заслонки», которые говорят сети, что удержать из прошлого, а что забыть.

Реалистичная оговорка: рынок не предсказуем достоверно; цель урока — научиться моделировать временные ряды, а не разбогатеть!

Подготовка данных

Цены имеют жёсткий масштаб; сначала нормализуем их (между 0 и 1), затем строим окна: для предсказания дня t на вход подаются цены за 60 предыдущих дней:

pythonimport numpy as np
from sklearn.preprocessing import MinMaxScaler

scaler = MinMaxScaler(feature_range=(0, 1))
scaled = scaler.fit_transform(df['Close'].values.reshape(-1, 1))

def make_windows(data, window=60):
    X, y = [], []
    for i in range(window, len(data)):
        X.append(data[i-window:i, 0])
        y.append(data[i, 0])
    return np.array(X), np.array(y)

X, y = make_windows(scaled)
X = X.reshape(X.shape[0], X.shape[1], 1)   # форма для LSTM

Форма входа LSTM: (число образцов, длина окна, число признаков).

Модель LSTM

pythonfrom keras.models import Sequential
from keras.layers import LSTM, Dense, Dropout

model = Sequential([
    LSTM(units=50, return_sequences=True, input_shape=(60, 1)),
    Dropout(0.2),
    LSTM(units=50, return_sequences=False),
    Dropout(0.2),
    Dense(units=1)          # следующая цена

return_sequences=True нужен для промежуточных слоёв, чтобы последовательность доходила до следующего слоя LSTM. После предсказания значение возвращается к реальному масштабу через inverse_transform.

Честная оценка

Никогда не меряйте точность на тех же данных, на которых обучали: разделите данные на train/validation/test и считайте RMSE на «предсказаниях за пределами виденного». На практике модели LSTM полезны для краткосрочного тренда, но не для внезапных скачков.

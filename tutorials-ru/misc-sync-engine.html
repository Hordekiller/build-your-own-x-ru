О чём это

Урок создаёт механизм синхронизации данных на основе Yjs: обмен изменениями между клиентами, совместное редактирование и слияние версий в реальном времени.

Что вы узнаете

  • CRDT: как Yjs объединяет изменения без конфликтов
  • Структуры данных Yjs: текст, массивы, карты
  • Обмен состоянием между клиентами по сети
  • Сохранение и восстановление состояния

Основная идея

Yjs использует CRDT — структуры данных, где каждое изменение математически объединяется с любым другим, поэтому совместное редактирование не теряет данные. Движок лишь передаёт «дельты» между узлами.

Совместная правка одного документа:

Node.jsconst ydoc = new Y.Doc();
const text = ydoc.getText("shared");
text.insert(0, "Привет, мир"); // изменение немедленно
// и рассылается всем подключённым клиентам

Почему это важно

Онлайн-редакторы и Figma живут на таких движках: поняв, как объединяются изменения, вы сможете строить совместные приложения и успешно выбирать библиотеки для них.

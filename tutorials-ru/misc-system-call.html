Напишем системный вызов

Что такое системный вызов?

Прикладные программы для доступа к ресурсам системы (файлы, сеть, процессорное время) должны действовать через API ядра. Системный вызов — это и есть вход из пользовательского пространства (user space) в пространство ядра (kernel space): конкретный номер, который процессор использует как индекс функции в таблице syscall.

В этом уроке вы напишете простой syscall, печатающий строку в ядре, затем зарегистрируете его в системной таблице и вызовете из пользовательской программы.

Устройство: таблица syscall

В ядре Linux каждый системный вызов регистрируется в таблице sys_call_table, и все они определяются через SYSCALL_DEFINEx. Например, syscall, принимающий сообщение:

c// Определение syscall с одним строковым аргументом
SYSCALL_DEFINE1(hello, const char __user*, buffer) {
    // Безопасное копирование из пользовательского пространства (kernel 5.16+)
    char kernel_buf[128];
    size_t len;
    ssize_t copied;

    copied = strncpy_from_user(kernel_buf, buffer, sizeof(kernel_buf) - 1);
    if (copied < 0) {
        return -EFAULT;
    }
    kernel_buf[copied] = '\0';

    printk(KERN_INFO "hello syscall: %s\n", kernel_buf);
    return 0;
}

Ключевой момент безопасности: поскольку данные приходят из пользовательского пространства, нельзя выполнять copy_from_user без проверки размера. Иначе возможны утечки данных или падение ядра.

Вызов из пользовательского пространства

Чтобы вызвать syscall из C, можно использовать syscall(). Номер системного вызова должен быть заранее зарегистрирован в таблице:

c#define SYS_HELLO 548   // номер, который вы назначили в ядре

#include <unistd.h>
#include <sys/syscall.h>
#include <stdio.h>

int main(void) {
    // Вызов нашего syscall
    long ret = syscall(SYS_HELLO, "Привет из пользовательского пространства!");
    if (ret < 0) {
        perror("syscall");
        return 1;
    }
    printf("syscall вернул: %ld\n", ret);
    return 0;
}

Посмотрев вывод ядра (dmesg), вы увидите напечатанное сообщение — то есть ваша программа действительно вошла в ядро и выполнилась там.

Итог

Написание системного вызова — лучший способ понять «границу» между ядром и прикладными программами. Вы на практике познакомитесь с таблицей имён, безопасным копированием между пространствами и контролем доступа — и подготовитесь к дальнейшему пути в разработке ядра.

Напишем системный вызов

Что такое system call?

Прикладные программы для доступа к ресурсам системы (файлы, сеть, процессор вовремя) действуют через API ядра. System call — то самое окно входа из пользовательского пространства (user space) в пространство ядра (kernel space): определённый номер, который процессор использует как индекс функции в таблице syscall.

В этом уроке вы пишете простой syscall, печатающий строку в ядре; затем регистрируете его в системной таблице и вызываете из пользовательской программы.

Структура: таблица syscall

В ядре Linux каждый syscall регистрируется в таблице sys_call_table, а все они определяются через SYSCALL_DEFINEx. Например, syscall, принимающий сообщение:

c// Определение syscall с одним строковым аргументом
SYSCALL_DEFINE1(hello, const char __user*, buffer) {
    // Безопасное копирование из пользовательского пространства (kernel 5.16+)
    char kernel_buf[128];
    size_t len;
    ssize_t copied;

    copied = strncpy_from_user(kernel_buf, buffer, sizeof(kernel_buf) - 1);
    if (copied < 0) {
        return -EFAULT;
    }
    kernel_buf[copied] = '\0';

    printk(KERN_INFO "hello syscall: %s\n", kernel_buf);
    return 0;
}

Ключевая заметка по безопасности: поскольку данные приходят из пользовательского пространства, нельзя делать copy_from_user без проверки размера. Иначе возможны проблемы вплоть до утечек или падений.

Вызов из пользовательского пространства

Для вызова syscall из C можно использовать syscall(). Номер syscall должен быть заранее зарегистрирован в таблице:

c#define SYS_HELLO 548   // номер, назначенный вами в ядре

#include <unistd.h>
#include <sys/syscall.h>
#include <stdio.h>

int main(void) {
    // Вызов своего syscall
    long ret = syscall(SYS_HELLO, "Привет из пользовательского пространства!");
    if (ret < 0) {
        perror("syscall");
        return 1;
    }
    printf("syscall вернул: %ld\n", ret);
    return 0;
}

После вывода из ядра (dmesg) вы увидите напечатанное сообщение — значит, ваша программа действительно вошла в ядро и выполнилась там.

Итог

Написание syscall — лучший способ понять «границу» между ядром и прикладными программами. Вы на практике узнаете таблицы имён, безопасное копирование между пространствами и контроль доступа — и будете готовы продолжить путь создания ядра.

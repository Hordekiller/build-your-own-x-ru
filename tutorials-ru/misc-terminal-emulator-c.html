Что происходит внутри терминала?

Эмулятор терминала (например, xterm или st) на вид — просто текстовое окно, но за ним стоит важный механизм: сетка (grid) из символьных ячеек, буфер для хранения содержимого и обработка escape-последовательностей — управляющих кодов, которые меняют цвет, положение курсора и состояние экрана.

Когда вы запускаете такую программу, как vim или ls, она отправляет последовательности байтов (например, \x1b[31m для красного цвета); терминал должен интерпретировать их и отрисовать фон и текст соответствующим образом.

Модель данных: ячейка и буфер

Сердце терминала — двумерный массив «ячеек». Каждая ячейка содержит символ, цвет текста и фона и несколько атрибутов (жирный, подчёркивание):

ctypedef struct {
    char c;          // символ ячейки
    int fg, bg;      // цвет текста и фона
    int bold, underline;
} Cell;

// Буфер: массив строк, каждая строка — массив ячеек
typedef struct {
    int rows, cols;
    Cell** cells;
} Buffer;

// Очистка экрана и установка курсора
void term_clear(Buffer* buf) {
    for (int y = 0; y < buf->rows; y++)
        for (int x = 0; x < buf->cols; x++) {
            buf->cells[y][x].c = ' ';
            buf->cells[y][x].fg = DEFAULT;
        }
}

Эта простая структура — основа всех операций рендеринга: любая операция лишь меняет значения в этом массиве, а затем один «проход рендера» выводит его на экран.

Разбор escape-последовательностей

Основная часть кода — конечный автомат, читающий входные байты. Когда встречается байт 0x1b, терминал переходит в состояние «escape» и разбирает следующую последовательность (например, [2J для очистки экрана):

c// Обработка последовательностей CSI (Control Sequence Introducer)
void handle_csi(char* params, int plen) {
    // "J" — очистка: 2J — весь экран
    if (params[plen-1] == 'J') {
        term_clear(&buf);
        return;
    }
    // "H" — перемещение курсора в (row, col)
    if (params[plen-1] == 'H') {
        int row = 0, col = 0;
        if (plen > 1)
            sscanf(params, "%d;%d", &row, &col);
        cursor.row = row - 1;
        cursor.col = col - 1;
    }
}

Для полноценного терминала нужно поддерживать сотни разных последовательностей, но уже с этими несколькими функциями имитируется базовое поведение xterm.

Итог

Создание терминала сочетает понятия операционной системы (pty, управляющие сигналы), текстовую графику и конечные автоматы. После этого введения можно перейти к полноценным проектам вроде st или alacritty и по-настоящему понять их архитектуру.

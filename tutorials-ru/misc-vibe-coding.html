Что такое vibe coding?

«Кодинг по вайбу» — создание ПО с опорой на генеративные ИИ-инструменты (вроде Claude или Copilot) и управление ими естественными описаниями, а не написание каждой строчки кода. Этот стиль рождает важный вопрос для проектов «сделай сам»: учимся ли мы так чему-то или просто машина отвечает?

Ответ этого репозитория: «да, если использовать правильно». Главное — вы всё равно должны понимать архитектуру и концепции; ИИ лишь ускоряет реализацию.

Адаптация проектов BYOX для vibe

Репозиторий даёт список классических проектов (веб-сервер, игра, интерпретатор, база данных и т.д.) с «готовыми промптами» и пошаговыми этапами, которые можно выполнять любым ИИ-инструментом. Каждый урок обычно включает: определение цели, ограничения дизайна, приёмочные тесты и учебный вывод.

Важный момент: для каждого проекта в промпте нужно просить инструмент «сначала объяснить», «реализовать отдельно» и «написать тесты». Это сохраняет цикл обучения.

Здоровый шаблон промпта

Предлагаемый в этом уроке шаблон снижает неоднозначность и увеличивает обратную связь:

textЦель: построить простой HTTP-веб-сервер на Python.

Ограничения:
- Используй только стандартные библиотеки.
- Только метод GET и путь "/" плюс один произвольный путь.
- Комментарии на русском языке.

Предлагаемый процесс:
1. Сначала объясни архитектуру и структуру файлов.
2. Затем напиши полный код (без многоточий).
3. Напиши и запусти небольшой тест с requests.
4. Найди и исправь возможную ошибку.

С такой структурой ассистент вместо «написания всей программы» работает с вами шаг за шагом, и вы можете ревьюить и спрашивать на каждом этапе — то есть ваш мозг по-прежнему участвует в создании.

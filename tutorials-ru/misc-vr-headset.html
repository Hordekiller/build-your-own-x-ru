Зачем домашний VR-шлем?

Коммерческие шлемы дороги, а внутри них — чёрный ящик. Проект Relativ показывает, что с одним дисплеем (по сути двумя панелями), инерциальным датчиком (IMU) и деталями с 3D-печати можно собрать шлем виртуальной реальности, работающий со SteamVR, — и весь его исходный код открыт.

Для любителей железа, электроники и разработки десктопного ПО этот проект — полный комбинированный опыт.

Основные компоненты

Сердце программной части — «драйвер», общающийся с играми через SteamVR-OpenVR. Ключевые компоненты: дисплей с высокой частотой обновления, IMU, дающий данные ускорения и гироскопа, микроконтроллер для обработки и отправки данных и линзы для фокусировки.

Важный инженерный момент: в VR задержка (latency) смертельно опасна. Чтобы снизить её, нужно быстро читать данные датчиков и выводить изображение с правильной инерционной пропорцией.

Пример кода: чтение и слияние данных IMU

Слияние данных гироскопа и акселерометра (sensor fusion) просто выполняется комплементарным фильтром:

cpp// Простое слияние данных акселерометра и гироскопа комплементарным фильтром
struct Orientation {
    float pitch, roll;
    double last_time;
};

void update_orientation(Orientation* o, float gx, float gy,
                        float ax, float ay, double dt) {
    const float alpha = 0.98f;   // вес гироскопа

    // Угол из акселерометра (вектор гравитации)
    float acc_pitch = atan2f(ay, sqrtf(ax*ax + 1.0f));
    float acc_roll  = atan2f(ax, sqrtf(ay*ay + 1.0f));

    // Слияние: гироскоп на длинном горизонте + акселерометр на коротком
    o->pitch = alpha * (o->pitch + gy * dt) + (1.0f - alpha) * acc_pitch;
    o->roll  = alpha * (o->roll  + gx * dt) + (1.0f - alpha) * acc_roll;
}

Этот простой фильтр с хорошей точностью вычисляет угол наклона головы между двумя отсчётами; в продвинутой версии используются фильтры Madgwick или Kalman.

Подключение к SteamVR

Чтобы игра увидела ваш шлем, нужно написать драйвер OpenVR, представляющий позицию (pose) и дисплей. Проект Relativ реализует эту часть с помощью простого UDP-сервера и глобального рендерера. После установки обычные VR-игры работают без дополнительного кода.

Итог

Этот проект показывает, что VR — не только для больших компаний: за 200 долларов и с каплей терпения можно собрать виртуальную реальность с нуля, по пути узнав многое об IMU, протоколах и драйверах операционной системы.

Rust в вебе?!

Rust компилируется в WebAssembly (wasm) и выполняется в браузере. Этот урок строит трёхмерную веб-сцену, в которой: сцена и вода создаются на Three.js, но волну воды вычисляет Rust, а результат каждого кадра отдаётся в WebGL.

Цикл рендера в Rust

Главное: структура Water в Rust, которая каждый кадр вычисляет высоты точек. Трёхмерные векторы — через nalgebra, передача чисел в JS — через wasm-bindgen:

rustuse wasm_bindgen::prelude::*;
use nalgebra::Vector3;

/// Геометрия воды: поверхность из точек (полигоны)
#[wasm_bindgen]
pub struct Water {
    pub segments: usize,
}

impl Water {
    /// Высота точки в момент t — простая синусоида
    pub fn height_at(&self, x: f32, y: f32, t: f32) -> f32 {
        ((x * 0.3 + t) as f64).sin() as f32 * 0.5
            + ((y * 0.2 - t) as f64).cos() as f32 * 0.3
    }
}

Сочетание двух волн с противоположными фазами даёт узор «спокойной воды» — основа всякой настоящей волновой симуляции (FFT, Gerstner) в простом колебании.

Связь с Three.js

На стороне JS строится сцена, и в каждом кадре высоты берутся из метода Rust, чтобы обновлять вершины. Как «родная функция», работающая кадр за кадром:

javascriptconst { Water } = wasm_bindgen('water_wasm.js');

// геометрия с сеткой 16×16
const geometry = new THREE.PlaneGeometry(10, 10, 15, 15);
const water = Water.new(16);
const material = new THREE.MeshPhongMaterial({ color: 0x1e88e5, wireframe: true });

function animate(time) {
  const pos = geometry.attributes.position;
  for (let i = 0; i < pos.count; i++) {
    const x = pos.getX(i), y = pos.getY(i);
    pos.setZ(i, water.height_at(x, y, time / 1000));  // работает Rust
  }
  pos.needsUpdate = true;
  renderer.render(scene, camera);
  requestAnimationFrame(animate);
}

Сочетание «Rust считает, JS рендерит» — популярная архитектура: высокая производительность без GC там, где это важно.

Зачем это учить?

Этот проект — мост в два мира: 3D-разработку (WebGL, шейдеры, геометрия) и WebAssembly (компиляция, байтовый бюджет, вход/выход через wasm-bindgen). Дальше в уроке: сборка через wasm-pack, бандлинг и более сложные анимации.

О чём это

Проект lhartikk строит криптовалюту на JavaScript: блоки, транзакции, кошелёк, P2P-сеть и HTTP API — всё меньше чем в 1500 строках, без внешних зависимостей.

Что вы узнаете

  • Блоки и транзакции в Naivecoin
  • Кошелёк: ключи и подписи
  • P2P-сеть: согласование узлов
  • API и клиентская часть

Основная идея

Naivecoin доказывает концентрацию: вся валюта — блоки, подписи, сеть и API. Урок за уроком код читается как учебник, а проект запускается как настоящая монета.

О чём это

Переиздание Naivecoin на TypeScript: блоки, транзакции, кошелёк, P2P-сеть и API с типами — полный крипто-проект с проверкой типов и модульным кодом.

Что вы узнаете

  • Структуры и типы криптовалюты
  • Транзакции с подписями
  • P2P-сеть и согласование
  • HTTP API и клиент

Основная идея

TypeScript добавляет контракты типов: блоки, транзакции и сообщения описанных типов исключают половину ошибок до запуска. Учебник приближается к прод-качеству.

Типизированная транзакция:

TypeScriptinterface Transaction {
  address: string;       // отправитель
  to: string;
  amount: number;
  signature: string;
}

Почему это важно

Типы улучшают учебники: этот проект покажет, как строгость помогает в таких системах, где полные типы закрывают классы ошибок.

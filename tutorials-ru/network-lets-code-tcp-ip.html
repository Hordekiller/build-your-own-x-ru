О чём это

Серия строит TCP/IP: Ethernet, ARP, IP, ICMP, TCP — собственный стек протоколов поверх сокетов raw.

Что вы узнаете

  • Кадры Ethernet и ARP
  • IP и фрагментация
  • TCP: рукопожатие и окна
  • Реализация на raw-сокетах

Основная идея

Стек протоколов — это слои: каждый слой инкапсулирует данные и добавляет свой заголовок. Серия делает каждый слой руками.

Заголовок IP — структура:

Cstruct iphdr {
    uint8_t  ihl:4, version:4;
    uint8_t  tos; uint16_t tot_len;
    uint16_t id; uint16_t frag_off;
    uint8_t  ttl; uint8_t  protocol;
    uint16_t check;
    uint32_t saddr, daddr;
};

Почему это важно

Понимание TCP/IP изнутри — суперсила: после этой серии трассировка пакетов становится чтением знакомого кода.

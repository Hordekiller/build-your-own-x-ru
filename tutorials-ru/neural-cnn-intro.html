Основная идея

CNN учат иерархию признаков: линии → формы → объекты. Урок объясняет каждый элемент.

Одна свёртка на NumPy:

Pythonimport numpy as np
def conv2d(img, kernel):
    out = np.zeros((img.shape[0]-2, img.shape[1]-2))
    for i in range(out.shape[0]):
        for j in range(out.shape[1]):
            out[i, j] = np.sum(img[i:i+3, j:j+3] * kernel)
    return out

Почему это важно

Введение в CNN — мост к современному CV: свёртки перестанут быть магией после этого урока.

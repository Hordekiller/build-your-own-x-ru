Введение в CNN на Python

Почему CNN для изображений?

Для классификации изображений «привет, мир компьютерного зрения» — это задача MNIST: распознать рукописную цифру на изображении 28×28. Обычная полносвязная сеть имеет большой недостаток: изображение 28×28 = 784 пикселя; при скрытом слое из 784 нейронов весов уже 600 тысяч, а пространственная структура изображения (близость пикселей) игнорируется. CNN решает эту проблему двумя ключевыми идеями: свёрткой (скольжение фильтра по изображению) и сдвиговой инвариантностью — где бы в изображении ни находился паттерн, он находится тем же фильтром.

Свёртка: детектор признаков

Фильтр (например, 3×3) скользит по небольшим участкам изображения и для каждого участка даёт скалярное произведение с пикселями. Результат — «карта признаков», показывающая интенсивность присутствия паттерна в каждой точке. Например, один фильтр может распознавать горизонтальное ребро: −1 в одной строке и 1 в другой:

pythonimport numpy as np

class Conv3x3:
    # Свёрточный слой с фильтрами 3x3

    def __init__(self, num_filters):
        self.num_filters = num_filters
        # фильтры: 3D-массив (число фильтров, 3, 3); деление на 9 для малой дисперсии
        self.filters = np.random.randn(num_filters, 3, 3) / 9

    def forward(self, input):
        # выход: карта признаков размером (h-2, w-2, num_filters)
        h, w = input.shape
        output = np.zeros((h - 2, w - 2, self.num_filters))
        for i in range(h - 2):
            for j in range(w - 2):
                im_region = input[i:(i + 3), j:(j + 3)]  # участок 3x3
                output[i, j] = np.sum(im_region * self.filters, axis=(1, 2))
        return output

В сети-примере первый слой имеет 8 фильтров и превращает изображение 28×28 в объём 26×26×8.

Слой Pooling: умное уменьшение

Карты признаков всё ещё велики. Слой Max Pooling сводит каждый блок 2×2 к одному значению (максимальному) — размеры уменьшаются вдвое, важнейшая информация сохраняется, плюс появляется небольшая устойчивость к сдвигам. В примере: 26×26×8 ← 13×13×8:

pythonclass MaxPool2:
    # Слой максимизации с окном 2x2 (без перекрытия)

    def forward(self, input):
        h, w, num_filters = input.shape
        output = np.zeros((h // 2, w // 2, num_filters))
        for i in range(h // 2):
            for j in range(w // 2):
                im_region = input[(i * 2):(i * 2 + 2), (j * 2):(j * 2 + 2)]
                output[i, j] = np.amax(im_region, axis=(0, 1))  # максимум по h и w
        return output

Слой Softmax: финальное решение

Для классификации 10 цифр на выходе должно быть 10 вероятностей. Слой Softmax (полносвязный) распрямляет объём, комбинирует его с весами и смещениями и через функцию softmax превращает в распределение вероятностей. Предсказание сети — цифра с наибольшей вероятностью:

pythonclass Softmax:
    # Полносвязный слой с активацией softmax

    def __init__(self, input_len, nodes):
        self.weights = np.random.randn(input_len, nodes) / input_len
        self.biases = np.zeros(nodes)

    def forward(self, input):
        input = input.flatten()
        totals = np.dot(input, self.weights) + self.biases
        exp = np.exp(totals)
        return exp / np.sum(exp, axis=0)   # распределение вероятностей

Полная компоновка и Forward

Три части вместе образуют сеть. Для каждого изображения выполняется инициализация и Forward, вычисляются потери cross-entropy и точность. Нормализация изображений из [0, 255] в диапазон [−0,5, +0,5] облегчает сети работу:

pythonconv = Conv3x3(8)                    # 28x28x1 -> 26x26x8
pool = MaxPool2()                    # 26x26x8 -> 13x13x8
softmax = Softmax(13 * 13 * 8, 10)   # 13x13x8 -> 10

def forward(image, label):
    out = conv.forward((image / 255) - 0.5)   # нормализация
    out = pool.forward(out)
    out = softmax.forward(out)

    loss = -np.log(out[label])                # потери cross-entropy
    acc = 1 if np.argmax(out) == label else 0
    return out, loss, acc

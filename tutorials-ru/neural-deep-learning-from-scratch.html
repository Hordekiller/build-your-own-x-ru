Глубокое обучение с нуля на Python

Философия проекта: «вы — сама библиотека autodiff»

Курс начинается с ясной идеи: чтобы понять глубокое обучение, лучше всего его построить. Путь организован в виде 35 небольших независимых шагов, которые начинаются с самого простого кирпичика — класса Value, ядра micrograd Карпати, — и с каждым шагом добавляют один слой сложности, пока мы не получим «мини-PyTorch» (MiniPyTorch).

Шаги 01–05: переписываем micrograd

Первые пять шагов повторяют путь знаменитого видео Карпати: класс Value со значением и производной (grad); построение вычислительного графа через хранение _prev (родителей) и _backward (локальной производной); операции сложения, умножения и возведения в степень; и наконец backward(), который с помощью топологической сортировки распространяет градиенты по всему графу:

python# Шаги 1–5: ядро autodiff — узел, помнящий своих родителей
class Value:
    def __init__(self, data, _children=(), _op=""):
        self.data = data
        self.grad = 0.0
        self._prev = set(_children)   # родители в вычислительном графе
        self._backward = lambda: None # локальная производная — задаётся в каждой операции

    def __add__(self, other):
        other = other if isinstance(other, Value) else Value(other)
        out = Value(self.data + other.data, (self, other), "+")
        def _backward():
            self.grad += out.grad            # + означает равное распределение градиента
            other.grad += out.grad
        out._backward = _backward
        return out

    def backward(self):
        # распространение градиентов топологической сортировкой (справа налево)
        order = []
        seen = set()
        def visit(v):
            if v not in seen:
                seen.add(v)
                for c in v._prev:
                    visit(c)
                order.append(v)
        visit(self)
        self.grad = 1.0
        for v in reversed(order):
            v._backward()

От скаляров к тензорам

Следующие шаги превращают скалярные значения в тензоры (многомерные массивы), чтобы можно было обучать настоящие сети на настоящих данных. Именно здесь правило цепочки видно в действии: каждая операция определяет свою локальную производную, а backward склеивает их вместе. Затем очередь доходит до компонентов сети:

  • Слои (Layers): Linear, Embedding и функции активации (ReLU, tanh, GELU и другие).
  • Оптимизаторы (Optimizers): SGD, Adam и другие — полный цикл обучения с forward, loss и backward.
  • Функции потерь: Mean Squared Error, Cross Entropy и другие.

Дальше: CNN, attention и Transformer

После полносвязных сетей современные архитектуры строятся с нуля:

  • Свёрточные сети (CNN): слои Conv2d, Pooling и их применение в компьютерном зрении.
  • Механизм внимания (Attention): устройство Self-Attention и Multi-Head Attention — сердце моделей-трансформеров.
  • Transformer: полное построение трансформера, а затем ViT (vision transformer) для изображений.
  • Языковая модель: обучение маленькой языковой модели со всеми построенными компонентами.
Совет: каждый шаг независим и запускаем (Notebook или Python-скрипт); рекомендуемый подход — прочитать шаг, закрыть его и переписать самостоятельно, затем сравнить с ответом.

Почему этот путь обучения ценен?

  • От монолита к деталям: «волшебная вещь» под названием PyTorch превращается в серию понятных инженерных решений.
  • Без чёрного ящика: после курса backpropagation и autodiff больше не «магия» — вы построили каждую строку сами.
  • Мост между micrograd и Transformer: закрывает огромный разрыв между базовыми уроками и современными статьями.
  • Глубокая практика: 35 шагов — это практика за практикой; переписывание заново — лучший тест на понимание.

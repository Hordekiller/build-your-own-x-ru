О чём это

Реализация глубокого обучения на Python с нуля: слои, обратное распространение и обучение — мини-фреймворк.

Что вы узнаете

  • Слои и граф
  • Обратное распространение
  • Оптимизация
  • Обучение сети

Основная идея

Проект строит мини-фреймворк: слои, прямые/обратные проходы и оптимизаторы. Всё на NumPy.

Класс слоя с градиентами:

Pythonclass Layer:
    def forward(self, x): return x @ self.W + self.b
    def backward(self, dout):
        self.gradW = x.T @ dout
        return dout @ self.W.T

Почему это важно

Мини-фреймворк — контроль над всей математикой: вы поймёте PyTorch изнутри до последнего градиента.

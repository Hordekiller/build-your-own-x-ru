Почему F# для нейросетей

Функциональные языки естественны для математики нейросетей: неизменяемость данных, строгая типизация и лаконичный синтаксис. Автор решает строить всё на MathNet.Numerics — без тяжёлого ML-фреймворка — чтобы увидеть глубину понятий: функция активации, слои, матрица весов, стоимость и обучение градиентным спуском. Результат — типы, у каждого из которых ясный смысл, а компилятор ловит логические ошибки рано.

fsharp// Типы, придающие смысл математике сети
type Node<'a> = { Values: Vector<'a> }
type Layer<'a> = { Nodes: List<Node<'a>> }
type NodesVect<'a> = { Nodes: Vector<'a> }

Нейрон и слой: две базовые абстракции

Каждый нейрон — вектор значений (несколько входов/выходов одновременно, ради матричной эффективности). Слой — список нейронов. Простой дизайн позже позволит нам соединять слои в цепочку: выход первого слоя — вход второго. Для весов используется матрица MathNet с готовыми оптимизированными функциями матричного умножения.

fsharp// Создание слоя из n нейронов; каждый нейрон — вектор значений
let createLayer (n: int) (size: int) =
    { Nodes = [ for _ in 1 .. n -> { Values = Vector.Build.Random(size) } ] }

Функция активации: гиперболический тангенс (tanh)

Функция активации даёт сети нелинейность; без неё любая глубина сети вырождается в линейное преобразование. Автор выбирает tanh: выход от −1 до +1, простая производная и симметричный центр — что ускоряет сходимость лучше, чем сигмоид. Производная tanh — 1 - tanh(x)² — играет ключевую роль в обратном распространении:

fsharplet tanh (x: double) = Math.Tanh(x)

// Производная tanh — нужна в backpropagation для распространения ошибки
let tanhDerivative (x: double) = 1.0 - (Math.Tanh(x) * Math.Tanh(x))

Прямое распространение (forward pass)

Выход каждого нейрона получается умножением матрицы весов на входы, прибавлением смещения и применением tanh. Прямое распространение — послойное применение этого вычисления до конечного выхода. При матричном представлении все нейроны слоя считаются сразу, векторно:

fsharp// Один шаг вперёд: выход слоя = tanh(матрица весов × значения нейронов + смещение)
let feedForward (weights: Matrix<double>) (inputs: Vector<double>) =
    weights * inputs
    |> Vector.map tanh

Этот шаг — «предсказание» сети: со случайными начальными весами выход бессмыслен; веса должны настраиваться обучением.

Стоимость и ошибка

Чтобы учиться, нужно измерить «плохость» сети: функция стоимости среднеквадратичной ошибки (MSE). Предсказанный выход сравнивается с ожидаемым; квадрат разности усредняется, чтобы большие ошибки наказывались сильнее и чтобы отрицательные/положительные ошибки не гасили друг друга:

fsharp// Среднеквадратичная ошибка между выходом сети и верным ответом
let cost (outputs: Vector<double>) (expected: Vector<double>) =
    let errors = outputs - expected
    errors.PointwisePower(2.0) |> Vector.Sum / float errors.Count

Дорога вперёд

Часть 1 строит инфраструктуру: типы Node/Layer, активацию tanh, прямое распространение и функцию стоимости. Никакого «обучения» ещё нет — веса случайны. Во второй части автор реализует обратное распространение и градиентный спуск, обучает сеть на реальном датасете и оценивает её.

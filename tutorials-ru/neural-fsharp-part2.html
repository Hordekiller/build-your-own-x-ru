Продолжение с части 1

В части 1 завершена инфраструктура: функция активации tanh, типы Layer и Node и прямое распространение. Проблема была в том, что веса случайны и сеть ничего не знает. В этой части приходит механизм обучения: обратное распространение (backpropagation), которое послойно возвращает ошибку выхода назад, и градиентный спуск, корректирующий веса.

Градиент и правило цепочки

Градиент функции стоимости по каждому весу говорит о «направлении и величине нужного изменения». Для его вычисления в глубоких сетях используется правило цепочки: производная ошибки по конечному выходу, умноженная на локальные производные каждого слоя, сзади наперёд. Для каждого веса: новое значение = старое − скорость обучения × градиент:

fsharp// Обновление веса: w ← w − η × градиент ошибки по w
let updateWeights (lr: double) (weights: Matrix<double>) (grad: Matrix<double>) =
    weights - (grad.Multiply(lr))

Скорость обучения (η) управляет балансом между скоростью и стабильностью: большая = перепрыгивание долин минимумов, малая = медленная сходимость.

Распространение ошибки в скрытых слоях

Главная проблема: ошибка напрямую вычисляется только в выходном слое. Для скрытых слоёв ошибка «распределяется»: ошибка следующего слоя умножается на транспонированную матрицу весов, чтобы получить вклад каждого скрытого нейрона в ошибку, а затем умножается на производную tanh (то есть 1 - tanh²) для создания ошибки «масштабированной уверенностью»:

fsharp// Распространение ошибки в скрытый слой:
// ошибка выхода, взвешенная транспонированной матрицей весов, затем умножение на производную tanh
let backpropagate (nextError: Vector<double>) (weights: Matrix<double>)
                 (hiddenOut: Vector<double>) =
    let weightedError = weights.Transpose() * nextError
    weightedError.PointwiseMultiply(hiddenOut.Map(tanhDerivative))

Полный цикл обучения

Теперь собираем все части вместе: прямое распространение ← вычисление ошибки ← обратное распространение ← обновление всех весов. Повторение цикла на всём датасете называется «эпохой» (epoch); с каждой эпохой ошибка сети уменьшается:

fsharp// Один полный обучающий шаг на одном образце
let trainStep (network: Network) (input: Vector<double>) (expected: Vector<double>)
              (lr: double) =
    let output = feedForward network input          // 1) предсказание
    let error = output - expected                   // 2) ошибка
    let grad = backpropagate error network.weights  // 3) распространение назад
    let newWeights = updateWeights lr network.weights grad // 4) правка весов
    { network with weights = newWeights }

Обучение и оценка на реальных данных

Автор обучает сеть на реальном датасете и следит за прогрессом через функцию стоимости: устойчивое снижение стоимости — признак здорового обучения. Для честной оценки данные делятся на обучающую и тестовую части — сеть видит только обучающую и проверяется на тестовой, чтобы измерить способность к обобщению (а не запоминанию). Точность (процент верных ответов) — главный отчётный критерий.

Дополнительное замечание: если стоимость обучения мала, а тестовая велика — признак переобучения; решения: больше образцов, сеть поменьше или ранняя остановка.

Итог

  • Обучение = обратное распространение ошибки + обновление весов градиентным спуском.
  • Транспонированная матрица весов — мост между ошибкой следующего слоя и вкладом скрытого слоя.
  • Производная tanh проста (1−tanh²); эта простота и делает backprop практичным.
  • Разделение обучения/теста — реальный показатель качества модели.

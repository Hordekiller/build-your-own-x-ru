Нейросеть на Go с нуля (deep learning)

Цель: классификация цветов ириса

Знаменитый датасет iris классифицирует три вида ирисов по четырём признакам (длина и ширина чашелистика и лепестка). Автор пишет нейросеть с нуля — без единой ML-библиотеки — чтобы и решить эту реальную задачу, и показать внутреннюю механику сети: структуру, инициализацию, прямое распространение, обратное распространение и обучение.

Модель и типы данных

Сеть определяется struct: веса (матрицы), число нейронов каждого слоя и функция активации. При матричном представлении прямое распространение — всего несколько матричных умножений:

go// Определение сети: веса между каждой парой слоёв + активация
type NeuralNet struct {
    config  NeuralNetConfig
    wHidden *mat.Dense   // веса скрытого слоя
    wOut    *mat.Dense   // веса выходного слоя
    bHidden *mat.Dense   // смещение скрытого слоя
    bOut    *mat.Dense   // смещение выходного слоя
}

// Конфигурация: размеры слоёв, скорость обучения и число эпох
type NeuralNetConfig struct {
    InputNeurons  int
    OutputNeurons int
    HiddenNeurons int
    NumEpochs     int
    LearningRate  float64
}

Случайная инициализация весов

Сеть стартует с небольшими случайными весами. Функция NewNetwork принимает конфигурацию, создаёт матрицы весов и инициализирует их нормальным распределением; смещения тоже инициализируются случайно (или нулём). Генератор случайных чисел снабжён seed, чтобы эксперименты были воспроизводимы:

go// Создание и случайная инициализация весов и смещений
func NewNetwork(config NeuralNetConfig) *NeuralNet {
    r := rand.New(rand.NewSource(time.Now().UnixNano()))
    wHidden := mat.NewDense(config.InputNeurons, config.HiddenNeurons, nil)
    bHidden := mat.NewDense(1, config.HiddenNeurons, nil)
    wOut := mat.NewDense(config.HiddenNeurons, config.OutputNeurons, nil)
    bOut := mat.NewDense(1, config.OutputNeurons, nil)

    // случайная инициализация из нормального распределения с нулевым средним
    for i := 0; i < config.InputNeurons; i++ {
        for j := 0; j < config.HiddenNeurons; j++ {
            wHidden.Set(i, j, r.NormFloat64())
        }
    }
    // ... то же для остальных матриц
}

Прямое распространение (feed forward)

Для каждого образца: выход скрытого слоя = сигмоид(вход × скрытый вес + скрытое смещение), затем конечный выход = сигмоид(скрытый × выходной вес + выходное смещение). Функция активации сигмоид и её производная определены отдельными функциями, чтобы использоваться и в backprop:

go// Запуск сети на векторе признаков
func (nn *NeuralNet) predict(x *mat.VecDense) mat.Matrix {
    // вычисление выхода скрытого слоя и применение сигмоида
    hiddenInputs := mat.NewDense(1, nn.config.HiddenNeurons, nil)
    hiddenInputs.MulVec(nn.wHidden, x)
    hiddenInputs.AddScaled(hiddenInputs, 1, nn.bHidden.RowView(0))
    hiddenOutputs := applySigmoid(hiddenInputs)

    // вычисление конечного выхода и применение сигмоида
    finalInputs := mat.NewDense(1, nn.config.OutputNeurons, nil)
    finalInputs.MulVec(nn.wOut, hiddenOutputs)
    finalInputs.AddScaled(finalInputs, 1, nn.bOut.RowView(0))
    return applySigmoid(finalInputs)
}

Обучение: обратное распространение

Итог

  • С gonum и парой простых функций математики строится полная сеть с нуля.
  • Сигмоид и его производная — вся «математика», нужная простому backprop.
  • iris — идеальный датасет для наблюдения за прогрессом обучения (визуализируемый и маленький).
  • Тот же базовый код работает и для других задач — просто изменением конфигурации.

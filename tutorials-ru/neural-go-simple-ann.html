Простая нейросеть на Go

Введение: что такое нейронная сеть

Искусственная нейронная сеть состоит из искусственных нейронов: каждый нейрон берёт взвешенную сумму входов, добавляет смещение и пропускает результат через функцию активации. Автор реализует всё это на базовых понятиях матриц в Go — никаких библиотек машинного обучения. Результат — маленькая, но полностью рабочая сеть, способная выучить простую задачу классификации.

go// Искусственный нейрон: Σ(вход × вес) + смещение ← затем функция активации
output := activation(bias + sum(wi * xi, for i = 1..n))

Сигмоидная функция активации

Сигмоид сжимает действительное значение в диапазон (0, 1) и даёт сети «вероятностный выход». Для обучения нужна и её производная — производная сигмоида через сам сигмоид проста: σ(x)(1−σ(x)):

go// Сигмоид и его производная
func sigmoid(x float64) float64 {
    return 1.0 / (1.0 + math.Exp(-x))
}

func sigmoidPrime(x float64) float64 {
    return sigmoid(x) * (1.0 - sigmoid(x))
}

Структура сети: две матрицы весов

Образцовая сеть имеет два слоя: входной и выходной (без скрытого). Значит, нужны две матрицы: w1 ведёт вход к выходу, и w2 — в однослойной версии та же связь. Для общности модель определяется массивом матриц весов, чтобы позже добавить больше слоёв:

gotype Network struct {
    inputs        int
    hidden        int
    outputs       int
    hiddenWeights *mat.Dense
    outputWeights *mat.Dense
    learningRate  float64
}

// Создание сети: вход 2, скрытый 2, выход 1
net := Network{
    inputs: 2, hidden: 2, outputs: 1,
    hiddenWeights: mat.NewDense(2, 2, nil), // веса инициализируются случайно
    outputWeights: mat.NewDense(2, 1, nil),
    learningRate: 0.1,
}

Прямое распространение на gonum

Выход вычисляется матричным умножением gonum/mat: вход умножается на hiddenWeights, применяется сигмоид, снова умножение на outputWeights и финальный сигмоид. Конечный выход — предсказание сети:

go// Вычисление выхода сети для входного вектора
func (n *Network) feedforward(x *mat.VecDense) *mat.VecDense {
    // скрытый слой = сигмоид(вход × скрытые веса)
    hidden := mat.NewVecDense(n.hidden, nil)
    hidden.MulVec(n.hiddenWeights, x)
    applySigmoid(hidden)

    // выход = сигмоид(скрытый слой × выходные веса)
    output := mat.NewVecDense(n.outputs, nil)
    output.MulVec(n.outputWeights, hidden)
    applySigmoid(output)
    return output
}

Обучение: ошибка, градиентный спуск и обновление

Эксперимент: изучение функции XOR

Классический пример — изучение XOR: функции, которую однонейронная сеть никогда не выучит (она нелинейна), но которая прекрасно изучается вот такой маленькой сетью за несколько эпох. Эксперимент ценен тем, что показывает: глубина (скрытый слой) действительно повышает выразительную силу модели.

Дополнительное замечание: меняя форму входного датасета (например, целые числа) и разные активации, ту же структуру можно применять к большому классу простых задач классификации.

Итог

  • Нейросеть = матрицы весов + нелинейная активация + градиентный спуск.
  • gonum/mat делает все матричные умножения чистыми и читаемыми.
  • Производная сигмоида проста и превращает backprop в несколько строк кода.
  • Изучение XOR доказывает: скрытый слой необходим и достаточен.

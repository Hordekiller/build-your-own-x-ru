LSTM для музыки на Keras

⚙ Язык: Python 📁 Нейросеть 🌐 Русская страница 🔗 Оригинальный источник
Оригинальный источник: «How to Generate Music using a LSTM Neural Network in Keras»
↗ Перейти к оригинальному уроку فارسی — Персидская версия EN — English version

Идея: музыка как «язык»

Музыка, как и текст, — это последовательность символов: нот и аккордов. Если выстроить ноты произведения подряд, задача превращается в «по последним N символам предскажи следующий» — то есть в задачу моделирования последовательностей. Рекуррентные сети (RNN) и особенно LSTM созданы именно для этого: у них есть внутренняя память, сохраняющая долгосрочные зависимости (например, возвращение главной темы через несколько тактов).

Извлечение нот из MIDI с помощью Music21

Первый шаг — превратить MIDI-файлы в последовательность символов. Библиотека Music21 упрощает это: converter.parse() читает файл, а flat.notes возвращает все ноты и аккорды по порядку. Каждая нота представляется как «имя + октава» (например, D#4), а каждый аккорд — списком своих нот (например, D#4.F#4.A#4):

pythonfrom music21 import converter

# Чтение MIDI-файла и извлечение последовательности нот и аккордов
notes = []
for element in converter.parse("song.mid").flat.notes:
    if element.isNote:
        notes.append(str(element.pitch))            # например "D#4"
    elif element.isChord:
        notes.append(".".join(str(n) for n in element.pitches))  # например "D#4.F#4.A#4"

print("Количество символов:", len(notes), "| уникальных символов:", len(set(notes)))

Кодирование символов и построение окон

Сеть понимает числа, а не строки. Поэтому символы переводятся в числовые индексы (через словарь). Затем последовательность делится на перекрывающиеся окна: входное окно содержит sequence_length символов, а выход — следующий символ. Выход кодируется one-hot (вектор из нулей и единицы на месте правильного символа):

pythonsequence_length = 100  # длина памяти: 100 предыдущих символов

network_input = []   # входные окна
network_output = []  # следующий символ каждого окна

for i in range(0, len(notes) - sequence_length, 1):
    seq_in = notes[i:i + sequence_length]
    seq_out = notes[i + sequence_length]
    network_input.append([note_to_int[n] for n in seq_in])
    network_output.append(note_to_int[seq_out])

# Преобразование в массив numpy и one-hot кодирование выхода
X = np.reshape(network_input, (len(network_input), sequence_length, 1))
X = X / float(n_vocab)                     # нормализация входа
y = to_categorical(network_output, num_classes=n_vocab)

Архитектура LSTM

Модель состоит из двух слоёв LSTM и двух полносвязных. У LSTM-слоёв две важные детали: return_sequences=True на первом, чтобы полный выход последовательности дошёл до второго слоя, и return_state=True на последнем LSTM, чтобы при генерации сохранять состояние памяти. Финальный выход через softmax — распределение вероятностей по всем символам:

pythonfrom keras.models import Sequential
from keras.layers import LSTM, Dense, Dropout

model = Sequential()
model.add(LSTM(512, return_sequences=True, input_shape=(X.shape[1], X.shape[2])))
model.add(Dropout(0.3))
model.add(LSTM(512, return_state=True))   # возвращаем состояние для генерации
model.add(Dropout(0.3))
model.add(Dense(256, activation="relu"))
model.add(Dense(n_vocab, activation="softmax"))

model.compile(loss="categorical_crossentropy", optimizer="rmsprop")
model.fit(X, y, epochs=200, batch_size=64)

Генерация музыки: символ за символом

Генерация — это «сцепление предсказаний»: случайная последовательность символов выбирается как стартовая точка; на каждом шаге сеть выдаёт распределение вероятностей следующего символа; следующий символ выбирается сэмплированием из этого распределения (не всегда самый вероятный!) — такая случайность даёт творческий выход и избегает бесконечных повторов. Затем окно сдвигается на один символ — и так до нужной длины:

pythondef generate_notes(model, start, n_vocab, int_to_note):
    pattern = start.copy()
    output = []
    for _ in range(500):
        # подготовка текущего паттерна для сети
        x = np.reshape(pattern, (1, len(pattern), 1)) / float(n_vocab)
        prediction = model.predict(x, verbose=0)[0]

        # сэмплирование из распределения вероятностей (со случайным творчеством)
        index = np.argmax(prediction)
        output.append(int_to_note[index])
        pattern.append(index)
        pattern = pattern[1:]   # сдвигаем окно на один шаг
    return output

Преобразование выхода в MIDI-файл

В конце последовательность символов снова превращается в объект Music21 и сохраняется как MIDI-файл, чтобы её можно было воспроизвести в любой музыкальной программе. Чтобы мелодия звучала, задаётся фиксированный ритм (например, каждая нота — одна доля):

pythonfrom music21 import stream, note, chord, tempo

def notes_to_midi(notes, output_file):
    offset = 0
    stream_notes = []
    for pattern in notes:
        if "." in pattern:          # аккорд
            notes_list = [note.Note(n) for n in pattern.split(".")]
            c = chord.Chord(notes_list)
            c.quarterLength = 0.5
            stream_notes.append(c)
        else:                       # простая нота
            n = note.Note(pattern)
            n.quarterLength = 0.5
            stream_notes.append(n)
        offset += 0.5

    midi_stream = stream.Stream(stream_notes)
    midi_stream.write("midi", fp=output_file)

Итоги и улучшения

  • Музыка = последовательность символов; LSTM отлично подходит для последовательностей.
  • Music21 берёт на себя чтение/запись MIDI — фокус остаётся на модели.
  • Случайное сэмплирование (вместо вечного argmax) даёт творчество в генерации.
  • Улучшения: добавление длительности нот во вход, два двунаправленных слоя, обучение на датасете больше одной песни.

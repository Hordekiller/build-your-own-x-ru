О курсе

В книге и видео-серии Nature of Code Шиффман симулирует природные явления кодом; десятая глава добирается до нейронных сетей: мозг как «природный алгоритм» и вдохновлённые им искусственные сети. Его подход обучающий и визуальный: каждое понятие (нейрон, перцептрон, слой, обучение) показывается визуальными скетчами на p5.js, чтобы была видна «механика» сети, а не только формулы. Для части материала референсом Шиффману служила книга Make Your Own Neural Network Тарика Рашида.

javascript// Простой перцептрон в p5.js: взвешенная сумма + ступенчатая активация
function guess(inputs) {
  let sum = 0;
  for (let i = 0; i < inputs.length; i++) {
    sum += inputs[i] * this.weights[i];   // взвешенная сумма входов
  }
  return sum > 0 ? 1 : -1;                // ступенчатый выход
}

Путь видео

  • Введение: что такое нейрон, почему нейросеть «естественна», обзор главы.
  • Перцептрон: простейшая сеть — один нейрон с несколькими входами, пропускающий взвешенную сумму через активацию; и его ограничения (XOR не решается).
  • Многослойный перцептрон: складываем перцептроны рядом — больше выразительной силы.
  • Обучение: настройка весов по ошибке; идея backpropagation и градиентного спуска интуитивно.
  • Применения: «умные» агенты, учащиеся на опыте, и взаимодействие перцептронов с симуляциями прошлых глав (движение и силы).

Почему смотреть этот курс полезно

  • Интуиция до формул: видно, как веса меняют форму выхода, ещё до заучивания формул.
  • Мало кода, живой код: примеры выполняются в браузере (p5.js Web Editor); можно манипулировать ими на лету.
  • Мост между искусством и ML: для тех, кто хочет применить сеть в творческих проектах (движение, взаимодействие, дизайн).
  • Крепкая база для продолжения: полная книга Nature of Code включает отдельные главы про сети и «нейроэволюцию» (neuroevolution).

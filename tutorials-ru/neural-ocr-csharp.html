Введение: почему нейросеть для OCR

Оптическое распознавание символов (OCR) — превращение изображения текста в редактируемый текст. Классический метод сравнения шаблонов (template matching) хрупок перед изменением шрифтов, размеров и поворотами букв. Статья Кириллова вместо этого использует многослойную нейронную сеть с обучением обратным распространением (backpropagation): сеть обучается на образцах букв, а затем распознаёт незнакомые. Реализация на C# с открытой библиотекой AForge.NET и без внешних зависимостей для обучения/работы.

Архитектура сети: вход, скрытый слой и выход

Главная идея: каждое изображение буквы превращается в числовой вектор, и сеть должна сопоставить этот вектор одной из букв алфавита. Для буквы с изображением 12×12 пикселей вход имеет 144 нейрона. Выход сети тоже размером с алфавит; каждый выходной нейрон представляет одну букву, а предсказание сети — тот нейрон, у которого значение максимально.

csharp// Определение нейронной сети: вход 144 нейрона, скрытый слой 50, выход = число букв
NeuralNetwork network = new ActivationNetwork(
    new SigmoidFunction(2),     // сигмоидная функция активации
    144,                        // число входных нейронов (пиксели изображения)
    50,                         // скрытый слой
    alphabetSize);              // выходной слой (число букв)

Выбор числа нейронов скрытого слоя — эмпирическая настройка: слишком мало = неспособность учить сложные закономерности, слишком много = риск переобучения (overfitting) и медленное обучение.

Создание обучающих образцов

Сердце обучения — данные. У Кириллова два источника образцов: рукописные буквы (пользователь рисует мышью в области 48×48) и печатные буквы, рендерящиеся из шрифтов Windows через GDI+: Arial, Courier New, Tahoma, Times New Roman и Verdana. Каждая буква рендерится в нескольких размерах и стилях (жирный/курсив), чтобы сеть выучила разнообразие.

csharp// Рендер печатной буквы из шрифта и превращение в входной вектор сети
Bitmap bitmap = DrawChar(letter, font, size);
double[] input = ImageToVector(bitmap);   // серый уровень каждого пикселя, нормированный от 0 до 1
double[] output = new double[alphabetSize]; // выходной вектор «one-hot»
output[letterIndex] = 1;
Замечание: для рукописных букв изображение сначала подвыборочно сжимается в сетку 12×12; это и уменьшает размер входа, и отчасти делает сеть устойчивой к небольшим смещениям.

Обучение обратным распространением

Обучение идёт алгоритмом backpropagation: сеть предсказывает выход, вычисляется ошибка предсказания, и эта ошибка «просачивается» от выходного слоя к предыдущим, чтобы веса корректировались в сторону уменьшения ошибки. В AForge это делает класс BackPropagationLearning:

csharp// Создание обучающего устройства с обратным распространением
BackPropagationLearning teacher = new BackPropagationLearning(network);
teacher.LearningRate = 0.1;   // скорость обучения
teacher.Momentum = 0.9;       // момент для ухода от колебаний

// Цикл обучения: подача всех образцов, десятки повторов (epoch)
for (int epoch = 0; epoch < 100; epoch++)
{
    for (int sample = 0; sample < samples.Length; sample++)
    {
        teacher.Run(samples[sample].Input, samples[sample].Output);
    }
}

Скорость обучения и момент — критические параметры: высокая скорость обучения ускоряет тренировку, но делает её нестабильной; момент придаёт весам «инерцию», помогая проходить локальные минимумы.

Распознавание (recognition)

После обучения на каждом входном изображении сеть выдаёт выходной вектор; предсказанная буква — индекс наибольшего значения. Важный момент статьи: качество предсказания можно оценить разницей между двумя наибольшими выходами — если сеть колеблется между двумя буквами, лучше объявить «неизвестно», чем ошибиться:

csharp// Запуск сети на изображении и поиск победившей буквы
network.Compute(ImageToVector(bitmap));

int best = 0, second = 1;
if (network.Output[1] > network.Output[0]) { best = 1; second = 0; }
for (int i = 2; i < network.Output.Length; i++)
{
    if (network.Output[i] > network.Output[best])
    {
        second = best;
        best = i;
    }
    else if (network.Output[i] > network.Output[second])
    {
        second = i;
    }
}

double diff = network.Output[best] - network.Output[second];
char recognized = (diff > Threshold) ? (char)('A' + best) : '?';

Результаты и ограничения

  • Печатные буквы с несколькими шрифтами распознаются хорошо, но чем декоративнее шрифт, тем больше обучающих образцов нужно.
  • Рукописные сложнее; разброс почерка каждого человека велик, поэтому больше рукописных образцов = выше точность.
  • Сеть чувствительна к масштабированию входа; изображения нужно стандартизировать до подачи.
  • Той же идеей вместо букв можно учить цифры, символы или любые другие классы изображений.

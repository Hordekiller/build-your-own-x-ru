Перцептрон на Go

Оригинальный источник: «Build a Multilayer Perceptron with Golang»
↗ Перейти к оригинальному уроку فارسی — Персидская версия EN — English version

Идея: обучение подражанием (imitation learning)

Автор начинает с простого эксперимента: вместо ручного кодирования поведения сеть обучается на «примерах» — то самое подражание демонстрации. Выбранная архитектура — многослойный перцептрон (MLP): входной слой, один или несколько скрытых слоёв и выходной слой, где каждый нейрон работает с нелинейной функцией активации.

Структура кода: NeuralLayer и MultiLayerNetwork

Код организован в одном файле Go (network.go) с тремя ключевыми частями: структура NeuralLayer, хранящая нейроны, смещение и активацию; структура MultiLayerNetwork, хранящая слои и матрицу весов; и главная функция, создающая сеть из массива вроде [4, 3, 3] — 4 входных нейрона, скрытый слой из 3 и выход из 3:

go// Нейронный слой: нейроны, смещения и функция активации
type NeuralLayer struct {
    neurons    int
    activation ActivationFunction
    bias       float64
}

// Многослойная сеть: слои + матрица весов + скорость обучения
type MultiLayerNetwork struct {
    layers      []NeuralLayer
    weights     []*matrix.Matrix
    lr          float64
}

// Создание сети с заданными размерами: вход 4, скрытый 3, выход 3
network, err := NewMultiLayerNetwork([]int{4, 3, 3}, 0.1)

Прямое распространение матричным умножением

Выход каждого слоя — произведение матрицы весов на выход предыдущего слоя, прошедшее через функцию активации (в этой реализации sigmoid). Преимущество матричного представления: все вычисления векторные, через библиотеку gonum/matrix:

go// Вычисление выхода сети для входа (прямое распространение)
func (nn *MultiLayerNetwork) Predict(input []float64) []float64 {
    activation := matrix.NewDenseMatrix(len(input), 1, input)
    for i := 0; i < len(nn.layers); i++ {
        activation = nn.weights[i].Times(activation)
        activation = activation.Apply(nn.layers[i].activation)
    }
    return activation.Array()
}

Обучение: обратное распространение и правка весов

На каждой итерации выход сравнивается с верным ответом, и ошибка распространяется от выходного слоя назад (backpropagation). Веса корректируются на lr × градиент, чтобы ошибка на следующей итерации уменьшилась:

go// Обучение на одном образце: backprop + обновление весов
func (nn *MultiLayerNetwork) BackPropagation(input, target []float64) error {
    // вычисление выхода каждого слоя и сохранение промежуточных значений (для производных)
    outputs := nn.feedForward(input)

    // ошибка выходного слоя, затем распространение назад послойно
    // delta = error × производная активации; затем веса обновляются
    error := matrix.NewDenseMatrix(len(target), 1, target)
    error.MinusEquals(outputs[len(outputs)-1])

    for i := len(nn.layers) - 1; i >= 0; i-- {
        delta := error.Apply(nn.layers[i].activationPrime).Times(nn.lr)
        gradient := outputs[i].Times(delta.Transpose())
        nn.weights[i].MinusEquals(gradient)
        error = nn.weights[i].Transpose().Times(delta)
    }
    return nil
}

Эксперимент: обучение на примерах

Автор обучает сеть на простом примере и наблюдает, как ошибка постепенно уменьшается, а предсказания приближаются к верному ответу. Эксперимент показывает: та же структура без всякого знания предметной области выучивает закономерность из данных:

go// Проведение одного раунда обучения на нескольких примерах с печатью средней ошибки
for epoch := 0; epoch < 5000; epoch++ {
    for i := range trainingInputs {
        err := network.BackPropagation(trainingInputs[i], trainingTargets[i])
        if err != nil {
            panic(err)
        }
    }
    if epoch%1000 == 0 {
        fmt.Printf("Epoch %d — средняя ошибка: %.6f\n", epoch, network.ComputeError(...))
    }
}

Итог

  • MLP = входной слой + скрытые слои + выходной слой, с нелинейной активацией.
  • Матричное представление делает код короче, а вычисления векторными (gonum).
  • Backpropagation с сохранением промежуточных значений каждого слоя прост и прослеживаем.
  • Обучение на примерах (подражание) заменяет ручные правила для сложного поведения.

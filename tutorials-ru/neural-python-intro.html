Нейрон: взвешенная сумма и активация

Каждый нейрон умножает входы на веса, складывает, добавляет смещение и пропускает результат через функцию активации. В статье выход линейный (без активации на последнем слое), потому что задача — регрессия. Начальные веса случайны — обучение и означает поиск правильных весов:

python# Вычисление выхода одного нейрона: СУММА(вход x вес) + смещение
def output(self, inputs):
    total = np.dot(self.weights, inputs) + self.bias
    return total   # без активации (регрессия)

Функция потерь: среднеквадратичная ошибка (MSE)

Качество предсказаний измеряется MSE: средний квадрат разницы между предсказаниями и реальными значениями. Цель обучения — минимизировать это число. Градиент MSE по выходу прост: 2×(выход − факт) / количество примеров — эта простота делает сходимость обучения прозрачной.

python# Функция потерь — среднеквадратичная ошибка
def mse_loss(predictions, targets):
    return np.mean((predictions - targets) ** 2)

Обратное распространение: правило цепочки в действии

Чтобы исправить веса, нужно понять, насколько каждый вес виноват в ошибке — то есть производную потерь по весу, которая вычисляется по правилу цепочки. В сети-примере (2→2→1) для каждого образца находится градиент каждого веса, затем берётся среднее:

d_L_d_ypred = 2 * (y_pred - y_true) / N      # производная MSE по выходу

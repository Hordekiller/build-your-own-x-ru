Цель проекта: «медленно», но прозрачно

Название SlowTorch — дружеская шутка: по сравнению с настоящим PyTorch он медленный, но эта «медленность» компенсируется прозрачностью. Проект написан на чистом Python (без numpy даже в ядре, только stdlib), чтобы тот, кто видит PyTorch как чёрный ящик, мог прочитать и понять каждую его часть построчно: что такое тензор, как работает autograd и что делают слои и оптимизаторы.

Структура: тензоры и autograd

Сердце проекта — класс Tensor, который, как и в PyTorch, имеет две стороны: числовые данные и «вычислительный граф» для автоматического дифференцирования. Каждая операция (сложение, умножение и т.д.) записывает и значение, и локальную производную; вызов backward() распространяет градиенты от выхода к входам:

Слои и функции

Поверх тензоров определены знакомые компоненты, чтобы можно было собрать настоящую сеть: Linear (матричное умножение + смещение), активации (ReLU, Sigmoid, Tanh, Softmax), функции потерь (MSELoss, CrossEntropyLoss) и базовый модуль Module — тот же паттерн, что и nn.Module:

python# Определение сети по паттерну PyTorch
class TwoLayerNet(Module):
    def __init__(self, in_dim, hidden, out_dim):
        self.fc1 = Linear(in_dim, hidden)
        self.fc2 = Linear(hidden, out_dim)

    def forward(self, x):
        x = self.fc1(x)
        x = relu(x)
        x = self.fc2(x)
        return softmax(x)

Оптимизаторы и цикл обучения

Реализованы оптимизаторы вроде SGD и Adam, чтобы цикл обучения был как в PyTorch: forward ← вычисление loss ← backward ← шаг оптимизатора. Наблюдение за этим циклом на чистом Python снимает «магию»:

python# Стандартный цикл обучения — в точности как PyTorch, но всё открыто
model = TwoLayerNet(2, 8, 1)
optimizer = SGD(model.parameters(), lr=0.1)

for epoch in range(100):
    loss_sum = 0
    for x, y in dataset:
        optimizer.zero_grad()
        pred = model(x)
        loss = mse_loss(pred, y)
        loss.backward()          # распространение градиентов
        optimizer.step()         # обновление весов
        loss_sum += loss.data
    print(f"epoch {epoch}: loss = {loss_sum / len(dataset):.6f}")

Почему это стоит читать?

  • Без зависимостей: только стандартный Python — можно запустить за несколько минут и отладить построчно.
  • Ориентировано на читаемость: код написан для обучения, а не для скорости; имена и структуры обучающие.
  • Встроенные тесты: в проекте есть тесты, проверяющие поведение на простых ручных примерах.
  • Мост к настоящему PyTorch: после чтения этого кода API и понятия PyTorch (модуль, параметр, autograd) больше не загадка.

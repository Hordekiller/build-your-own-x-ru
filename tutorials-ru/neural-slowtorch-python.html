О чём это

SlowTorch — мини-фреймворк глубокого обучения: автодиф, слои и оптимизаторы — PyTorch в 500 строк.

Что вы узнаете

  • Автодифференцирование
  • Граф операций
  • Слои
  • Оптимизаторы

Основная идея

SlowTorch реализует суть PyTorch: граф операций, автодиф и обучение. Проект — наглядная версия фреймворка.

Операция с автодифом:

Pythonclass Mul(Function):
    @staticmethod
    def forward(a, b): return a * b
    @staticmethod
    def backward(grad, a, b): return grad * b, grad * a

Почему это важно

SlowTorch — лучшее объяснение фреймворков: вы будете понимать PyTorch, а не просто им пользоваться.

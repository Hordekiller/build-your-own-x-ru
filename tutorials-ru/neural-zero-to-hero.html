Zero to Hero: нейросети с нуля (Крапат)

Об этом курсе

«От нуля до героя» — видеокурс Андрея Карпати (сооснователя OpenAI), который учит нейросетям через «реальное построение»: на каждом занятии совместно кодируется и обучается настоящая система — от одного скалярного значения до языковой модели. Всё машинное обучение начинается только с базового знания Python и небольших воспоминаний о школьном матанализе. Jupyter-ноутбуки всех занятий опубликованы в репозитории karpathy/nn-zero-to-hero.

▶ Смотреть плейлист на YouTube

python# micrograd: класс Value с вычислительным графом для autodiff
class Value:
    def __init__(self, data):
        self.data = data
        self.grad = 0
        self._backward = lambda: None

    def __add__(self, other):
        out = Value(self.data + other.data)
        def _bw():                        # распространение градиента
            self.grad += out.grad
            other.grad += out.grad
        out._backward = _bw
        return out

Первое занятие строит именно этот класс, и все сети и языковые модели курса основаны на этом графе.

План занятий

  • Занятие 1 — строим micrograd: пошаговое введение в нейросети и backpropagation: создание небольшого движка autodiff (класс Value с вычислительным графом) и нейросети на нём — без единой библиотеки.
  • Занятие 2 — строим makemore (bigram): первая языковая модель: посимвольная биграммная модель, которая простым подсчётом учит распределение следующей буквы; введение torch.Tensor и понятий обучения (loss, сэмплирование, оценка).
  • Занятие 3 — MLP: многослойный перцептрон для той же задачи — первая «настоящая сеть» с автоматическим backprop от PyTorch.
  • Занятие 4 — активации и BatchNorm: почему активации (tanh, ReLU и др.) и пакетная нормализация позволяют обучать более глубокие сети.
  • Занятие 5 — ниндзя backprop: ручная реализация обратного распространения для всей сети (без autograd) — отличный путь к глубокой интуиции.
  • Занятие 6 — строим WaveNet: современная языковая модель по мотивам архитектуры WaveNet (свёртки с расширением), которая генерирует текст.
  • Дальнейшие занятия: GPT с нуля — полное построение языкового трансформера, от токенизатора до сэмплирования, на данных Шекспира.

Почему этот курс стоит посмотреть?

  • «Никакого чёрного ящика»: каждое число и каждый градиент на виду — всё строится с нуля.
  • От школьной математики до трансформера: прямой мост между основами и современными языковыми моделями (GPT).
  • Живой стиль преподавания: ошибки и отладка прямо во время кодинга — сами по себе часть обучения.
  • Открытые материалы: ноутбуки + задания каждого занятия + репозиторий micrograd (вместе с pytorch) доступны всем.

Baking Pi: ОС для Raspberry Pi

Оригинальный источник: «Baking Pi — Operating Systems Development»

О курсе

Baking Pi — бесплатный курс Кембриджского университета, который преподаёт основы разработки операционных систем на Raspberry Pi и почти полностью на ассемблере ARMv6. Подход курса необычен: вместо построения целой ОС каждый урок доводит до конца одну «маленькую задачу» — от включения светодиода до командной строки, — и каждый урок содержит необходимую теорию и полную практическую работу. Никаких предварительных знаний об ассемблере или ОС не предполагается.

Инструменты и окружение

Требования: Raspberry Pi (с SD-картой и блоком питания) и отдельный компьютер для разработки с установленным кросс-компилятором ARMv6. Результат сборки — файл kernel.img, который заменяет ядро Linux на SD-карте (всегда храните копию оригинального ядра!). Установка кросс-компилятора в Linux проста:

bash# Установка ARM-кросс-компилятора для Raspberry Pi (старый ARMv6)
sudo apt install gcc-arm-none-eabi binutils-arm-none-eabi

# Сборка проекта по шаблону Makefile OS Template
make        # выход: kernel.img, kernel.list, kernel.map

Уроки: от LED до командной строки

Курс делится на три серии, и каждый урок строится на предыдущем:

  • Серия OK LED (для начинающих): OK01 — включение LED через настройку GPIO; OK02 — мигание; OK03 — функции на ассемблере; OK04 — таймер для точного мигания; OK05 — азбука Морзе SOS.
  • Серия Screen (продвинутая): Screen01 — цветовой градиент на экране; Screen02 — рисование линий и случайные числа; Screen03 — вывод текста и знакомство с kernel command line; Screen04 — вывод вычисленных значений.
  • Серия Input (продвинутая): Input01 — теория драйверов, линковка и клавиатура — использование готового USB-драйвера и печать букв; Input02 — полноценная командная строка, выполняющая команды пользователя.

Пример кода: включение LED (OK01)

Первая ОС отправляет сообщение контроллеру GPIO, чтобы активировать пин 16 (светодиод на плате). Любопытный факт: аппаратура спроектирована так, что LED загорается при выключении пина! А поскольку процессор никогда не останавливается, в конце нужно поставить бесконечный цикл:

arm// main.s — включение OK/ACT LED на Raspberry Pi (ARMv6)
.section .init          // эта секция выполняется первой
.global _start

_start:
    ldr r0, =0x20200000  // базовый адрес контроллера GPIO
    mov r1, #1           // настройка выходных битов для пина 16
    lsl r1, #18          // (пин 16 — каждые 3 бита, значит бит 18)
    str r1, [r0, #4]     // запись в GPFSEL1: пин 16 стал выходом

    mov r1, #1
    lsl r1, #16
    str r1, [r0, #40]    // GPCLR0: «выключение» пина 16 ← LED горит!

loop$:
    b loop$              // бесконечный цикл

Сборка через make создаёт три файла: kernel.img (загрузочный образ), kernel.list (реальный ассемблерный вывод) и kernel.map (карта адресов меток). После копирования на SD-карту и включения Pi зелёный LED загорится — это ваша первая операционная система!

Почему этот курс стоит пройти

  • Реальное железо: вы работаете на настоящей плате, а не только в эмуляторе.
  • Чистый ассемблер: никакого C-компилятора посередине; связь между кодом и железом полностью прозрачна.
  • Теория + практика в каждом уроке: каждая концепция (драйвер, линковка, таймер, таблица поиска) объясняется до кода.
  • Полные ответы к урокам: эталонные решения каждого урока лежат на странице загрузки курса.
Дополнительно: этот курс — отличная отправная точка для тех, кто захочет затем взяться за более продвинутые ARM-учебники, например mini-arm-os — он тоже переведён в этом каталоге.

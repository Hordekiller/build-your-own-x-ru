ОС с нуля на C (Bitwise)

О серии

Bitwise — видеоплейлист Пера Вогнсена (Per Vognsen, известного разработчика компиляторов и преподавателя) с простой философией: «мы построим все слои компьютера снизу вверх, чтобы ничто больше не оставалось для нас чёрным ящиком». Путь серии начинается с базовых компонентов и постепенно поднимает полноценный компьютер и зачаточную операционную систему на нём.

Траектория обучения: от логических вентилей до ОС

Серия начинается на удивление фундаментально, и каждое видео поднимается на один слой выше. Вот общая «карта пути»:

  • Концептуальное железо: логические вентили, сумматоры, память, проектирование простого CPU — с самодельными симуляциями.
  • Ассемблер и окружение: ассемблер, загрузчик (loader), режимы процессора.
  • Язык C на «голом железе»: начало ОС на C, начальное управление памятью.
  • Сервисы: ввод/вывод, таймер, прерывания и структура маленького ядра (kernel).
Verilog// Полусумматор: первый шаг к сумматору на логических вентилях
module half_adder(
  input  a, b,
  output sum, carry
);
  assign sum   = a ^ b;   // XOR: сумма без переноса
  assign carry = a & b;   // AND: перенос
endmodule

От этих полусумматоров серия переходит к полному сумматору, АЛУ и затем к CPU — ровно та цепочка, которую проходят видео.

Чем эта серия особенная

  • Ответы на «почему»: вместо готового кода объясняется причина каждого решения.
  • Без предпосылок: начинается с самого базового уровня (даже с цифровой логики).
  • Непрерывный путь: это не только загрузчик и не только ядро — строится вся цепочка «вентиль → CPU → ОС».
  • Глубокий, спокойный стиль: каждое видео длинное и детальное, подходит для настоящего обучения, а не быстрого просмотра.

Как пользоваться этими видео

Этот плейлист лучше всего проходить «руками на клавиатуре»: останавливайте каждое видео, воспроизводите написанный код и до просмотра продолжения сами предсказывайте поведение кода. Дополнительно к серии полезно пройти маленькие уроки по загрузчику (например, урок Джо Бержерона в этом же каталоге) и сравнить своё решение с решением Вогнсена — это завершит опыт обучения.

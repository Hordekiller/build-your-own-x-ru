Оригинальный источник: «Writing a Bootloader»
↗ Перейти к оригинальному уроку فارسی — Персидская версия EN — English version

Почему этот урок особенный

Большинство учебников либо загружаются через GRUB (в обход написания загрузчика), либо делают только демонстрационный загрузочный сектор. Эта статья идёт средним путём: мы пишем настоящий двухэтапный загрузчик, где первый этап (ассемблер) читает второй этап с диска, переходит в 32-битный режим, а второй этап (C) загружает и запускает ядро. Результат — полное понимание цепочки «BIOS → загрузчик → ядро».

Этап 1: загрузочный сектор на ассемблере

Первый 512-байтный сектор диска делает три вещи: печатает сообщение, читает секторы второго этапа с диска сервисом int 0x13 и затем передаёт туда управление через jmp. Чтение диска в 16-битном режиме выполняется прерыванием BIOS:

nasm; Чтение сектора с диска сервисом BIOS (int 0x13)
read_sector:
    mov ah, 0x02        ; функция: чтение сектора
    mov al, 1           ; количество секторов: один
    mov ch, 0           ; цилиндр 0
    mov cl, 2           ; сектор 2 (первый был загрузчиком)
    mov dh, 0           ; головка 0
    mov dl, 0x80        ; первый диск (жёсткий)
    mov bx, 0x7E00      ; адрес загрузки в память
    int 0x13            ; вызов BIOS
    jc read_sector      ; при ошибке — повторить
    ret

Этап 2: вход в 32-битный режим

Второй этап по-прежнему на ассемблере и теперь должен загрузить GDT, включить бит PE в cr0 и дальним прыжком (far jump) перейти в защищённый режим. Это тот самый ответственный шаг, который присутствует почти во всех проектах ОС:

nasm; Вход в защищённый режим
lgdt [gdt_descriptor]
mov eax, cr0
or eax, 1
mov cr0, eax

jmp 0x08:protected       ; far jump: полная перезагрузка сегментов

[bits 32]
protected:
    mov ax, 0x10
    mov ds, ax
    mov ss, ax
    mov esp, 0x90000     ; новый стек
    ...

Этап 2: ядро на C

После входа в 32-битный режим управление передаётся C-коду. Для простоты статья собирает ядро одним Makefile и запускает в QEMU, чтобы увидеть финальное сообщение:

bash# Сборка загрузчика и ядра и запуск
make
qemu-system-i386 -fda os.img

Что вы узнаете

  • Сервисы BIOS для печати и чтения диска.
  • Структуру двухэтапного загрузчика (в реальном мире используется тот же паттерн).
  • Переход из 16-битного в 32-битный режим с GDT.
  • Совместную работу ассемблера и C в bare-metal-проекте.
Дополнительно: этот урок — лучший мост между «демонстрационным загрузочным сектором» (как урок Джо Бержерона) и «ядром через GRUB» (как Kernel 101) — все три переведены в этом каталоге.

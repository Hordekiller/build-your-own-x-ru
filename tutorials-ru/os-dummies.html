ОС для «чайников»: ядро на C

Подход статьи

Автор — как видно из названия «для чайников» — исходит из того, что у читателя нет никакого опыта разработки ОС. Статья максимально простым языком объясняет, что такое операционная система: «программа, которая выполняется при загрузке и управляет аппаратными ресурсами», — а затем в несколько практических шагов на C и ассемблере собирает загружаемый образец.

Этапы разработки

  • Этап 1 — предпосылки: установка кросс-компилятора (gcc), эмулятора (QEMU или Bochs) и знакомство с нужными инструментами; объяснение, почему кросс-компилятор, а не обычный.
  • Этап 2 — загрузчик: сборка простого загрузчика на ассемблере и печать первого сообщения на экран.
  • Этап 3 — вход в защищённый режим: GDT и переход в 32-битный режим; простое объяснение «почему 16-битного режима недостаточно».
  • Этап 4 — C-ядро: написание первого ядра на C, управление экраном и главный цикл.
  • Этап 5 — развитие: добавление таких возможностей, как управление прерываниями и клавиатурой, с рекомендованными путями продолжения.

Пример кода: структура загрузки и ядро

Та же классическая схема, но с объяснениями, действительно понятными новичку, — загрузчик передаёт управление функции kernel_main на C:

bash# Быстрая сборка и запуск образца ОС
nasm -f elf32 boot.asm -o boot.o
gcc -m32 -c kernel.c -o kernel.o
ld -m elf_i386 -T linker.ld boot.o kernel.o -o kernel.bin

# Запуск в эмуляторе
qemu-system-i386 -kernel kernel.bin
c// kernel.c — главный цикл ядра
void kernel_main(void) {
    char *video = (char *) 0xB8000;   // видеопамять VGA

    video[0] = 'H';
    video[1] = 0x07;                  // белый на чёрном
    video[2] = 'i';
    video[3] = 0x07;

    while (1) {
        __asm__("hlt");               // ждать до следующего прерывания
    }
}

Почему это хорошо для начала

  • Простой и тёплый язык: сложные концепции ОС объясняются без сухих академических терминов.
  • Короткие шаги: каждый этап даёт видимый результат и быстро мотивирует.
  • Путь продолжения: в конце автор даёт рекомендованные источники для дальнейшего пути.

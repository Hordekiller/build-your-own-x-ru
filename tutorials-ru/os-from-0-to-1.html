О книге

Книга «From 0 to 1» (сокращённо OS01) — свободная и полная книга о построении операционной системы, проходящая путь «источники → устройство → ОС» с фокусом на понимание документации Intel. Её подход, в отличие от большинства учебников, не считает простое копирование кода достаточным: большая часть книги посвящена правильному чтению и интерпретации Intel Manuals, чтобы читатель научился сам находить ответы на свои вопросы в документации.

Структура: три части и тринадцать глав

  • Часть 1 — основы: среда разработки, командная строка и инструменты; пошаговое обучение ассемблеру x86 (глава 2) и «обучение чтению Intel Manual» (глава 3).
  • Часть 2 — от ресурсов к устройству: построение настоящей ОС: оптимизация x86 (глава 4), ограничения x86 и проектирование os (глава 5), структура полноценной ОС (глава 6), управление памятью (глава 7), приложения и способ их запуска (глава 8).
  • Часть 3 — приложения: главы 9–13, включающие дополнительные приложения (загрузчик, отладка, сравнение с Linux и т.д.) — частично незавершённые и носящие скорее справочный характер.

Практический проект книги — ОС os.asm, воспроизводимая в том же репозитории: загрузчик, ядро в защищённом режиме, управление страничной памятью и переход в 64-битный режим.

Ключевые особенности

  • Линковка и ELF-файлы: книга глубоко объясняет, что делают линкер и ELF-файлы и почему они обязательны для bare-metal.
  • 64-битный режим: в отличие от многих учебников, останавливающихся на 32-битном режиме, этот курс доводит ядро до long mode.
  • Полный список инструментов: компилятор, ассемблер, линкер, эмулятор и подготовка окружения описаны целиком.
  • Опора на источники: ответ на каждое «почему» показывается в документации Intel — навык, который переживёт любое простое ядро.

Пример из практики: переход в защищённый режим

Часть процесса построения ОС в книге: после загрузчика CPU должен выйти из 16-битного режима через определение GDT (глобальная таблица дескрипторов) и войти в 32-битный:

nasm; Загрузчик os.asm — определение GDT и вход в 32-битный режим
gdt_start:

gdt_null:              ; нулевой дескриптор (обязателен)
    dd 0
    dd 0

gdt_code:              ; дескриптор сегмента кода (исполняемый код)
    dw 0xffff          ; предел
    dw 0x0000          ; база (первая часть)
    db 0x00            ; база (вторая часть)
    db 0b10011010      ; флаги: код, доступен для чтения
    db 0b11001111      ; флаги + предел
    db 0x00            ; база (третья часть)

gdt_data:              ; дескриптор сегмента данных
    dw 0xffff
    dw 0x0000
    db 0x00
    db 0b10010010
    db 0b11001111
    db 0x00

gdt_end:

gdt_descriptor:
    dw gdt_end - gdt_start - 1
    dd gdt_start

; затем: загрузка GDT через lgdt и дальний переход (far jump) в 32-битный код

Это лишь пример; книга объясняет в тексте все детали и «причины» каждого бита, а после этого переходит к управлению памятью и long mode.

Рекомендуемый путь обучения

Эта книга подходит тем, кто уже прошёл короткий курс (например, os-tutorial) и хочет теперь углубиться. Рекомендуемый путь: полностью прочитайте главы 2 и 3 (ассемблер + чтение Intel Manual), а затем во время сборки проекта os.asm всякий раз, когда возникнет вопрос, обращайтесь к документации — привычка, которой обучает глава 3.

Дополнительно: благодаря охвату long mode и управления памятью эта книга — отличное дополнение к простым учебникам по загрузчику, ведущее подготовленного читателя прямо к проектам уровня настоящих ОС.

Хак виртуальной памяти

Идея серии

«Hack the Virtual Memory» — серия учебных статей, показывающих виртуальную память «руками пригодной к взлому»: вместо сухой теории мы вскрываем память реально работающего процесса инструментами Linux и изменяем её. Глава 0 начинается просто и в то же время удивительно — с C-строк и файловой системы /proc.

Карта памяти процесса

Каждый процесс Linux имеет «виртуальное адресное пространство» со стандартными секциями: text (код программы), data (глобальные переменные), stack (стек) и heap (динамическое выделение). C-строковые переменные в зависимости от способа определения попадают в разные секции:

  • Строковый литерал (например, "hello") — в секцию text (только для чтения).
  • Глобальный массив (например, char s[] = "…" на глобальном уровне) — в секцию data.
  • Локальная переменная — на стек (stack).

Окно в память: /proc/pid/mem

Ключевой момент: Linux выставляет память любого процесса через файл /proc/<pid>/mem. Читая этот файл (как обычный файл) и пользуясь /proc/<pid>/maps (картой секций), можно увидеть содержимое памяти живого процесса и даже перезаписать его:

c// Чтение одного символа из памяти живого процесса
int read_byte(pid_t pid, long addr) {
    char path[64];
    snprintf(path, sizeof path, "/proc/%d/mem", pid);

    int fd = open(path, O_RDONLY);
    char byte;
    pread(fd, &byte, 1, addr);   // чтение одного байта по заданному адресу
    close(fd);
    return byte;
}

Если программа не остановлена через ptrace или attach, открытие /proc/pid/mem может дать ошибку EIO — это само по себе важный урок о правах доступа и состоянии остановки процесса.

Настоящий хак: изменение строки в живом процессе

Знаменитый пример главы: программа печатает на экран строку; мы находим её адрес в карте памяти, затем записью в /proc/pid/mem меняем её содержимое — и при следующей печати программа показывает нашу строку:

c// Изменение одного байта строки живого процесса
int write_byte(pid_t pid, long addr, char value) {
    char path[64];
    snprintf(path, sizeof path, "/proc/%d/mem", pid);

    int fd = open(path, O_WRONLY);
    pwrite(fd, &value, 1, addr);
    close(fd);
    return 0;
}

Чтобы найти точный адрес, подключаем GDB: x/s показывает адрес строки, а p/x — адреса переменных.

Что мы узнаём

  • Реальную разницу между секциями памяти (stack / data / text) прямым наблюдением.
  • Практическое применение /proc и понятия PID и прав доступа.
  • Концепцию виртуальных и физических адресов — почему адреса в maps «виртуальные».
  • Инструменты, которыми пользуются разработчики отладчиков и инструментов для взлома памяти.
Дополнительно: у серии есть и другие главы (виртуальные адреса, внутренности malloc и т.д.); глава 0 благодаря простоте и наглядности — лучший вход в мир управления памятью Linux.

Ядро 101: первые шаги

Главная идея

Этот урок строит два первых ядра: одно на ассемблере и одно на C — оба загружаются с помощью GRUB, чтобы не писать загрузчик самостоятельно. Цель — показать «самую простую вещь, которую можно назвать загружаемым ядром»: ELF-файл, печатающий на экран «Hello World».

Ядро на ассемблере: вход через GRUB и стек

Когда загружается GRUB, он по стандарту Multiboot загружает ядро и передаёт ему управление. Тонкий момент: на этом этапе ESP не определён (GRUB не задаёт надёжного значения стека), поэтому первое, что должно сделать ядро, — построить собственный стек:

nasm; kernel.asm — ассемблерное ядро: определение стека и печать сообщения
bits 32
section .text

global start
start:
    mov esp, stack_top  ; построение стека (обязательно! ESP не определён)
    call kmain          ; переход в основную функцию
    hlt                 ; остановка процессора

section .bss
resb 8192               ; 8 килобайт под стек
stack_top:

Ядро на C: прямая запись в видеопамять VGA

У C-версии есть красивая деталь: вместо каких-либо систем достаточно писать в видеопамять 0xB8000 (текстовый режим VGA). Каждый символ = 2 байта (код символа + атрибут цвета). Функция kmain для каждой буквы записывает атрибут зелёный-на-чёрном:

c// kmain.c — C-ядро: печать в видеопамять VGA
#define VGA_ADDRESS 0xB8000
#define WHITE_ON_BLACK 0x0f00
#define GREEN_ON_BLACK 0x2a00

void kmain(void) {
    const char *str = "my first kernel";
    unsigned short *vga = (unsigned short *) VGA_ADDRESS;

    for (int i = 0; str[i] != '\0'; ++i) {
        vga[i] = GREEN_ON_BLACK | str[i];
    }

    for (;;) {        // бесконечный цикл: ядро «закончило»
        __asm__("hlt");
    }
}

Компиляция и запуск

C-ядро линкуется в 32-битный ELF-файл (адрес от 1MB) и затем файлы kernel и grub помещаются в загрузочный ISO с помощью grub-mkrescue:

bash# Компиляция и линковка ядра
gcc -m32 -c kernel.c -o kernel.o
ld -m elf_i386 -T link.ld kernel.o -o kernel

# Сборка загрузочного ISO с GRUB
grub-mkrescue -o os.iso kernel_dir

# Запуск в QEMU
qemu-system-i386 -cdrom os.iso

Через несколько секунд на экране QEMU появится надпись «my first kernel».

Почему это важно

  • Максимально короткий путь к «настоящему ядру» — без мороки с написанием загрузчика.
  • Понятие Multiboot объясняется наглядно и на примере.
  • Линковка и ELF для bare-metal объясняются на файле линкера.
  • Хороший мост к Kernel 201 (того же автора), который добавляет ввод с клавиатуры и работу с экраном.

Цель статьи

Ядро Kernel 101 только печатало сообщение. Эта статья берёт то же ядро и даёт ему две настоящие возможности: вывод на экран с полным контролем (прокрутка, цвета, курсор) и чтение клавиатуры через прерывания. Это значит, что наше ядро впервые по-настоящему взаимодействует с железом: через порты I/O и прерывания.

Порты ввода-вывода: чтение и запись через in/out

Железо x86 общается с CPU через «порты» — специальные адреса, доступные командами in и out. Два важных порта: 0x3F8 (последовательный порт) для вывода и 0x60 для клавиатуры. Пример — печать символа в последовательный порт:

c// Запись в последовательный порт COM1
#define PORT_SERIAL 0x3F8

void serial_write(char c) {
    __asm__ volatile (
        "outb %0, %1"        // вывод байта c в порт PORT_SERIAL
        : : "a"(c), "Nd"(PORT_SERIAL)
    );
}

Экран: переход на новую строку и прокрутка

Монитор VGA в текстовом режиме сам не прокручивает: ядро должно управлять прокруткой, вычисляя адрес «следующей строки» в памяти 0xB8000 и очищая последнюю строку. Перемещение курсора выполняют два специальных порта (0x3D4 / 0x3D5):

c// Перемещение курсора отправкой 16-битного адреса контроллеру VGA
void move_cursor(int row, int col) {
    unsigned short pos = row * 80 + col;

    outb(0x3D4, 14);            // выбор регистра «старший байт»
    outb(0x3D5, (pos >> 8) & 0xFF);  // старший байт
    outb(0x3D4, 15);            // регистр «младший байт»
    outb(0x3D5, pos & 0xFF);    // младший байт
}

Клавиатура через прерывания

Нажатия клавиш приходят прерыванием IRQ1. Ядро должно построить IDT (таблицу дескрипторов прерываний) и определить обработчик, который читает скан-код из порта 0x60 и переводит его в символ. У каждой клавиши два кода: нажатие (например, 0x1E для A) и отпускание (со старшим битом 0x80). Фрагмент таблицы перевода раскладки QWERTY:

c// Перевод скан-кода в символ (часть таблицы)
unsigned char keyboard_map[128] = {
    0,  27, '1', '2', '3', '4', '5', '6', '7', '8',
    '9', '0', '-', '=', '\b',
    '\t', 'q', 'w', 'e', 'r', 't', 'y', 'u', 'i', 'o',
    'p', '[', ']', '\n',
    0,                      // Ctrl
    'a', 's', 'd', 'f', 'g', 'h', 'j', 'k', 'l', ';',
    '\'', '`',
    0, '\\', 'z', 'x', 'c', 'v', 'b', 'n', 'm', ',',
    '.', '/', 0, '*',
    0, ' ',                 // Space
    // ...
};

Запуск

Как и в Kernel 101, собираем ISO через grub-mkrescue и запускаем в QEMU. Теперь при нажатии клавиши её символ появляется на экране, а когда текст доходит до конца — корректно прокручивается:

bashmake          # сборка ядра
grub-mkrescue -o os.iso kernel_dir
qemu-system-i386 -cdrom os.iso

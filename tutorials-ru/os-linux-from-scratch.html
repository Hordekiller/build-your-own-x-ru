О чём это

Linux From Scratch: система Linux, собранная вручную — компиляция ядра, инструментов и конфигурация из исходников.

Что вы узнаете

  • Инструментальная цепочка
  • Сборка ядра
  • Конфигурация системы
  • Свой дистрибутив

Основная идея

LFS учит собирать Linux из исходников: кросс-компиляция, конфигурация и запуск — полный контроль над системой.

Настройка ядра — команда:

Bashmake menuconfig   # выбор компонентов ядра
make -j$(nproc)    # сборка ядра
make modules_install && make install

Почему это важно

LFS — глубокое погружение: после него вы знаете свою систему до последнего пакета.

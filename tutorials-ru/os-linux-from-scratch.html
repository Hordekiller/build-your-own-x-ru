Что такое LFS?

Linux From Scratch — это подробный, точный проект-документация, который говорит: «как собрать полноценную систему Linux только из исходного кода». Никаких готовых бинарных пакетов: каждый пакет (glibc, gcc, coreutils и т.д.) компилируется и устанавливается из исходников по точным командам из книги. Результат — личный, минимальный и полностью понятный дистрибутив Linux: вы знаете, где лежит каждый файл системы и почему он установлен.

Структура книги

  • Главы 1–3 — подготовка: знакомство с инструментами, проверка диска, разметка и создание файловой системы, установка пакетов хост-системы (host).
  • Глава 4 — предварительные шаги: структура каталогов, ограничение окружения и права пользователя (ничего нельзя строить от root!).
  • Глава 5 — временный toolchain: компиляция Binutils pass 1, GCC pass 1 и Glibc — первая «цепочка инструментов», всё ещё зависящая от хост-системы.
  • Глава 6 — временные инструменты: завершение набора инструментов сборкой пакетов вроде Coreutils, Bash и Make (пока временных).
  • Глава 7 — вход в окружение LFS: создание виртуальной файловой системы и chroot в новое окружение; сборка initramfs.
  • Глава 8 — установка финальных пакетов: повторная сборка Binutils и GCC (pass 2) и всех основных пакетов — на этот раз «по-настоящему», без зависимости от хост-системы.
  • Глава 9 — настройка системы: загрузочные файлы, /etc, ядро Linux kernel и его полная сборка.
  • Глава 10 — сделать загружаемой: grub, fstab и первый запуск вашего личного Linux.

Идея toolchain (два прохода)

Ключевая концепция LFS — и самая трудная для понимания — «двухпроходная» сборка компилятора: поскольку Glibc ещё нет, первый GCC (pass 1) используется только для сборки временных инструментов, а короткими командами (spec-файлом) ему запрещают смотреть на файлы хост-системы:

bash# Краткая схема сборки GCC pass 1 (глава 5 LFS)
mkdir -v build && cd build
../configure --prefix=$LFS/tools \
    --with-local-prefix=$LFS/tools \
    --disable-nls --disable-shared --disable-libssp \
    --enable-languages=c --disable-bootstrap

make -j$(nproc) && make install

# Самый важный момент: специальный «spec», заставляющий
# компилятор никогда не смотреть на файлы хост-системы
ln -sv $LFS/tools/bin/gcc /usr/bin/gcc   # во временном chroot
cat > dummy-gcc.sh << "EOF"
# ...
EOF

Именно здесь многие терпят неудачу: временный компилятор не должен видеть заголовки и библиотеки хост-системы, иначе «чистые» бинарники не получатся. Книга подробно объясняет эти ошибки.

Обучающая ценность LFS

  • Понимание цепочки компиляции: binutils → gcc → glibc и «проблема курицы и яйца» при начальной сборке.
  • Понимание системы Linux: в конце вы будете знать смысл каждой директории и каждого файла конфигурации.
  • Точность и дисциплина: многократная сборка инструментов тренирует терпение и внимательность.
  • Следующий шаг — BLFS: после LFS книга Beyond LFS (BLFS) учит установке остального софта (сети, GUI и т.д.).
Дополнительно: LFS отличается от других уроков этой коллекции — вы не пишете ядро Linux, а собираете руками всю операционную систему вокруг него; лучшее дополнение для тех, кто прошёл уроки по написанию ядер.

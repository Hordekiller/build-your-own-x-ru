Mini ARM OS на C

О проекте

mini-arm-os — известный учебный репозиторий, который реализует базовые концепции ОС на архитектуре ARM (эмулируемая плата STM32 в QEMU) и без каких-либо сторонних библиотек, урок за уроком. Каждый урок — отдельная ветка (branch) на GitHub; в каждой ветке собирайте через make и запускайте командой QEMU, чтобы увидеть поведение урока. Выбор ARM даёт преимущество: читать и писать код проще, чем на x86.

Восемь уроков

  • 01-HelloWorld: базовая структура, кросс-компиляция (cross compile) для ARM и печать сообщения.
  • 02-ContextSwitch: переключение контекста — сердце многозадачности; вход в режим ядра через svc (Supervisor Call).
  • 03-Interrupt: аппаратные прерывания и работа с NVIC (контроллер прерываний ARM).
  • 04-Process: определение процессов, PCB (блок управления процессом) и простое планирование.
  • 05-Timer: системный таймер — основа честного планирования.
  • 06-Preemptive: вытесняющее планирование; процессы принудительно переключаются по прерыванию таймера.
  • 07-Threads: нити (threads) внутри одного процесса и конкурентность (concurrency).
  • 08-CMSIS: использование библиотеки CMSIS; более чистая и реалистичная версия прошлых уроков.

Пример кода: переход в режим супервизора для переключения контекста

В уроке 02 пользовательский процесс командой svc (сервис ядра) переходит в привилегированный режим супервизора, чтобы ядро могло переключать контексты. Красивая деталь: в ARM адрес возврата из прерывания хранится в lr (Link Register) со смещением 4 байта, которое нужно компенсировать при продолжении выполнения:

arm@ context_switch.S — сохранение регистров и переключение на следующий процесс
.global context_switch
context_switch:
    @ сохранение состояния текущего процесса
    stmfd sp!, {r0-r12, lr}     @ сохранение регистров и адреса возврата
    mrs r0, spsr                @ состояние процессора до прерывания
    stmfd sp!, {r0}

    @ загрузка состояния следующего процесса
    ldmfd r0!, {r1-r12, sp, lr} @ восстановление регистров и стека
    msr spsr_cxsf, r0           @ восстановление состояния

    @ продолжение выполнения следующего процесса
    ldmfd sp!, {r0, pc}^

Запуск

Сборка и запуск очень просты — достаточно ARM-кросс-компилятора и QEMU с mcu-type stm32-p103:

bash# Например, урок 03 (прерывания)
git checkout 03-Interrupt
make
qemu-system-arm -M stm32-p103 -kernel build/interrupt.elf \
    -serial stdio -monitor none -nographic

Последовательный вывод показывает поведение процессов/прерываний.

Почему mini-arm-os

  • Минимальный путь ARM: каждый урок — одна концепция, без лишних сложностей.
  • Запуск в QEMU: никакого железа не нужно, вы получаете мгновенную обратную связь.
  • Чистый и читаемый код: код компактный и сфокусирован на сути.
  • С сопроводительными статьями: объяснения каждого урока лежат в той же ветке.
Дополнительно: для того, кто уже освоил ARM-ассемблер (например, по курсу Baking Pi) и теперь хочет увидеть концепции ОС с минимумом отвлечений, этот набор — отличный выбор.

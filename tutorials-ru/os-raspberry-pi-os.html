ОС для Raspberry Pi на C

О проекте

Этот репозиторий в шести уроках строит довольно полную ОС для Raspberry Pi 3, которая в конце умеет одновременно запускать несколько пользовательских процессов и переключаться между ними — совсем как миниатюрный Linux. Отличительная особенность курса: после каждого урока есть глава сравнения, показывающая, как тот же приём выполняет настоящий Linux. Поддерживается и QEMU, что позволяет разрабатывать без железа.

Шесть уроков

  • Урок 1 — подготовка ядра: структура загрузки, настройка адресов, стека и первого C-кода; включение UART для последовательного вывода.
  • Урок 2 — подготовка процессора: управление процессором, таблица уровней Exception Level и режимы выполнения (EL1/EL0 в AArch64).
  • Урок 3 — прерывания: IRQ и контроллер прерываний; реализация таймера и клавиатурного ввода через прерывания.
  • Урок 4 — планировщик (Scheduler): определение процессов, блока управления процессом (PCB) и переключение между процессами.
  • Урок 5 — пользовательские процессы: пользовательский режим (EL0), системные вызовы (syscall) и запуск пользовательских программ.
  • Урок 6 — виртуальная память: MMU, таблицы страниц и трансляция виртуальных адресов в физические.

Пример кода: загрузка и первое сообщение (урок 1)

Первый шаг — загрузочный ассемблер, который настраивает стек и передаёт управление C, а затем инициализация UART для печати «Hello World»:

arm// kernel.c (урок 1) — инициализация UART и печать сообщения
#include "uart.h"

void kernel_main(void) {
    uart_init();               // инициализация последовательного порта
    uart_send_string("Hello, world!\n");

    while (1) {
        // читать символ и возвращать его (эхо)
        uart_send(uart_recv());
    }
}

Просмотр вывода: положите образ ядра (kernel8.img) на SD-карту и подключитесь к последовательному порту, либо запустите в QEMU с -kernel kernel8.img, чтобы увидеть текст на консоли.

Чем этот курс отличается

  • Современная архитектура: AArch64 (64 бита) вместо старого x86 — другой взгляд на прерывания и память.
  • Сравнение с Linux: каждая концепция сравнивается с реальной реализацией в Linux; связь обучения и реальности.
  • Полный путь: от загрузки до пользовательских процессов и виртуальной памяти — почти все компоненты миниатюрной ОС.
  • Поддержка QEMU: если платы нет, всё эмулируется.
Дополнительно: этот проект — естественное продолжение Baking Pi: освоив ARM с нуля в Baking Pi, этот курс использует тот же язык для построения более полной ОС.

О серии

Эта серия — самый популярный и полный урок по созданию операционной системы на Rust. Каждая статья покрывает одну тему с полным кодом и глубокими пояснениями, и все статьи строятся друг на друге единой цепочкой. Текущая (вторая) версия использует современную архитектуру: компиляция в freestanding binary без каких-либо зависимостей от ОС и загрузка через специальный crate под названием bootloader.

Интересная деталь о версиях: первая версия (старая) работала через стандартные GRUB и Multiboot, а вторая версия перешла на собственный загрузчик со стандартом, заточенным под Rust (загрузка в режимах UEFI и BIOS), и код полностью управляется инструментом cargo.

Список статей

  • Freestanding Rust Binary: сборка бинарника без ОС — объявление #![no_std] и специальной цели (target).
  • Minimal Rust Kernel: первое ядро с функцией _start и выводом сообщения в память VGA; запуск через crate bootloader и выполнение в QEMU.
  • VGA Text Mode: запись в видеопамять через модуль vga_buffer и управление println.
  • Testing: инфраструктура модульных и интеграционных тестов для ядра.
  • CPU Exceptions: таблица IDT, прерывания CPU и обработчики.
  • Double Faults: обработка двойной ошибки и её стек.
  • Hardware Interrupts: аппаратные прерывания, контроллер PIC и таймер — первая основа многозадачности.
  • Introduction to Paging: страничная адресация и управление виртуальной памятью через четырёхуровневую таблицу страниц (P4..P1).
  • Heap Allocation: аллокатор кучи внутри ядра.
  • Allocator Designs: сравнение дизайнов аллокаторов (списки свободных блоков и т.д.).
  • Async/Await: паттерн async на уровне ОС и построение исполнительного рантайма.

Пример кода: минимальное ядро

Маленькое ядро серии — это freestanding-бинарник, собираемый компилятором Rust, где выброшенное (например, std) заменяется обработчиком паник Rust:

rust//! Минимальное ядро — freestanding Rust binary
#![no_std]          // без стандартной библиотеки
#![no_main]         // без обычного main

use core::panic::PanicInfo;

static HELLO: &[u8] = b"Hello World!";

#[no_mangle]
pub extern "C" fn _start() -> ! {
    let vga_buffer = 0xb8000 as *mut u8;

    for (i, &byte) in HELLO.iter().enumerate() {
        unsafe {
            *vga_buffer.offset(i as isize * 2) = byte;
            *vga_buffer.offset(i as isize * 2 + 1) = 0xb;  // зелёный
        }
    }

    loop {}         // система «завершила работу»
}

#[panic_handler]
fn panic(_info: &PanicInfo) -> ! {
    loop {}
}

Сборка и запуск выполняются инструментами Rust; собственный загрузчик (crate bootloader) формирует загрузочный образ:

bashcargo build
cargo run    # со встроенной конфигурацией QEMU запускает ядро

Сильные стороны

  • Точность и глубина: каждая концепция объяснена с деталями архитектуры x86_64.
  • Актуальность: статьи постоянно обновляются под новые версии Rust и инструментов.
  • Тесты в проекте: полная тестовая инфраструктура — вы учитесь тестировать своё ядро, как обычный софт.
  • Высокий уровень: серия доходит до async/await — такого нет в C-уроках.
Дополнительно: если вы знакомы с Rust (или хотите выучить Rust «под предлогом» ОС) — эта серия лучший выбор; иначе сначала пройдите C-путь (например, Little OS Book), а потом вернитесь сюда, чтобы увидеть разницу с безопасностью Rust.

О чём это

Серия Molloy: мини-ядро Unix — планировщик, память, syscalls — ОС на C по шагам.

Что вы узнаете

  • Ядро
  • Память
  • Планировщик
  • Системные вызовы

Основная идея

Серия воспроизводит идеи Unix: процессы, память и syscalls — фундамент современных ОС на учебном примере.

Создание задачи планировщиком:

Ctask_t *task_create(func_t func, uint32_t arg) {
    task_t *t = alloc_task();
    t->context = setup_context(func, arg); // сохранить контекст
    return t;
}

Почему это важно

Клон Unix — глубина и проверка: вы соберёте ядро, которое работает, и узнаете цену Unix-идей.

О курсе

CodePulse (Дэвид Калланан) создал один из самых популярных видеокурсов по разработке ОС. Каждое видео в живом режиме написания кода строит очередную часть ОС, и зритель «вблизи» видит, как принимается каждое решение. В отличие от статей, у видео есть большое преимущество: видны ошибки, отладка и ход мыслей автора.

C// Первый код курса: вывод символа прямо в текстовый экран
static void print_char(char c) {
  static uint16_t* vga = (uint16_t*)0xB8000;   // видеопамять VGA
  static uint8_t row = 0, col = 0;
  vga[row * 80 + col] = (0x0F << 8) | c;        // яркий цвет + символ
  col++;
}

Этот простой принтер символов — первый кирпич, от которого курс поднимается до прерываний и планировщика.

Путь курса

  • Первые части — загрузка: структура загрузчика, первый ассемблер, загрузка в эмуляторе и печать сообщения.
  • Средние части — ядро: вход в 32-битный режим, управление экраном, прерывания и драйвер клавиатуры.
  • Финальные части — завершение: планировщик, управление памятью и итог финальной ОС.

Полный исходный код проекта лежит в репозитории GitHub os-series, и каждую часть можно проходить отдельно.

Что вы узнаете

  • Как реально работают загрузчик, GDT, IDT и прерывания — вживую.
  • Написание драйверов клавиатуры и экрана.
  • Начальное управление памятью и планирование процессов.
  • Паттерны отладки ядер.

Как смотреть

Лучший способ — кодить одновременно с видео: остановите видео, внесите то же изменение сами и запустите, прежде чем продолжать. Код курса на каждом этапе запускается в QEMU; если застряли на какой-то части — сравните свой код с оригинальным репозиторием.

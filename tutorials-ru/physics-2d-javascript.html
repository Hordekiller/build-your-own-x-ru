Физический движок 2D на JavaScript

Об уроке

Этот урок IBM (опубликован 19 ноября 2012) на практике показывает, как устроен простой двумерный физический движок для браузерных игр. Цель урока — построить его с нуля и без готовой физической библиотеки: обнаружение столкновений, реакция на столкновения и базовые понятия разработки игр. Сам урок предлагает сравнить свою реализацию с существующими движками (например, Box2D и его JavaScript-версией box2d-js), чтобы увидеть разницу между простой и профессиональной реализацией.

Предпосылки: знакомство с JavaScript и рисованием через canvas. Начальные понятия кинематики (положение, скорость, ускорение) тоже повторяются по ходу урока.

Архитектура MVC

Отличительная черта урока — разделение модели и представления (паттерн MVC):

  • Модель (физика): физический мир с телами, столкновениями и законами движения — независима от рендеринга.
  • Представление (Canvas): отрисовка тел на холсте — только читает состояние модели.
  • Контроллер/игровой цикл: связывает модель и представление в каждом кадре через requestAnimationFrame.
javascript// Игровой цикл: в каждом кадре сдвинь модель, затем нарисуй
function gameLoop() {
    physics.step(dt);   // физика: модель
    renderer.draw();    // отрисовка: представление
    requestAnimationFrame(gameLoop);
}

Такое разделение делает физический движок переиспользуемым и тестируемым как есть.

Базовая физическая модель

Модель состоит из простых тел (например, шаров/окружностей и прямоугольников); у каждого тела есть положение, скорость и масса, и на каждом шаге оно обновляется по законам движения. Базовый закон — то самое интегрирование Эйлера:

javascript// Обновление кинематики тела
function integrate(body, dt) {
    body.velocityY += GRAVITY * dt;      // ускорение гравитации
    body.x += body.velocityX * dt;       // перемещение
    body.y += body.velocityY * dt;
}

Гравитация применяется как постоянное ускорение, и тела ускоряются вниз со скоростью, зависящей от времени.

Столкновения

Затем добавляется обнаружение столкновений: сначала с границами сцены (землёй/стенами), потом тело-тело. Для каждого столкновения нужна реакция, чтобы тела не проваливались друг в друга — например, инверсия скорости с коэффициентом восстановления или привязка положения к границе:

javascript// Столкновение с землёй: отскок вверх с потерей энергии
function collideWithGround(body) {
    if (body.y + body.radius > floorY) {
        body.y = floorY - body.radius;
        body.velocityY *= -RESTITUTION;
    }
}

Для столкновения тело-тело расстояние между центрами сравнивается с суммой радиусов, и скорости меняются по закону сохранения импульса.

Сравнение с Box2D и продолжение пути

В разделе ресурсов урок ссылается на Box2D и его JavaScript-порт (box2d-js) и предлагает сравнить результат вашего простого движка с профессиональным по стабильности, точности и устойчивости — та разница, которая делает осязаемыми такие концепции, как итеративный решатель, манифолды и коррекция положений. Дополнительные ресурсы урока — официальное руководство по Canvas и материалы по кинематике.

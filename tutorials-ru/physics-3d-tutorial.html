Введение — что мы строим

Этот плейлист — полноценный видеокурс, который шаг за шагом, с нуля строит трёхмерный физический движок. Подход серии — «всё делаем сами»: вместо готовых физических библиотек вы напрямую реализуете векторы, матрицы, интегрирование и обнаружение столкновений, а чтобы увидеть результат, сцена визуализируется через OpenGL.

Результат серии — работающий движок: твёрдые тела (сферы и кубы) падают под действием гравитации, сталкиваются с землёй и друг с другом, реагируют импульсами и вращением — те самые базовые возможности любого игрового физического движка.

Примечание: по правилам этого сайта видео не размещаются на нём; для просмотра серии перейдите в оригинальный плейлист на YouTube и смотрите видео по порядку.

Путь обучения серии

Серия проходит примерно такие этапы (тематическая разбивка по содержанию самой серии):

Этап 1 — основы 3D-математики

  • Класс трёхмерного вектора (Vec3): сложение, вычитание, умножение на скаляр, скалярное произведение, векторное произведение, длина и нормализация.
  • Класс матрицы 4×4 и кватернионы для вращения — потому что трёхмерное вращение нельзя выразить простым углом.
C++// Ядро класса 3D-вектора — то, что серия строит в первую очередь
struct Vec3 {
  float x, y, z;

  Vec3 operator+(const Vec3& o) const { return {x + o.x, y + o.y, z + o.z}; }
  Vec3 operator*(float s)     const { return {x * s,   y * s,   z * s};   }

  float dot(const Vec3& o) const { return x * o.x + y * o.y + z * o.z; }
  Vec3  cross(const Vec3& o) const {
    return {y * o.z - z * o.y, z * o.x - x * o.z, x * o.y - y * o.x};
  }
  Vec3 normalized() const { return *this * (1.0f / sqrt(dot(*this))); }
};

Этап 2 — основы физики

  • Законы движения Ньютона и понятия силы, массы, ускорения, скорости и положения.
  • Численное интегрирование (метод Эйлера и более устойчивые версии) с фиксированным шагом времени.
  • Применение гравитации и ограничение шага времени для устойчивости.

Этап 3 — трёхмерное твёрдое тело

  • Структура RigidBody: положение, линейная скорость, ориентация, угловая скорость, масса и момент инерции.
  • Динамика вращения через кватернионы и обновление момента инерции в мировом пространстве (тензор инерции).

Этап 4 — обнаружение столкновений

  • Базовые тесты: сфера-сфера (расстояние между центрами против суммы радиусов), сфера-плоскость (знаковое расстояние), сфера-AABB (ближайшая точка).
  • Генерация нормали столкновения и глубины проникновения для перехода к этапу решения.

Этап 5 — разрешение столкновений

  • Линейный импульс для разделения тел с коэффициентом восстановления (restitution).
  • Вращательный импульс: с плечом r от центра масс до точки контакта энергия передаётся и в угловую скорость — то же стандартное уравнение, что в движках типа Bullet.

Этап 6 — рендеринг и сцена

  • Рендеринг тел через OpenGL, чтобы увидеть результат в действии.
  • Цикл сцены: обновление физики, столкновения и отрисовка каждого кадра.

Почему стоит посмотреть эту серию

  • Настоящий 3D: большинство бесплатных уроков «свой физический движок» — двумерные; эта серия показывает настоящие 3D-сложности (кватернионы, тензор инерции, рендеринг).
  • Всё с нуля: никаких готовых движков; после серии вы напрямую написали каждую увиденную часть — лучшая тренировка для чтения кода больших движков, таких как Bullet.
  • Замкнутый цикл разработки: математика → тело → столкновение → решение → рендеринг; у вас на руках полноценный движок, который может стать основой следующего проекта.

Предпосылки: среднее знакомство с C++ и базовые математические понятия (векторы). Если хотите освежить линейную алгебру, текстовые статьи по физике этого же сайта (например, «Как работают физические движки») — хорошее дополнение.

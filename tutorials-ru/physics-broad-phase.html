Основная идея

Broad-phase отбрасывает невозможные пары: сортировка по осям и сетки сокращают проверки с O(n²) до почти O(n).

Sweep-and-prune по X:

JavaScriptbodies.sort((a, b) => a.x - b.x);
for (let i = 0; i < bodies.length; i++) {
    for (let j = i + 1; j < bodies.length; j++) {
        if (bodies[j].x - bodies[i].x > 0) break; // кандидаты
    }
}

Почему это важно

Оптимизация столкновений — сердце физики: broad-phase применяется в играх, симуляциях и VFX.

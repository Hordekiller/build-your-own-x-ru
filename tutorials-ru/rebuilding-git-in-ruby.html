О чём это

Урок воссоздаёт git на Ruby: объекты, коммиты, ветки и merge — полный цикл на точном классическом языке.

Что вы узнаете

  • Модель объектов
  • Коммиты
  • Ветки
  • Merge и resolve

Основная идея

Ruby-реализация показывает ясность алгоритмов: структуры гита перестают быть пугающими.

Класс Commit на Ruby:

Rubyclass Commit
  attr_reader :tree, :parent, :message
  def initialize(tree:, parent:, message:)
    @tree, @parent, @message = tree, parent, message
  end
end

Почему это важно

Пересборка git на втором языке закрепляет модель: вы поймёте git на уровне, который не даёт ни одна шпаргалка.

О чём это

Известная серия обучает Redis на Go: клиент-сервер, парсинг RESP, хранение строк, итерации и таймеры — сетевое хранилище обычной сложностью.

Что вы узнаете

  • Перефразировка клиента и сервера
  • RESP и протокол
  • Строки и карты
  • Next steps: AOF и репликация

Основная идея

Урок проходит полный контур: сервер принимает команды, договаривается по RESP, хранит данные в памяти. Код чист и короток.

Команда GET в мини-Redis:

Gocase "GET":
    val, ok := store[key]
    if !ok { write(s, "$-1\r\n") } else { write(s, "$%d\r\n%s\r\n", len(val), val) }

Почему это важно

Go + Redis — мощная пара для изучения сетевых хранилищ: вы разберёте протокол и поймёте, почему in-memory базы такие быстрые.

Что вы узнаете

Основная идея

Redis на Python — это 100 строк: сервер принимает команды, операционная память — хранилище. Легко прочитать, легко расширить.

Обработчик команды в Python:

Pythondef handle(cmd, args):
    if cmd == b"get":
        return store.get(args[0], b"")
    if cmd == b"set":
        store[args[0]] = args[1]; return b"OK"

Почему это важно

Компактный Redis-на-Python — идеальная отправная точка для изучения сетевых баз: вы поймёте и сервер, и клиента.

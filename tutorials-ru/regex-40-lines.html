Введение

Несколько дней назад я наткнулся на статью, в которой Роб Пайк реализует начальный движок регулярных выражений на C. Я перевёл его код на JavaScript и добавил тестовую спецификацию, чтобы любой мог провести себя по созданию regex-движка. Спецификация и решение доступны в этом репозитории GitHub. Этот пост — путеводитель по моему решению.

Задача

Наш regex-движок поддерживает следующий синтаксис:

Синтаксиссинтаксис  значение                       пример   сопоставляется с
a          конкретный литеральный символ  q        q
*          ноль и более предыдущего       a*       "", a, aa, aaa
?          ноль или один предыдущего      a?       "", a
.          любой символ                   .        a, b, c, d, e ...
^          начало строки                  ^c       c, ca, caa, cbb ...
$          конец строки                   a$       ba, baaa, qwerta ...

Цель — дать надёжный синтаксис, покрывающий большую часть случаев использования regex минимальным кодом.

Сопоставление одного символа

Первый шаг — функция, принимающая односимвольный шаблон и односимвольный текст и возвращающая булево значение: сопоставляются ли они. Шаблон . считается джокером и сопоставляется с любым символом.

Несколько примеров:

jsmatchOne('a', 'a') -> true
matchOne('.', 'z') -> true
matchOne('', 'h') -> true
matchOne('a', 'b') -> false
matchOne('p', '') -> false
jsfunction matchOne(pattern, text) {
  if (!pattern) return true; // любой текст сопоставляется с пустым шаблоном
  if (!text) return false; // если шаблон задан, а текст пуст, сопоставление невозможно
  if (pattern === ".") return true; // любой входной текст сопоставляется с джокером
  return pattern === text;
}

Сопоставление строк одинаковой длины

Теперь добавим поддержку более длинных шаблонов и текстов. Пока рассмотрим только пары шаблон/текст одинаковой длины. Я знаю, что решение напрашивается на рекурсию, поэтому используем рекурсию. Хотим многократно вызывать matchOne на последовательных парах символов из комбинации шаблон/текст.

jsfunction match(pattern, text) {
  if (pattern === "") return true;
  // базовый случай - если шаблон пуст, любой входной текст сопоставляется
  else
    return (
      matchOne(pattern[0], text[0]) && match(pattern.slice(1), text.slice(1))
    );
}

Код выше идёт посимвольно по парам шаблон/текст. Сначала сравнивает pattern[0] с text[0], затем pattern[1] с text[1] и так до i === pattern.length - 1. Если в любой точке они не сопоставились, знаем, что шаблон не может сопоставиться с текстом.

Приведём пример. Предположим, вызываем match('a.c', 'abc'), что превращается в matchOne('a', 'a') && match('.c', 'bc'). Продолжая вычислять эти функции, приходим к matchOne('a', 'a') && matchOne('.', 'b') && matchOne('c', 'c') && match("", ""), что равно true && true && true && true. Сопоставление есть!

Символ $

Добавим поддержку специального символа шаблона $, позволяющего сопоставлять конец строки. Решение сводится к добавлению базового случая в функцию match:

jsfunction match(pattern, text) {
  if (pattern === "") return true;
  if (pattern === "$" && text === "") return true;
  else
    return (
      matchOne(pattern[0], text[0]) && match(pattern.slice(1), text.slice(1))
    );
}

Символ ^

Добавим поддержку специального символа шаблона ^, позволяющего сопоставлять начало строки. Введём новую функцию search:

jsfunction search(pattern, text) {
  if (pattern[0] === "^") {
    return match(pattern.slice(1), text);
  }
}

Эта функция станет новой точкой входа нашего кода. До сих пор мы сопоставляли только шаблоны, начинающиеся с начала текста. Теперь делаем это явным, требуя префикс ^. А как же шаблоны, встречающиеся в любом месте текста?

Сопоставления, начинающиеся с любого места

Сейчас следующие случаи возвращают true:

jssearch("^abc", "abc")
search("^abcd", "abcd")

Но search("bc", "abcd") возвращает undefined. Хотим, чтобы возвращалось true.

Если пользователь не указал, что шаблон сопоставляется с началом текста, хотим искать шаблон в любой возможной стартовой точке внутри текста. Если шаблон не начинается с ^, переходим к этому поведению по умолчанию:

jsfunction search(pattern, text) {
  if (pattern[0] === "^") {
    return match(pattern.slice(1), text);
  } else {
    // Этот код выполняет match(pattern, text.slice(index)) на каждом индексе текста.
    // То есть пробуем шаблон в каждой стартовой точке текста.
    return text.split("").some((_, index) => {
      return match(pattern, text.slice(index));
    });
  }
}

Символ ?

Хотим сопоставлять ноль или один символ перед ?.

Несколько примеров:

jssearch("ab?c", "ac") -> true
search("ab?c", "abc") -> true
search("a?b?c?", "abc") -> true
search("a?b?c?", "") -> true

Первый шаг — изменить match, чтобы распознавать присутствие символа ? и передавать работу функции matchQuestion, которую определим дальше:

jsfunction match(pattern, text) {
  if (pattern === "") {
    return true;
  } else if (pattern === "$" && text === "") {
    return true;
    // обратите внимание: смотрим на pattern[1], а не pattern[0].
    // pattern[0] - символ, который должен сопоставляться ноль или один раз.
  } else if (pattern[1] === "?") {
    return matchQuestion(pattern, text);
  } else {
    return (
      matchOne(pattern[0], text[0]) && match(pattern.slice(1), text.slice(1))
    );
  }
}

matchQuestion должен обрабатывать два случая:

  • Символ перед ? не сопоставляется, но текст сопоставляется с остатком шаблона (всем, что после ?).
  • Символ перед ? сопоставляется, и остаток текста (минус один сопоставленный символ) сопоставляется с остатком шаблона.

Если любой из этих случаев truthy, matchQuestion может вернуть true.

Рассмотрим первый случай. Как проверить, что текст сопоставляется со всем шаблоном, кроме синтаксиса _?? Иными словами, как проверить, что символ перед ? появился ноль раз? Отрезаем два символа от шаблона (первый — символ перед ?, второй — сам ?) и вызываем функцию match:

jsfunction matchQuestion(pattern, text) {
  return match(pattern.slice(2), text);
}

Второй случай чуть сложнее, но, как и раньше, переиспользует уже написанные функции:

jsfunction matchQuestion(pattern, text) {
  if (matchOne(pattern[0], text[0]) && match(pattern.slice(2), text.slice(1))) {
    return true;
  } else {
    return match(pattern.slice(2), text);
  }
}

Если text[0] сопоставляется с pattern[0] и остаток текста (минус часть, сопоставленная matchOne) сопоставляется с остатком шаблона — мы успешны. Можно переписать код так:

jsfunction matchQuestion(pattern, text) {
  return (
    (matchOne(pattern[0], text[0]) && match(pattern.slice(2), text.slice(1))) ||
    match(pattern.slice(2), text)
  );
}

Что мне нравится во втором подходе — булев OR явно показывает: есть два случая, каждый из которых может быть истинным.

Символ *

Хотим сопоставлять символ перед * ноль или более раз.

Всё это должно возвращать true:

jssearch("a*", "")
search("a*", "aaaaaaa")
search("a*b", "aaaaaaab")

Как и при поддержке ?, передаём работу функции matchStar из match:

jsfunction match(pattern, text) {
  if (pattern === "") {
    return true;
  } else if (pattern === "$" && text === "") {
    return true;
  } else if (pattern[1] === "?") {
    return matchQuestion(pattern, text);
  } else if (pattern[1] === "*") {
    return matchStar(pattern, text);
  } else {
    return (
      matchOne(pattern[0], text[0]) && match(pattern.slice(1), text.slice(1))
    );
  }
}

matchStar, как и matchQuestion, должен обрабатывать два случая:

  • Символ перед * не сопоставляется, но текст сопоставляется с остатком шаблона (всем, что после *).
  • Символ перед * сопоставляется один или более раз, и остаток текста сопоставляется с остатком шаблона.

Поскольку есть два случая, оба ведущих к сопоставлению, знаем, что matchStar можно реализовать булевым OR. Более того, случай 1 для matchStar — в точности случай 1 для matchQuestion, и его можно реализовать одинаково: match(pattern.slice(2), text). Значит, остаётся построить выражение, удовлетворяющее случаю 2:

jsfunction matchStar(pattern, text) {
  return (
    (matchOne(pattern[0], text[0]) && match(pattern, text.slice(1))) ||
    match(pattern.slice(2), text)
  );
}

Рефакторинг

Теперь можно вернуться и умно упростить search трюком, которому я научился у Питера Норвига:

jsfunction search(pattern, text) {
  if (pattern[0] === "^") {
    return match(pattern.slice(1), text);
  } else {
    return match(".*" + pattern, text);
  }
}

Используем сам символ *, чтобы позволить шаблону появляться в любом месте строки. Префикс .* говорит: любое число любых символов может стоять перед нашим шаблоном.

Заключение

Удивительно, насколько прост и элегантен код такой обобщённой и сложной программы. Полный исходник доступен в этом репозитории GitHub. (Автор также написал продолжение о fuzz-тестировании этого движка.)

Сноска: в коде намеренно оставлен маленький баг: не покрыт случай пустой строки в search. Когда text === '', text.split("") возвращает пустой массив и match корректно не вызывается.

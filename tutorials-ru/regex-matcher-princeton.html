Основная идея

Сопоставитель превращает regex в недетерминированный автомат и проходит по нему. Этот урок из Кернигана и Пайка — легенда.

Сопоставление звёздочки (Kleene star):

Cint matchstar(int c, char *re, char *text) {
    do { if (matchhere(re, text)) return 1; }
    while (*text != '\0' && (*text++ == c || c == '.'));
    return 0;
}

Почему это важно

Регекспы — компиляция автоматов: этот классический урок остаётся образцом краткости и глубины.

Основная идея

Scala-версия строит регекспы на комбинаторах: маленькие парсеры собираются в мощное сопоставление.

Тип regex-выражения на Scala:

Scalasealed trait Re
case class Lit(c: Char) extends Re
case class Star(r: Re) extends Re
case class Alt(a: Re, b: Re) extends Re
case class Seq(a: Re, b: Re) extends Re

Почему это важно

«Без магии» — девиз урока: тип-система Scala сделает структуру регекспов очевидной.

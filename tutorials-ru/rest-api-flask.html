О чём это

Практическое руководство по созданию REST API: вы реализуете ресурсы, методы GET/POST/PUT/DELETE, сериализацию в JSON и обработку ошибок на Flask, поняв, как проектируются современные бэкенд-сервисы.

Что вы узнаете

  • Принципы REST: ресурсы и их идентификация по URL
  • Реализация CRUD-операций над ресурсом
  • Сериализация данных в JSON и обратно
  • Корректные статус-коды для успехов и ошибок

Основная идея

REST-контракт прост: каждой сущности — ресурс с URL, а действиям над ней соответствуют HTTP-методы. Flask позволяет буквально за несколько строк построить такой интерфейс.

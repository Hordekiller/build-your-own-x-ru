О чём это

Серия уроков на Java создает программный рендерер: модели, камеры, проецирование, заливка граней и затенение — полноценный CAD-подобный просмотр 3D-объектов своими руками.

Что вы узнаете

  • Загрузка простых 3D-моделей
  • Камера и проект граней на экран
  • Заливка и освещение граней
  • Вращение и орбита камеры

Основная идея

Рендеринг на Java — линейно, без чудес: каждая грань — три вершины, каждая вершина проходит через матрицы и попадает на экран. Проекция и заливка — весь секрет.

Проверка видимости грани (backface culling):

Java// Грань направлена к камере? Считаем знак нормали
Vector3 n = face.normal();
if (n.dot(cameraDirection) > 0) drawFace(face);

Почему это важно

Восторг от первой 3D-модели на собственном рендерере не забывается: уроки дадут вам инструмент, с которым можно экспериментировать бесконечно.

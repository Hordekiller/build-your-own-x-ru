О чём это

Серия уроков по созданию CLI на Rust: парсинг аргументов, файловые операции, error handling и цветной вывод — практическое введение в системные утилиты.

Что вы узнаете

  • Основы Rust CLI
  • Работа с файлами
  • Обработка ошибок
  • Цвета и тесты

Основная идея

Серия наращивает навыки от «hello» к утилите: аргументы, чтение файлов, ошибки, стиль. Каждая глава — готовый кусок production-кода.

Простой парсер аргументов:

Rustlet args: Vec<String> = env::args().collect();
match args.get(1).map(String::as_str) {
    Some("list") => list_files(),
    _ => print_usage()
}

О чём это

Известная серия Savjee строит блокчейн на JavaScript: интересные объяснения PoW, транзакций и подписей, с панелью визуализации и минёром прямо в браузере.

Что вы узнаете

  • Простая цепочка с PoW
  • Транзакции и подписи
  • Визуальная панель майнинга
  • Эксперименты с взломом цепочки

Основная идея

SavjeeCoin сделан, чтобы играть: вы можете майнить блоки кнопкой, менять данные и видеть, как цепочка «ломается». Понимание рождается из опытов.

Проверка целостности в SavjeeCoin:

JavaScriptfor (let i = 1; i < this.chain.length; i++) {
  const current = this.chain[i];
  if (current.hash !== this.computeHash(current)) return false;
  if (current.previousHash !== this.chain[i - 1].hash) return false;
}

Почему это важно

Интерактивность — лучший учитель технологии: эксперименты с цепочкой оставят вас с интуицией, которую не даст никакая лекция.

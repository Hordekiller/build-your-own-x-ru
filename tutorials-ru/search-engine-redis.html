О чём это

Поиск на Redis: индексация, наборы и полнотекст — быстрый мини-поиск на in-memory структурах.

Что вы узнаете

  • Инвертированный индекс в Redis
  • Команды SET и SINTER
  • Ранжирование по частоте
  • Поиск по подстроке

Основная идея

Redis идеален для индексов: термы — ключи, документы — множества, пересечение — SINTER. Поиск становится набором операций.

Пересечение множеств по термам запроса:

Pythonkeys = [f"term:{w}" for w in query.split()]
docs = r.sinter(*keys)  # документы со всеми словами

Почему это важно

Перенос индекса в Redis — та самая «взрослая» архитектура: урок соединит поиск и in-memory базы.

TF-IDF: поиск по частоте термов

Зачем нужен TF-IDF?

Когда у вас есть текст и вы хотите понять, «о чём этот текст», простого подсчёта слов недостаточно: частые слова вроде «the» и «and» выходят в топ, но не несут никакой информации. TF-IDF (частота слова в документе × обратная частота документа) — это способ измерить «важность» слова в документе относительно набора документов: слово, которое часто встречается в одном документе, но редко в остальных, является признаком темы этого документа. Стивен Лориа в этом коротком уроке реализует данную метрику примерно в 14 строк Python и демонстрирует её на реальных примерах.

Определения: tf и idf

  • TF (Term Frequency): сколько раз слово встретилось в документе. Иногда нормализуется, но в этой простой реализации — просто сырое количество.
  • IDF (Inverse Document Frequency): обратная величина «какой процент всех документов содержит это слово». Логарифм обратного отношения числа документов со словом к общему числу документов; слово, которое есть во всех документах → idf≈0, редкое слово → большое idf.
  • TF-IDF: произведение этих двух величин — число, которое учитывает и частоту слова в документе, и его редкость в наборе документов.
pythonfrom math import log
from collections import Counter

def tf(word, doc):
    """Частота слова в документе = число вхождений, делённое на общее число слов"""
    counts = Counter(doc.split())
    return counts[word] / len(doc.split())

def idf(word, docs):
    """Обратная частота документа: логарифм (все документы / документы со словом) — просто, без сглаживания"""
    n_docs_with = sum(1 for d in docs if word in d.split())
    if n_docs_with == 0:
        return 0.0
    return log(len(docs) / n_docs_with)

def tfidf(word, doc, docs):
    """Итоговая оценка: повторяемость в документе × редкость во всём наборе"""
    return tf(word, doc) * idf(word, docs)

Функция idf в статье имеет необязательный параметр default (начальное число для log, которое можно настроить по желанию), чтобы поведение было определённым, когда слово не встречается ни в одном документе.

Полная реализация и пример

В статье с помощью TextBlob 0.6.1 (Python-библиотека для обработки текста) создаётся демонстрационный набор: несколько коротких документов, у каждого своя тема (например, один про биткойн, один про химию/книги и т.д.), после чего вычисляются и сортируются оценки TF-IDF всех слов, чтобы определить «важные слова» каждого документа. Полный код шаг за шагом:

pythonimport math
import numpy as np
from textblob import TextBlob
from collections import Counter

# 1) Создание набора текстовых документов (обучающие тексты по каждой теме)
doc1 = "The bitcoin blockchain is a distributed ledger that records every transaction..."
doc2 = "Chemistry is the scientific study of the properties and behavior of matter..."
doc3 = "Reading books helps you learn new things and improves your vocabulary..."
docs = [doc1, doc2, doc3]

# 2) Через TextBlob получаем нормализованные слова (без стемминга)
def get_tokens(doc):
    blob = TextBlob(doc)
    return [token.singularize().lower() for token in blob.words]

tokenized = [get_tokens(d) for d in docs]

# 3) TF-IDF каждого слова для каждого документа
def tf_idf(word, doc_index):
    tokens = tokenized[doc_index]
    tf = tokens.count(word) / float(len(tokens))
    n_docs_with = sum(1 for t in tokenized if word in t)
    idf = math.log(len(docs) / float(n_docs_with))
    return tf * idf

# 4) Важные слова каждого документа: оценка и сортировка по убыванию
for i, tokens in enumerate(tokenized):
    uniques = Counter(tokens)
    ranked = sorted(uniques, key=lambda w: tf_idf(w, i), reverse=True)
    print("Самые важные слова документа", i + 1, ":", ranked[:5])
Смысл кода выше: суть урока — не только математика; важна комбинация: нормализация слов с TextBlob (приведение к единственному числу и нижнему регистру), подсчёт, вычисление tf и idf и, наконец, «сортировка слов каждого документа по оценке TF-IDF» для поиска представителей темы. Вывод примера из статьи в точности показывает, что слова «блокчейн», «химия» и «книга» получают в своих документах самые высокие оценки.

Почему это важно?

  • Извлечение темы/ключевых слов: самый быстрый способ понять, «о чём этот набор текстов», не читая его целиком.
  • Основа поиска: TF-IDF — сердце многих классических поисковых движков (вы это уже видели в уроках «Векторное пространство» и «Поиск с Redis» из этого же раздела).
  • Взвешивание при анализе текста: перед сложными алгоритмами ML превращение документа в TF-IDF-вектор часто бывает достаточно и эффективно.

Итоги

Меньше чем в двадцати строках кода вы научились превращать текст в «оценки важности слов» — инструмент, применимый в поиске, суммаризации и классификации текста. Предложенный следующий шаг: соединить эти оценки с «векторным пространством» и «обратной связью пользователя», чтобы построить настоящий поисковый движок.

Введение: поиск как геометрия

В серии статей Бойтера цель — строить настоящие поисковые движки с нуля и понимать их. Эта часть посвящена модели векторного пространства (Vector Space Model): мы представляем каждый документ как вектор в пространстве «слов», запрос пользователя — тоже вектор, а «релевантность» означает угловую близость этих двух векторов — она измеряется косинусным сходством (cosine similarity). Простыми словами: похожие документы тянутся из начала координат в близких направлениях.

Главная идея: вместо поиска «слово за словом» мы превращаем текст в геометрические координаты и вычисляем «похожесть» через угол между векторами — модель, лежащая в основе большинства классических движков.

Строим словарь: функция concordance

Первый шаг — построение словаря (vocabulary): функция читает содержимое всех файлов папки, разбивает их на слова и строит отображение «слово → номер». Этот номер и есть «размерность» вектора — позже для каждого документа строится вектор с этими же размерностями. Бойтер называет эту функцию concordance():

pythonimport os, re

def concordance(path):
    """Чтение всех файлов папки и построение словаря (слово → номер)"""
    words = {}
    for f in os.listdir(path):
        text = open(os.path.join(path, f), 'r').read().lower()
        for word in re.findall(r'\w+', text):
            words.setdefault(word, len(words))   # каждое новое слово — новая размерность
    return words

Вектор каждого документа: подсчёт слов

Теперь для каждого файла строим вектор, у которого в размерности, соответствующей слову, стоит количество вхождений этого слова в файл. Получается «матрица документ×слово»: интенсивность присутствия каждого слова в каждом документе. Бойтер показывает полный код этого шага поэтапно (повторное чтение файлов, подсчёт через счётчик и заполнение векторов) — обратите внимание, что на этот раз используется построенный словарь, чтобы все векторы были «одинаковой размерности».

pythondef build_vectors(path, concord):
    """Для каждого файла построить вектор подсчёта слов"""
    vectors = {}
    files = os.listdir(path)
    for f in files:
        counts = {}
        text = open(os.path.join(path, f), 'r').read().lower()
        for word in re.findall(r'\w+', text):
            counts[word] = counts.get(word, 0) + 1
        vec = [0] * len(concord)
        for word, count in counts.items():
            vec[concord[word]] = count
        vectors[f] = vec
    return vectors

Ранжирование по косинусному расстоянию

Кульминация урока: функция, вычисляющая «косинусное сходство» двух векторов — скалярное произведение векторов, делённое на произведение их норм:

pythonfrom math import sqrt, acos

def dot(vec_a, vec_b):
    return sum(a * b for a, b in zip(vec_a, vec_b))

def norm(vec):
    return sqrt(sum(x * x for x in vec))

def cosine_similarity(vec_a, vec_b):
    """Косинусное сходство: 1 — сонаправленные (очень похожие), 0 — несвязанные"""
    if norm(vec_a) == 0 or norm(vec_b) == 0:
        return 0.0
    return dot(vec_a, vec_b) / (norm(vec_a) * norm(vec_b))

def cosine_distance(vec_a, vec_b):
    """Косинусное расстояние = 1 - сходство; меньшее число значит больше релевантности"""
    return 1.0 - cosine_similarity(vec_a, vec_b)

Затем для запроса: сначала строится вектор запроса (в том же пространстве, с тем же словарём), потом вычисляется косинусное расстояние до вектора каждого документа, и результаты сортируются по этому расстоянию — документ с наименьшим расстоянием (наибольшим сходством) получает первое место.

Улучшенный алгоритм: IDF против незначащих слов

У простой первой версии есть известная проблема: частые бессмысленные слова («the», «and», «of») сближают векторы и затеняют редкие ключевые слова. Решение, которое Бойтер называет «улучшенным алгоритмом», — применение веса IDF: слово, присутствующее во всех файлах, несёт мало информации, и его вес снижается; слово, встречающееся лишь в нескольких файлах, — «признак», и его вес растёт. В доработанном коде перед вычислением сходства каждый элемент вектора умножается на IDF соответствующего слова; практический эффект — значимые результаты выходят в вершину ранжирования.

pythonimport math

def calculate_idf(vectors, concord):
    """Вес каждого слова: логарифм отношения числа документов со словом к общему числу документов (обратно)"""
    n = len(vectors)
    idf = {}
    for word, idx in concord.items():
        docs_having = sum(1 for v in vectors.values() if v[idx] > 0)
        idf[word] = math.log(n / docs_having)
    return idf

def apply_idf(vectors, idf, concord):
    """Умножение векторов на IDF — частые слова бледнеют, редкие выделяются"""
    result = {}
    for fname, vec in vectors.items():
        result[fname] = [vec[i] * idf[word] for word, i in concord.items()]
    return result
Почему «векторное пространство»? Потому что каждое слово — это «ось», а каждый документ — точка/вектор в этом пространстве. Документы можно сравнивать как геометрию — именно на этом десятилетиями строятся классические поисковые движки (например, Lucene).

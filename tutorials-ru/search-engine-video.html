Об этом видео

В этой лекции шаг за шагом строится поисковый движок на Python, и по ходу дела раскрываются проектные решения и структуры данных, стоящие за сценой. Основные темы, которые проходятся в видео:

  • Построение инвертированного индекса словарём Python: каждое слово (или n-грамма) сопоставляется со списком позиций, и каждая позиция содержит идентификатор документа (doc id) и позицию слова в тексте — этой тройки достаточно для поиска и ранжирования.
  • n-граммы от 3 до 6: хранение многокомпонентных последовательностей позволяет искать составные фразы и сопротивляться слишком общим словам.
  • Поиск по индексу вместо сканирования документов: запрос обращается к записи словаря, комбинирует списки позиций и сортирует результаты с помощью простой оценки.

Это видео — лучшая отправная точка для тех, кто хочет своими глазами увидеть «мозг» поискового движка — без сложностей распределённых систем. Если после просмотра захочется письменной практики, отличными дополнениями из этого же раздела будут «TF-IDF» и «Векторное индексирование».

Python# Инвертированный индекс: каждое слово → список (id документа, позиция)
index = {}
for doc_id, words in enumerate(documents):
    for pos, word in enumerate(words):
        index.setdefault(word, []).append((doc_id, pos))

def search(query):
    return index.get(query, [])   # поиск прямо по индексу, без сканирования документов

Это та самая структура данных, которую строит видео; n-граммы — это просто многокомпонентные «слова» с таким же отображением.

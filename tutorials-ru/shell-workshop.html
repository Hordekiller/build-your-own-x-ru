О чём это

Интерактивный воркшоп по шеллу на C: парсинг, пайпы, фоновые задачи и сигналы — практика системного программирования.

Что вы узнаете

  • Парсер команд
  • Трубы и дескрипторы
  • Сигналы и завершение
  • Управление задачами

Основная идея

Воркшоп — лаборатория: вы собираете шелл порциями и проверяете его на реальных командах. Каждая часть — учебный вызов.

Создание пайпа между командами:

Cint fds[2];
pipe(fds);
if (fork() == 0) {
    dup2(fds[1], STDOUT_FILENO); // левая команда пишет в трубу
} else {
    dup2(fds[0], STDIN_FILENO);  // правая читает из трубы
}

Почему это важно

Терминал и шелл — основа программного мира: воркшоп превратит их в конструктор, который вы умеете менять.

Введение: как «представить» лицо?

Распознавание лиц — биометрическое решение, которое измеряет уникальные черты лица. Главный вопрос: как представить лицо в численном, сопоставимом виде? Предыстория: в 1960-м Вудроу Бледсо (Woodrow Bledsoe) размечал координаты выдающихся черт лица (линия волос, глаза, нос). Затем, в 2015-м, исследователи Google опубликовали статью о FaceNet: свёрточная нейросеть (CNN), которая вместо ручного извлечения признаков напрямую работает с пикселями изображения и достигла рекордной точности 99,63% на датасете LFW.

Ключевой приём FaceNet: представление лица как эмбеддинга — вектора из 128 измерений. Поскольку эти векторы лежат в общем векторном пространстве, векторное расстояние становится мерой схожести двух лиц; эти эмбеддинги служат входом для задач классификации, кластеризации или регрессии. Функция потерь FaceNet — «triplet loss»: минимизация расстояния до положительных примеров (той же личности) и максимизация расстояния до отрицательных — то есть лица одного человека должны быть ближе друг к другу, чем лица разных людей.

Инструменты: Docker, TensorFlow, Dlib и OpenCV

Установка TensorFlow, OpenCV и особенно Dlib (который даёт обнаружение и выравнивание лиц) доставляет хлопоты; поэтому автор ставит всё внутрь Docker, получая согласованную и кросс-платформенную среду. Структура проекта:

text├── Dockerfile
├── etc/20170511-185253/20170511-185253.pb     # предобученные веса модели
├── data/                                      # датасет LFW
└── medium_facenet_tutorial/
    ├── align_dlib.py                          # инструменты выравнивания Dlib
    ├── preprocess.py                          # предобработка (детекция+кадрирование+выравнивание)
    ├── download_and_extract_model.py
    ├── lfw_input.py                           # параллельная загрузка изображений
    ├── train_classifier.py                    # обучение SVM
    └── shape_predictor_68_face_landmarks.dat  # модель ключевых точек лица

Обучающий датасет: LFW (Labeled Faces in the Wild) — 177 МБ, для каждого человека своя папка с несколькими изображениями (например, Tyra_Banks_0001.jpg). Эту структуру папок можно заменить собственным датасетом.

Предобработка: обнаружение, кадрирование и выравнивание с Dlib

Предобработка решает две задачи: сегментацию и выравнивание. Сначала через align_dlib.py находится самое крупное лицо на изображении (поэтому данные не обязаны быть заранее обрезанными). Затем, поскольку лицо обычно не строго по центру кадра, изображение выравнивается по модели ключевых точек (shape_predictor_68_face_landmarks.dat) относительно положения внутренних уголков глаз и нижней губы, чтобы все входы стали стандартизированными (освещение, затенение и разница фона — частые проблемы, с которыми помогает эта стандартизация):

bash$ docker run -v $PWD:/medium-facenet-tutorial   -e PYTHONPATH=$PYTHONPATH:/medium-facenet-tutorial   -it colemurray/medium-facenet-tutorial   python3 medium_facenet_tutorial/preprocess.py   --input-dir data --output-dir output/intermediate --crop-dim 180

Скрипт читает каждое изображение, находит самое крупное лицо, выравнивает его и пишет результат; если лицо не найдено, имя файла попадает в лог. Скрипт поддерживает параллелизацию, поэтому на нескольких ядрах работает быстрее.

Создание эмбеддингов с TensorFlow

Выбранная нейросеть — Inception Resnet V1 (та же архитектура FaceNet). Скачиваются предобученные веса (модель 20170511-185253.pb). Затем через Queue API TensorFlow предобработанные изображения загружаются параллельно (в несколько потоков) — на GPU это значит, что предобработка идёт на CPU, а перемножение матриц на GPU, без простоев. На выходе — вектор из 128 измерений для каждого лица.

Обучение классификатора SVM

Теперь эмбеддинги используются как «признаки» для машины опорных векторов (SVM) из scikit-learn, которая обучается на каждую личность. Личности с меньше чем 10 изображениями отбрасываются (параметр, настраиваемый из командной строки):

bash$ docker run -v $PWD:/medium-facenet-tutorial   -e PYTHONPATH=$PYTHONPATH:/medium-facenet-tutorial   -it colemurray/medium-facenet-tutorial   python3 medium_facenet_tutorial/train_classifier.py   --input-dir output/intermediate   --model-path etc/20170511-185253/20170511-185253.pb   --classifier-path output/classifier.pkl   --num-threads 16 --num-epochs 25   --min-num-images-per-class 10 --is-train
# ~16 минут на MacBook Pro

Для оценки та же команда запускается без --is-train, чтобы делать предсказания на невиденных изображениях; автор с пятью эпохами достигает точности 85%.

Итоги и уроки

  • Современный пайплайн распознавания лиц: детекция + выравнивание через Dlib → эмбеддинг глубокой сетью → классификация SVM. Каждый этап — отдельная задача со своим лучшим инструментом.
  • Эмбеддинги вместо прямой классификации: 128-мерный вектор FaceNet пригоден для любой последующей задачи (классификация, кластеризация, регрессия, поиск по сходству).
  • Управление средой через Docker: воспроизводимость в машинном обучении начинается с середины пути — контейнеризируйте капризные зависимости вроде dlib.
  • Предобработка важнее модели: выравнивание лица до подачи в модель влияет сильнее, чем усложнение сети.
Дополнительное замечание: уже в те годы эта архитектура (Dlib + FaceNet-подобные эмбеддинги + SVM) стала стандартом для таких инструментов, как face_recognition; в современных приложениях распознавание лиц в диком виде (переменные углы и свет) заменяется более сильными моделями, но логика пайплайна та же.

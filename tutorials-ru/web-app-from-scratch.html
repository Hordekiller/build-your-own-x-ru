Веб-приложение с нуля — 1-я часть

Введение

Это первый пост из серии, в которой мы пройдём процесс построения веб-приложения (и его веб-сервера) с нуля на Python. Для этой серии мы полагаемся только на стандартную библиотеку Python и игнорируем стандарт WSGI.

Без лишних предисловий, начнём!

Веб-сервер

Для начала мы напишем HTTP-сервер, который будет питать наше веб-приложение. Но сначала потратим немного времени и посмотрим, как работает протокол HTTP.

Как работает HTTP

Простыми словами, HTTP-клиенты в сети подключаются к HTTP-серверам и отправляют строку данных, представляющую запрос. Сервер интерпретирует запрос и отправляет клиенту ответ. Весь протокол и форматы запросов и ответов описаны в RFC2616.

Формат запроса

Запросы представлены набором строк, разделённых \r\n, первая из которых называется «строкой запроса». Строка запроса состоит из HTTP-метода, затем пробела, затем пути запрошенного файла, затем ещё одного пробела, затем версии протокола HTTP, на котором говорит клиент, и наконец символа возврата каретки (\r) и перевода строки (\n):

HTTPGET /some-path HTTP/1.1\r\n

После строки запроса идёт ноль или более строк заголовков. Каждая строка заголовка состоит из имени заголовка, затем двоеточия, затем необязательного значения и затем \r\n:

HTTPHost: example.com\r\n
Accept: text/html\r\n

Конец раздела заголовков объявляется пустой строкой: \r\n. Наконец, запрос может иметь «тело» — дополнительную нагрузку, отправляемую вместе с запросом на сервер.

Собрав всё вместе, простой GET-запрос:

HTTPGET / HTTP/1.1\r\n
Host: example.com\r\n
Accept: text/html\r\n
\r\n

и простой POST-запрос с телом:

HTTPPOST / HTTP/1.1\r\n
Host: example.com\r\n
Accept: application/json\r\n
Content-type: application/json\r\n
Content-length: 2\r\n
\r\n
{}

Формат ответа

Ответы, как и запросы, состоят из набора строк, разделённых \r\n. Первая строка ответа называется «строкой состояния» и состоит из версии протокола HTTP, пробела, кода состояния ответа, ещё одного пробела, причины кода состояния и затем \r\n:

HTTPHTTP/1.1 200 OK\r\n

После строки состояния идут заголовки ответа, затем пустая строка и затем необязательное тело ответа:

HTTPHTTP/1.1 200 OK\r\n
Content-type: text/html\r\n
Content-length: 15\r\n
\r\n
<h1>Hello!</h1>

Простой сервер

Исходя из того, что мы знаем о протоколе, напишем сервер, который независимо от входящего запроса отправляет один и тот же ответ.

Для начала нужно создать сокет, сделать bind на адрес, а затем начать слушать соединения:

pythonimport socket

HOST = "127.0.0.1"
PORT = 9000

# По умолчанию socket.socket создаёт TCP-сокет.
with socket.socket() as server_sock:
    # Это говорит ядру переиспользовать сокеты, находящиеся в состоянии TIME_WAIT.
    server_sock.setsockopt(socket.SOL_SOCKET, socket.SO_REUSEADDR, 1)

    # Это говорит сокету, на какой адрес делать bind.
    server_sock.bind((HOST, PORT))

    # 0 — количество ожидающих соединений, которые сокет может иметь перед
    # отклонением новых соединений. Поскольку этот сервер будет обрабатывать
    # по одному соединению за раз, мы хотим, чтобы лишние соединения отклонялись.
    server_sock.listen(0)
    print(f"Listening on {HOST}:{PORT}...")

Если запустить этот код сейчас, он напечатает прослушивание на 127.0.0.1:9000 и затем выйдет. Для реальной обработки входящих соединений нужно вызвать метод accept на нашем сокете. Это заблокирует процесс, пока клиент не подключится к серверу:

pythonwith socket.socket() as server_sock:
    server_sock.setsockopt(socket.SOL_SOCKET, socket.SO_REUSEADDR, 1)
    server_sock.bind((HOST, PORT))
    server_sock.listen(0)
    print(f"Listening on {HOST}:{PORT}...")

    client_sock, client_addr = server_sock.accept()
    print(f"New connection from {client_addr}.")

Получив сокетное соединение с клиентом, мы можем с ним общаться. С помощью метода sendall отправим пример ответа подключившемуся клиенту:

pythonRESPONSE = b"""\
HTTP/1.1 200 OK
Content-type: text/html
Content-length: 15

<h1>Hello!</h1>""".replace(b"\n", b"\r\n")

with socket.socket() as server_sock:
    server_sock.setsockopt(socket.SOL_SOCKET, socket.SO_REUSEADDR, 1)
    server_sock.bind((HOST, PORT))
    server_sock.listen(0)
    print(f"Listening on {HOST}:{PORT}...")

    client_sock, client_addr = server_sock.accept()
    print(f"New connection from {client_addr}.")
    with client_sock:
        client_sock.sendall(RESPONSE)

Если запустить код сейчас и зайти на http://127.0.0.1:9000 в любимом браузере, он должен отрендерить строку «Hello!». К сожалению, сервер выходит после отправки ответа, поэтому обновление страницы падает. Давайте это исправим:

pythonRESPONSE = b"""\
HTTP/1.1 200 OK
Content-type: text/html
Content-length: 15

<h1>Hello!</h1>""".replace(b"\n", b"\r\n")

with socket.socket() as server_sock:
    server_sock.setsockopt(socket.SOL_SOCKET, socket.SO_REUSEADDR, 1)
    server_sock.bind((HOST, PORT))
    server_sock.listen(0)
    print(f"Listening on {HOST}:{PORT}...")

    while True:
        client_sock, client_addr = server_sock.accept()
        print(f"New connection from {client_addr}.")
        with client_sock:
            client_sock.sendall(RESPONSE)

В этой точке у нас есть веб-сервер, который может раздавать простую HTML-страницу на каждый запрос — всего примерно в 25 строк кода. Неплохо!

Сервер файлов

Расширим HTTP-сервер, чтобы он мог раздавать файлы с диска.

Абстракция запроса

Прежде всего нужно прочитать и разобрать входящие данные запроса от клиента. Поскольку мы знаем, что данные запроса представлены строками, разделёнными \r\n, напишем функцию-генератор, которая читает данные из сокета и yield-ит каждую строку:

pythonimport typing


def iter_lines(sock: socket.socket, bufsize: int = 16_384) -> typing.Generator[bytes, None, bytes]:
    """Принимая сокет, читает все разделённые CRLF строки
    и yield-ит каждую, пока не встретит пустую строку. Возвращает
    остаток после пустой строки.
    """
    buff = b""
    while True:
        data = sock.recv(bufsize)
        if not data:
            return b""

        buff += data
        while True:
            try:
                i = buff.index(b"\r\n")
                line, buff = buff[:i], buff[i + 2:]
                if not line:
                    return buff

                yield line
            except IndexError:
                break

Это может выглядеть устрашающе, но вот что оно делает: читает любой объём данных, который может прочитать из сокета (кусками по bufsize), складывает их в буфер (buff) и постоянно разделяет буфер на отдельные строки, yield-я по одной каждый раз. Дойдя до пустой строки, возвращает лишние прочитанные данные.

С помощью iter_lines мы можем печатать запросы, получаемые от клиентов:

pythonwith socket.socket() as server_sock:
    server_sock.setsockopt(socket.SOL_SOCKET, socket.SO_REUSEADDR, 1)
    server_sock.bind((HOST, PORT))
    server_sock.listen(0)
    print(f"Listening on {HOST}:{PORT}...")

    while True:
        client_sock, client_addr = server_sock.accept()
        print(f"New connection from {client_addr}.")
        with client_sock:
            for request_line in iter_lines(client_sock):
                print(request_line)

            client_sock.sendall(RESPONSE)

Определяем класс Request, который пока знает только метод, пути и заголовки запроса:

pythonimport typing


class Request(typing.NamedTuple):
    method: str
    path: str
    headers: typing.Mapping[str, str]

Чтобы охватить логику построения запроса, добавляем к Request метод класса from_socket:

pythonclass Request(typing.NamedTuple):
    method: str
    path: str
    headers: typing.Mapping[str, str]

    @classmethod
    def from_socket(cls, sock: socket.socket) -> "Request":
        """Читает и разбирает запрос из объекта сокета.

        Исключения:
          ValueError: когда запрос не может быть разобран.
        """
        lines = iter_lines(sock)

        try:
            request_line = next(lines).decode("ascii")
        except StopIteration:
            raise ValueError("Request line missing.")

        try:
            method, path, _ = request_line.split(" ")
        except ValueError:
            raise ValueError(f"Malformed request line {request_line!r}.")

        headers = {}
        for line in lines:
            try:
                name, _, value = line.decode("ascii").partition(":")
                headers[name.lower()] = value.lstrip()
            except ValueError:
                raise ValueError(f"Malformed header line {line!r}.")

        return cls(method=method.upper(), path=path, headers=headers)

Запускается на подключённом сокете и печатает строки вроде этих:

ConsoleRequest(method='GET', path='/', headers={'host': 'localhost:9000', 'user-agent': 'curl/7.54.0', 'accept': '*/*'})

Поскольку from_socket в определённых ситуациях может выбрасывать исключения, сервер сейчас может упасть на недопустимом запросе. Чтобы управлять этим, оборачиваем вызов from_socket в try-except и отправляем клиенту ответ «400 Bad Request», получив плохой запрос:

pythonBAD_REQUEST_RESPONSE = b"""\
HTTP/1.1 400 Bad Request
Content-type: text/plain
Content-length: 11

Bad Request""".replace(b"\n", b"\r\n")

with socket.socket() as server_sock:
    server_sock.setsockopt(socket.SOL_SOCKET, socket.SO_REUSEADDR, 1)
    server_sock.bind((HOST, PORT))
    server_sock.listen(0)
    print(f"Listening on {HOST}:{PORT}...")

    while True:
        client_sock, client_addr = server_sock.accept()
        print(f"Received connection from {client_addr}...")
        with client_sock:
            try:
                request = Request.from_socket(client_sock)
                print(request)
                client_sock.sendall(RESPONSE)
            except Exception as e:
                print(f"Failed to parse request: {e}")
                client_sock.sendall(BAD_REQUEST_RESPONSE)

В этой точке мы готовы начать реализацию части раздачи файлов, но сначала сделаем нашим ответом по умолчанию «404 Not Found» и добавим ответ «405 Method Not Allowed» — на случай, когда приходит что-то кроме GET-запроса:

pythonNOT_FOUND_RESPONSE = b"""\
HTTP/1.1 404 Not Found
Content-type: text/plain
Content-length: 9

Not Found""".replace(b"\n", b"\r\n")

METHOD_NOT_ALLOWED_RESPONSE = b"""\
HTTP/1.1 405 Method Not Allowed
Content-type: text/plain
Content-length: 17

Method Not Allowed""".replace(b"\n", b"\r\n")

Определяем константу SERVER_ROOT, показывающую, откуда сервер раздаёт файлы, и функцию serve_file:

pythonimport mimetypes
import os
import socket
import typing

SERVER_ROOT = os.path.abspath("www")

FILE_RESPONSE_TEMPLATE = """\
HTTP/1.1 200 OK
Content-type: {content_type}
Content-length: {content_length}

""".replace("\n", "\r\n")


def serve_file(sock: socket.socket, path: str) -> None:
    """Принимая сокет и относительный путь файла (относительно
    SERVER_SOCK), отправляет файл в сокет, если он существует. Если
    файла нет, отправляет ответ «404 Not Found».
    """
    if path == "/":
        path = "/index.html"

    abspath = os.path.normpath(os.path.join(SERVER_ROOT, path.lstrip("/")))
    if not abspath.startswith(SERVER_ROOT):
        sock.sendall(NOT_FOUND_RESPONSE)
        return

    try:
        with open(abspath, "rb") as f:
            stat = os.fstat(f.fileno())
            content_type, encoding = mimetypes.guess_type(abspath)
            if content_type is None:
                content_type = "application/octet-stream"

            if encoding is not None:
                content_type += f"; charset={encoding}"

            response_headers = FILE_RESPONSE_TEMPLATE.format(
                content_type=content_type,
                content_length=stat.st_size,
            ).encode("ascii")

            sock.sendall(response_headers)
            sock.sendfile(f)
    except FileNotFoundError:
        sock.sendall(NOT_FOUND_RESPONSE)
        return

serve_file принимает сокет клиента и путь файла. Пытается преобразовать этот путь в реальный файл внутри SERVER_ROOT, и если путь резолвится за пределы корня сервера, отправляет ответ «not found». Затем пытается открыть файл, узнать его mime-тип и размер через os.fstat, построить заголовки ответа и записать файл в сокет системным вызовом sendfile. Если файла на диске нет, отправляет ответ «not found».

Цикл сервера с serve_file:

pythonwith socket.socket() as server_sock:
    server_sock.setsockopt(socket.SOL_SOCKET, socket.SO_REUSEADDR, 1)
    server_sock.bind((HOST, PORT))
    server_sock.listen(0)
    print(f"Listening on {HOST}:{PORT}...")

    while True:
        client_sock, client_addr = server_sock.accept()
        print(f"Received connection from {client_addr}...")
        with client_sock:
            try:
                request = Request.from_socket(client_sock)
                if request.method != "GET":
                    client_sock.sendall(METHOD_NOT_ALLOWED_RESPONSE)
                    continue

                serve_file(client_sock, request.path)
            except Exception as e:
                print(f"Failed to parse request: {e}")
                client_sock.sendall(BAD_REQUEST_RESPONSE)

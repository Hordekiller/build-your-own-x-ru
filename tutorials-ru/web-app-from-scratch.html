О чём это

Серия статей, в которой веб-приложение на Python создаётся полностью с нуля, без фреймворков: от разбора запросов и маршрутизации до рендеринга страниц. Вы узнаете, что прячется под капотом Django и Flask и почему фреймворки строятся именно так.

Что вы узнаете

  • Архитектура веб-приложения без фреймворка
  • Маршрутизация запросов по URL собственными силами
  • Шаблонизация и генерация HTML-страниц
  • Разделение логики: запрос, обработчик, ответ

Основная идея

За веб-фреймворками стоит одна и та же идея: получить запрос, смаршрутизировать его к функции, собрать ответ. Приложение на чистом Python повторяет этот контур вручную.

Минимальный маршрутизатор умещается в несколько строк:

PythonROUTES = {}

def route(path):
    def wrap(handler):
        ROUTES[path] = handler
        return handler
    return wrap

@route("/")
def index(request):
    return render_page("index.html")

Почему это важно

Сделав веб-приложение сами, вы перестанете воспринимать фреймворк как чёрный ящик: любой маршрут, форма или шаблон — всё это код, который вы уже видели собственными глазами.

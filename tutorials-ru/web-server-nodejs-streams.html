Напишем веб-сервер с нуля с помощью потоков NodeJS

О чём это

Урок показывает, как собрать веб-сервер на Node.js, опираясь на потоки (streams): вы научитесь принимать подключения, корректно читать входящие данные порциями и отправлять ответы через pipe, не загружая всё в память целиком.

Что вы узнаете

  • Что такое поток (stream) и чем он лучше работы со всей строкой сразу
  • Чтение тела запроса порциями через событие data
  • Отправка ответа с помощью pipe и обработка завершения
  • Борьба с переполнением памяти при больших передачах

Основная идея

Node.js создавался вокруг асинхронной модели ввода-вывода. Вместо того чтобы ждать полный запрос, вы подписываетесь на фрагменты данных и обрабатываете их по мере поступления.

Базовый контур сервера на потоках:

Node.jsconst http = require("http");

const server = http.createServer((req, res) => {
  // Читаем входящие данные порциями
  req.on("data", chunk => console.log(chunk.toString()));
  req.on("end", () => res.end("done"));
});

Почему это важно

Потоки — ключ к эффективным серверам: они позволяют обслуживать тысячи соединений и огромные объёмы данных при скромном потреблении памяти — тот же приём, что стоит внутри nginx и Express.

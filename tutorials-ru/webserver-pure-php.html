Создание веб-сервера на чистом PHP

О чём это

Статья реализует HTTP-сервер на чистом PHP без каких-либо расширений: вы открываете сокет, принимаете соединения, разбираете запрос GET и POST и возвращаете корректные HTTP-ответы, полностью отказываясь от встроенного веб-сервера PHP.

Что вы узнаете

  • Работа с сокетами: stream_socket_server, accept, чтение и запись
  • Разбор строки запроса и заголовков вручную
  • Формирование ответа с корректными заголовками
  • Обслуживание нескольких клиентов в цикле

Основная идея

PHP умеет работать с сетью на уровне сокетов точно так же, как C или Python. Сервер открывает порт, ждёт подключения и отвечает на каждый запрос, который готов сам разобрать.

Каркас сервера занимает десяток строк:

php$server = stream_socket_server("tcp://0.0.0.0:8080", $errno, $errstr);

while ($conn = stream_socket_accept($server)) {
  // Читаем запрос и отвечаем
  fclose($conn);
}

Почему это важно

Этот опыт показывает, что PHP — полноценный язык для сетевых задач, а встроенные в него серверные решения — лишь обёртки над теми же сокетами и строками ответов.

Создание веб-сервера на чистом PHP

⚙ Язык: PHP 📁 Веб-сервер 🌐 Русская страница 🔗 Оригинальный источник
Оригинальный источник: «webserver-pure-php»

Введение: да, это почти бесполезно, но возможно!

Этот учебник поможет вам лучше понять, как может работать простой веб-сервер, и что написать его на PHP — совершенно несложно. Но использовать его в продакшене — это как есть суп вилкой; так что... просто не делайте этого. Позвольте вкратце объяснить, почему это не самая лучшая идея:

PHP — это скриптовый язык, который на самом деле не создан для подобных вещей.

Веб-сервер — это долгоживущий процесс, а PHP не создан для такого. Также PHP изначально не поддерживает многопоточность (pthreads), что делает разработку хорошего и быстрого веб-сервера трудной или невозможной. Выделение памяти в PHP тоже может быть затратным, и даже при высокой скорости интерпретатора присутствуют накладные расходы интерпретатора.

Но в будущем всё может измениться. Если вы общались с программистами, вы встречали хотя бы одного, кто шутит о том, как плох PHP, и у него есть веские причины, почему PHP стал таким «промышленным анекдотом». Но язык и его экосистема сильно эволюционировали. Всё ещё есть люди, которые не видят подоплёки шуток; многие из них либо не прикасались к PHP как минимум 10 лет, либо слепо копируют чужое мнение. Готов поспорить, что таких вещей, как долгоживущие PHP-приложения со встроенными веб-серверами, будет появляться всё больше и больше.

Основы: как работает веб-сервер?

  • Сервер ожидает входящие соединения.
  • Клиент подключается к серверу.
  • Сервер принимает соединение и обрабатывает входные данные.
  • Сервер отвечает клиенту.

Весь исходный код доступен на GitHub: ClanCatsStation/PHPWebserver

Структура

Мы строим это на абстракциях Request и Response. Способов спроектировать приложение много; автор, как первый шаг, предпочитает написать часть программы, которая потребляет API, а потом уже сам API. Значит, мы ожидаем, что сможем использовать его вот так:

php// Создание экземпляра сервера
$server = new Server( '127.0.0.1', 80 );

// Начало прослушивания
$server->listen( function( Request $request ) 
{
	return new Response( 'Hello Dude' );
});

Запуск

Теперь создадим файл скрипта (server), отвечающий за запуск сервера. Расширение .php мы не добавляем, чтобы bash знал, что делать; добавьте этот заголовок:

php#!/usr/bin/env php
<?php

Сервер всегда подключаем к localhost, но порт хотим задавать аргументом командной строки:

php// Первый аргумент нам не нужен
array_shift( $argv );

// Следующий аргумент должен быть портом; если его нет — используем 80
if ( empty( $argv ) )
{
	$port = 80;
} else {
	$port = array_shift( $argv );
}

Это позволит позже запускать сервер вот так:

Bash$ sudo php server 8008

В сочетании с ранее определённым получается такой файл:

Объект Server

Далее создаём файл src/Server.php, который работает с сокетом:

php<?php namespace ClanCats\Station\PHPServer;

class Server 
{
}

Наш класс сервера должен хранить host, port и ресурс сокета; добавьте эти переменные класса:

phpprotected $host = null;
protected $port = null;
protected $socket = null;

Создание сокета

Нам нужен он, чтобы сделать bind сокета; создадим функцию createSocket:

phpprotected function createSocket()
{
	$this->socket = socket_create( AF_INET, SOCK_STREAM, 0 );
}
  • Первый аргумент задаёт семейство протоколов/домен; AF_INET — для протоколов IPv4, TCP и UDP.
  • Второй аргумент определяет тип соединения сокета; SOCK_STREAM — простой байтовый поток на основе соединения, полнодуплексный (full-duplex).
  • Третий аргумент задаёт протокол.

Bind сокета

Функция socket_bind возвращает false при ошибке. Такого никогда не должно происходить, поэтому бросаем исключение с сообщением об ошибке сокета:

phpprotected function bind()
{
	if ( !socket_bind( $this->socket, $this->host, $this->port ) )
	{
		throw new Exception( 'Could not bind: '.$this->host.':'.$this->port.' - '.socket_strerror( socket_last_error() ) );
	}
}

Создание и bind сокета в конструкторе

Для простоты делаем это внутри конструктора:

phppublic function __construct( $host, $port )
{
	$this->host = $host;
	$this->port = (int) $port;
	
	// Создание сокета
	$this->createSocket();
	
	// Bind сокета
	$this->bind();
}

Прослушивание соединений

Функция listen — главный бесконечный цикл сервера:

phppublic function listen( $callback )
{
	// Проверяем, что callback корректен; если нет — бросаем исключение
	if ( !is_callable( $callback ) )
	{
		throw new Exception('The given argument should be callable.');
	}
	
	// Именно это делает процесс долгим, бесконечным и бескрайним..
	while ( 1 ) 
	{
		// Прослушивание соединений
		socket_listen( $this->socket );
		
		// Пытаемся получить ресурс сокета клиента
		// Если false — у нас ошибка; закрываем соединение и идём дальше
		if ( !$client = socket_accept( $this->socket ) ) 
		{
			socket_close( $client ); continue;
		}
		
		// Создаём новый экземпляр Request с заголовком клиента
		// В реальном мире нельзя фиксировать максимальный размер на 1024..
		$request = Request::withHeaderString( socket_read( $client, 1024 ) );
		
		// Выполняем callback
		$response = call_user_func( $callback, $request );
		
		// Проверяем, что действительно получили объект Response
		// Если нет — возвращаем объект Response с ошибкой 404
		if ( !$response || !$response instanceof Response )
		{
			$response = Response::error( 404 );
		}
		
		// Собираем из нашего ответа строку
		$response = (string) $response;
		
		// Пишем ответ в сокет клиента
		socket_write( $client, $response, strlen( $response ) );
		
		// Закрываем соединение, чтобы принимать новые
		socket_close( $client );
	}
}

Объект Request

Файл src/Request.php управляет входными данными. Request должен хранить method, uri, parameters и headers:

php<?php namespace ClanCats\Station\PHPServer;

class Request 
{
	protected $method = null;
	protected $uri = null;
	protected $parameters = [];
	protected $headers = [];
}

Разбор заголовка

HTTP-заголовок выглядит так:

HTTPGET / HTTP/1.1
Host: 127.0.0.1:8008
Connection: keep-alive
Accept: text/html
User-Agent: Chrome/41.0.2272.104
Accept-Encoding: gzip, deflate, sdch
Accept-Language: en-US,en;q=0.8,de;q=0.6

Первая строка показывает метод запроса, uri и протокол, а после неё идут параметры заголовка в виде пар ключ/значение:

phppublic static function withHeaderString( $header )
{
	// Разбиваем строку на строки
	$lines = explode( "\n", $header );
	
	// Извлекаем метод и uri
	list( $method, $uri ) = explode( ' ', array_shift( $lines ) );
	
	$headers = [];
	
	foreach( $lines as $line )
	{
		// Очистка строки
		$line = trim( $line );
		
		if ( strpos( $line, ': ' ) !== false )
		{
			list( $key, $value ) = explode( ': ', $line );
			$headers[$key] = $value;
		}
	}	
	
	// Создание нового объекта запроса
	return new static( $method, $uri, $headers );
}

Конструктор принимает $method, $uri и $headers. Для этого примера хотим также отделить и разобрать параметры запроса:

phppublic function __construct( $method, $uri, $headers = [] ) 
{
	$this->headers = $headers;
	$this->method = strtoupper( $method );
	
	// Разделение uri и строки параметров
	@list( $this->uri, $params ) = explode( '?', $uri );

	// Разбор параметров
	parse_str( $params, $this->parameters );
}

Для доступа к данным запроса создаём несколько getter-ов; getter-ы header и param позволяют задавать значение по умолчанию:

phppublic function method()
{
	return $this->method;
}

public function uri()
{
	return $this->uri;
}

public function header( $key, $default = null )
{
	if ( !isset( $this->headers[$key] ) )
	{
		return $default;
	}
		
	return $this->headers[$key];
}

public function param( $key, $default = null )
{
	if ( !isset( $this->parameters[$key] ) )
	{
		return $default;
	}
		
	return $this->parameters[$key];
}

Конструктор Response

Общие параметры, которые должен реализовывать объект Response, — это состояние status, тело body и остальные заголовки. Тело должно быть обязательным аргументом конструктора, а состояние и остальные заголовки — необязательными. Конструктор также должен задавать значения по умолчанию, такие как Date и Server:

phpprotected $status = 200;
protected $body = '';
protected $headers = [];

public function __construct( $body, $status = null )
{
	if ( !is_null( $status ) )
	{
		$this->status = $status;
	}
	
	$this->body = $body;
	
	// Установка начальных заголовков
	$this->header( 'Date', gmdate( 'D, d M Y H:i:s T' ) );
	$this->header( 'Content-Type', 'text/html; charset=utf-8' );
	$this->header( 'Server', 'PHPServer/1.0.0 (Whateva)' );
}

Установка заголовков

Для добавления новых параметров заголовка создаём setter:

phppublic function header( $key, $value )
{
	$this->headers[ucfirst($key)] = $value;
}

Сборка строки заголовка

Нельзя передать объект Response напрямую в писатель сокета; нужно собрать из наших данных строку:

phppublic function buildHeaderString()
{
	$lines = [];
		
	// Состояние ответа
	$lines[] = "HTTP/1.1 ".$this->status." ".static::$statusCodes[$this->status];
		
	// Добавление заголовков
	foreach( $this->headers as $key => $value )
	{
		$lines[] = $key.": ".$value;
	}
		
	return implode( " \r\n", $lines )."\r\n\r\n";
}

Магия!

Магическим методом __toString возвращаем всю строку, записываемую в открытое соединение:

phppublic function __toString()
{
	return $this->buildHeaderString().$this->body;
}

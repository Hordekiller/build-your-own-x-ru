Пишем шелл на C

О чём это

Урок создаёт собственный шелл на C: parsing, fork/exec, пайпы и перенаправление — командная строка без мозга.

Что вы узнаете

  • Чтение и разбор команд
  • fork и exec
  • Пайпы и редиректы
  • Фоновые задания

Основная идея

Шелл — это цикл: прочитать строку, разбить, fork+exec, дождаться. Урок добавляет пайпы и сигналы, и получается настоящий shell.

Запуск команды — сердце шелла:

Cpid_t pid = fork();
if (pid == 0) {
    execvp(args[0], args); // ребёнок становится программой
} else {
    waitpid(pid, &status, 0);
}

Почему это важно

Поняв связку fork/exec, вы поймёте, почему шеллы такие мощные, и сможете строить свои воркфлоу на любом языке.

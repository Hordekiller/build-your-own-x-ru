О чём это

Wyag — «Write Yourself a Git»: реализация команд git на Python с нуля: init, add, commit, log, branch — git, написанный для понимания.

Что вы узнаете

  • Магистраль системы объектов
  • Индекс и статус
  • Ветки и refs
  • Что реально делает git

Основная идея

Wyag воспроизводит git-команды, чтобы понять их: каждый вызов — сценарий, каждый файл — объект. Урок дарит полную картину.

Запуск команды через словарь:

Pythoncommands = {"init": cmd_init, "add": cmd_add, "commit": cmd_commit}
cmd = sys.argv[1]
commands[cmd](sys.argv[2:])

Почему это важно

Wyag — школьная классика программирования: после него вы сможете объяснять внутренности git кому угодно и отлаживать свои репозитории по-новому.
